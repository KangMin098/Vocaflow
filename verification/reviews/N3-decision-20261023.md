- 도구 제약: 최초 Git 읽기는 dubious ownership으로 거부됐다. 전역 설정 변경 없이 해당 읽기 명령에만 정확한 safe.directory를 지정했다. rg는 설치되지 않아 PowerShell 읽기로 대체했다. Git 커밋·push·통합은 요청대로 수행하지 않았다.
