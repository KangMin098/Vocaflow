[Codex / Claude Code 공통] Vocaflow CSAT 기출분석 전역 기본골격 v4.0 — S0 착수

최상위 기준서: Vocaflow_CSAT_전역_기본골격_최종합의기준_v4.0_20261023.md

목표
수능/모의평가/학력평가 영어의 실존 전체 문항 유형 × 판단 기능 × 증거 매체 × 콘텐츠 준비/검수/공개 상태의 사실 기반 등록부를 완성한다. 기존 코드/DB/콘텐츠를 가급적 재사용하고, 이전 임시 R19/L07을 공인 완전 분류라고 가정하지 않는다. 결과가 확인되면 S1 계약 매핑을 수행할 수 있도록 한다.

수행 범위(원칙적으로 읽기 전용)
1. 현재 워크트리/브랜치/실제 3000 서빙 워크트리, 소스 커밋을 먼저 확인하고 사실과 추정 분리.
2. 실제 문항 분류/기존 A1~A9 역량 코드/원문 및 선택지 데이터 구조/강의/해설/의미/비교 자료/사용권·권한 여부를 읽기 전용 집계.
3. 각 실제 문항 유형을 타입×판단 기능×매체×준비도에 매핑. 미매핑/미확인 상태는 UNKNOWN 또는 DATA_GAP으로 표시, 숫자 임의 채우기 금지.
4. 유형별 정상 사례·경계 사례를 확보된 실제 문항 중 선정(없으면 결손 보고). 2026-34·22·38을 기준 회귀 사례로 보존.
5. 강의 37 cue는 원본/차례/역할/대상/분석 revision과 별개 version을 확인. 34 c1/c4/c12, 22 c13, 38 c1/c12의 조건 생략/과잉 일반화는 원문 근거를 들어 수정 후보로만 보고. 원본 덮어쓰기 금지.
6. 읽기/듣기 증거 모델(원문 PDF 로컬 처리, 도표 셀, 평가 원음·전사·화자·시간 구간)과 현재 컴포넌트의 부족분 파악.
7. v4.0 CORE-01~12, AT01~20을 실제 기존 코드에 매핑하여 '이미 가능/신규 구현/자료 부족/검증 미실시' 구분.

필수 산출물
- TYPE_REGISTRY.md 또는 CSV: 실제 유형/판단 기능/증거 매체/표본 문항/근거 경로
- READINESS_MATRIX.md 또는 CSV: 해설·v3·의미·원문·선지·강의·비교별 ready/missing/stale/mismatch/unknown + 검수/공개 독립 상태
- REPRESENTATIVE_EDGE_CASES.md: 유형별 정상·경계 사례와 근거
- GAP_AND_ASSUMPTION_REGISTER.md: 데이터 공백/정확성 미검증/권한·PDF·TTS 미검증
- S1_ADAPTER_PLAN.md: 기존 화면/API/학습지도에 연결할 최소 구현 순서와 AT 테스트 목록

완료/보고
S0 PASS는 '실제 분류에 대한 전수 메타데이터 매핑 또는 미매핑·공백 정직한 보고, 대표/경계 표본 근거 표시, 기존 계약과 충돌 요인 식별'이다. 실제 전체 문항 내용 감수, UI 구현, 실제 학생 효과를 PASS라고 보고하지 않는다. 승인 없이 DB/시드 변경·데이터 삭제·기존 원문·강의 원본을 수정하지 않는다. 권한으로 막힌 항목은 BLOCKED로 근거와 함께 기록하고 읽기 전용 가능한 작업은 계속한다.

진행 방식
불필요한 신규 TASK·브랜치·PR 생성/전면 CI 반복 금지. 필요 최소 검증→간략 문서화→커밋·가능한 push. 현행 중앙 개발 정책, 보안·RLS 및 DB 변경 승인 경계를 준수. 매 단계마다 추가 진행 여부를 묻지 않고 실제 blocker와 결과를 한 번에 보고.
