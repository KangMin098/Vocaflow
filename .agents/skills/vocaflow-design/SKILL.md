# Vocaflow Design — 발명 엔진 + 병합 정본

> **이 스킬은 금지 목록이 아니다.** Part 1(§A–§G)이 전부다 — 제약 절(옛 Part 2 §0–§8)은 DD-65(2026-09-21, 사용자 결정)로 삭제했다.
> 제약만 지킨 화면은 "규정 위반이 없는 평범한 화면"이지 혁신이 아니다.
> 외부 취향 스킬(2026-09-04 기준 13개 설치 · 2026-09-18 부터 활성 2개)은 *생성 장치*(Design Read · Variation Engine · 개념법)를 갖고 있는데,
> 그 장치들은 전부 **시각 변주**를 만든다. 이 제품에서 **스타일은 차별점이 아니다. 자산의 형태는 차별점이다** —
> 그래서 Part 1 은 같은 자리에 **학습 메커니즘 변주 엔진**(§A–§F)과 **형태 발명 엔진**(§G)을 놓는다.
> **목표는 혁신뿐이고, 평균은 어떤 화면에서도 허용하지 않는다**(2026-09-18 사용자 지시) — §G5 가 그것을 테스트로 강제한다.
> (2026-09-18 추가) 메커니즘만 발명하면 형태는 기본값(카드·표·3열)으로 떨어진다 — 그 빈 칸을 **§G 형태 발명**이 채운다.
> 복제되는 것은 *스타일*이고, **N1 자산의 형태**(R(t) 곡선 · 채색 지문 · 주묵 선)는 자산 없이 못 그린다.
> 정본 수치는 전부 저장소·DB 에서 읽은 실측값이다(출처를 각 줄에 적었다).

# Part 1 — 발명 (목표)

## §A. 혁신 판정 4문 — 통과 못 하면 그건 장식이다

새 화면·기능·프로세스를 제안할 때 **코드보다 먼저** 세 줄로 답한다.
(`design-taste-frontend` §0.B 의 "Design Read" 를 학습 제품용으로 바꾼 것이다.)

| # | 질문 | 통과 기준 | 불합격 예 |
|---|---|---|---|
| **N1** | **자산 의존** — 우리만 가진 실측 자산 없이는 성립 불가한가 | `shared_dictionary` 48,969 · `library_books` 401 · R(t) 동적 계산(`lib/srs/fsrs.ts`) · 커버리지 계산(`lib/textfit/coverage.ts`) · 4축 V-Level · CSAT 코퍼스 중 **최소 1개**에 의존 | 폰트·여백·그라디언트만 바뀐 안 — 경쟁사가 하루면 베낀다 |
| **N2** | **즉시 증명** — 200ms 안에 화면에서 눈으로 확인되는가 | 방문자가 값을 바꾸면 결과가 바뀐다(AGENTS.md I3) | "AI 가 분석해 드립니다"라고 쓰고 결과는 로그인 뒤에 두는 것 |
| **N3** | **학습과학 개선** — 7원칙 중 **어느 것**을 더 잘 하는가 | 원칙 번호를 하나 대고 이전보다 나아지는 이유를 한 줄 | "재미있어서" · "요즘 트렌드라서" |
| **N4** | **형태 판정** — 이 화면의 골격(첫 시선이 닿는 형태)을 N1 자산 없이 그릴 수 있는가 | 없이는 못 그린다(R(t) 곡선·채색 지문·주묵 선·서가 변형 중 하나가 골격) | 자산은 데이터로만 쓰이고 골격은 카드 목록·표·3열 격자인 화면 — N1 통과, N4 불통과 = "자산을 담은 평범한 화면" |

세 줄을 못 쓰겠으면 그 안은 아직 발명이 아니다. **N1 이 가장 자주 탈락한다.**
화면(UI)을 만드는 안이면 **N4 까지 네 줄**이다 — N4 의 답은 §G2 절차로 만든다.

## §B. 발명 엔진 — 5축 조합 (같은 칸을 두 번 만들지 않는다)

외부 스킬(`imagegen-frontend-*` §22 · `image-to-code` §12)의 Combinatorial Variation Engine 은
Theme / Hero Architecture / Motion Language 를 조합해 **시각**을 변주한다.
여기서는 같은 방식으로 **학습 메커니즘**을 조합한다.

| 축 | 값 |
|---|---|
| 1. 인지 계층 | L0 노출 · L1 이해 · L2 맥락 · L3 수집 · L4a 재인 · L4b 시각생성 · L4c 청각생성 · L5 정복 · L6 완성 · L7 회고 |
| 2. 증거 표면 (무엇을 보여줘야 "내 것"이 되는가) | 지문 채색 · 서가 · 회상률 곡선 · 오답 계보 · 시간대 분포 · 커버리지 % · 난이도 사정권 |
| 3. 주체 | 혼자 · 교사→학급 · 또래 · **과거의 나** |
| 4. 시간 | 지금(세션) · 오늘 · 이번 주 · 학기 |
| 5. 자산 | 사전 48,969 · 도서 401 · 챕터 퀴즈 2,453 · CSAT 코퍼스 · 만화 969호 · FSRS 상태 |

**규칙**: 각 축에서 하나씩 뽑는다. 뽑힌 조합이 이미 있는 화면과 같으면 **버리고 다시 뽑는다.**

> 9개 모듈이 거의 전부 `(혼자 · 지금 · 재인)` 근처에 몰려 있다 —
> **그래서 10번째 모듈은 아무리 잘 만들어도 새롭게 느껴지지 않는다.**
> 비어 있는 칸이 발명 지점이다: 「과거의 나 × 학기 × 회상률 곡선」,
> 「교사→학급 × 이번 주 × 커버리지」, 「또래 × 오늘 × 난이도 사정권」.

## §C. 디자인 발명 렌즈 6 — 일반 랜딩 취향으로는 나오지 않는 것

화면을 새로 만들 때 이 여섯을 순서대로 대 본다. 하나라도 걸리면 그쪽이 대개 더 좋은 안이다.

1. **망각을 보여준다** — `R(t) = exp(ln(0.9)·t/S)` 는 연속 함수인데 UI 는 스냅샷(4색)만 보여준다.
   시간을 축으로 꺼내면 "지금 안 하면 목요일에 이만큼 잃는다"가 **눈에 보인다.** 경쟁사엔 이 곡선이 없다.
2. **지문이 곧 인터페이스** — 컨트롤을 지문 바깥 툴바에 두지 않는다.
   아는 단어/모르는 단어가 칠해진 지문 자체가 조작면이다.
3. **성장은 환경으로** (철학 4 Implicit Progress) — 게이지를 그리고 싶어질 때마다
   "대신 무엇이 **변형**되는가"를 답한다. 서가가 차오르고, 색이 risk→stable 로 옮겨가고, 배경 톤이 달라진다.
4. **빈 상태가 최고의 전시장** — 기록이 아직 없을 때가 **실측 데이터로 남의 결과를 보여줄 유일한 기회**다
   (`lib/marketing/hero-demo.ts` 가 그 예). 빈 화면에 "데이터가 없습니다"를 쓰는 것은 발명의 포기다.
5. **실패의 계보** — 오답을 낱개로 세지 않는다. 어떤 단어가 어떤 오답을 낳고 그게 어느 문항에서 다시
   나오는지 **사슬**로 보여준다. `library_chapter_quiz` 2,453 과 FSRS 상태를 동시에 가진 곳만 할 수 있다.
6. **교사의 3분** — 허용 CAC 가입당 ₩400 이라 광고 경로가 성립하지 않고 **교사→학급 경로만 남는다**
   (`docs/PLATFORM_AUDIT.md`). 그러므로 모든 공개 표면은 *"교사가 3분 안에 학급에 던질 수 있는가"* 를
   통과해야 한다. 통과 못 하면 예뻐도 성장에 기여하지 않는다.

## §D. 기능 혁신 — 공급이 아니라 수요 쪽에서 찾는다

이 저장소의 실패 모드는 **공급 비대 · 수요 0** 이다 (공급:수요 **3,480:1**, 가입자 3).
새 기능을 제안할 때 **한 줄로 먼저 답한다**: *"이건 공급을 늘리는가, 수요를 늘리는가."*

- **공급 증가**(새 소스 · 새 코퍼스 · 새 콘텐츠 유형)면 **순위를 내린다.** 이미 충분하다.
- **수요 증가**(교사 유입 · 재방문 · 완료율 · 공유)면 올린다.
- **새 테이블을 만들기 전에 기존 자산의 새 결합을 먼저 시도한다.** 대부분의 발명은 **조인 하나**에서 나온다.
  예: `CSAT 코퍼스 × 개인 V-Level` = "이 지문이 네 수능에서 몇 등급 자리인가".

## §E. 프로세스 혁신 — 드레인이 이 저장소의 진짜 발명이다

Claude Code 3단 드레인(export → 내가 채움 → import)이 ScriptQuiz **1,292문항** · 사전 **466낱말** ·
PDCP **969호**를 만들었다. 새 작업을 설계할 때 먼저 묻는다:
**"이걸 드레인으로 돌릴 수 있게 export/import 를 먼저 만들 수 있나?"**

- **재실행 안전**(이미 채운 건 건너뛴다) · **빈 값 import 금지** — 둘 중 하나만 빠져도 구멍이 영영 남는다.
- **계측을 같은 커밋에** — 새 공개 표면은 진입 + 내부 상호작용 이벤트를 함께 넣는다(AGENTS.md D2).
  **안 재면 혁신인지 아닌지 영원히 모른다.**
- Admin 화면도움말도 같은 커밋에 — 프로세스가 바뀌었는데 도움말이 낡으면 잘못된 조작을 부른다.

## §F. 혁신처럼 보이지만 아닌 것

| 장식 | 왜 아닌가 |
|---|---|
| 자산과 무관한 새 미감·새 폰트·새 그라디언트 | N1 불통과. 하루면 복제된다. (자산의 형태를 골격으로 세우는 것은 §G — 장식이 아니다) |
| 새 애니메이션 · 3D 배경 | Calm UI 위반이고 LCP 를 깎는다 (AGENTS.md 모션 예산) |
| 10번째 학습 모듈 | §B 축에서 기존과 같은 칸이면 모듈 수만 늘어난다 |
| 새 콘텐츠 소스 추가 | 공급 측. 3,480:1 을 더 벌린다 |
| "AI 로 ~해 드립니다" 카피 | N2 불통과 — 증명이 로그인 뒤에 있으면 없는 것과 같다 |
| 외부 스킬의 Awwwards 연출 이식 | 청중이 다르다. 교사·수험생은 수상작을 보러 오지 않는다 |

## §G. 형태 발명 — 자산이 골격이 된다 (시각 변주 엔진의 자리)

외부 스킬의 Variation Engine 은 Theme/Hero/Motion 을 조합해 스타일을 변주한다. 이 제품에서 그 자리는 비어 있었고,
빈 자리는 기본값(카드·표·3열)으로 채워졌다. 여기서는 스타일이 아니라 **자산의 형태**를 변주한다.
씨앗 인벤토리(경로·쓰이는 화면·골격 여부): [docs/design/00-form-seeds.md](../../../docs/design/00-form-seeds.md) —
2026-09-18 실측 씨앗 10개 중 화면의 골격인 것은 3개뿐이었다.

### G1. 형태 축 — 우리만 그릴 수 있는 것

| 축 | 자산 | 형태 | 이미 있는 곳 |
|---|---|---|---|
| 망각 | R(t) 동적 계산 | 시간축 위 감쇠 곡선, 4색 구간 · 밑줄 두께 | 렌즈1 · `lib/srs/fsrs.ts` · `components/layout/MemorySparkline.tsx` · `DecayUnderline`(`components/ui/press`) |
| 채색 지문 | 커버리지 계산 | 지문 자체가 조작면, 아는/모르는 단어의 면 | 렌즈2 · `lib/textfit/coverage.ts` · `components/marketing/CoverageHero.tsx` |
| 주묵 문법 | CSAT 분석 자료 | 실선+화살표=지지, 점선+막대=배제, ○•✓↻ 기록 지도, 막대 길이=문장 길이 | DESIGN_SYSTEM §✒ 형태 문법 · `components/csat/session/visual-analysis.module.css` |
| 환경 변형 | FSRS 상태·서가 | 서가가 차오르고 배경 톤이 옮겨간다(Implicit Progress) | 렌즈3 · `components/dashboard/DurabilityLadder.tsx`(부분) |
| 계보 | 챕터 퀴즈×FSRS | 오답이 다음 문항으로 이어지는 사슬 | 렌즈5 · (코드 0) |
| 시험지 사물 | CSAT 코퍼스 | 2단 격자·문항 번호·출제자 펜·정오표·바를 정 회독 | (신규) · 가장 가까운 것 `components/csat/session/learning-home.module.css` |

### G2. 절차 — 코드 전에 세 줄

1. **골격 선언**: 이 화면의 첫 시선 형태는 G1 중 무엇인가. 하나만. (카드·표·격자는 골격이 될 수 없다 — 그것들은 정보를 담는 그릇이지 형태가 아니다)
2. **서명 선언**: 그 골격에서 기억에 남을 요소 하나(예: 대조 순간 주묵 실선이 그려지는 200ms). 화면당 하나.
3. **N4 답**: 이 골격을 자산 없이 그릴 수 있는가 — "없다"가 답이어야 진행.

### G3. 큰 재설계의 발산

새 화면·전면 재설계는 G1 축이 서로 다른 4안을 먼저 만든다(최고 성능 모델·고노력 — 싼 모델은 이름만 넷인 한 안을 돌려준다).
각 안: 이름 · 골격(G1 축) · 서명 · 토큰명으로 적은 색 4~6 · 타입 역할 3 · 모션 1곳(요소·트리거·ms) · "다른 셋과 무엇이 다른가".
자기검토: 로고를 가리고 (a) 앱 종류 (b) 이 제품인지 알 수 있는가. (b) 불가면 탈락. [own-portfolio.md](../../../docs/design/own-portfolio.md) 와 쌍둥이면 표시.
산출물은 `compare.md` 한 장(4안 표 + 자기검토 결과). 고르는 것은 사람. 고른 안을 2회 수정해 골든 스크린(스크린샷 3장, [docs/design/golden/](../../../docs/design/golden/README.md))으로 고정한다. 이후 화면은 골든을 닮게 만든다.

### G5. 평균 금지 — 권고가 아니라 실패하는 테스트

권고는 기본값에 진다. 그래서 아래 둘은 **CI 에서 떨어진다**(`pnpm turbo run test`):

| 장치 | 막는 것 | 파일 |
