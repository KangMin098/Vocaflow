이 이슈는 **Vocaflow AI-Control 목표 접수함**입니다. 사용자가 ChatGPT(Work)에 자연어로 제품 목표를 말하면, ChatGPT 가 이 이슈에 **댓글 하나**로 아래 블록을 남깁니다. AI-Control 브리지가 몇 분 안에 가져갑니다.

## ChatGPT 가 할 일

1. 사용자의 요청 원문을 그대로 `request` 에 넣는다. 요약하거나 범위를 줄이지 않는다.
2. 아래 표에서 가장 가까운 정본 L3 목표 id 를 하나 이상 `canon_goal_ids` 에 넣는다. 확신이 없으면 비운다(AI-Control 이 기존 목표와 맞춰 보고, 없으면 보류한다).
3. 지금 대화의 URL 을 `chat_url` 에 넣는다(`https://chatgpt.com/…`). 이 대화가 그 목표의 대표 Work 대화가 된다.
4. 이미 진행 중인 목표라면 `goal_ref` 에 그 id(예: `UG-c8315ad8-0002`)를 넣는다.
5. 댓글에는 블록을 **정확히 하나**만 넣는다. 다른 파일·저장소·이슈는 건드리지 않는다.

```json vfc-goal-request
{
  "schema": "vfc-goal-request/1",
  "request": "사용자가 말한 목표 원문",
  "title": "짧은 제목(선택)",
  "canon_goal_ids": ["VG-L3-…"],
  "goal_ref": null,
  "chat_url": "https://chatgpt.com/c/…",
  "owner_hint": null
}
```

## AI-Control 이 하는 일

- `goal_ref` · 같은 `chat_url` · 비슷한 제목의 기존 목표가 있으면 **그 목표를 재사용**한다. 요청은 그 목표의 사용자 방향(next_scope)에 더한다.
- 기존 목표가 없고 정본 목표가 있으면 **새 목표**를 만든다. 첫 설계는 이 저장소의 PR 로 Work 에 다시 요청한다.
- 정본 목표가 없으면 새 목표를 만들지 않는다(`needs_canon`).
- 이 요청은 **승인이 아니다.** 설계 승인 · owner 배정 · DB 변경은 사용자의 대화형 승인을 따로 거친다.
