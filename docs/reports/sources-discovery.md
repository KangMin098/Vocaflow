## 1. 방법 — 두 관문 + 같은 자

### 1-1. 세 가지를 따로 잰다

`scripts/textbook/graded-source-probe.mjs` 가 세운 규율을 그대로 잇는다:

> **robots.txt 는 라이선스가 아니다.**
> (Breaking News English 는 robots 가 전면 허용인데 저작권 고지는 판매·부분복사·LMS 게재를 전부 금지했다.)

| 관문 | 무엇을 보나 | 실패하면 |
|---|---|---|
| ① robots | `User-agent: *` 의 Disallow · **AI 이용 거부 선언**(`ai-train=no` · GPTBot/CCBot/ClaudeBot 차단) | **측정도 하지 않는다** — 뜻이 분명한 신호를 넓게 읽지 않는다 |
| ② 라이선스 고지 | 문서에 실제로 박힌 라이선스 문자열(추정하지 않는다) | 고지를 못 읽었으면 후보가 아니다 |
| ③ 대량 취득 경로 | API·덤프·피드·사이트맵의 HTTP 상태와 목록 가능 편수 | 경로가 없으면 규모를 말할 수 없다 |

셋을 다 통과한 후보만 본문을 표본한다.

### 1-2. 표본은 **기존 원천과 같은 자**로 잰다

후보 청크의 **모양이 `source-scorecard-export.mts` 의 산출과 같다.** 그래서 같은 검증기
(`source-scorecard-verify.mts` — sha256·건수·스키마 대조)와 같은 채점 산식이 그대로 돈다.
CEFR 은 기존 원천과 동일한 3중 합의(어휘 0.5 + 가독성 0.3 + LLM 0.2)이고, 기준선도 같다
(기출 802편 · DD-57 정정).

**검증 결과: 6개 청크 중 5 통과 · 1 실패**(`nsf` — 목록에서 기사 1편만 나와 판정 자체를 하지 않았다).

### 1-3. ⚠️ 이 측정의 한계 — F2 는 후보가 아니라 **내 추출기**를 잰 값이다

표본 5곳의 **결함 없음 비율이 0 · 0 · 0 · 0 · 8%** 다. 이것이 후보 5곳이 똑같이 나쁘다는 뜻일 수 없다.
원인은 하나다 — 이 프로브는 **범용 `<p>` 수집기**를 쓰는데, 기존 21곳은 각자 **전용 어댑터**를 갖고
사이트 크롬을 이미 떼어 낸다. 판정 에이전트 5곳이 독립적으로 같은 말을 했다:

| 후보 | 크롬의 정체 | 고칠 수 있나 |
|---|---|---|
| `global_voices` | 33/34 편이 **동일한 1,429자 CSS 블록 + 기부 배너**로 시작 | 결정론적 · 1회성 |
| `standard_ebooks` | **13/13 편이 책 본문이 아니라 상세 페이지 소개문** — 다운로드 형식 목록·기부 안내 | 취득 경로를 본문 URL 로 바꿔야 한다 |
| `medlineplus` | `.gov` 보안 배너 + 면책 문구가 **50/50** · 추출기가 `<ul>/<ol>` 를 통째로 버려 문장이 콜론에서 끊긴다 | 결정론적 |
| `nps` | `.gov` 헤더/경보 + 앱 안내가 **50/50** | 결정론적 |
| `wikinews` | 꼬리의 `Sources`/`Related news` 블록이 **사실상 전편** | 결정론적(고정 제목) |

**그래서 후보의 F2 를 기존 원천의 F2 와 직접 비교하면 안 된다.** 아래 표에서 후보 순위는
**F1(난이도)·F3(소재)** 으로 읽고, F2 는 「전용 어댑터를 만들면 얼마를 회수할 수 있는가」의
하한으로만 읽는다. 이 한계를 적지 않으면 다음 사람이 「후보가 전부 더럽다」로 읽는다.

## 3. 취득 불가 — 사유별

### 3-1. AI 이용 거부 선언 (5곳) — **측정도 하지 않았다**

`nature_comms` · `aeon` · `undark` · `knowable` · `openstax`(사이트).
robots 가 `ai-train=no` 또는 GPTBot/CCBot/ClaudeBot/Google-Extended 를 차단한다.
크롤은 허용돼 있을 수 있지만 뜻이 분명한 신호이고, **「허용 범위」를 넓게 읽는 것은 우리가 할 일이 아니다.**

> ⚠️ 한 가지 단서. `nature_comms`·`bmc` 의 실제 취득 경로는 **Europe PMC API**(이미 배선된 경로)이지
> 발행사 사이트가 아니다. 발행사 robots 는 그 경로의 관문이 아니다. 그래서 이 둘은
> 「AI 거부로 불가」가 아니라 **「경로를 Europe PMC 로 잡으면 라이선스 문제만 남는다」**가 정확하다.
> `openstax` 도 같다 — 본문은 `github.com/openstax/osbooks-*` 에 있고 openstax.org robots 와 무관하다.
> **표에는 실측한 대로 적되 이 단서를 함께 남긴다.**

### 3-2. 라이선스가 막거나 확정되지 않음 (4곳)

| 후보 | 실측 | 판정 |
|---|---|---|

## 4. 표본을 뜬 5곳 — 실측과 판정

### 4-1. `wikinews` — 소계 38.1 · **조건부**

| | |
|---|---|
| 라이선스 | **CC-BY 4.0**(2024-12-16 이후) · CC-BY 2.5(2005~2024) · PD(2005 이전) — 전부 L0~L1 |
| 취득 | MediaWiki API (`categorymembers` + `extracts`) — **이미 쓰고 있는 어댑터와 같은 모양** |
| 규모 | **22,237편**(siteinfo 실측) |
| 3중 합의 | **B2 52 · B1 48** · 기출거리 **16.3**(후보 1위 · 기존 원천 중에서도 Gutenberg 12.1 다음) · 밴드내 100% |
| register | news 80 · reference 20 — **expository·argumentative·narrative 0** |
| 소재 | 사회·경제 40 · 분류불가 34 · 예술·문화 10 · 과학·자연 10 |
| 구조 | 자족 60% · 산문 80% · 유형폭 6 · 어수 중앙 297 |
| 결함 | `citation-apparatus` 42% · `boilerplate` 20% · `non-prose` 20% |

**가장 중요한 실측은 점수가 아니라 구성이다.** 표본 50편 중 **17편(34%)이 스포츠**(크리켓 점수표·
유도 메달표·빈 NCAA 대진표)이고, NPOV + 역피라미드 구조라 **R-CLAIM 0 · R-INSERT 0 · R-MOOD 0 · R-ORDER 1**.
문항을 실을 수 있는 것은 **50편 중 9편(18%)** 이다.

> **이 원천은 이미 `SOURCE_SPECS` 에 있는데 `library_articles` 에 0행이다.** 배선만 하면 되는 줄 알았던
> 자리인데, 실측은 「배선하면 22,237편이 들어오지만 그중 6분의 1만 쓴다」고 말한다.
> **조건부**: 수집 단계에서 스포츠·결과 카테고리 제외 + 어수 ≥250 + 문단 ≥4 + 꼬리 `Sources` 블록 제거.
> 그러면 50편당 15~20편이 남고 대부분 사회·경제 B2 다.
> ⚠️ 표본에 혐오 표현 인용 1건이 있었다 — 학습자 화면 전에 내용 판정이 필요하다.

- **고칠 수 있는 것** — 34편 중 33편이 동일한 CSS + 기부 배너로 시작한다. 1회성 결정론 수정이다.
  `support-global-voices-*` 슬러그 2편은 기사가 아니라 모금 페이지이므로 슬러그 차단이 필요하다.
- **고칠 수 없는 것** — **44%(15/34)가 지역 정치 맥락을 전제**한다(정당 약어·인명이 리드에 설명 없이 나온다).
  그리고 **B2 바닥이라 그 아래 밴드를 못 채운다**.

또 하나: 예술·문화 11.8% 중 깨끗한 것은 2편뿐이라 **예술·문화 구멍은 사실상 안 메워진다.**
사회·경제 공급원으로 한정해 붙이는 것이 정확하다.

### 4-3. `standard_ebooks` — 소계 31.0 · **재측정 필요(이 수치는 쓸 수 없다)**

라이선스는 후보 중 가장 깨끗하다 — 본문 PD + Standard Ebooks 자체 작업은 **CC0**, bulk 다운로드와
Atom·OPDS 피드가 있다(**L0**). 그런데 **표본 13편 전부가 책 본문이 아니라 상세 페이지 소개문**이었다.
`prose` 0/13 · 결함 100% boilerplate · CEFR B2 100%.

> **이 수치는 Standard Ebooks 를 잰 것이 아니라 내 수집기를 잰 것이다.** 목록 엔드포인트가
> 상세 페이지 URL 을 주는데 본문 URL 로 바꾸지 않았다. 판정 에이전트가 먼저 그렇게 보고했고,
> 나도 같은 결론이다. **소계 31.0 을 이 원천의 점수로 읽으면 안 된다.**
> 본문 수집기로 다시 재야 하고, 그때는 19세기 문학 산문이므로 **C1~C2** 가 나올 가능성이 높다
> (Gutenberg 표본이 그랬다). 즉 narrative 구멍은 메우되 밴드는 올라간다.

### 4-4. `medlineplus` — 소계 27.6 · **반려**

PD(미 연방정부)이고 25,534 loc 의 사이트맵이 열려 있어 취득은 가장 쉽다. 그런데 **성질이 맞지 않는다.**

- register **reference 66 · expository 34** — 정의→증상→진단→치료 슬롯을 채운 **조회 항목**이지 설명문이 아니다.
- 유형폭 **3** · `csatTypes` 빈 배열 **37/50(74%)** — **R-CLAIM·R-BLANK·R-ORDER·R-INSERT·R-SUMMARY 가 한 건도 없다.**
- 소재 과학·자연 90% → 부족칸 **10%** (이미 과잉인 칸을 더 채운다)
- 자족 40% · 산문 64%

**반려 근거는 라이선스도 규모도 아니라 「논지가 없다」다.** CEFR 은 B1/B2 반반으로 좋지만
빈칸·순서·삽입을 실을 글이 구조적으로 없다. 살릴 만한 것은 비임상 슬라이스
(대기오염·농약·허리케인·만성질환 대처 등) 약 **8/50 = 16%** 인데, 적재 파이프라인 + 크롬 제거기를
새로 만들 값이 안 된다.

### 4-5. `nps` — 소계 26.5 · **반려(이전 정찰의 낙관 수정)**

이전 정찰(2026-09-07)은 「채택 · 19,634 URL · 표본 채택률 2/4」로 적었다. **표본을 4편에서 50편으로 늘리니 낙관이 깨진다.**

- 산문 **36%** · 자족 34% · 문항 적재 가능 **34%**
- 실패가 두 종류로 뭉쳐 있다: (a) 본문이 전혀 추출되지 않는 페이지 5편,
  (b) **동일 템플릿의 전시 안내판 설명 11편 연속**(패널에 적힌 것을 묘사한 글) — 11편이 아니라 사실상 1종이다.
- 소재 **역사·인류 42 · 분류불가 28 · 과학·자연 26 · 예술·문화 4** → 부족칸 **4.0%**.
  **사회·경제·심리·인지·교육·언어·기술·매체·철학·윤리가 0** 이다 — 수능이 가장 많이 기대는 칸이 통째로 없다.
- 라이선스 신호가 **PD-Government 와 ARR 이 함께** 잡힌다(제3자 권리 고지). 편당 확인이 필요하다.

강한 지문은 50편당 약 1편이다. **크롤 단위당 수율이 낮다.**

## 5. 그래서 무엇이 나왔나 — 발굴의 결론

### 5-1. 새 원천은 기존 상위 원천을 못 이긴다

F1+F2+F3 (60점) 을 나란히 놓으면:

| | 원천 | F1 | F2 | F3 | 소계 |
|---|---|---:|---:|---:|---:|
| 기존 | `original` | 14.0 | 19.4 | 14.2 | **47.6** |
| 기존 | `wikipedia` | 15.2 | 18.8 | 12.7 | **46.7** |
| 기존 | `gutenberg` | 18.1 | 16.5 | 10.8 | **45.4** |
| 기존 | `frym` | 15.6 | 19.2 | 10.2 | **45.0** |
| **신규** | `wikinews` | 17.7 | 8.4† | 11.9 | **38.1** |
| **신규** | `global_voices` | 13.0 | 9.4† | 14.8 | **37.1** |

† 범용 추출기로 잰 값이므로 전용 어댑터를 만들면 오른다(§1-3). F2 를 기존 평균 17 로 가정해도
`wikinews` 47.2 · `global_voices` 45.2 로 **간신히 기존 상위권과 같아진다.**

### 5-2. 두 후보는 「새 원천」이 아니라 **이미 우리 것인데 안 쓰고 있는 것**이다

| 후보 | 상태 |
|---|---|
| `wikinews` | `SOURCE_SPECS` 에 등재돼 있다(CC-BY-2.5 · B1-B2 · news). **`library_articles` 0행.** 어댑터는 `_mediawiki.ts` 가 이미 있다 |
| `worldbank_okr` | `source-key.ts` 의 `GovernedSource` 이고 `scripts/csat/harvest-worldbank.mjs` 가 있다. **`library_articles` 0행.** OAI `completeListSize` **40,415** 실측 |

**온보딩 비용이 가장 낮은 두 곳이 발굴 결과가 아니라 재고 점검 결과다.**

### 5-3. 부족칸을 실제로 메우는 후보는 하나뿐이다

부족칸(심리·인지·사회·경제·예술·문화·기술·매체·교육·언어) 기여율:

```
global_voices 79.4%  │ 사회·경제 58.8 — 다만 시위·선거·언론자유 한 갈래에 몰려 있다
wikinews      56.0%  │ 사회·경제 40 · 분류불가 34
standard_ebooks 53.9% │ 예술·문화 38.5 — 단 §4-3 의 재측정 전제
medlineplus   10.0%  │ 과학·자연 90 — 이미 과잉인 칸
nps            4.0%  │ 역사·인류 42 — 이미 과잉인 칸
```

**심리·인지는 후보 25곳 어디에서도 안 나온다.** 표본 5곳 합계에서 심리·인지는 `wikinews` 2% ·
`medlineplus` 2% 뿐이다. 이 칸의 가장 큰 잠재 공급선은 **`noba`(CC BY-NC-SA → L3 · robots 전면 차단)** 와
**`openstax` Psychology(CC-BY-NC-SA → L3)** 인데 **둘 다 NC 다.**
즉 **심리·인지 구멍은 발굴로 풀리지 않고 정책 결정(L3 채택 여부)으로만 풀린다** — Gate 3 질문 (ii).

## 6. 재현 방법

```bash
# ① 두 관문 + 목록 가능 편수 (읽기 전용 · UA 명시 · 요청 간 대기)

  --out .agent-logs/source-candidates --per-source 50

  --json .agent-logs/source-candidates/candidates-verified.json
```
