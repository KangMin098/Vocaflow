# 학습자 표면 전수 감사 루브릭 (v1)

저장소: `D:\workspace\Vocaflow` · 앱: `apps/web`

## 원칙

- **읽고 확인한 것만 적는다.** 파일을 열어 줄 번호를 확인하지 않은 지적은 쓰지 않는다.
- **추측 금지.** "…일 수 있다" 는 결함이 아니다. 재현 조건(어떤 입력·상태에서 무엇이 보이는가)을 적는다.
- **파일을 수정하지 않는다.** 이 단계는 감사만이다.
- 중복 지적 금지 — 같은 원인이 여러 화면에 나타나면 한 항목으로 묶고 영향 화면을 나열한다.

## 프로젝트 규칙 (위반은 결함)

- 색: `--p` 축약형만. v5 롱폼(`--color-primary`) 금지
- 폰트: 한글에 Lora 금지 · 영어에 산세리프 금지 · Inter/Roboto/Arial 금지
- `memory_state` / `mastery_progress` / `last_days` / `next_days` 컬럼 사용 금지 (R(t) 동적 계산)
- 모든 인터랙티브 요소에 hover + active + focus + disabled 4상태
- `data-theme="dark"` 대응
- 파일 첫 줄에 경로 주석
- 모션: 총 1초 초과 금지 · `transform`/`opacity` 만 · 학습 중 모션 화이트리스트 7종 외 금지 · 폭죽/트로피/콘페티/루프 애니메이션 금지
- `prefers-reduced-motion` 은 끄기가 아니라 낮추기 — 페이드는 남긴다
- 한글 텍스트에 `break-keep`

## 산출물

지정된 경로에 마크다운 한 편. 형식:

```
# <슬라이스 이름> 감사

## 요약
- 검사한 화면: N개 (목록)
- 결함: blocker X · major Y · minor Z

## 결함 목록

### [B1] <한 줄 제목>   (blocker|major|minor · 축 A2)
- 위치: `apps/web/src/...:120-134`
- 증상: 학습자가 무엇을 겪는가 (재현 조건 포함)
- 근거: 코드가 무엇을 하는지 (인용 2~5줄)
- 고칠 방향: 구체적으로. 파일과 무엇을 바꿀지
- 영향 화면: /a, /b
```

심각도 기준:
- **blocker** — 학습자가 진행 못 하거나(막다른 길·되돌아갈 수 없음), 데이터가 유실되거나, 화면이 깨진다
- **major** — 되긴 하는데 헛수고·혼란·낭비가 명확하다(불필요한 단계·중복 요청·빈 상태 안내 없음)
- **minor** — 다듬기(문구·간격·미세한 접근성)

없으면 "결함 없음" 이라고 쓴다 — 억지로 채우지 않는다.
