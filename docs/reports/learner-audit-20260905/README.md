  ([CONVENTIONS.md](../../CONVENTIONS.md) — 「문서를 근거로 결론내지 말 것」).
- 해소된 항목의 경위는 [CHANGELOG.md](../../CHANGELOG.md) 의
  「학습자 표면 전수 감사」 절에 있다.

  다음 감사가 같은 자리를 다시 파지 않도록 남겨 뒀다.
