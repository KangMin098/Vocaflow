### 슬라이스 총평 — 세 구역의 품질이 다르다

| 구역 | 상태 |
|---|---|
| **받아쓰기 4단** | 가장 성숙하다. 4단이 아니라 실은 **2경로**다(오늘의 받아쓰기는 hub→session 직행, 설정은 실제 결정 8개를 받는다). 단계를 더 줄일 자리는 없다. 남은 결함은 힌트 3단(M4)·완주 경합(M5)·네트워크 실패(B4) 셋이다 |
| **지문 뷰어(`/text/[id]`)** | **가장 나쁘다.** 목업 텍스트·목업 통계·저장 안 되는 북마크가 실화면에 그대로 살아 있다(B1·B2·M11) |
| **EchoMatch** | 실패 경로가 전부 뭉개져 있다 — 마이크 거부·재생 오류·비교 오류가 모두 "음성 모델 로드 실패" 한 문장으로 나온다(M6·M7). 마이크는 끝까지 안 꺼진다(M8) |

### 질문별 답

1. **받아쓰기 4단 프로세스** — 각 단계가 결정을 받는다. `/dictate/setup` 은 묶음·문항수·순서·채점·속도·반복·힌트 7축을 받고 미리보기가 **실제 조립 규칙과 같은 계산**으로 문항 수를 낸다(`DictationSetupClient.tsx:138-167`). 지나가는 화면이 아니다. **단계는 줄일 수 없다** — 오늘의 받아쓰기는 이미 설정을 건너뛴다. 중간 이탈 복구는 **작동한다**: 문항마다 `dictation_attempts` 를 즉시 적재하고(`useDictationSession.ts:287`), 재진입은 localStorage → DB 복원 2단(`useDictationSession.ts:186-220`), 허브 이어하기도 로컬·DB 둘 다 본다(`DictationHubClient.tsx:105-106`). 코드로 확인했다.
2. **쿼리 파라미터 의존** — **잃는 것은 없다.** `/dictate/setup` 은 좌표가 없으면 `router.replace('/dictate')` 하면서 "이동하고 있어요 + 손으로 갈 링크" 를 함께 준다(`DictationSetupClient.tsx:203-218`) — 모범 사례다. `/dictate/results` 만 같은 처리를 안 했다(m6).
3. **뒤로가기** — 지문 뷰어 팝오버 3종(RecallCard·SupportGloss·WordLookupPopover)은 각자 닫기 + 페이지 Esc 로 전부 닫힌다(`text/[id]/page.tsx:603-608`). InsightPanel 은 열려 있을 때만 Esc 로 닫히지만 **닫힌 상태에서도 Tab 으로 들어간다**(M15). echo·comic → 지문 복귀 링크는 둘 다 있다(`echo/page.tsx:140`, `comic/page.tsx:30`). 워크스페이스 → 라이브러리 복귀는 있으나 32px 이다(M14).
4. **낭비** — 세 곳이 크다: 허브가 모든 챕터 본문을 내려받고(M2), echo/comic 이 워크스페이스 layout 의 조회·쓰기 체인을 통과한 뒤 본문을 **또** 가져오며(M3), 탭 전환이 서버 컴포넌트를 다시 돌린다(M13). 사전 조회 N+1 은 **없었다** — `ExtractionPanel` 은 길이 기준 청킹 + `.in()` 일괄 조회이고(`ExtractionPanel.tsx:317-324`), layout 의 v_level 조회도 일괄이다(`text/[id]/layout.tsx:352-353`). TTS 는 문장 캐시 + LRU 12(`neural-voice.ts:31-64`)와 세대 번호 방어(`audio-control.ts:27`)로 잘 관리돼 있다.
5. **에러 처리** — 마이크 권한 거부는 **브라우저 원문(영어)** 이 그대로 나온다(M6). TTS 미지원은 받아쓰기 쪽만 제대로 다룬다(내려받기 제안까지 — `DictationSessionClient.tsx:440-460`, 모범). 오디오 로드 실패는 EchoMatch 에서 잘못된 이름표를 붙인다(M7).

## 부록 — 잘 되어 있는 것 (되돌리지 말 것)

감사 중 확인한 것 중, 다른 화면이 본받아야 할 자리:

- **문항마다 즉시 적재** — 중도 이탈해도 푼 만큼 남는다(`useDictationSession.ts:287`, `persist.ts` 헤더). 이 슬라이스에서 유일하게 이탈 복구가 설계된 곳이다.
- **이중 제출 잠금을 ref 로** — `setOutcome` 이 비동기라 같은 tick 의 Enter 반복을 못 막는다는 것을 알고 `submittedRef` 로 잠갔다(`DictationSessionClient.tsx:173-195`).
- **IME 조합 중 Enter 를 가로채지 않는다** — 한글 IME 에서 확정 Enter 가 제출로 새면 문항이 소모된다(`:231-235`). 타이핑이 본체인 화면에서 가장 중요한 방어다.
- **Tab 을 건너뛰기로 쓰지 않는다** — 2.1.1/2.1.2 근거까지 주석에 남겼다(`:21-25`).
- **TTS 세대 번호** — 불리언 `cancelled` 가 눌어붙어 소리가 영영 안 나던 결함을 세대 번호로 구조적으로 없앴다(`audio-control.ts:18-27`). 발화 Promise 에 예산 타임아웃도 있다(`:95-101`).
- **영어 음성이 없는 기기에 해결책을 준다** — 안내에서 멈추지 않고 17MB 를 밝히며 한 번 물어본다(`DictationSessionClient.tsx:438-460`). 이 슬라이스 최고의 에러 처리다.
- **채점 결과를 색만으로 말하지 않는다** — 색 + 밑줄/취소선/점선 + 범례 + `sr-only` 요약(`:704-717, 854-897`).
- **빈 탭마다 다음 걸음** — `SourcePicker` 는 세 탭 각각에 문구 + 44px CTA 를 짝지어 뒀다(`SourcePicker.tsx:36-52, 180-194`). M13 이 이것을 그대로 베끼면 된다.
