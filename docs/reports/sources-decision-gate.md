## D. 사람이 정할 것 — 두 질문을 분리해 올린다

두 질문은 **서로 독립**이다. 하나를 정해도 다른 하나는 열린 채로 둘 수 있다.

### 질문 (i) — **L2(CC-BY-SA) 를 채택하는가**

| | |
|---|---|
| **지금 상태** | 이미 쓰고 있다. `wikipedia`(76.2 · 유지 2위) · `simple_wikipedia`(73.7 · 유지 4위)가 L2 다 |
| **채택하면 더 열리는 것** | `wikibooks`(두 관문 통과 · MediaWiki API) · Wikiversity |
| **치르는 것** | **SA 전염**. CC-BY-SA 본문에서 만든 문항·단어세트·교재가 **같은 조건으로 공개돼야 한다.** 교재 전체가 아니라 그 파생물이지만, 한 권에 SA 지문이 섞이면 권 단위로 번진다 |
| **채택 안 하면** | `wikipedia`·`simple_wikipedia` 를 **빼야 한다** — 유지 8곳 중 둘이 빠지고, 적격 문항 3,115(wikipedia 971 + simple 2,144)이 사라진다 |
| **지금 정하지 않으면** | 현 상태가 「암묵적 채택」이다. 발행 규모가 커진 뒤 되돌리기 어렵다 |

### 질문 (ii) — **L3(CC-BY-NC) 를 채택하는가**

| | |
|---|---|
| **지금 상태** | 채택 안 함. `source-policy.test.ts` 가 「`SOURCE_SPECS` 에 restricted 등급 소스가 없다」를 잠그고 있고, DB `acp_classify_license` 가 NC 를 `copyright_safe_in_kr=false` 로 막는다 |
| **채택하면 열리는 것** | **심리·인지 칸** — `noba`(심리학 교재 전량) · `openstax` **41종**(Psychology·Biology 등 인기 교재). 이 칸은 **후보 25곳 어디에서도 NC 없이는 안 나온다**(기출 14.2% vs 재고 10.0%) |
| **치르는 것** | **상업 배포와 충돌.** 유료 서비스 안에 NC 콘텐츠를 두는 것 자체가 「비상업적 사용」인지 다툼의 여지가 있다. ND 와 달리 `display_only` 우회도 부적절하다 |
| **부분 채택안** | NC 전용 `display_only` 티어(읽기 + 툴팁 · 파생 단어세트·문항 발행 금지). 설계는 `ACP_OPENSTAX_DESIGN` §2 에 이미 있다 |
| **채택 안 하면** | 심리·인지 구멍은 **발굴로 안 메워진다.** 남는 길은 `original` 자작뿐이고, 그건 §C-3 을 먼저 고쳐야 한다 |

## E. 승인 시 Gate 4 실행 순서 (제안)

비용이 낮고 되돌리기 쉬운 것부터. **원천당 PR 하나.**

```
1  C-1 라이선스 슬러그 가드 + 80편 백필      마이그레이션 1 · 회귀 1        → legal 차단 80편 해제
2  C-2 register 분리 (최소 조치부터)         컬럼 1 · 코드 N               → narrative 재고 재계산
3  보류 5곳 중 frontiers 게이트 판정          드레인(분류 이미 있음)         → 1,957편 판정
4  wikinews 조건부 온보딩                     마이그레이션 0 · 필터 3       → 표본 500편 시범 → 수율 실측
5  worldbank_okr 라이선스 확정 + 표본 측정    읽기 전용                     → 채택 여부 재상정
6  global_voices 어댑터 (승인 시)             마이그레이션 1                → 표본 500편 시범
```

3~6 은 **(i)·(ii) 와 무관**하게 진행할 수 있다. (i)·(ii) 가 바꾸는 것은
`wikipedia`·`simple_wikipedia` 의 존속과 심리·인지 칸의 공급선뿐이다.

## F. 이번 게이트에서 하지 않은 것

- DB 쓰기·마이그레이션·화면 코드 **0**. 구조적 결함 3건은 **측정과 가드 설계까지만** 했다.
- 상위 10 신규 후보를 채우지 않았다 — 표본 실측이 5곳뿐이라 나머지는 근거가 없다.
- `standard_ebooks` 를 순위에 넣지 않았다 — 측정한 것이 원천이 아니라 수집기였다.
- 취득 불가 12곳의 「우회」를 시도하지 않았다 — AI 이용 거부와 403 은 **넓게 읽지 않는다.**
