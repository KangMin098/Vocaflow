# 학년별 독해 교재 benchmark: 표본틀 탐색 점검 (2026-10-06)

이 보고서는 **봉인 전 탐색 인벤토리**다. 학년별 9축 benchmark 표본이나 난도 분포가 아니다. 기준은 [benchmark 계약 초안](../ACADEMIC_READING_BENCHMARK.md)이다. 기존 시중교재 코퍼스는 저장소 밖 `d:/workspace/textbook-corpus`에 있고, 상업 교재 원문은 이 보고서에 복사하지 않았다.

## 로컬 보유 자산의 실제 범위

읽기 전용 `node scripts/textbook-corpus/query.mjs stats` 결과: 전체 94문서·5,229쪽, 독해 범주 60문서·4,307쪽이다. 이 수치는 **책/미리보기/해설이 섞인 문서 단위**다. 독해 본책·본문·미리보기 중 추출 성공·단일 학년 문서는 초4·초5·초6 NE능률 리딩튜터 스타터 각 1, 중1 NE능률 리딩튜터 주니어 1과 출판사 미상 중학 수능 딥독 1, 중2 미상 중학 수능 딥독 1, 중3 NE능률 리딩튜터 챌린저 1과 미상 중학 수능 딥독 1, 고1 EBS 올림포스 1, 고3 EBS 수능특강 1이다. 고1~고2 등 복수 학년 교재는 단일 학년 참조군에서 제외한다. `미상`은 독립 출판사로 세지 않는다.

기존 `docs/reports/passage-ruler.json`은 출판사 인쇄 어수 표식을 이용해 131쪽에서 72개 지문을 추출하고 그중 59개를 유지했다. 이 중 **46개가 `중1~중3` 라벨**이며, NE능률 1316 Reading 44건과 리딩인사이드 2건이다. 단일 학년 라벨은 초6 1, 중1 2, 중2 2, 중3 1로 합계 6개이며, 이 추출 결과에는 고등 지문이 없다. 이는 해당 추출기가 어수 표식이 있는 초·중 교재 일부만 대상으로 하기 때문이다. 59건의 FK·문장 길이는 기존 탐색 지표이며, 지문/문항 9축 측정·판본·권리·ISBN 검증을 거친 benchmark 측정치가 아니다.

## 공식 출판사 카탈로그에서 확인한 탐색 후보

다음 링크는 **2026-10-06에 접근한 공식 상품/로드맵 페이지**로, 표본틀 검색 출처 후보일 뿐 ISBN·최신 판본·본문 접근권·독립 지문·문항 확인을 마친 표본이 아니다. 검색 출처와 마감일을 봉인하기 전의 탐색이므로 사전등록 표본에 소급 편입하지 않는다. `카탈로그 확인`은 웹 상품 설명을 읽었다는 뜻이며, `미리보기 미확인`·`본문 미확인`은 실제 파일을 열어 분석하지 않았다는 뜻이다.

| 출판사 | 공식 근거 | 접근 상태·현재 용도 |
|---|---|---|

비상 Reader’s Bank처럼 **시리즈 전체가 초·중·고를 덮는다는 설명**만으로 권별 학년을 배정하지 않는다. EBS 로드맵의 `중1~중3`도 단일 학년 권의 증거가 아니다. 공식 카탈로그에 미리보기 버튼이 있다는 사실은 본문 분석·원문 저장·재배포 권한의 증거가 아니다.
