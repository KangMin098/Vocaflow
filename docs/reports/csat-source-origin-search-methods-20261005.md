# 기출 원문 출처: 후보가 적은 이유와 탐색 수단 점검

2026-10-05. `knowledge_csat_origins`와 연결된 `csat_items.passage`를 직접 조회했다. 단위는 중복 지문을 묶은 등록부 행이다. 이 조사는 기존 검색 기록 전체를 진단하고 대체 수단을 시험한 것이다. 미확인 600개 모두에 새 검색을 실행한 것은 아니다.

## 현재 수량

| 범위 | 전체 | A 직접 확인 | B 후보·부분 근거 유추 | C 소재 계보만 | G 미확인 |
|---|---:|---:|---:|---:|---:|
| 수능 | 338 | 77 | 21 | 1 | 239 |
| 모의평가 | 375 | 14 | 0 | 0 | 361 |
| 합계 | 713 | 91 | 21 | 1 | 600 |

수능 A+B는 98/338(29.0%), 전체는 112/713(15.7%)다. 연결 문항 수로는 전체 802개 중 A 96개·B 22개·C 1개·G 683개다. 한 지문이 여러 문항에 연결되므로 지문 수와 문항 수를 섞지 않는다. 이번 조사에서 DB 등록 상태를 바꾸지 않았다.

## 왜 후보·유추가 적은가

1. **새 유추 기준으로 실제 재검토한 범위가 작다.** 직전 부분 근거 검토는 14개였다. G→B 11개와 기존 B 3개 보완/정정이다. 현재 B 21개 중 14개에 새 부분 근거 기록이 있고 7개는 기존 후보다. 기준을 완화했어도 원작의 제목·저자와 지문의 연결 근거를 새로 찾지 않으면 B가 늘지 않는다.
2. **수능과 모의평가의 탐색 깊이가 다르다.** 현재 수능 G 239개는 초기/후속 일반 검색 기록이 각 2회이고, 별도 심화 검색·보류 판정도 있다. 모의평가 G 361개는 일반 검색 각 1회와 책 사이트 검색 각 1회만 있으며, 별도 심화 보류 판정이 없다. 계획에 구절 3개가 있어도 검색 로그의 실행 횟수와 같지 않다.
3. **책 검색 경로가 좁았다.** 초기 책 검색 기록 713개는 모두 고유 구절에 `site:books.google.com`을 붙인 웹 검색이고 전부 `Empty search results`다. Google Books 내부 본문 검색/API 실행 기록이 아니다. 이 결과로 ‘713개 모두 책 본문에 없다’고 판단할 수 없다.
4. **보류 문구가 원인을 남기지 않았다.** 현재 수능 G 239개 중 232개는 ‘원문 전체 및 서지를 함께 확인할 자료를 확보하지 못했다’는 동일 문구다. 접근 실패인지, 잘못된 후보인지, 편집으로 검색이 실패했는지 알 수 없다. 이 판정 문구에는 예전의 완전 본문 확인 조건이 남아 있지만, 완화하면 몇 개가 등록되는지 문구만으로 계산할 수 없다.
5. **시험 재게시와 단어만 겹치는 문서가 많아 보이는 검색이 있었다.** 개별 기록에서 Tadelis 교재와 Congressional Record는 단어만 겹쳐 탈락했다. 같은 문단을 담은 수능 풀이 자료는 문단 존재를 확인할 뿐 원작 서지를 알려주지 않는다. 이 사례로 전체 검색 결과의 비율을 추정하지 않았다.

기존 장문 구절의 일부가 현재 본문에 연속으로 존재하는지도 전량 점검했다. 수능 G는 239/239, 모의평가 G는 325/361이다. 모의평가 36개의 불일치는 마커·전처리·본문 버전 등도 원인일 수 있다. 이것을 ‘시험 편집 때문에 출처 탐색이 실패한 36개’로 세지 않았다. 초기 로그에는 현재 본문 해시가 없어 본문 직접 검증 기록으로 쓰지 않는다. 반면 수능 심화 보류 239개는 현재 연결 문항 본문 해시와 모두 일치했다.

## 요청한 1·2·3·4 사유 분포

**실제 원인의 분포는 아직 산정할 수 없다.** 아래는 현재 기록에서 관찰된 장애다. 사유 3은 사유 1과 중복하고, 2의 기록 부재는 실제 발생 0개를 뜻하지 않는다.

| 사유 | 기록에서 관찰된 수 | 해석 |
|---|---:|---|
| 1. 접근·열람 장애 | 2 | `2014B#34` 스캔 장 자료, `2019#26` 공식 PDF 404. 후보 자료 접근 장애이며 원작이 확정된 책의 제한이라고 단정하지 않는다. |
| 2. 단어 교체·생략·순서 변경이 탐색 실패의 원인 | 미산정 | 현재 보류 기록에 원문과 편집 차이를 대조해 실패 원인으로 특정한 사례가 없다. |
| 3. 재인용·판본 관계 불확실 | 1개에 불확실성 기록 | `2014B#34`의 재인용 관계 미확인. 사유 1에 포함된 같은 항목이다. 실제 재인용을 입증한 것은 아니다. |
| 4. 검색했지만 원작을 식별하지 못함 | 237 | 공통 보류 232개+개별 단서 불충분/후보 탈락 5개. 원래 고유 단서가 없다는 의미가 아니다. |
| 세부 사유 미분류 | 361 | 모의평가. 초기 검색만 있고 개별 심화 사유 기록이 없다. |

서로 배타적인 운영 분류는 **접근 장애 2+원작 미식별 237+미분류 361=600**이다. 실제 인과를 모르므로 1~4번의 원인 비중 그래프를 만들지 않는다. 600개 각각의 ID·연결 문항·현재 본문 해시·검색 횟수·보류 근거·분류 한계를 [진단 JSON](./csat-source-origin-search-diagnosis-20261005.json)에 보관했다.

개별 사유 7개도 직접 읽었다. `2014B#34`·`2019#26`은 위 접근 장애이고, `2015#33`(문서 제목만), `2016#20`(시험 재게시), `2021#32`(Tadelis 후보 탈락), `2023#20`(Edge 전체 목록과 불일치), `2024#26`(Congressional Record 후보 탈락)은 원작 미식별이다. 2015 자료를 2013 시행 시험의 사용 원본으로 삼지 않는다.

## 대조 시험 결과

| 시험 | 실제 결과 | 결정 |
|---|---|---|

| 위 책 Google Books 서지·목차·색인 확인 | ‘자기 보호 하위자아’ 색인과 관련 장 목차, 저자·출판사·2013 서지 확인. 내부 구절 검색 링크는 접근 오류 | 본문 귀속은 미확인. 기존 G 유지 |

두 대조 책은 *The Art of Choosing*과 *Understanding Fashion History*다. 확인된 짧은 구절은 각각 `expertise carries costs`, `Garments should be seen`이다. 표본이 작고 책 본문 미색인 여부는 알 수 없으므로 내부 본문 검색의 성공률을 주장하지 않는다. API 할당량 오류의 외부 프로젝트 식별자는 보고서에 보관하지 않는다.

4개 탐색 대상은 `2014B#34`, `2015#33`, `2016#20`, `2023#20`이다. 짧은 구절만 검색하면 여전히 시험 재게시물이 우선 나올 수 있었다. 제목/저자 가설이 틀릴 수도 있으므로 가설을 다음 검색으로 넘길 때 근거와 탈락 조건을 기록한다. *The Rational Animal*은 [출판사 서지](https://www.hachettebookgroup.com/titles/douglas-t-kenrick/the-rational-animal/9780465040971/)와 [Google Books 목차·색인](https://books.google.com/books/about/The_Rational_Animal.html?id=4VEPAAAAQBAJ)에서 확인했다. 특정 문단의 고유 구절과 전개를 확인할 때까지 탐색 단서로만 둔다.

## 다른 탐색 방안과 적용 순서

우선순위는 전량 검색 기록에서 발견한 공백과 수단의 기능에 따른 것이다. 대체 경로를 600개 모두 실행한 회수율 순위가 아니다. 전체 예상 등록 수를 제시할 근거는 아직 없다.

| 순서 | 방안 | 현재 기록에 보완되는 점 | 실행·판정 방식 |
|---|---|---|---|
| 1 | 알려진 후보/단서의 제목·저자·ISBN으로 책을 찾고 내부 본문 검색 | 책 사이트 웹 검색의 사각지대와 유추 재검토 범위 부족 | 여러 판본을 확인하고 짧은 고유 구절·내용 전개·서지를 연결. 전체 본문 공개를 요구하지 않고 B 근거 필드에 확인 범위와 불확실성을 기록 |
| 2 | 문단 앞·중간·뒤의 서로 다른 짧은 구절과 희귀 용어 조합 | 최초 구절 하나에 의존한 모의평가 361개 | 3~6단어 구절, 떨어진 두 구절, 인용부호 없는 희귀 용어를 별도 시도. 삽입·순서 문항의 마커와 요약문을 원문 구절에서 제외. 검색 성공 후에 원작 판정 |
| 3 | Internet Archive/HathiTrust 본문 검색 병행 | 일반 웹·서지 검색에 나오지 않는 스캔/OCR 책 | 메타데이터 검색과 본문 검색을 구분. HathiTrust는 전체 열람 가능 책만 필터링하지 않고 검색만 가능한 책도 포함. 실제 접근·검색 오류를 별도로 기록 |
| 4 | 재인용 자료의 참고문헌→원작·장 저자로 역추적 | 재인용·편집자/장 저자·판본 혼동 | 대학 리포지터리, 출판사 장 소개·목차, 저자 공개 자료의 인용을 사용. 후대 자료는 연결 증거로 쓰고 시험 사용 판본이라고 단정하지 않음 |
| 5 | EBS 연계교재/교사 자료의 출전 정보와 시험 지문 연결 | 한국어 출처 단서·원작 제목을 검색에서 놓칠 가능성 | ‘원문 보기’가 외부 원작인지 교재 본문인지 먼저 확인. 출전 서지가 실제 있을 때만 역추적. 시험 재게시 자체를 원작 증거로 등록하지 않음 |
| 6 | 의미·문단 구조로 후보를 찾고 식별 구절로 검증 | 단어 교체·생략 때문에 정확 구절 검색이 실패할 수 있는 항목 | 발견용 검색에만 사용. 주제 유사성만으로 B 판정하지 않음. 후보가 생긴 뒤 동일 사례/논증 순서/고유 구절을 대조 |

Google Books 공식 API는 `q`를 본문 검색 질의로 정의하고 부분 공개 필터도 제공한다. [공식 API 문서](https://developers.google.com/books/docs/v1/reference/volumes/list). 이번 실행에서는 할당량 오류가 있었으므로 API 자동화 완료라고 보고하지 않는다. 책 내부 검색/다른 경로를 함께 사용한다.

Internet Archive는 메타데이터·전체 텍스트·개별 책 내부 검색을 구분하며, 전체 텍스트 검색은 OCR 텍스트를 사용한다. [공식 검색 안내](https://archivesupport.zendesk.com/hc/en-us/articles/360018359991-Search-A-Basic-Guide). 후보 스캔을 얻은 뒤 OCR로 해당 문단을 찾는 것이 가능하지만, 미확인 지문의 모든 원작을 OCR만으로 찾을 수 있다는 뜻은 아니다.

HathiTrust에서는 본문 검색과 전체 열람이 다른 조건이다. 검색만 가능한 제한 자료를 포함하는 경로를 사용할 수 있다. [UC HathiTrust 지원 안내](https://help.hathitrust.universityofcalifornia.edu/support/solutions/articles/9000223665-full-text-full-view-better-searching-in-hathitrust). 이번 조사에서는 해당 경로의 미확인 지문 회수율을 측정하지 않았다.

## 다음 탐색에서 남길 기록

- `검색 0건`, `요청/접근 실패`, `후보 발견`, `후보 탈락`, `귀속 근거 확보`를 나눠 기록한다. 오류를 0건으로 넣지 않는다.
- 방법·실제 질의·확인 URL·문항 ID·현재 본문 해시를 남긴다. 계획된 질의와 실행한 질의를 구분한다.
- 1~4번은 대조 근거가 있을 때만 장애 태그로 붙이고 중복을 허용한다. 모르는 원인은 `미분류`로 둔다.
- 탐색 단서와 등록된 B를 분리한다. 고유 구절·내용 전개·서지 연결이 맞으면 부분 근거로 B를 등록하고 확인 범위·설명 가능한 차이·남은 불확실성을 함께 남긴다.
- 첫 실행은 수능의 서지 단서가 있는 항목부터, 이후 수능 미확인 239개와 모의평가 361개의 미실행 경로를 순차 처리한다. 각 경로의 전량 결과를 얻은 뒤 시간당 등록 수와 실제 회수율로 순서를 다시 정한다.

검증: DB 713개 상태 직접 집계, G 600개 ID/해시 유일성, 운영 분류 합계 600개, 심화 보류 239개 현재 본문 해시 충돌 0개를 확인했다. 다른 세션의 조사 파일은 읽기 전용으로 사용했다.
