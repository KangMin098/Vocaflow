## 검색한 범위와 남은 조사

적용 전 미확인 **600행** 전량에 본문 해시를 묶어 **2,397개 질의**를 생성했다. 문장·시험 블록 경계를 넘지 않는 희소 구절을 고르고, 네 단어 구절 두 개를 함께 검색하거나 각각 검색한다. `scripts/csat/source-origin-search.mjs`의 `alternativeQueries`는 질의만 만들며 검색·판정을 자동 실행하지 않는다.

이 중 수능 **239행에 각 한 번씩, 총 239개 질의**를 실제 실행했다. 이 검색 배치의 요청 오류는 0건이지만 결과 대부분은 시험 재게시물이었으며, 239건 모두 원서 본문을 읽었다는 뜻은 아니다. 모의평가 361행은 이번 회차에 검색하지 않았다. 기준선 질의 중 미실행은 2,158개이며, 이미 등록된 8행의 질의도 포함된다. 다음 배치는 DB 상태와 연결 본문 해시를 다시 읽어 A/B 등록행을 건너뛰어야 한다.

기존 서지 후보 7개 중 한 개만 A로 승격했다. 나머지 6개는 *Social Media ROI*, *The Gig Economy*, *Sport Entrepreneurial Ecosystems*, *Strategic Issues in Global Grain Trade*, *Interior Design Illustrated*, *Effective Data Storytelling*이다. 각각 공개 본문 접근 실패·목표 문단 부재·서지 연결 부족 등이 남아 기존 B를 유지했다. 공식 미리보기라도 목차·색인만 있으면 해당 문단 확인으로 세지 않았다. 특히 곡물 무역 후보는 독립 서지 재확인이 필요하다. 이 6개는 이번 신규 부분 근거 검수 통과 수에 포함하지 않는다.

2021#41/#42의 Simon 개미 관련 후보와 2015#24 Ehret 전기 후보는 주제·사건 유사성만으로 원작을 특정할 수 없어 G를 유지했다. 이유·URL·본문 해시를 보류 기록에 남겼다.

[Open Library 공식 책 내부 검색 API](https://openlibrary.org/dev/docs/api/search_inside)에 따라 Internet Archive의 공개 내부 검색을 실제 요청했으나 해당 원서는 **403 Item not available**이었다. Google Books 내부 검색도 접근 오류였다. 이들은 검색 결과 0건이 아니다. 비공개 파일이나 접근 제한을 우회하지 않았다. 반면 공개된 저자 장 PDF는 추출 텍스트가 거의 없는 스캔이어서 페이지 이미지를 읽어 재인용 근거를 확보했다.

다음 순서는 남은 수능 단일 구절 변형 → 미검색 모의평가 → 기존 B 6개의 원서 문단·서지 재확인 → 접근 가능한 책 내부 검색·공개 스캔·참고문헌 역추적이다. 이번 일부 조사로 과거 1~4번 사유 분포를 새 전량 분포처럼 갱신하지 않는다. 실제 관찰된 장애와 원작 미식별·사유 미분류는 구분해 유지한다.

## 첨부 제안 적용: 연합 검색 실험 — 추가 등록 0개

웹 검색 반복보다 도서·학술 본문 API와 로컬 정렬을 먼저 시험했다. 현재 DB를 다시 읽은 기준선은 위와 동일하게 A+B 120/713, 미확인 592개다. **이번 연합 검색 실험에서는 새 A/B 등록이 없으며**, 앞 회차의 신규 8개와 혼용하지 않는다.

제안의 중요한 전제 두 가지를 공식 명세로 정정했다. [Semantic Scholar snippet 명세](https://api.semanticscholar.org/api-docs/snippets)의 `query`는 일반 텍스트이고 특수 검색 문법을 지원하지 않는다. 약 500단어 발췌와 참고문헌 annotation은 제공하지만, `"fish ladder"~3` 형태의 proximity 검색을 이 endpoint의 기능으로 구현하지 않았다. [CORE 공식 API 문서](https://api.core.ac.uk/docs/v3)는 비인증 이용자의 전문 반환 제한을 명시한다. 본문 API가 있다는 사실만으로 현재 계정에서 전문을 일괄 확보할 수 있다고 보지 않는다.

본 배치의 준비 질의는 2,367개, 실제 HTTP 요청은 594개(논문 592회·장애 provider 각 1회), 장애로 미실행 1,773개다. 이어서 Europe PMC 시행 연월 제한 검색 175회를 실행했다. 위의 서비스 대조 시험은 별도 로그다. Google Books의 exact phrase 등 질의·필터 기능은 [공식 문서](https://developers.google.com/books/docs/v1/using) 기준으로 구현했다. 출처 후보 생성과 해당 책의 본문 열람은 구분한다.

Europe PMC 추가 검색에서 반환된 서지는 총 658건, 중복 제거한 OA 논문은 648개였다. [공식 fullTextXML 경로](https://europepmc.org/RestfulWebService)로 **633개 본문을 확보**, 15개는 본문 미제공/접근 문제로 기록했다. API별 반환은 최대 10개라 전체 결과나 전체 OA 코퍼스를 내려받은 것은 아니다. XML을 문단으로 나눠 **33,297개 문단 블록**에 5단어 shingle·희소 토큰 역색인을 만들고 미확인 592개 전량을 로컬 검색했다. 참고문헌 자체는 본문 일치 코퍼스에서 제외했다.

지문 468개에 원시 순위 결과가 생겼지만 **원천 후보 468개를 확보했다는 뜻은 아니다**. 순위로 반환한 문단 쌍 2,934개 중 최대 지문 토큰 일치는 12.7%였다. 상위 10쌍의 실제 지문·문단을 읽었다. 시간 안내문과 연구 측정 시간이 겹치거나, Festinger 전기와 Bruner 논문의 관용 표현이 겹치는 사례 등이었다. 2024#33은 Charles Le Brun의 역사적 사실이 겹쳤지만 주장·전개가 달랐고, 2020#25는 전력 접근 지표 주제만 같고 시험 도표 수치·연도가 확인되지 않았다. 모두 A/B 등록 근거로는 부족했다. 이번 제한된 코퍼스의 낮은 일치율을 다른 원서에도 적용해 원작 부재나 1~4번 원인을 단정하지 않는다.

정렬은 token 수준 Smith–Waterman으로 삽입·삭제·치환 비용을 계산한다. 동의어 의미를 자동 판정하지 않으며 `order_preservation`은 최적 국소 구간의 일치 토큰/일치+편집 비율이다. 알려진 직접 확인 원서 4개에서 1,311개 블록으로 대조 시험했을 때 각각 올바른 책이 1위였다. 본문이 두 문단으로 나뉜 사례의 단일 블록 coverage는 54.2%였다. 이 네 사례는 구현 점검이며 일반화된 정확도나 신규 확보 예상 수가 아니다.

후보 evidence에는 문서 ID·서지·지문/원문 해시·일치량·정렬 구간·열람 범위·문서 역할·판정을 보존했다. 관련 API 후보에서 나온 329개 문단 쌍에는 참고문헌 연결 129개를 기록했지만, 이는 해당 단락의 인용 관계일 뿐 일치 문장의 저자 귀속 증거는 아니다. 아직 `candidate_role: unclassified`, `verdict: unreviewed`이며 등록 DB와 분리했다.

기존 등록 120개도 분석했다(A 95·B 25 분리). 출판사 상위는 Routledge 9, Oxford University Press 8, Wiley 8, Cambridge University Press 6이다. 수집·열람 편향이 있는 관찰 빈도이므로 78% 같은 검색 경로 확률을 만들지 않았다. M2206#22의 2023년은 열람한 후기 판본이고 기존 note에도 앞 판본 가능성이 기록돼 있었다. 이런 열람 판본 연도를 원작 최초 발행 연도처럼 학습시키지 않는다. 자료 종류·최초 발행·편집률 라벨을 검수하기 전 통계 모델을 학습하지 않는다.

재실행 도구는 기존 `scripts/csat/source-origin-search.mjs`를 확장했다.

```powershell
# 입력은 DB에서 다시 읽은 원천·지문·연결 본문 SHA 스냅샷이다.
node scripts/csat/source-origin-search.mjs <fresh-rows.json> <attempts.jsonl>
node scripts/csat/source-origin-search.mjs --oa <oa-attempts.jsonl> <local-directory>
node scripts/csat/source-origin-search.mjs --local <fresh-rows.json> <paragraph-documents.json> <ranking.json>
```

네트워크 CLI는 성공한 동일 provider/query/현재 연결 해시만 건너뛰고 장애·미실행은 다음 실행에서 재시도한다. 새 로그 경로를 쓰면 전체 검색을 새로 실행한다. 429/접근 거부 후 같은 provider를 반복 호출하지 않는다. `--oa`는 공개 OA로 표시된 PMCID만 요청하고 XML 캐시는 본문이 있는지 다시 확인한다. `--local`은 로컬 순위 결과만 쓰며 DB를 바꾸지 않는다. 전체 코퍼스가 클 때는 문단 분할·코퍼스 규모를 조절한다. 원문 XML·문단 텍스트는 로컬 작업 디렉터리에 두고 저장소에는 해시·서지·점수·판정 기록을 남겼다.

HTRC·Common Crawl은 후속 조사 경로로 남긴다. [Common Crawl URL Index](https://commoncrawl.org/url-index)는 구절 전문 검색 엔진이 아니므로 URL·도메인 후보 없이 전량 스캔을 시작하지 않았다. JSTOR 대량 TDM은 [공식 연구 요건](https://support.jstor.org/hc/en-us/articles/32479181127575-JSTOR-Text-Analysis-Support-Getting-Started)에 제품 제작 목적 제한이 있어 이 제품 파이프라인에서 요청하지 않았다. 기존 공개 장 발췌 열람과는 다른 경로다.

연합 검색·OA 추출·편집 정렬·오류/미실행 구분을 포함한 회귀 **18/18 통과**. 현재 DB 출처·공백 변경과 마이그레이션은 없다. 실측상 이번 OA 경로에서 추가 출처는 0개였으므로, 다음 확대는 도서 API의 정상 접근 확인과 출판사 공개 원문 중심으로 진행하며 OA 결과 수만 보고 대량 코퍼스 확대를 권하지 않는다.
