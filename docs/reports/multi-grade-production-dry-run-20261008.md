# Multi-grade production synthetic dry-run

The `textbook-product-order-group/1` contract now has an executable synthetic path from prepared `ready` passage evidence through items, explanations, editorial reviews, units, volume, and HTML rendering. Run `node --import tsx scripts/textbook/multi-grade-factory-dry-run.mjs <input.json> <new-output-directory>` with a JSON input containing the sealed group, recorded/current evidence, caller-supplied per-grade promotion snapshots, stage artifacts, and render settings. The output directory must not exist. The runner writes `volume.html` and `lineage-manifest.json` together through a staged directory rename; a retry uses a new directory.

Each grade is checked against its own child order hash, current promotion lineage, source/rights/benchmark snapshot, article reference, passage hash, item digest, explanation, editorial decision, activity/analysis hash, and unit HTML hash. The volume plan validates group and grade unit sets before the existing `renderVolumeDocument` creates HTML. The manifest binds the rendered HTML and every grade/item/unit hash. Shared passage with separate items, separate grade adaptations, and mixed-grade units have synthetic success tests. Cross-grade order mixing, reused reading children or items, stale promotion/certificate evidence, changed rights, item or explanation edits, non-approved review, and changed unit HTML have failure tests.

This path accepts prepared stage artifacts and a caller-supplied current-lineage snapshot. It does not query the DB, generate new items, certify a commercial benchmark, issue Gold-S, or authorize publication. The output explicitly records `evidence_level=caller_supplied_unverified`, `render_eligible=false`, and `seed_eligible=false`, and the HTML carries a dry-run warning. Render metadata are schema-validated but their factual claims are not independently audited. A future operational adapter must obtain current lineages from the DB and run the existing promotion proof/rights checks before reusing these contracts. Actual benchmark corpus, Gold-S, and DB seed remain zero.
