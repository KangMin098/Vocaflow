### 읽는 법 두 가지

**① 학교 문단(40~200)이 어디서나 최대 창이다.** 성인 대상 학술 초록·논평의 자연 길이가
거기 몰린다. 수능 짧은 지문(90~200)은 그 부분집합이라 실효 공급은 **「200어 이하 산문」
한 덩어리**로 보는 편이 정확하다.

**② ~~장문(260~400)은 초록으로는 안 된다~~ — 무효. 내가 또 같은 실수를 했다.**

처음에 「비율이 5%대라 안 된다」고 적었다. **비율을 공급량으로 착각한 것**이고,
길이로 원천을 거르지 말라는 지적을 받고도 같은 모양으로 다시 판정한 것이다.
전체 재고로 환산하면 **초록만으로 장문이 6만 편이 넘는다**:

| 원천 | 표본 장문 | 비율 | **전체 환산** |
|---|---:|---:|---:|
| EconStor | 165 / 3,075 | 5.4% | **17,232** |
| OpenAlex 인문 | 202 / 1,968 | 10.3% | **35,659** |
| SciELO sza | 403 / 3,000 | 13.4% | **7,805** |
| OLH | 167 / 4,000 | 4.2% | 515 |
| **합계** | | | **≈61,200** |

**그리고 「초록의 한계」라는 말 자체가 원천의 성질이 아니라 내 측정의 한계다.**
이 넷은 전부 본문(PDF·전문 XML)이 뒤에 있고, 나는 API 가 싸게 주는 초록만 쟀다.
EconStor 재수집 보고가 그것을 정확히 적어 두었다 —
「장문 5.4% 는 **초록의 한계이지 EconStor 본문의 한계가 아니다**」.

**남는 사실 하나**: 201~259 구멍(§1-2)이 장문 공급을 실제보다 작아 보이게 만든다.
SciELO 의 863건은 장문 하한에 20~60어 모자랄 뿐이다.

## 1-2. ★창과 창 사이에 구멍이 있다 — 201~259어

**SciELO 에서 나온 이 발견이 이번 재점검의 최대 수확이다.**
버려지는 것의 정체가 「길이 초과」가 아니라 **우리 창의 틈**이었다.

| SciELO sza 초록 보유 2,430건 중 어느 창에도 안 드는 889건 |  |
|---|---:|
| 6어 미만 | **0** |
| 400어 초과 | 26 (1.1%) |
| **201~259어 (수능 짧은 상한 200 ↔ 장문 하한 260 사이)** | **863 (97%)** |

그리고 SciELO 어수 분포의 **최빈 구간이 200~249**(730건)다. 창 상한 200 이
**봉우리 한가운데를 가르고 있다.**

다른 원천도 같은 자리에 쌓인다 — OLH 479건(12.0%) · EconStor 332건(10.8%) ·
OpenAlex 358건(14.9%).

**이건 원천의 결함이 아니라 우리 창 정의의 문제다.** 짧은 지문 상한을 220~260 으로
한 번 올리면 SciELO 커버리지가 **63.4% → 98.9%** 가 된다.

⚠️ **그러나 창을 바꾸는 것은 내가 정할 일이 아니다.** `CSAT_ITEM_WORDS` 는 조판·채점·
학습이 공유하는 정본이고, 상한 200 은 「수능 지문 상단(약 130어)에 여유를 둔 값」이라는
근거가 주석에 적혀 있다. 바꾸면 이미 조판된 권의 판정이 함께 움직인다.
**측정 결과만 올리고 결정은 사람에게 맡긴다.**

## 3. 「짧다」와 「없다」를 갈라야 한다 — 내가 세 번 틀린 것

세 원천에서 같은 것이 나왔다. 「6어 미만」으로 세던 것이 **본문 결측**이었다.

| 원천 | 「너무 짧음」으로 세던 것 | 실제 결측 | 실제 6어 미만 |
|---|---:|---:|---:|
| OLH | 875 | **853** | 22 |
| EconStor | 472 | **471** | 1 |

**처방이 정반대다** — 짧으면 묶으면 되지만, 없으면 다른 데서 가져와야 한다.
결측을 짧은 것으로 세면 「이 원천은 글이 너무 짧다」는 **없는 진단**이 만들어진다.

그리고 본문 키가 원천마다 다른데 `text` 하나만 봐서 **OLH 4,000편이 집계에서 통째로
조용히 빠져** 있었다(키가 `abstract`). 도구는 이제 못 찾으면 **키 목록과 함께 이유를 인쇄**한다.
