## 분리한 평가 기준

요청한 의미 보존 7항목에서 원문이 지원하지만 불필요한 추가와 근거 없는 추가를 따로 판정해 8항목으로 구현했다. 전문가별 `claim_preserved`는 핵심 주장과 필수 정보, `relation_preserved`는 인과·비교, `scope_preserved`는 조건·범위, `epistemic_strength_preserved`는 추론 강도, `no_hallucinated_content`는 지원되지 않는 정보 여부로 계산한다. 미평가는 null이다. 항목 하나라도 fail/unassessed이면 gold가 될 수 없다.

학생 측정은 읽기 시간, 명시 정보 이해도, 문맥 어휘 정확도, 문장 의미 정확도, 근거 기반 추론 정확도, 미지어 등장 비율, 어휘/문장/추론 부담, 체감 난도를 각각 보관한다. 무응답·부분 기록도 null/빈 응답으로 보존하고 승격 표본에서 제외한다. 없는 축의 정확도는 0 대신 null이다. 실제 결과 없이 목표 V3나 학년을 측정값으로 표시하지 않는다. `*_level`은 축별 정확도의 운영 측정이며 공인 학년 척도가 아니다.

[taxonomy-1.json](../../scripts/textbook/frym-validation/taxonomy-1.json)은 기존 관찰 사례 F05-A1, F09-A1, F10-A2, F13-A2의 원천 UUID/해시·연구 DOI/해시·양쪽 짧은 인용 anchor와 코드 대응을 보존한다. 비교 순서 역전은 인과 역전과 구분한다. 이 사례들은 전문가가 인증한 자동 검사기의 정답 세트가 아니며 자동 의미 탐지 모델도 이번 단계에서 만들지 않았다.

## 승격의 범위와 남은 실증 작업

사람 책임자의 정확한 프로토콜/문항 사전 등록 → 독립 전문가 최소 2명의 의미 보존 통과 → 해당 학년 학생 버전별 최소 5명의 실제 측정 → 왜곡/원천/링크/측정 범위 통과 순서를 검사한다. 표본 최소치와 통과 범위는 pilot 설계 제안이다. 현재 두 학년 범위는 같은 초기 값이므로 사람이 문항·표집·범위를 검토하고 등록해야 한다. 범위 충족 자체가 일반적인 학년 난이도를 증명하지는 않는다.

신원·자격·학년은 사람 책임자가 별도 증빙을 확인하는 신뢰 경계다. JSON 입력만으로 실제 사람임을 인증할 수 없다. 증빙 참조를 요구하지만 그 외부 증빙의 진위를 도구가 검증하지는 않는다.

Gold는 정확한 passage/target/protocol에 한정한다. 완성 생성 청크의 import는 동일 본문 인증을 요구하며 인증 파일이 실행 중 바뀌면 적재를 거절한다. 실제 published DB 행의 본문/부모/target까지 일치할 때만 production을 계산한다. 권리 확인·내용 판정·발행 게이트도 계속 필요하다.

다음 실증 작업은 사람이 문항과 기준을 확정하고 실제 blind 판정과 학생 측정을 수집하는 것이다. 그 결과가 없으므로 DB seed는 실행하지 않았다.
