# 원문 운영 기능 확장

`vocaflow-design-loop` 적용. 기존 원천 목록·상세 패널을 보존하고 적격 판정 탭에 개별 원문 검토를 연결한다.
전면 시각 재설계가 아닌 기존 작업공간의 운영 기능 확장이므로 별도 4안 선택을 강제하지 않는다.

- 골격: 주묵 문법 — 반려 사유에서 원문, 연결 문항으로 이어지는 검토 흐름.
- 서명: 선택한 차단 사유와 실제 원문의 같은 신호를 한 inspector 안에 유지한다. 전환은 색·불투명도 200ms 이내.
- N4: 연결 문항 수·정책 결과·본문 근거 없이는 차단 경로와 검토 순서를 만들 수 없다.
- 핵심 행동: 큐 수치 선택 → 실제 원문 선택 → 이유/본문/발췌/연결/이력 확인 → 원문을 바꾸지 않는 재검증.
- 인지 부하: 전체 본문과 분석 JSON은 펼쳐 읽고, 기본은 사유와 영향부터 보여 준다.
- 기준 화면: `.agent-logs/csat-sources-ui-before.png`, 1280×900, light.
  기존 e2e 1280 통과, 첫 원천 행 하단 765px. 실제 이미지 열람 완료.
