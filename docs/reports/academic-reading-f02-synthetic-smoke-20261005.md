> **Execution limitation (discovered after the 28-output run):** The v1 Windows `cmd.exe` call did not use `windowsVerbatimArguments`, so the intended `--system-prompt` argument may have been split. The preserved hashes verify the *intended invocation and recorded outputs*, but cannot attest the exact argv received by Claude. Treat all 28 outputs and score statistics below as exploratory diagnostics, not a controlled system-prompt experiment or evidence of grade validity. The corrected v2 runner uses `windowsVerbatimArguments: true`, changes the invocation hash, and rejects reuse of v1 caches. A fresh one-packet v2 execution completed with one valid response and score; a full 28-packet v2 rerun has not been performed.

F02의 실제 학생 pilot은 미봉인 상태로 보존하고 새 **합성 진단 경로**를 추가했다. 14개 epistemic profile × 고정 본문 2개에서 blind 패킷 28개를 재현 가능하게 내보낸다. 생성/응답/채점을 같은 모델 계열이 혼자 수행하지 않도록 응답 import에서 모델 계열 분리를 요구한다. 문항 ID·답변·0/0.5/1 점수, 현재 채점키 해시를 확인한 뒤 지문 언어 지표와 합성 문항 기술 통계만 낸다. [실행 계약](../../scripts/textbook/frym-synthetic/README.md).

실제 Claude Haiku(`claude-haiku-4-5-20251001`)가 28개 패킷에 각각 응답하고 Codex(`gpt-6.1-sol`)가 현재 채점키로 별도 채점했다. [응답·점수 28행](../../scripts/textbook/frym-synthetic/evidence/f02-smoke-v1.responses.json)은 14개 profile×본문 쌍이며, **실제 학생 28명 또는 독립 모델 28개가 아니다.** [실행 요약](../../scripts/textbook/frym-synthetic/evidence/f02-smoke-v1.run-summary.json)은 유효 28/28·실패 0과 프롬프트 해시를 기록한다. [공급자 원출력 번들](../../scripts/textbook/frym-synthetic/evidence/f02-smoke-v1.raw.json)은 응답과 채점의 원래 바이트를 base64로 보존하며, `verify-evidence`가 행별 해시·내용 연결을 검사한다. 각 행은 학생 역할의 시스템·사용자 프롬프트와 모델 설정을 합친 호출 해시, 채점 호출 해시, 공급자 원출력의 SHA-256도 기록한다. seal SHA-256은 `55b46215e7bbc16f6d8ee4f81549041692b1f8476b4e7776880cb6fedeb16031`, 응답 파일 SHA-256은 `6d443914c947b8040e004943a1aea29a1072d76b246d55bb2218003d1d0ffb40`, 원출력 번들 SHA-256은 `d5e324e6cee0144d5ada06db49eed2c502aeaf5afccba13db4b066947a297ec3`이다.

합성 점수 평균은 91.37%(최저 83.33%, 최고 100%; 총 336개 점수 중 1점 279·0.5점 56·0점 1)였다. 중1 프로필의 중1판/고1판 평균은 91.67%/90.48%, 고1 프로필은 89.29%/94.05%였다. 같은 프로필의 고1판−중1판 평균 차는 **+1.79%p**로, 높은 학년판이 더 어려워야 한다는 기대 방향이 나타나지 않았다. 낮은 프로필도 대체로 높은 점수를 얻어 능력 프로필의 분리가 약하고 천장 효과가 크다. 이는 이 한 모델 계열과 한 채점자에서 얻은 진단 결과이며 학생 정답률 추정치가 아니다. 지문 표면 지표도 중1판 200단어·평균 11.11단어/문장, 고1판 196단어·평균 8.91단어/문장으로 단순 문장 길이가 의도한 난도 순서와 일치하지 않았다.

현재 `student N=0`, 합성 **모델 출력 28개**, 독립 응답 모델 계열 **1개**, `gold=0`, `DB seed=0`이다. 자동 seal은 **입력 동일성**만 뜻하며 학년별 절대 난도, IRT 모수, `TARGET_FIT`, `LEVEL_SEPARATION`, Gold-S 또는 seed 자격을 부여하지 않는다. 외부 benchmark에 대한 예측력과 다른 응답 모델 계열의 재현을 확인하기 전까지 판정 상태는 `synthetic_diagnostic_unbenchmarked`다. 전체 CI의 유일한 실패는 별도 워크트리 미추적 화면 3개로 인한 `unreachable-modules` 42/39였고, F02 집중 회귀와 해시 검사는 통과했다.

근거의 적용 범위를 분리했다. [Que et al.](https://aclanthology.org/2026.findings-acl.302/)은 능력별 단일 LLM의 편향을 보고했고, [Acquaye et al.](https://aclanthology.org/2026.findings-acl.1807/)은 **수학 객관식/NAEP**에서 합성 응답 기반 난도 추정 가능성을 시험했다. 이 결과를 F02 영어 독해나 한국 중1·고1의 정답률로 직접 옮기지 않는다. [Olivera-Aguilar et al.](https://aclanthology.org/2026.aimecon-wip.9/)은 합성 자료의 문항 모수 복원이 불충분할 수 있음을 보고했다. 이에 v1에서는 IRT를 계산하지 않고, 향후 외부 기준과 대조한 예측 성능이 확보될 때 별도 revision으로 판정 기준을 정한다.
