### A. 정합 5축 — 파이프라인이 플랫폼과 맞물리는가

| 축 | 묻는 것 | 2점 | 1점 | 0점 |

| **A3 상태 가시성** | 항목이 **어떤 상태로 몇 개** 있는지 화면에서 보이는가 | 항목 × status 매트릭스 | 개수만 | 없다 |
| **A4 실측 정합** | 수치가 DB 실측인가, 그리고 **언제 잰 것인지** 말하는가 | 실측 + 시점 | 캐시·스냅샷이되 시점을 정직히 적음 | 못 읽거나 시점 없음 |

### B. 에이전트 운영 6조건 — 지금 도는 에이전트가 이 단계를 혼자 밀 수 있는가

## 3. A5 역추적 증명 — 교재 한 권을 골라 출고 → 학습자까지 따라간다

**고른 교재: `Vocaflow Vocab Advanced`** (`textbook_volume_renders` 의 `series='vocab'`, `band=5`, `step=5`).

| 단계 | 관찰 | 근거 |
|---|---|---|
| ⑧ 조판 기록 | `band 5 · series vocab · units 20 · items 120 · auto_passed 10/10 · failed_checks NULL · brand_fingerprint 8ded9c49 · rendered_at 2026-09-06` | SQL `select * from textbook_volume_renders` |
| Admin 카탈로그 | 「Vocaflow Vocab 6/6권 · 시장 3」 — 고1 칸이 **「냈음」(초록 점)** | 캡처 `02-catalog@1280.png` |
| Admin ⑧ 조판 화면 | 같은 권이 「규격 최신」 · 「해설 없음 0」 | 캡처 `10-press@1280.png` |
| Admin ⑦ 검수 화면 | 같은 권의 3인 검수 = **1 / 60** | 캡처 `09-review@1280.png` |
| 학습자 매대 | `/library/textbooks` 의 `SeriesTabs` 가 vocab 탭을 **공개 표면에 링크한다**(`SeriesTabs.tsx:21-34`) — 비로그인 접근 가능 | 코드 |
| 학습자 상세면 | `/library/textbooks/vocab/5` → **HTTP 200**. 제목은 「Vocaflow Vocab Advanced」 | `curl` 실측 |
| **그 화면의 목차** | 「Contents 목차 **10단원 · 문항 60 · 약 4시간**」 · 수록 원글 「The Will to Power…」 「USGS Installs Storm-Tide Sensors…」 · 유형 「주장 · 제목 · 주제 · 함축 의미 · 글의 목적 · 장문 · 지칭」 | `curl` 로 받은 HTML 실측 |

**판정 — 어긋남 두 가지가 같은 화면에서 동시에 드러난다.**

1. **학습자가 보는 목차가 다른 시리즈의 것이다.** 조판 기록은 vocab 5단 = **20단원 · 120문항**인데, 화면은 **10단원 · 60문항**에 독해 원글과 독해 유형을 인쇄한다. 원인은 `contentsOf(vLevels)` 가 스냅샷을 **V-Level 키 하나로만** 찾기 때문이다(`volume-contents.ts:152-159`) — 그런데 `volume-contents.json` 은 `generatedAt 2026-09-13` 에 **reading 7권만** 구워져 있다(`volumes` 키 = `1..7`, `title` 전부 `Vocaflow Reading *`). 즉 vocab·syntax 권은 **reading 4단의 목차를 자기 것으로 인쇄한다.**
2. **⑧ 의 게이트가 학습자 경로를 안 지난다.** 조판 기록(`out_path` 로컬 HTML)을 읽는 학습자 코드는 0곳이고, 학습자 매대는 `fetchTextbookShelf`(재고 mv)로 그려진다. 그래서 **3인 검수 1/60 인 권이 「냈음」으로 카탈로그에 서고 공개 URL 로 열린다.**

이 두 가지가 A5 의 PR·RV 0점의 실체다. 한 권을 따라가면 **조판 기록 · 검수 기록 · 학습자 화면이 서로 다른 세 가지를 말한다**.

## 4. 이 점수표가 말하는 한 문장

> 교재 공장은 **재료 두 단계(EV 20 · SR 19)가 거의 만점**이고 **출고 쪽(EX 9 · PR 10)이 바닥**이다.
> 0점 항목 셋(B4 실패 목록 · B5 승인 지점 · B6 상태·사유 필드)은 전부 **「기록을 남기지 않는다」** 는 같은 병이고,
> 그 병이 가장 아픈 곳이 학습자 바로 앞 두 칸(⑦ 검수 · ⑧ 조판·발행)이다.
> 재료 두 단계는 이미 그 병을 고쳐 놓았다 — **재설계는 발명이 아니라 SR 의 모양을 나머지 일곱에 옮기는 일**이다.
