# 소스 확보 정찰 규격 (정본)

목표 표 86개 소스 중 **미확보분의 확보 경로를 정찰**한다. 이 규격은 정찰자마다
다른 것을 조사해 서로 비교가 안 되는 사고를 막는다.

## 이 단계에서 하지 않는 것

- **수확하지 않는다.** 대량 내려받기 금지 — 경로가 있는지만 확인한다(표본 3~5편).
- **DB 에 쓰지 않는다.** 등록부·기사 표를 건드리지 않는다.
- 수확기 스크립트를 짜지 않는다. 어떻게 짤지만 적는다.

## 반드시 답해야 하는 7가지

정찰이 실패하는 방식은 하나다 — **"있는 것 같다" 로 끝나는 것.** 아래 7개는 전부
**실제로 호출해 본 결과**여야 한다. 못 확인했으면 "확인 실패" 라고 적는다(추정 금지).

| # | 항목 | 왜 |
|---|---|---|
| 1 | **대량 접근 경로** | API·OAI-PMH·덤프·사이트맵·RSS 중 무엇인가. 실제 URL 과 호출 예시 1개 |
| 2 | **전문(full text)이 오는가** | 초록만 오면 지문으로 못 쓴다. PLOS 는 전문이 와서 51,465편이 됐고, 초록만 오는 소스는 채택률이 0 에 수렴한다 |
| 3 | **라이선스 — 특히 변형 허용 여부** | ⚠️ **가장 중요.** CC BY·CC0 는 변형 가능. **CC BY-ND 는 변형 금지**(The Conversation 이 ND 다). CC BY-SA 는 변형 가능하나 결과물도 SA 로 전염된다. NC 는 상업 교재에 못 쓴다. 소스마다 **항목별로 다를 수 있으므로** 메타데이터에 라이선스 필드가 오는지 확인 |
| 4 | **안정 식별자** | 중복 방지의 열쇠. DOI·핸들·URL 중 무엇이 항목마다 고정인가. 이것이 없으면 재수확 때마다 같은 글을 다시 판정한다 |
| 5 | **증분 수확 커서** | 날짜 필터·시퀀스·페이지 토큰 중 무엇으로 "지난번 이후" 를 집어내는가. ⚠️ 정렬 없는 페이지네이션은 **중복과 누락을 동시에** 만든다(2026-08-16 IA 실측: 214건 중복·동수 누락) |
| 6 | **현실적 확보 가능 편수** | 목표 표의 추정치가 아니라 **정찰로 센 값**. 검색 결과 총계·OAI 레코드 수 등 근거와 함께 |
| 7 | **지문 적합성 표본 판정** | 표본 3~5편을 실제로 읽고, 300어대 발췌로 잘랐을 때 수능/교재 지문이 되는지. 안 되면 왜 |

## 표본 판정에 쓸 기준

`scripts/csat/gate-article-drain/JUDGING.md` 와 같은 어휘를 쓴다 —
`use`(설명·논증문, 자족적) · `narrative`(시간순 이야기) · `reject`(차단 장르 9종).

## 산출물

`docs/reports/source-probe/<슬러그>.md` 한 파일. 아래 머리말로 시작한다:

```
# <소스명> 확보 정찰

| | |
|---|---|
| 판정 | **채택** / **보류** / **반려** |
| 확보 가능 편수 | 실측 N (근거) |
| 라이선스 | <값> · 변형 **가능/불가** |
| 전문 | 온다 / 초록만 |
| 안정 식별자 | <필드> |
| 증분 커서 | <방법> |
| 정찰 일자 | 2026-09-07 |
```

그 아래에 7항목의 근거를 적고, **마지막에 「수확기를 짠다면」** 절을 둔다 —
어느 기존 스크립트를 본뜨면 되는지(`scripts/csat/harvest-plos.mjs` 가 API 형,
`scripts/textbook/mediawiki-lead-ingest.mjs` 가 위키 형, `scripts/acp/collect-daily.mjs`
가 RSS 형이다), 커서 파일을 어디에 둘지, 몇 번에 나눠 돌릴지.

**판정 기준**: 「반려」는 전문이 안 오거나 · 변형 금지 라이선스거나 · 대량 접근 경로가
없을 때. 「보류」는 경로는 있으나 편수가 100 미만이거나 지문 적합성이 낮을 때.

## 정직함에 대해

**확인 못 한 것을 확인한 것처럼 쓰지 않는다.** 이 저장소는 문서의 수치를 근거로 썼다가
틀린 값으로 결정을 내린 전례가 있다(2026-08-16: `library_books 20` 이라 적혀 있었으나
실제 401). 호출이 막히면 "막혔다" 고, 편수를 못 세면 "못 셌다" 고 적는다 —
그 편이 잘못된 숫자보다 쓸모 있다.

## 정찰 중 걸린 벽 (실측으로 계속 채운다)

- **`WebFetch` 가 403 인데 `curl` 은 통과하는 사이트가 있다.** 2026-09-07 Smithsonian 실측.
  WebFetch 실패를 "접근 불가" 로 적기 전에 `curl` 로 한 번 더 확인할 것 — 이 저장소에는
  `scripts/csat/lib-curl-fetch.mjs` 가 이미 있다. 도구의 한계를 소스의 한계로 적으면
  쓸 수 있는 소스를 잃는다.
- **라이선스는 약관 페이지보다 기사 HTML 의 `rel="license"` 가 빠르고 정확하다.**
  2026-09-07 실측. 약관은 사이트 전체를 두루뭉술하게 말하지만 기사에 박힌 `rel="license"`
  는 **그 기사 하나에 대한 답**이다. 먼저 grep 하고, 없을 때 약관으로 간다.
- **"CC 라고 알려져 있다" 를 믿지 않는다.** 2026-09-07 정찰에서 사전 가설이 **5건 틀렸다** —
  Aeon·Psyche·Quanta 는 ND 가 아니라 **아예 CC 가 아니었고**(건별 유료 계약 $350~650),
  Undark 는 CC BY-ND 가 아니라 자체 지침이었으며, Nieman Lab 은 3.0 이 아니라 4.0 이었다.
  **전부 1차 자료로 확인한다.**
- **봇 차단이 곧 반려다.** 프로그램 접근 경로가 없으면 라이선스가 무엇이든 쓸 수 없다.
  우회를 시도하지 않는다 — "Akamai 봇 차단, 6경로 403" 처럼 **막힌 방식을 적는다**.
- **집계 API 의 라이선스 필드는 「그 사본」의 라이선스가 아니다.** 2026-09-07 PhilSci-Archive 실측:
  OpenAlex `best_oa_location.license` 로 세면 cc-by **1,606편**으로 보이지만, 그것은
  **저널 판본**의 라이선스다. 리포지터리 사본만 골라 세면 114건 중 CC 는 **1건**이었다.
  우리가 내려받는 것은 리포지터리 사본이므로 **그 사본에 붙은 라이선스**를 봐야 한다.
  (OpenAlex·DOAJ·Crossref 는 발견에 쓰고, 권리 판단은 원본 레코드로 한다.)
