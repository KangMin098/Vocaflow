# 기출 원천 부분 근거 유추 등록 — 2026-10-05

사용자 지정에 따라 원작 전체 문단 접근을 등록의 필수 조건에서 제외했다. 접근·미리보기 제한, 시험 편집, 재인용·판본 차이, 원작 검색 단서 부족에 대해 고유 구절·내용 전개·서지 연결로 차이를 설명할 수 있으면 B(`supported_candidate`)로 등록한다. A(`confirmed_exact`) 직접 확인과 구분하고 확인 범위·남은 불확실성을 함께 남긴다.

이 기준은 전체 수능·평가원 모의평가 등록부 713행·802문항에 적용된다. 이번 실행은 이전 심화 회차에서 찾은 수능 보류 단서 및 후보를 재검토한 결과이며, 713행 전체를 새로 검색하거나 개별 재판정했다는 뜻은 아니다. 미확인 사유별 분포도 아직 전량 분류하지 않았다.
