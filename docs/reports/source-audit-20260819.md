## 3. 그룹 2 · The Conversation (CC-BY-ND)

**배선된 피드 4개 중 3개가 엉뚱한 주제를 걷고 있었다.**

주소가 `topics/<슬러그>-<번호>` 형태인데 해소되는 것은 번호이고 슬러그는 장식이다.
그 번호의 주제명이 바뀌자 301 로 다른 곳에 도착했다:

| 배선된 라벨 | 실제로 오던 것 |
|---|---|
| Science + Tech (`science-1391`) | molecular-biology |
| Health + Medicine (`health-39`) | **transport** |
| Politics + Society (`politics-127`) | **nbn**(광대역망) |

기사는 계속 들어오고, 영어이고, 라이선스도 같고, 형식도 맞다. **틀린 것은 "무엇에 관한
글인가" 뿐이라 어떤 자동 검사도 안 울렸다.** 고친 뒤 재수집하니 20건이 전부 "새 것" 으로
나온 것이 직접 증거다.

번호 없는 섹션 경로로 교체했다 — 이름이 곧 주소라 바뀌면 404 로 드러난다.

### ⚠️ 판단이 필요한 지점 — ND 가 단어세트를 막는다

`license_class = 'cc_by_nd'` → `display_only = true` → 발행 트리거가 단어세트를 건너뛴다
(`NOT display_only AND lexical_noise ≤ 0.08` 일 때만 발행).

즉 The Conversation 글은 **읽기 자료로만** 쓰인다. 대기 중인 76건도 마찬가지다.

이 판정은 보수적으로 내려진 것이고, **다시 볼 여지가 있다** — ND 가 금지하는 것은
*2차적 저작물*(각색·번안)이고, 본문을 그대로 두고 **낱말을 뽑아 뜻을 붙이는 것**이
2차적 저작물인지는 다툼의 여지가 있다. 색인·용어집은 통상 원저작물의 개작으로 보지 않는다.

다만 이건 **법적 판단이라 코드가 정할 일이 아니다.** 현재 설정을 유지했고,
바꾸려면 사람이 결정해야 한다. 바뀌면 얻는 것: The Conversation 전량이 읽기 자료에서
전 모듈 학습 자료가 된다(수능 논증문 register — 현재 유일한 argumentative 소스다).

## 6. 다시 재려면

```bash
pnpm dlx tsx scripts/acp/feed-probe.mjs                 # 43개 전부
pnpm dlx tsx scripts/acp/feed-probe.mjs --group voa     # 그룹만
```

피드가 살아 있는지는 **프로브가 실측으로** 보고, 드리프트에 취약한 *형태*인지는
**회귀 테스트가 네트워크 없이** 본다. 두 가지는 다른 질문이라 도구도 다르다.
