궁금한 점이 있으신가요?

기존에 생성한 단어장, 학습 기록, 점수 데이터 모두 그대로 유지됩니다. 업그레이드 즉시 모든 Pro 기능을 사용할 수 있습니다.
PDF, DOCX(Word), TXT 파일을 지원합니다. 파일 크기는 최대 10MB입니다. URL 직접 입력을 통한 웹 본문 추출 기능은 Phase 2에서 추가될 예정입니다.
OpenAI TTS-1 모델을 사용하며 자연스러운 미국식 영어 발음을 제공합니다. 재생 속도는 0.75× ~ 2.0×로 조절 가능하며, 생성된 음성은 캐싱되어 빠르게 재생됩니다.
네, 언제든지 해지할 수 있습니다. 해지 후에도 남은 기간 동안 Pro 기능을 계속 사용할 수 있으며, 기간 만료 후 자동으로 Free 플랜으로 전환됩니다.
현재 웹 버전이 모바일 브라우저에 최적화되어 있습니다. iOS와 Android 네이티브 앱은 개발 중이며, 조만간 출시될 예정입니다.
