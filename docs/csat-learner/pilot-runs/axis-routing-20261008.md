## 1. 계약 — `AXIS_EXAM_EVIDENCE`
| 축 | 기출 관측 특성 | 1위일 때 학생 행동(하나) |
|---|---|---|
| R 문장 관계 · E 근거·선지 | exam_observable | RANKING_GATE 통과 → 그 단계 「먼저 확인」(지금 동작 그대로 · provisional 문구 유지) |
| V 어휘·표현 | exam_assisted | 단독 추천 금지 → **V 와 R/E 를 가르는 구분 확인**. 학생의 틀린 V 문항이 R · E 와 겹친 수(`vOverlap`)로 고른다 — 같으면 V↔R·E 공통 활동, 옛 스냅샷이면 순위 추정이 더 낮은 쪽 |
| X 시간 내 통합 | exam_assisted | 「시간 때문인지 내용 이해 때문인지」 — 시간 제한 없이 다시 풀기 |
| S 문장 이해 | direct_diagnostic | 관찰돼 분명한 1위여도(여러 회 누적) 직접 확인. 다른 행동이 없고, 관찰된 축이 있고, 그중 하나라도 「관찰 높음」 선(0.8) 아래일 때만 **직접 확인** — 모든 학생에게 띄우지 않는다 |
| L 듣기 | out_of_scope | 지금처럼 데이터 없음 |
우선순위: ① verified(아직 없음) ② exam_observable 안정 1위 ③ 불안정 · exam_assisted → 구분 확인 ④ S 직접 확인 ⑤ 기록 · 추가 진단 안내. 순위가 불안정(RANKING_GATE)하면 축 특성과 무관하게 구분 확인.

학생 문구(내부 용어 없음): R/E 「현재 기록에서는 문장 관계를 먼저 확인해 볼게요」 · V↔R 「어휘 때문인지 글의 연결 때문인지 먼저 확인해 볼게요」 · V↔E 「표현을 몰라서인지, 본문과 선지를 연결하다 막힌 것인지 먼저 확인해 볼게요」 · V↔R·E 「어휘 때문인지, 글의 연결이나 선지 판단 때문인지 먼저 확인해 볼게요」 · X 「시간 때문인지 내용 이해 때문인지 먼저 확인해 볼게요」 · S 「문장 자체를 정확히 읽는 힘은 기출 기록만으로 판단하기 어려워요. 짧게 직접 확인해 볼게요」. CTA 는 언제나 하나.
