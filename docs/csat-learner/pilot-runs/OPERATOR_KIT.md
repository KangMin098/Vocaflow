## 2. 학생 안내 · 동의 초안 (§15 — 기관 동의 절차는 별도 확인)

> **영어 오답 원인 기록 시범 운영 안내**
>
> - **무엇을 하나요**: 평가원 영어 시험 2회를 풀고, 틀렸거나 헷갈린 문항에서 「어디서 막혔는지 · 왜 그 답을 골랐는지 · 문장을 어떻게 읽었는지」를 짧게 남깁니다. 필요하면 추가 질문이 1–3개 나옵니다(건너뛸 수 있어요).
> - **왜 하나요**: 오답이 생기는 과정을 이해해 학습 도구를 개선하기 위한 운영 시험입니다.
> - **모으는 것**: 고른 답 · 막힌 곳 · 이유 · 「이렇게 읽었다」는 글(자유서술) · 범주 선택 · 추가 질문 응답 · 시각. 자유서술은 저장되며, 외부에 공개되는 기록에는 원문이 들어가지 않습니다. 분석에 AI 모델을 쓸 때는 이름 · 학교 · 연락처를 지운 뒤 보냅니다.
> - **정답 공개**: 기록을 다 남긴 뒤에 정답 · 해설 · 점수가 열립니다.
> - **그만두기**: 언제든 그만둘 수 있습니다. 그만둔 회차는 운영자가 정리한 뒤 결과를 열어 드립니다.
> - **불이익 없음**: 이 기록은 성적 · 학습 평가에 불이익으로 쓰이지 않습니다.
> - **자유서술에 적지 말 것**: 이름 · 학교 · 반 · 연락처 같은 개인 정보는 적지 말아 주세요.
>
> ☐ 위 내용을 읽고 참여에 동의합니다. (미성년자는 보호자 동의 절차를 기관 안내에 따릅니다.)

## 3. 정해지면 — 한 번에 봉인까지

1. 대응표를 `.pilot-private/participants.txt`(git 이 무시하는 폴더)에 쓴다 — 한 줄에 `P001=<계정 uuid>`.
2. 고정할 커밋에서(작업 트리 깨끗하게):

```
node --tls-max-v1.2 --env-file=apps/web/.env.local scripts/csat/pilot/prepare-run.mjs \
  --run ec-pilot-run-<YYYYMMDD>-1 --exams <시험1>,<시험2> --mapping .pilot-private/participants.txt
```

   대응표 검사 → 식별정보 가드 selftest → production 빌드 · E2E → run 봉인까지 하고, 배포 env 초안을 `.pilot-private/<run id>.env` 에 쓴다(계정 id 를 화면에 출력하지 않는다).
3. 배포 env 설정 · 그 커밋으로 배포 → `start-check.mjs` 전 항목 PASS → G6 시작 승인 요청(채팅에는 익명 key · 시험 ID · 커밋 · run 해시 · E2E · start-check 결과만).
