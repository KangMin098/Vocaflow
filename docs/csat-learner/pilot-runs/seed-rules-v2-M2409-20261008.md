엔진 구조상 **역량 가중치는 연결 여부(> 0)로만 쓰인다**(`map-evidence` attributePoints — 배점 가중 정답률, 가중치는 곱하지 않음). 그래서:

진단 순위 안정성 과제로 따로 기록한다(이번 단위에서 엔진은 고치지 않음): ① 1·2위 차가 작으면 둘 다 「확인 후보」로 같은 무게로 보이기 ② 축 관측 문항 수가 적은 축은 「근거 적음」 표시 ③ 시험 2회 이상 누적 뒤에만 1위 고정.
