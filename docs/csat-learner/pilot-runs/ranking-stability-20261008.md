## 0. 순위 판정 계약(2026-10-08 사용자 승인 — 숫자가 아니라 원칙을 승인)
- **근거 부족**: 최소 관측을 못 채운 축은 순위 경쟁에서 「낮은 능력」으로 읽지 않는다(insufficient — 「기록 더 필요」).
- **안정적 1위**: 근거가 충분하고, 문항 · 태그 하나를 바꾸는 작은 흔들림에도 1위가 유지될 때만 「먼저 확인」의 단일 후보.
- **불안정 · 사실상 동률**: 약점처럼 확정하지 않는다 — 두 후보를 가르는 확인하기 하나.
- **가중치 1/2**: 공식 의미(보조/핵심)가 있어도, binary 대비 안정성 · 설명력이 실제로 좋아진다는 근거가 있을 때만 순위에 반영한다. 2 라서 2배로 세지 않는다.
- **margin 등 숫자(RANKING_GATE)**: 교육적 기준이 아니라 **내부 안정성 기준**이다. 흔들림 · 하나 빼기 결과로 보정하고, 시험 · 검수 데이터가 바뀌면 `ranking-calibrate.mts` 로 다시 잰다.
- **학생 화면**: 언제나 지금 할 행동 하나 — 안정적이면 그 단계 확인, 불안정하면 구분 확인.
- **verified_diagnosis 전**에는 어디까지나 「먼저 확인」 — 약점 확정 · 처방으로 올리지 않는다.

## 1. 0 / 1 / 2 의 계약
| 질문 | 답(코드 · 문서 근거) |
|---|---|
| 원래 의미 | 0 = 이 문항에서 진단 근거로 안 씀 · 1 = 보조 · 2 = 핵심. 관리자 태깅 화면 범례(`TaggingBoard` 「0 없음 · 1 보조 · 2 핵심」) · 검수 RPC 는 0~2 만 받는다(CHECK) |
| 공식 계약인가 | **화면 · 도움말 수준의 계약**이다. DB 주석에는 의미가 없고 마이그레이션 시드는 「초기 추정」이라고만 적었다 |
| 가중하려던 설계 | 있다 — 진단 리포트의 역량 숙달(`rule-v1` `attributeMastery`)은 `가중치 × 감쇠 × 확신 점수` 로 **곱한다**. 리포트의 약한 역량 추천(`recommend`)이 이 값을 쓴다 |
| 모두 같은 의미인가 | 아니다. 리포트 = 가중 · **학습 지도 = 연결 여부만**(`map-evidence` attributePoints: weight > 0 인 문항의 배점 가중 정답률) |
| 지도의 binary 는 의도인가 | **목표율과 단위를 맞추려는 의도**였다(파일 머리 주석: 「목표율이 『반드시 맞혀야 하는 문항』의 배점 비율이라 같은 단위로 비교해야 한다」). 다만 그 값으로 핵심 축 「먼저 확인」 순위를 매길 때 1/2 를 어떻게 다룰지는 정한 적이 없다 — 순위 쪽에서는 **결정되지 않은 채 binary 가 된 것** |
→ 이번 결정: 지도 순위는 binary 유지(아래 §4 비교에서 가중이 낫지 않았다). 1/2 는 **리포트 숙달과 데이터 의미**를 위한 값으로 문서화한다(검수 패킷 Tier 2 표기).

## 2. 1위가 흔들리는 이유(margin 만의 문제가 아니다)
gen-link/binary 1,000명(후보 761) — 조건 없이 1위를 쓰면 「태그 하나 바꾸기 + 문항 하나 빼기」에 안정한 비율 **40.6%**. margin 구간을 올려도 0.2 이상에서 42%, 0.1~0.2 에서 59~68% — **margin 만으로는 안정되지 않는다.**
흔들리는 원인 셋:
1. **동률** — 1·2위 차 0~0.02 구간 안정 0%, 태그 하나로 뒤집히는 비율 평균 14~17%.
2. **선 바로 아래** — 1위가 「관찰 낮음」 선(0.6) 바로 아래면 문항 하나로 후보에서 빠진다.
3. **관측이 최소 관측(5) 바로 위** — 1위 축 관측 문항 0~7개 구간 안정 **0%**(문항 하나 빼면 근거 부족). 8~11개 70~74%.

## 3. 문턱 보정 — 세 조건 격자(margin × headroom × 관측 여유)
| 조건 | gen-link/binary 확정 비율 · 안정 | gen-weight/binary 확정 · 안정 |
|---|---|---|
| 조건 없음 | 100% · 40.6% | 100% · 46.0% |
| margin ≥ 0.05 만 | 73.3% · 52.5% | 80.5% · 56.1% |
| 관측 ≥ 6 만 | 65.3% · 62.2% | 70.5% · 65.3% |
| **margin ≥ 0.05 · headroom ≥ 0.05 · 관측 ≥ 6** | **40.3% · 95.4%** | **48.1% · 93.9%** |
안정 = 모든 문항 하나 빼기에 1위 유지 + 바꿀 수 있는 보조 태그(184가지)의 95% 이상에서 1위 유지. 두 생성기 모두에서 세 조건이 85~95% 를 넘는 가장 넓은 조합으로 수렴했다 → `RANKING_GATE = { margin 0.05, headroom 0.05, minLineN 6 }`.
확정 비율이 40~48% 로 줄어드는 것은 의도다 — 나머지는 「구분 확인」으로 간다(약점을 고르지 않는다).
시드 v1/v2 태그에서 검수안 1위 유지: 조건 없음 54~61% → margin 0.06~0.15 구간 65~85%.

## 4. binary vs weighted(가중치 곱) — 채택 안 함
| | gen-link binary | gen-link weighted | gen-weight binary | gen-weight weighted |
|---|---|---|---|---|
| 정답 축 일치(1위 ∈ 약한 역량의 축) | 66.1% | 64.7% | 64.2% | 67.6% |
| 조건 없이 안정 | 40.6% | 40.8% | 46.0% | 43.6% |
| 게이트 통과 시 안정 | **95.4%** | 89.5% | **93.9%** | 87.6% |
weighted 는 **가중치로 오답을 만든 생성기에서만** 정답 축이 3%p 높고(자기 가정을 맞힌 것), 안정성은 두 생성기 모두 낮다. 축 편향(1위 비율 vs 약한 역량 비율): 두 방식 모두 R · E 가 과소(1위 9~17% vs 약함 33~37%), S · X 가 과대 — 문항이 많은 축(A3 21문항)은 희석되고 적은 축은 출렁인다. 가중으로 풀리지 않는 **관측량 편향**이라 별도 과제로 남긴다.

## 5. 세 상태와 학생 화면(행동 하나 원칙 유지)
| 상태 | 판정 | 학생에게 |
|---|---|---|
| 충분한 근거 + 명확한 1위 | `ranking.kind = clear` | 지금처럼 「{단계} — 확인 시작」 → 그 단계 확인하기 |
| 사실상 동률 · 선 바로 아래 · 관측 적음 | `unstable` (reasons near_tie · near_line · thin_evidence), 경쟁 축 = 관찰값 2위 | 「{A} 때문인지 {B} 때문인지 먼저 확인해 볼게요」 → 확인 시작 → **두 후보를 가르는 활동 하나**(예: V↔S 「막힌 문장의 낱말 뜻을 먼저 확인하고 다시 해석 — 해석되면 어휘·표현, 안 되면 문장 이해」). 두 단계 모두 「먼저 확인」 표시 |
| 근거 부족 | 축 status `insufficient` — 순위 · 경쟁 축에 들어오지 않는다 | 그 단계는 「기록 더 필요」. 「문제 없음」으로 읽지 않는다. 시드에 태그를 더해 관측을 맞추지 않는다 |
구분 활동은 듣기를 뺀 축 쌍마다 하나(V·S·R·E 6쌍 + X↔각 축 「시간 제한 없이 다시 풀기」). 지도 과제(DB)가 아니라 코드 정의라 완료 기록은 없다 — 저장이 필요해지면 과제 행을 승인받아 더한다.

## 7. 답(완료 판정 질문)
1. **언제 1위를 믿나** — 1·2위 차 ≥ 0.05, 1위가 관찰 낮음 선보다 ≥ 0.05 아래, 1위 축 라인마다 관측 ≥ 6.
2. **언제 확정하면 안 되나** — 셋 중 하나라도 어긋날 때(태그 하나 · 문항 하나에 뒤집히는 영역).
3. **근거 부족 vs 동률** — 근거 부족은 축에 관찰값이 없음(순위 밖 · 「기록 더 필요」). 동률은 두 축 모두 관찰값이 있고 차가 작음(구분 확인).
4. **그때 학생에게** — 두 후보를 가르는 확인 활동 하나(CTA 하나).
5. **1/2 의 의미** — 진단 리포트 역량 숙달에서는 가중치(곱함), 학습 지도에서는 연결 여부만. 지도 추천을 바꾸는 것은 0 ↔ 1 이상(Tier 3)뿐이다.
