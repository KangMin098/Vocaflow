# LM-G1.4 — 승인 대기 정책(미적용)

> 지금 계약으로 **정할 수 없어서** 화면이 「아직 근거 없음 · UNKNOWN」으로 두는 것들이다. SQL · 정책은 적용하지 않았다.

| # | 항목 | 지금 | 정해야 하는 것 |
|---|---|---|---|
| P1 | 지연 유지 간격 | NOT_ESTABLISHED 고정 | 최소 간격(예: 7일 · 21일), 지연 확인 전용 문항(미노출 · 다른 원문), 사이 학습 허용 여부, 120일 만료와의 관계 |
| P2 | 루브릭 · 정책 버전 | 원장에 열 없음 → UNKNOWN | 시도 행에 rubric/policy 버전을 남길지(열 추가 = 마이그레이션 승인), 옛 행 처리 |
| P3 | 전문가 루브릭 검수(R3) | 주석 자동 채점만 | 검수 표본 · 일치 기준 · 검수 전 주장 한계 |
| P4 | C2(적용 독립성) | 적용은 「경험」만 | 적용 수행에서 독립 · 도움 구분을 확인 근거로 쓸지 |
| P5 | G(일반화) | 관찰하지 않음 | 다른 유형으로의 전이를 어떤 과제로 볼지 |
| P6 | 새 단계(delay 등) | 없음 | 원장 `phase` 값 추가 여부 · 계획/지도 상의 위치 |
| P7 | 같은 지문 다른 문항 | 기존 문항 집계 유지·실제 포함 문항 수 표시. 별개 글의 독립 관찰로 해석하지 않음 | skillDiagnosis 의 독립 문항 수에서 뺄지(지금 판정 변경 금지라 그대로) |

승인 전에는 이 항목으로 숙달 · 유지 · 효과를 주장하지 않는다.
