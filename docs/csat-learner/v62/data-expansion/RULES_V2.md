# 문항↔TASK 판정 규칙 v2 (제안 · Codex 검증 전)

> 근거: map-data-pilot-1 의 갈림 177쌍을 눈으로 읽은 결과(README §3). 갈림은 무작위가 아니라 **경계 정의 공백**이었다.
> TASK 정의(codebook.json)는 바꾸지 않는다 — 이 규칙은 분석 계약(ANALYST_CONTRACT §1)에 덧붙는 판정 절차다.
> 상태: **제안**. 제3 판정 실측(§6)으로 효과를 재고, Codex 독립 검증 후 계약 v2 로 확정한다. 확정 전에는 확대 배치에 쓰지 않는다(R5 · R6 확대는 v1 그대로 — 두 TASK 는 v1 에서 κ ≥ .85).

## 1. direct · indirect 공통 판정 절차

1. `decision_path` 의 **결정 지점**(정답과 가장 강한 오답을 가르는 원문 위치)을 먼저 고정한다.
2. 문항을 푸는 **한 실제 판단 경로**에서 그 수행이 결정 지점의 판단 자체를 하는가?(연구 v1.4 정의 그대로 — 다른 경로가 있는지는 묻지 않는다. Codex P1 ①로 「다른 경로가 남는가」 반사실 기준을 철회했다)
   - 결정 지점에서 쓰인다 → `direct`(서로 다른 경로가 각각 다른 TASK 를 결정적으로 쓰면 둘 다 direct)
   - 결정 지점 **앞** 단계(전제 · 범위 좁히기)로만 쓰인다 → `indirect`
   - 경로 어디에도 쓰이지 않는다 → `not_applicable`
3. 문항 유형 이름 · 연결어나 낱말의 **존재**만으로는 2 의 어느 칸도 정하지 않는다.

## 2. TASK별 경계

| TASK | direct 조건 | indirect 조건 | 갈림 사례(표본) |
|---|---|---|---|
| E2 근거 찾기 | 정답을 가르는 근거를 **경쟁 후보(문장 · 구절 · 표시 후보) 사이에서 특정**해야 한다 — 거리와 무관(같은 문장 안이어도) | 근거 위치가 발문 · 소제목 · 표시로 이미 지정되어 특정 판단이 없다 | Codex P1 ③: 거리 기준은 §1 결정성과 충돌해 철회. 2026#38·39 가 거리 해석으로 갈렸다 |
| R2 인접 문장 관계 | 두 인접 문장의 관계(인과 · 대조 · 예시 · 환언) 판단이 정답을 가른다 — 순서 · 삽입 · 무관한 문장 · 연결어 빈칸 | 관계가 위치 · 범위를 좁히지만 정답은 다른 데서 갈린다 | Therefore · Suddenly 가 있기만 한 목적 · 심경 문항 → not_applicable 또는 indirect |

## 3. 통합 TASK · 발문 요구(E1) — 문항 단위 판정 범위

선택형 응답 하나로는 **통합 수행(S-O1 · R-O1 · E-O1)과 발문 요구 해석(E1)이 고유하게 쓰였는지 관찰할 수 없다**. 표본에서 한쪽은 늘 무관, 다른 쪽은 늘 간접을 써 κ ≤ .18 이었다.

- 기본값: `unknown` — why 는 `integrated_not_item_level` 또는 `task_demand_not_item_level` 로 시작한다(무관이 아니다 → `relevance.ts` 계약상 unknown 은 not_applicable 이 아니다).
- 예외(그때만 판정):
  - **E1** `direct`: 발문이 비표준 요구를 담는다 — 「일치하지 **않는**」「변화」「두 조건 동시」「밑줄 친 것 중 쓰임이 다른」 등, 그 요구를 놓치면 다른 선지가 정답처럼 보인다(그 오답 번호를 why 에 적는다).
  - **R-O1** `indirect`: 장문 세트(41–42 · 43–45)처럼 여러 단락의 의미 통합이 결정 지점에 쓰인다.
  - **S-O1** · **E-O1**: 예외 없음 — 직접 확인 도구(창작 세트 · 서술 응답)로만 다룬다.

## 4. 시각 자료 의존 문항

도표 · 그림이 입력에 없으면 그 자료에 기대는 TASK 는 `unknown`(why `visual_missing`), `independent_assessment = not_suitable`.

## 5. 이 규칙이 하지 않는 것

- 학습자 결손 · 숙달 판정, NeedRank 입력, 사람 검수 대체.
- 기존 연구 v1.4 의 direct 정의(한 실제 판단 경로의 고유 수행)를 넓히지 않는다 — §1 은 그 정의를 결정 지점 기준으로 조작화한 것이다.

## 6. 검증 계획(실측)

- 제3 판정: 갈림 177쌍을 원문 + 이 규칙만 받은 새 판정자가 다시 판정(A · B 판정은 보지 않음).
- 지표: TASK별 제3 판정 ↔ A · B 각각의 일치, 규칙이 정한 기본값(§3) 적용 비율.
- 통과 기준: 규칙 대상 TASK 의 제3 판정이 A 또는 B 와 같은 비율이 아니라, **새 A/B 재판정(규칙 v2) 일치 κ ≥ .85** — 제3 판정은 효과 신호일 뿐 확정 근거가 아니다.
- Codex 검증 질문: (1) §1 조작화가 v1.4 direct 정의와 충돌하는가 (2) §3 기본값 unknown 이 목표 관련도 계산에서 TASK 를 조용히 지우는가(정본 §445) (3) E2 · R2 경계 반례.

## 8. 판정자들이 보고한 모호점 (v3 입력)

1. E1 「비표준」 범위 — 「어법상 틀린」「적절하지 않은」「관계 없는」은 유형의 표준 문구이기도 하다. 두 빈칸 요약을 「두 조건 동시」로 볼지. 지문 안 부정(「cannot be ___」)은 대상인지.
2. E2 「인접」 — 바로 다음 문장 포함 여부, 소제목이 근거를 가리키는 안내문, 표시가 없는 주제 · 요지 · 제목 문항, 선지 자체가 지문 문장인 순서 · 삽입 · 무관 문항.
3. V1 — 선지 낱말(감정 형용사 · 빈칸 선지)이 「결정 지점」에 드는가.
4. R2 ↔ R4 — 순서 문항에서 둘 다 direct 조건을 만족, 하나만 고를 규칙 없음(복수 direct 허용인지 명시 필요).
5. V4 — 한글 선지 대응이 번역인지 환언인지, E2 · R2 · E3 와 함께 결정할 때의 우선순위, 빈칸의 의미 대응이 V4 인지 R6 인지.
6. R-O1 — 장문 세트 소속만으로 indirect 인가, 결정 지점이 지역적이면 unknown 인가.
7. **빈칸의 R5 ↔ R6 귀속**(교차 모델 T-0101): 정답 의미가 본문에 재진술되어 있으면 Codex 는 R5(중심 압축) · R6 무관, Claude 는 R6 direct — R1 R6 direct 6/19 가 여기서 뒤집혔다. 제안: R6 direct 는 「정답 의미가 본문 어디에도 진술 · 재진술되지 않아 함의를 도출해야 할 때」만, 재진술이면 R6 not_applicable · R5 또는 E3 로 본다(정의 「쓰이지 않은 의미를 도출」에 맞춤).
