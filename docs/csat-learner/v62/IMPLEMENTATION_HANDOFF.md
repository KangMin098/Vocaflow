# Vocaflow 학습지도 v6.2 — Claude Code·Codex 실행 핸드오프

> **정본:** `Vocaflow_CSAT_Learning_Map_v6_2_CANON.md` (2026-10-14). 이 문서만 읽고 작업하지 말고 반드시 정본과 최신 `main`·v1.2 연구 원장을 함께 읽을 것.  
> **이 문서는 지시서이며 구현 결과 보고가 아니다.** DB·스키마·기존 사용자 데이터 변경은 기존 승인 정책을 준수한다.

## 0. 최상위 목표

학평·모평·수능 영어 기출을 학습하는 사용자를 위한 **단일 영역·TASK 관계도 학습지도**를 실제 제품에서 구축한다. 30개 영구 TASK의 의미·판정·교수·콘텐츠·계획·이력을 보존한다. v1.2 연구의 자동 기출-TASK 후보를 검증된 능력 판정으로 승격하지 않는다.

완료 여정: **전체 교육 지도 보기 → 목표/시험기록 확인 → TASK 선택 → 실제 기출의 출제·근거·정답·오답 분석 → 학습방법/교재/계획 → FIND/REPAIR/TRANSFER/CHECK → 동일 TASK 복귀 → 근거 기반 지도·PLAN 갱신**.

## 1. 공통 작업 시작 순서

1. 최신 `origin/main`, 진행 중 PR/타 워크트리, 교육 정본 버전, `AGENTS.md`와 기존 AUTO_CONTINUE 정책 확인.
2. 메인 브랜치를 강제 수정하지 않고 소유 브랜치·워크트리에서 독립 작업.
3. v6.2 정본과 `docs/csat-learner/v4/{codebook,relations,workspaces}.json`, `docs/research/csat-reading/V12-{REPORT,D,E,F,G,H,I,J...}`를 함께 읽음(연구 자료가 main에 없다면 `research/csat-reading-20261012`의 **검증된 HEAD**를 읽기 전용으로 참조).
4. 바뀐 정의·UI·데이터 계약의 영향/승격 금지/원장 보존을 작업 목적에 적음.
5. 한 게이트를 **구현→단위/통합/브라우저 회귀→문서→커밋/push→PR/CI→정책상 허용된 safe-merge**로 닫되 사소한 단계마다 멈추지 않음.
6. DB 구조/이전 데이터 삭제가 필요하면 SQL·영향·체크포인트·롤백을 별도 제시하고 승인 전 실행하지 않음.
