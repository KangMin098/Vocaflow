## 1. 무엇이 생겼나

TASK Inspector 「기출과 출제 논리」 안에 **「기출 해부로 공부하기 — 출제 의도 · 정답 · 오답 설계」**.
링크는 기존 공개 v3 문항 해설 화면(`/csat/item/<slug>`)으로 가고, 복귀 문맥(`map_task` · `ws` · 버전)을 실어 같은 TASK 로 돌아온다. 새 해설 콘텐츠를 만들지 않았다.

| 열어도 되는 문항 | 근거 |
|---|---|
| 이 TASK 의 확인 문항 중 **이미 풀어 본** 것 | 독립 확인 근거는 이미 남았다 — 이제 해설을 봐도 그 근거를 해치지 않는다 |
| 연구 v1.4 에서 AI 두 명이 같은 판정(직접 · 간접)을 낸 문항 중 **확인 · 전이 묶음 밖** | 「연구 사례 · 사람 검수 전」으로 표시(R1) |

| 열지 않는 문항 | 이유 |
|---|---|
| 아직 안 푼 확인 문항 · 다른 글 적용(전이) 문항 | 해설을 먼저 보면 독립 확인 · 전이로 쓸 수 없다 — 링크를 만들지 않고 보류 수만 보인다 |

규칙은 `lib/csat/map/v62/study-items.ts`(순수 함수 · 단위 테스트). 문항 화면의 Reveal/Embargo · 권리 게이트는 그대로 적용된다.

## 2. 확인 모드 정답 선노출 검사

로그인 상태로 확인 모드(`?check=1`)의 서버 HTML 과 Flight(RSC) 응답을 받아, 같은 문항 일반 화면 데이터의 정답 근거 · 오답 거르기 문구(문항당 7~9개)가 들어 있는지 대조했다.

| 문항 | 해설 문구 | 확인 모드 HTML | 확인 모드 Flight | 정답 앵커 |
|---|---|---|---|---|
| 2022-20 | 7 | 0 | 0 | 없음 |
| 2026-22 | 9 | 0 | 0 | 없음 |
| 2026-31 | 7 | 0 | 0 | 없음 |

확인 패널은 문장 수 · 과제 키만 받는다(정답 · 근거 위치는 채점 API 에서만). **`?check=1` 은 화면에서 해설을 빼는 장치일 뿐 독립성 자격 자체가 아니다** — 자격은 여전히 첫 시도 원장의 도움 · 해설 · 시각 조건이 정한다(기존 규칙 그대로).

## 3. 실제 브라우저 E2E(`scripts/csat/map/v62/e2e-map-study.mjs` — ALL PASS 6)

1. 처음엔 안 푼 확인 문항 해부 링크 없음 · 다음 확인 문항도 링크에 없음(보류 안내만)
2. 확인 문항 하나 풀이 저장
3. 그 문항만 「이미 풀어 본 확인 문항」으로 열림 · 나머지 12개는 계속 보류
4. 해부 링크 = 해설 화면(확인 모드 아님) · 복귀 문맥 실림 · 「학습 지도로」 → 같은 TASK
5. 해설 · 연구 근거를 연 것만으로 근거 상태 · 학습 요구 불변
6. E3 도 같은 규칙

연구 사례 16개 문항은 로그인 상태에서 모두 실제 해설 화면으로 열린다(2014A · 2014B 회차 포함).
