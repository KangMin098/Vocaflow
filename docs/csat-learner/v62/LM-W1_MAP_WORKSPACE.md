### 상호작용

- **초점(3B 와 같이)**: 처음엔 초점 없음(모든 노드 선명). 노드 · Workspace 를 고르면 초점이 켜지고, Esc · 요약 알약 ✕ 로 끈다. 초점은 주소(`map_task` · `ws`)에 있을 때만 남는다 — 고르지 않은 화면을 새로 고쳐도 초점이 저절로 켜지지 않는다.
- **TASK → Workspace**: 노드를 한 번 누르면 초점(관련만 선명) + 요약 알약, 다시 누르거나 ⋮ 를 누르면 빠른 팝업(지금 근거 · 목표까지 · 이번 단계 · 연결 Workspace(중심/지원) · 다음 행동 · 자세한 근거). 리스트에서 그 TASK 를 담은 행이 중심 = 초록 면 + 「중심 연결」, 지원 = 옅은 면 + 「지원 연결」. 다른 행은 그대로 남는다. 담은 Workspace 가 없으면 리스트 머리에 「… 를 다루는 Workspace 는 아직 없어요」.
- **Workspace → TASK**: 행을 누르면 지도에서 중심 TASK = 초록 면 + 진한 왼쪽 띠, 지원 = 파란 왼쪽 띠, 나머지는 흐림 + 약한 블러(숨기지 않음 · 마우스를 올리면 선명), 그 Workspace 안 TASK 끼리 관계선만 진하게. 목표 · 진단 상태는 바뀌지 않는다.
- **선택 규칙(한 곳 · 고정점)**: TASK 를 고르면 지금 Workspace 가 그 TASK 를 담으면 그대로, 아니면 중심 Workspace. Workspace 를 고르면 지금 TASK 가 담기면 그대로, 아니면 첫 중심 TASK. 왕복해도 같은 곳(단위 시험 · 브라우저 W08).
- **문맥 보존**: 고른 `map_task` · `ws` 를 주소에 replaceState — 새로 고침 · 뒤로가기 그대로. 학습 뒤 「학습 지도로」(저장 계획 문맥 `ws` + `map_plan`)는 그 묶음의 계획 탭을 다시 연다(옛 「계획 열림」 복귀 계약). 일회성 문맥(`map_ws` · `map_plan` · `map_goal`)은 처음 그릴 때 쓰고 주소에서 지운다(새로 고침마다 모달이 다시 뜨지 않게).
- **팝업 접근성**: 빠른 팝업 = 비모달(`role=dialog aria-modal=false`) · 화면 안으로 위치 맞춤 · Esc/✕ → 연 노드로 포커스. 모달 · 드로어 = `aria-modal` · 포커스 가둠/복원 · Esc · 바깥 누르기 · 배경 스크롤 잠금. 동작 줄이기 설정에서는 이동 없이 페이드만.
