## 3. 바꾼 것

**2층 「지금 무엇부터」(`FocusStrip`)** — 목표 · 기록 바로 아래. `ranksOf` 결과만 그린다(새 판정 없음).
- 상태별 첫 문장: 목표 없음(「목표를 정하면 먼저 볼 TASK 가 정해져요」) · **기록 없음(「아직 무엇이 부족한지 정하지 않았어요 — 약점으로 정한 것은 없어요」 · 「기출 한 회 기록하기」 가 주 행동)** · 준비됨(「목표까지 이 순서로 확인 · 학습해요 — 실력 점수 · 약점 확정 아님」) · 이어 할 활동 없음.
- 카드 1~3 = ActionRank 순서: 번호 · TASK · **왜**(NeedRank 요구 + 「확정 아님」) · **지금**(근거 상태) · **다음 행동**(복귀 문맥 `map_task` · `from=map` 실림). 화면의 진한 버튼은 하나(준비됨: 1번 카드 / 기록 없음: 기록하기).
- 「필요하지만 지금은 할 수 없는 TASK n개」(접힘) — 각각 이유(확인 자료 준비 중 · 측정 방법 정하는 중 · 연결 확인 전 …)와 함께, 누르면 지도에서 그 TASK 를 연다. 학생의 부족이 아니라 준비 상태라고 말한다.

**Inspector 기본 / 근거 분리** — 지우지 않고 순서 · 접힘만:
`현재와 목표(지금 근거 · 목표까지 · 다 했다고 보는 기준)` → `학습 경로 · 필요한 자료(확인 · 바로잡기 · 다른 글에 적용 · 다시 확인 · 계획 수행량 → 이 TASK 에 필요한 자료 · 준비 상태 → 기출 해부로 공부하기)` → `자세한 근거 — 기출 · 출제 논리 · 연구(접힘)` → `결과와 개선 · 지원 상태(접힘)`.

학습량: 정량은 기존 계획 값만(계획 문항 · 수행 · 남음 — 「실력 점수 아님」), 정성은 TASK 의 「다 했다고 보는 기준」. 계획량을 목표 달성 보장량으로 쓰지 않는다.
콘텐츠: 공급 단계는 P-F8e 그대로 — 실제 주문 · 납품 기록이 없으면 「주문됨 · 공급 완료」 0, V2 · S5 는 수요를 숨기지 않고 「준비 중」, 공장 재고 · 테스트 교재를 「지금 학습」 으로 올리지 않는다.
