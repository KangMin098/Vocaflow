## 2. 회귀 발견 · 수정 — 문항 화면 확인 모드

PR #211(다른 세션 · F01 2026-10-10)이 「문항을 열면 해설을 바로 보여 주므로 그 열람을 해설 먼저 봄(viewed_first)으로 남긴다」로 바꿨다. 원칙은 옳지만 학습 지도의 확인 · 다시 확인 링크가 바로 그 화면이라, **그 뒤 모든 학습자의 확인 문항 풀이가 독립 근거에서 빠져 확정 · 해소가 불가능**했다(실측: 9문항 모두 timing_uncertain / viewed_first).
수정: 지도에서 들어오는 확인 링크만 `?check=1` — 해설 극장 · 강의를 그리지 않고 확인 과제만 보인다(해설 열람 기록 없음). 과제 뒤 「해설 보기」는 일반 화면(F01 그대로). 일반 진입은 바뀌지 않는다.

## 3. 전이 일반화(P0-2 일부)

- 문항 화면 풀이는 적용 대상 조건 `role: "transfer"` 이면 `phase: 'transfer'` 로 기록(직접 확인 근거에 섞이지 않음).
- 「다른 글에 적용」 링크를 모든 과제로 — 주장과 근거는 연습 화면, 다른 과제는 role=transfer 로 출시된 문항의 문항 화면(확인 모드). 확인 묶음과 전이 문항은 같은 문항을 공유하지 않는다(5차 가드 + 이 경로).
