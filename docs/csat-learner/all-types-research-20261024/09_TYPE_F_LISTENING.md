# 09 · TYPE F — 듣기 전 유형 (청취 평가·오디오 교수설계)

> 작성 2026-10-24 · 역할: 듣기 평가·오디오 교수설계 연구 에이전트 · **읽기 전용 조사 결과**(저장소·DB·다른 worktree 수정 없음, DB는 SELECT 1회).
> 출제자 의도는 모두 **가설**이다. 원음·전사·선택지·정답은 확보된 것만 인용하고, 없으면 `DATA_GAP`, 확인 못 한 것은 `NOT_VERIFIED`.

**추가로 드러난 사실 (주장에 없던 것)**

1. **분류 이상치**: `2014A#21` 이 `L-PURPOSE` 로 분류되어 있다. 2014 형식에서 21번은 세트 1번 위치(2014B#21 = L-SET-TOPIC)라 **세트 주제 문항의 오분류 가능성** — `NOT_VERIFIED`(발문 정규식 히트만으로 결정됨, `hit_count` 기반).
2. **전사(대본) 자료는 별도 집합**: `scripts/csat/data/listening-all.json` = **272문항 / 16회**(수능 2017~2023 7회 + 모평 M1906·M1909·M2109·M2206·M2209·M2306·M2309·M2406·M2409 9회). 필드: `exam,no,stem,turns[{who,text}],script,words,nTurns,speakers,isDialogue,typeGuess,typeGuessAll`. **선택지·정답·시간 코드·음원 경로 필드는 없다.**
3. 248 분류 집합과 272 전사 집합의 **교집합 = 119문항**(2017~2023 수능 7회 × 17). 발문으로 대조해 번호가 일치함을 표본(2017#1·#3·#13) 확인. **2014~2016, 2024~2026 수능 듣기 129문항은 대본 미확보 = `DATA_GAP`**. `L-TOPIC`·`L-MAIN`·`L-MENTIONED` 는 대본 표본 **0**.
4. 사람 승인 유형 정본 `scripts/csat/map/source/listening-approved.json`(2026-10-02): **6회 × 17 = 102** 문항(M2706, 2026, M2609, M2606, 2025, M2509), `verifiedType` 14종(목적·의견·요지·그림 내용 불일치·할 일·지불 금액·이유·언급되지 않은 내용·담화 내용 불일치·도표 선택·대화 응답·상황에 적절한 말·세트 주제·세트 언급되지 않은 내용), `scope:"명시된 6회만"`. 이 파일은 sha256 만 갖고 **대본·음원 본문은 없다**. 승인 14종 ≠ 분류 18종 ≠ `listening-all.typeGuess` 17종 — **세 분류를 같은 목록으로 취급하지 않는다**(v6.0 AT23).
5. `listening-measure.json`: 번호별 평균 어절·턴(예: 1번 94어절/1턴, 11~12번 ≈53어절/3~4턴, 13~14번 ≈132어절/12~13턴, 16~17번 164어절/1턴), 회당 듣기 평균 ≈2,067어절. **대본 기반 측정이며 원음 길이(초)는 없다.**
6. **원음 파일 0**: `apps/web/public/audio` 는 `games`·`sfx` 뿐. 원음 경로·권리(평가원 음원 이용 허락)·공개 범위 자료는 저장소에서 발견되지 않음 → 전 유형 `DATA_GAP(AUDIO)`·`DATA_GAP(RIGHTS)`.
7. **선택지·정답 0**: 248 분류 행은 발문만(`stem`), 272 전사 행도 선택지 없음. `corpus-sync.mjs` 주석: 평가원 "정답표 PDF 가 실제로는 듣기 대본" 인 회차가 있다. → 전 유형 **7번(공식 정답)·8번(오답 근거)은 `DATA_GAP`**. 정답을 추정·생성하지 않는다.

## 1. 공통 계약 — 원음 · 전사 · 구간 · 근거 결속 (모든 유형에 적용)

### 1-1. 자료 층과 정체성
| 층 | 정체 | 현재 상태 |
|---|---|---|
| A. 평가 원음 (`exam_audio`) | 회차 단위 원본 mp3 + sha256 + 출처 URL + 권리 상태 | **DATA_GAP** |
| B. 문항 구간 (`item_audio_range`) | A 위에서 `[start_ms,end_ms]`, 문항 지시문 낭독 구간과 대화 본문 구간을 분리 | **DATA_GAP** (정렬 도구 없음) |
| C. 전사 (`transcript_turn`) | `exam,no,turn_idx,who,text` — `listening-all.json.turns` 가 원천 후보 | 119/248 확보, **검수 상태 NOT_VERIFIED**(PDF 추출, 사람 대조 기록 없음). `who:'?'` 지문(예: `[Telephone rings.]`) 존재 |
| D. 턴 구간 (`turn_audio_range`) | C 각 턴 ↔ B 내부 시간 구간 | **DATA_GAP** (강제 정렬 필요) |
| E. 근거 (`evidence`) | 선택지/정답 ↔ D(턴+시간)·이미지 영역·표 셀·수치 | 선택지·정답 부재로 **DATA_GAP** |
| F. 강의 TTS (`lecture cue`) | `est_sec`/`total_sec_est` 추정치, 설명 음성 | 코드 존재(독해용). 듣기 cue 0 |

**결속 키**: `exam_id + item_no + transcript_sha256 + audio_sha256`. 전사 또는 음원이 바뀌면 E 는 무효(재검증). 2014A/B 는 `listening_end=22` 로 18~22번이 듣기 — 번호 상한을 17로 하드코딩하지 않는다.

### 1-2. 원음 vs 설명 TTS 분리 규칙
- **평가 원음은 시험 재현 조건**(1회 청취·정속·지시문 포함 — 실제 수능은 11~17번 등 일부 2회 방송 관행이 있다는 일반 지식이 있으나 이 저장소에서 문항별 방송 횟수 자료는 **NOT_VERIFIED**).
- **강의 TTS 는 설명 채널**이다. 같은 화면에서 동시에 재생하지 않는다(상호 배타 재생 + 시각적 구분: 원음 = "시험 음성" 라벨/파형, TTS = "해설" 라벨).
- **원음이 없을 때 TTS 로 대본을 읽어 "원음 대용"으로 쓰지 않는다.** 그렇게 하면 화자 성별·억양·속도·잡음 조건이 바뀌어 평가 조건이 아니다. 대본 TTS 를 만든다면 "합성 재낭독 — 시험 음성 아님" 고지 + 숙달 산입 금지가 최소 조건(가설적 설계, 결정 아님).
- `est_sec` 는 TTS 추정 시간이다. 원음 구간 시간과 같은 필드에 섞지 않는다.

### 1-3. 듣기 / 다시 듣기 / 전사 확인의 교수 역할 (공통)
| 단계 | 역할 | 기록 |
|---|---|---|
| 1차 청취(전사 숨김) | 시험 조건 인출 — 판단을 먼저 고정 | 선택 + 확신도(닫힌 열거형) |
| 근거 구간 지목 | "어느 순간에 결정했나"를 학습자가 시간축/턴 위치로 표시 | 지목 턴 idx(전사 공개 전엔 시간 위치) |
| 표적 재청취 | 지목 구간만 재생 — 전체 재청취보다 판단 근거를 좁힘 | 재청취 구간 수 |
| 전사 확인 | 들은 것 vs 실제 텍스트 대조(지각 실패 vs 판단 실패 분리) | 불일치 턴 표시 |
| 해설 TTS | 판단 규칙 설명 — 원음 재생과 분리 | — |

- **지각 실패**(단어/숫자 못 들음) vs **판단 실패**(들었지만 조건 잘못 적용)를 분리하는 것이 듣기 피드백의 핵심 가설. 전사 확인 후에 "들었다/못 들었다" 자기보고는 숙달에 산입하지 않는다(정책: 탐색·클릭 숙달 산입 금지).
- 자유서술 평가 없음 — 모든 학습자 행동은 선택·지목·대조형.

## 3. 묶음별 17항목

> 1·7·8·15 항목은 유형별로 따로 적는다. 나머지는 묶음 공통 + 유형 차이.

### F1 담화 핵심 — L-PURPOSE · L-OPINION · L-MAIN · L-TOPIC

1. **실제 ID·출처** (classified.json; (T)=listening-all 대본 있음)
   - L-PURPOSE 15: 2014B#4, 2014A#5, 2015#3, …, 2017#3(T), 2018#3(T), 2026#1. 대본 7. 이상치 2014A#21(NOT_VERIFIED). 전사 예: 2023#1 "Hello, Lockwood High School students… bookmark design competition…" 1턴 101어절.
   - L-OPINION 13: 2014B#7, 2014A#8, 2016#4, 2017#4(T), 2018#4(T), 2026#2. 대본 7.
   - L-MAIN 3: 2024#3, 2025#3, 2026#3. **대본 0**.
   - L-TOPIC 5: 2014B#5, 2014B#6, 2014A#6, 2014A#7, 2015#4. **대본 0**.
2. **발문 요구**: "하는 말의 목적"(1인 담화) / "의견"(대화, 특정 화자) / "요지" / "주제". 
3. **학습자 목표**: 전체를 다 듣기 전 성급히 고정하지 않고, 반복·전환 신호로 중심 명제를 확정한다.
4. **사고 기술**: 화행 식별, 반복 개념 추적, 도입부(배경) vs 핵심(요청·주장) 구분, 화자 귀속.
5. **관찰 대상**: 담화 표지(So/That's why/I'd like to/make sure), 반복 명사구, 명령·권유문, 의견 대화에서 상대 반박 후 재진술.
6. **추론 연쇄**: 도입 맥락 → 전환 표지 → 요청/주장 문장 → 반복으로 확증 → 세부(날짜·상품)는 기각.
7. **공식 정답·근거**: **DATA_GAP**(선택지·정답 미확보). 출제 의도 가설: 도입부 화제와 실제 목적을 다르게 두어 첫 문장 고정을 변별.
8. **오답 실패 유형(가설)**: 도입 화제 선택 / 세부 정보를 목적으로 격상 / (의견) 상대 화자 의견 귀속. **근거 범위**: 전사 턴 단위로만 지목 가능(시간축 DATA_GAP). 선택지 부재로 실제 오답 텍스트 대조 불가.
9. **학습자 행동**: 1차 청취 후 선택 → "결정한 순간" 턴 지목 → 표적 재청취 → 전사에서 전환 표지 위치 확인.
10. **시각/오디오 구조**: 턴 타임라인(단일 화자는 문장 단위 세그먼트), 도입/전환/핵심 3구간 표시는 **학습자 지목 뒤**에만 공개.
11. **강의 턴**: ① 발문에서 화자·담화형태 확인 ② 도입부 재생 후 "아직 목적 아님" ③ 전환 구간 재생 ④ 핵심 문장 + 반복 확인 ⑤ 오답 유형 대비(선택지 확보 시).
12. **피드백·오개념**: "첫 문장=목적" 오개념, "많이 나온 단어=주제" 오개념(빈도 ≠ 중심). 지각 실패(전환 표지 못 들음) vs 판단 실패 분리.
13. **원리 조건·한계**: 전환 표지가 없는 담화에는 "표지 찾기" 규칙이 성립 안 함 — 반복 규칙으로 대체. 대본 0인 MAIN·TOPIC 에는 원리 검증 불가.
14. **비교 가능성**: 독해 목적·요지·주제 유형과 판단 기능 동일 가설 → **매체만 다름**(선형 1회성). 독해 교수 모델 재사용 여부 비교 대상이나, 되돌아보기 불가라는 조건 차이가 있다.
15. **자료·공백**: 대본 PURPOSE 7/15, OPINION 7/13, MAIN 0/3, TOPIC 0/5. 원음·선택지·정답·권리 전부 DATA_GAP.
