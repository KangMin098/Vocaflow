## 2. 17항목

### 1. IDs + 출처
위 표. 추가 관찰 대상: `H2407G3#19`(body_ok=false — 학습 투입 금지 후보).

### 2. 발문 요구
「글에 드러난 X의 심경 변화」 = 글 앞부분 상태(A)와 뒷부분 상태(B)를 **각각** 판정하고 순서까지 맞춰야 한다. 분위기형은 장면 전체 정서 1개(형용사 쌍).

### 3. 학습자 목표
- 인물 상태를 **행동·생각·신체 반응 단서**로 추론해 영어 감정 형용사로 명명한다.
- 전환점(turning point)을 찾아 글을 전/후로 나눈다.
- 직접 감정어(at ease, relax)와 추론해야 하는 상태(checked his watch, blankly looked)를 구분한다.

### 4. 사고 기술
단서 수집 → 상태 추론 → 감정어 어휘 매핑(A1 어휘) → 전환점 탐지(A3 논리흐름) → 극성(+/−)·각성도 비교 → 선지의 두 칸을 **독립 검증**(A5 근거판단).

### 5. 지문 관찰
- `2024#19`: 전반부 단서 — kept looking back and forth between his watch…, “I can’t be late…”, couldn’t feel at ease. 전환점 — saw a different bus coming. 후반부 — “Phew! Luckily…”, took a deep breath, finally able to relax. 직접 감정어와 행동 단서가 **양쪽에 다 있다**(쉬운 대표).
- `M2706#19`: 전반부 — didn’t feel like going, nothing better to do, checked his watch, blankly looked, feeling sleepy. 전환점 — Just as…, the monorail rose above the clouds. 후반부 — opened his mouth, couldn’t believe how marvelous. 전반 감정어(bored)는 **본문에 없고** 행동으로만 추론된다.
- `H2109G1#19`: 단서 — middle of the night, no answer, someone in his room, rhythmic, scratchy breathing, lay awake. 「변화」 없음, 누적형.

### 6. 추론 사슬 (`2024#19` 예)
시계를 반복 확인 + 지각 걱정 독백 + couldn’t feel at ease → 전반 = 불안(−, 고각성) → 다른 버스 도착(사건) → Phew/Luckily + 깊은 숨 + relax → 후반 = 안도(+, 저각성) → (−→+) 선지 중 nervous → relieved.

### 7. 공식 정답과 이유
- `2024#19` ①: 두 칸 모두 본문 단서와 일치, 극성 방향(−→+) 일치.
- `M2706#19` ①: bored ← 마지못한 참여·멍함·졸림(추론), amazed ← 입 벌림·믿기지 않음(행동+진술).
- `H2109G1#19` ⑤: 정체 불명 존재 + 공포 반응 단서 누적.

### 8. 오답 실패 + 근거 범위 (가설 분류)
| 실패 | 예 | 근거 범위 |
|---|---|---|
| 한 칸만 맞음 | `M2706` ⑤ nervous → pleased: 후반 +는 맞으나 전반 nervous는 단서 없음(시계 확인을 초조로 과독) | 전반부 문장 2~5 |
| 방향 역전 | `2024` ③ pleased → confused, `M2706` ④ delighted → scared | 전환점 앞뒤 |
| 극성 맞고 각성도/종류 틀림 | `2024` ② lonely → hopeful: 「혼자 정류장」 장면을 lonely로 과독 | 본문에 고립 단서 없음 |
| 상식 연상 | `2024` ④ indifferent → delighted: 첫 출근 = 무관심 아님 | 독백 “I can’t be late” |
| 장면 ≠ 인물 혼동(분위기형) | `H2109` ③ calm and peaceful: 「한밤·조용히」 표면어 연상 | 후반 breathing 단서 |
**과독(over-reading)** 핵심: 같은 행동(시계 확인)이 `2024`에선 불안, `M2706`에선 지루함 — 단서는 **주변 문맥과 묶여야** 상태가 결정된다.

### 9. 학습자 자신의 행동
1) 전환점 문장 선택(클릭/키보드) → 2) 전/후 구역에서 단서 구절 각각 1개 이상 표시 → 3) 각 구역 극성(+/−/0) 판정 → 4) 선지 5개를 전/후 두 칸으로 분해해 칸별 일치/불일치 표시 → 5) 최종 선택. 모든 판단은 **선택형**, 자유서술 채점 없음.

### 10. 시각 구조
지문 위에 가로 **전/후 2구역 띠**(전환점에서 분할) + 각 구역 옆 극성 게이지. 선지는 `A → B` 두 칸 매트릭스(행=선지, 열=전/후)로 재배열해 칸별 ✓/✗. 분위기형은 띠 1개(분할 없음) — 같은 화면 틀에서 「전환점 없음」을 선택지로 둔다.

### 11. 강의 턴 (제안, 실제 강의 데이터 28건 NOT_VERIFIED)
T1 발문 해부(누구·변화인가 단일인가) → T2 전환점 찾기(학습자 먼저) → T3 전반 단서·극성 → T4 후반 단서·극성 → T5 선지 칸 분해 소거 → T6 과독 오답 하나 반박(근거 범위 제시).

### 12. 피드백 / 오개념
- 「감정어가 본문에 없으면 못 푼다」 → 행동 단서 대응표로 교정(`M2706`).
- 「한 칸 맞으면 정답 후보」 → 칸별 소거 강제.
- 「장면의 사물 = 분위기」(night → calm) → 인물 반응 단서 우선.
피드백은 학습자가 표시한 단서 위치를 근거로 「그 구절은 어느 구역인가」를 되묻는 형식. 감정 판단 정오는 공식 정답 기준만.

### 13. 원리 적용 조건과 한계
- 전/후 2구역 모델은 「변화」 109문항에만 전제된다. 단일 18 · 분위기 5에는 분할을 강제하지 않는다.
- 전환점이 문장 하나로 뚜렷하지 않은 문항(점진 변화) 비율은 미측정 — DATA_GAP.
- 감정어 어휘 수준이 병목인 학습자에겐 추론 훈련 전에 어휘(A1) 보충 필요(가설).
- 학습 효과 개선은 학습자 검증 전 주장하지 않는다.

### 14. 비교 가능성
- 수능(13) vs 학평(대다수): 발문·5지·「A → B」 형식 동일 → 같은 틀 재사용 가능(VERIFIED 형식, 난이도 비교는 오답률 없어 DATA_GAP).
- 타 유형: 01 매트릭스의 F-POLAR(극성 판단) 공유. 전환점은 R-MOOD 고유. 순서·삽입 유형의 담화 전환 표지(Just as, When… again)와 연결 가능(가설).
