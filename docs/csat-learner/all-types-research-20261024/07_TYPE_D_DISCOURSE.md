2. **발문 요구**: 글 전체 흐름과 관계 없는 문장. polarity negative.
3. **학습자 목표**: 문장마다 앞 문장에서 받는 것·뒤 문장에 넘기는 것을 확인하고, **낱말 반복이 있어도** 비교 상대·판단 기준이 바뀌어 흐름 사슬을 끊는 문장을 근거로 고른다.
4. **사고 기술**: 지시 대상 추적(that happens, that grant deadline, this) · 대조 짝 탐지(In the short term ↔ in the long term) · 화제와 판단 기준 구분 · 반복 낱말 함정 식별.
5. **지문 관찰**: 3번 자기 관리 먼저 포기, 4번 `that happens`, 5번 `that grant deadline`·`In the short term`, 6번 `before the design class`(비교 상대 변경), 7번 `But … in the long term`·`this is the exception`.
6. **추론 사슬**: 7번 this가 받는 "자기 관리 포기"와 in the long term이 맞설 단기 진술(5번)이 7번 바로 앞에 와야 함 → 6번이 그 사이에서 기준을 경쟁률·이득으로 바꿈 → 6번 제거 시 5→7 짝 회복.
7. **정답**: ④(6번) (v3 기준, 공식 대조 NOT_VERIFIED).
8. **오답 실패 + 증거**: ③(5번)은 woodworking class 반복으로 오답처럼 보이나 hobbies의 예이고 단기 짝을 공급(1·5·7번). ⑤(7번)은 But으로 결론 — 대조어가 있다고 무관하지 않음.
9. **학습자 행동**: 각 문장의 "받는 표현/넘기는 표현" 선택 → 한 문장을 지웠을 때 앞뒤 짝이 회복되는지 토글로 대조(제거 조건 조작) → 근거 지목.
10. **시각 구조**: 문장 사슬 + 대조 짝 연결선(5↔7). 후보 문장을 빼면 연결선이 이어지는지 보여 주는 전후 비교. 화제(같은 낱말)와 기준(무엇을 무엇과 비교)을 두 열로 분리 표시.
11. **강의 턴**: ① "7번의 this와 in the long term은 무엇을 원하나?" ② "6번이 비교하는 두 대상은?" ③ "6번을 빼고 5→7을 읽어 보라."
12. **오개념**: 반복 낱말 = 관련 · 새 낱말 = 무관 · 대조어(But) 문장 = 이탈.
13. **원리 조건·한계**: 글이 처음부터 여러 활동의 우선순위를 비교하는 글이면 활동 간 비교 문장도 흐름에 속함(v3 when_not).
14. **비교 가능성**: 삽입의 "기존 연결 보존"을 역으로 본 과제 — 삽입은 끊지 않을 자리, 무관은 끊고 있는 문장. 같은 이음매 틀 재사용 가능.
15. **데이터·공백**: 표본 1건만 조사. 다른 기제(화제 이동형·관점 이동형) 무관 문항 수집 필요 → DATA_GAP.
16. **판정 후보**: v3 = REUSE 후보 · 제거 토글 비교 = NEW 후보 · 표본 확충 = 선행 과제.
17. **구현·검증**: 제거 전후 이음매 판정은 닫힌 형식. 토글 조작 횟수는 숙달 아님.

## 5. 세 유형 공통 설계 제안(가설)

- **공통 단위 = 이음매(앞 요구 · 뒤 공급 · 기존 연결)**. 삽입·순서·무관을 같은 판정 언어로 묶어 전이를 노린다(학습 효과는 미검증).
- **지시 범위를 점이 아닌 구간으로** 표현·저장. C1이 보여 준 결함(범위 축소)이 데이터 구조에서 다시 생기지 않게 한다.
- **결정 이음매와 필요조건 이음매를 구분**해 보여 준다(38: these=필요, 8번 접합=결정).
- **표면 결속(같은 낱말)과 특성·기준 결속을 분리**한 대조 장치(36 ⑤, 35 ③).
- 금지: 자유서술 자동 채점, 탐색·클릭의 숙달 산입, 미검증 효과 주장.
