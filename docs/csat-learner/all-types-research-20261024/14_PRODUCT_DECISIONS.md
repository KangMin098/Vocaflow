> 상태: 사용자 결정 3건을 설계 계약으로 옮긴 문서. 결정 자체는 사용자 확정, **계약 문구·적용 범위는 작성자 자체 검증**이며 공식 독립 수용 전이다.

## 결정 1 — 정답 공개 정책: 통제는 하되 순서는 강제하지 않는다

### 1.1 계약

| 규칙 | 내용 |
|---|---|
| R1 경로 자유 | 학습자는 근거 탐색 우선 · 해설 우선 · 강의 우선을 언제든 고르고 바꾼다. 어느 경로도 다른 경로의 선행 조건이 아니다 |
| R2 공개 상태는 학습자 선택으로만 바뀐다 | 시스템(강의 진행 · 자동 장면 · 타이머)은 공개 상태를 바꾸지 않는다 |
| R3 안내 | 정답 · 정답 암시가 있는 강의 구간에 닿기 **전에** 「이 구간은 정답(또는 정답을 좁히는 단서)을 말해요」 를 알리고, 학습자가 「계속 / 이 구간 건너뛰기 / 여기서 멈춤」 중 고른다. 기본 동작은 멈춤이 아니라 **안내 표시 후 학습자 응답 대기** |
| R4 단일 공개 출처 | 화면 정답 표시 · 강의 음성 · 역할 라벨 · 오답 소거 순서 · 강조 순서 · ARIA 문구가 같은 공개 상태를 읽는다(어느 하나만 숨기면 나머지로 답이 샌다 — 10 · 02 CC-06) |
| R5 기록 분리 | 아래 4종을 다른 기록으로 저장 · 표시한다 |

| 기록 | 뜻 | 숙달 증거 |
|---|---|---|
| `answer_viewed` | 정답을 본 시점(시도 전/후) | 아니오 |
| `checked_after_explanation` | 해설 · 강의 뒤 다시 확인함 | 아니오 |
| `independent_attempt` | 정답 · 정답 암시를 보기 전 스스로 고른 응답(닫힌 선택) | 예 — 단 판정은 별도 규칙 |
| `mastery` | 서로 다른 시점 · 문항의 독립 수행을 묶어 내린 판정 | 학습지도 숙달 규칙이 정한다(자동 승격 금지) |

탐색 · 클릭 · 강의 청취 · 해설 열람은 숙달에 산입하지 않는다.

### 1.2 필요한 데이터 · 현재 상태

- 강의 cue 별 `disclosure`(none / hint / answer) 태그 — **없음(GAP)**. 태그 전 cue 는 `answer` 로 간주(fail-closed: 안내 대상).
- main 강의 대본의 「정답은」 구간: 회차 파일 29개 전부, 회차당 23~30회(12 E2 정정) — 태깅 드레인 대상.
- 시도 전/후 구분 기록 — 현 저장 구조 미확인(NOT_VERIFIED).
- 구현 상태: **미구현**. 다음 구현 범위(§4) 참조.
