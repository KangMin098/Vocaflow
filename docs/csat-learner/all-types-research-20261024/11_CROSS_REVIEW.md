# 11 · 교차 검토 — **모의 검토**(실제 전문가·학생 아님)

2026-10-24 · 통합 에이전트 J 가 5개 관점을 역할극으로 수행. 실제 사람의 의견이 아니며 학습 효과 근거가 될 수 없다. 대상: 00_INTEGRATED_DESIGN.md 초안.
기준(모든 역할 공통): ① 학습자 판단 행동이 있는가 ② 근거가 자료로 결속되는가 ③ 과잉 일반화/누설 ④ 자료 공백을 숨기는가 ⑤ 결정 근거 없는 사전 결정.

## 1. 1차 — 독립 반려 사유

| 역할 | 반려 사유 |
|---|---|
| A 기초 학습자(모의) | 이원 판정 표와 이음매 3개 판정은 처음 보는 사람에게 조작이 많다. "무엇을 먼저 눌러야 하는지" 한 개만 보여 달라. 정답이 언제 나오는지 모르겠다. |
| B 상위권 학습자(모의) | 34② 같은 "지문으로 판단 불가" 선지를 참/거짓 2칸에 넣으면 틀린 훈련이 된다. 강의가 정답을 먼저 말하면 건너뛸 수밖에 없다. |
| C 고교 영어 교사(모의) | NO_DATA 대상 수가 183으로 적혀 분석 0행 문항 119가 빠졌다. 교사가 과제로 낸 문항이 빈 화면이면 신뢰를 잃는다. R-MOOD 는 아예 연구가 없다. |
| D 수능 전문 강사(모의) | GIST·TOPIC·TITLE 을 F-CENTRAL 하나로 묶으면 제목의 은유·주제의 화제 수준 차이가 사라진다. "부정어 뒤=거부" 같은 요령이 원리로 들어오면 안 된다. 무관 문장·지칭은 표본 1건으로 설계했다. |
| E 교육평가·교수설계(모의) | 우선순위가 "효과"처럼 읽힌다. 수용 테스트에 학습 효과 항목이 섞이면 안 된다. 2칸 판정은 측정 구인 오지정. |

## 2. 00 에 반영한 수정
- R1 C-1 판정 3값화(B·E) · R2 우선순위·AT 에 "효과 근거 아님" 명시(E) · R3 NO_DATA 302 정정(C) · R4 공통화 금지 목록(D) · R5 P1-13 R-MOOD·얕은 표본(C·D) · R6 초보 "다음 행동 1개"는 04 §3.2 로 연결만(A).
- 반영하지 않은 것: A 의 "정답 시점 안내"는 공개 단계 UI 결정이라 F07/F08(Codex 소유·UNDETERMINED) 범위 — 증거로만 남김.
