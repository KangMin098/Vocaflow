## 1. 설계 원칙 — 두 활동을 동질화하지 않는다

| | 정보 대조(R-FACT·R-NOTICE·R-CHART·X-FACT) | 언어 형식 판단(R-GRAMMAR·R-VOCAB·X-VOCAB) |
|---|---|---|
| 판단 대상 | 선지 진술 ↔ 지문/표/도표의 **성분**(주체·행위·시점·조건·수량·단위) | 밑줄 자리 **하나의 형태/낱말**이 문장 구조·문맥 방향과 맞는가 |
| 증거 범위 | 지문 속 **해당 위치 1곳**(찾기 + 성분 정렬) | 밑줄 **주변 절 구조** 또는 **앞뒤 논리 방향** |
| 학습자 행동 | 선지를 성분으로 쪼개 → 지문 위치 연결 → 성분별 일치/불일치 표시 | 구조 표지(주어·정동사·수식 대상) 지정 → 요구 형태 선택 / 방향(+/−) 지정 |
| 오류 원형 | 성분 하나 바꿔치기(시점·주체·전칭·배수) | 수일치·준동사/정동사·관계사·태 / 반의어 극성 |
| 화면 골격 | 좌: 선지 성분 열, 우: 지문 하이라이트 연결선(대조표) | 문장 확대 구조 띠(괄호·화살표) / 문맥 방향 저울 |

둘 다 "다음" 클릭·펼치기·열람으로 숙달 산입하지 않는다. 숙달 산입은 **최종 선지 선택**(공식 정답 대비)과 **닫힌 선택형 중간 판단**(성분 일치 O/X, 요구 형태 2지)만.

17. 구현: 정렬은 드레인(에이전트가 선지→문장 index 채움, 표본 원문 대조). 학습자 검증: 성분 칩 판단 정확도와 최종 선지 정답률을 분리 기록.
