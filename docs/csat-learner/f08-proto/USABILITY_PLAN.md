# F08 후보 A·B·C 실제 학습자 비교 평가 계획 (미실행)

> 상태: **계획만 있다.** 사람 참가자로 실행한 적이 없다. 이 계획을 실행하기 전까지 F08 최종 배치를 정하지 않는다.
> 학습 효과(점수 향상·전이)는 이 평가로 판정하지 않는다. 타당한 평가 문항을 따로 준비한 뒤 별도로 검증한다.

## 1. 묻는 것

같은 문항(2026 수능 34번)으로 같은 과제를 할 때, 세 화면 구조 가운데 어느 것이 다음 다섯 가지를 덜 힘들게 하는가.

1. 원문 탐색 — 근거 문장(6·7번)을 찾아 선지에 연결하기
2. 명제 비교 — 1번과 3번을 빈칸에 넣은 두 명제의 차이를 판별하기
3. 조건 이해 — If 조건과 `cannot be` 부정 범위를 확인하기
4. 화면 이동 부담 — 원문과 선지·도구 사이 왕복
5. 조작 가능성 — 막힘·오조작·키보드만으로 완료

## 2. 설계

- **집단 간 비교를 1차 분석으로 한다.** 같은 문항을 한 사람이 세 번 풀면 두 번째부터는 답과 근거를 이미 안다(이월 효과). 그래서 참가자 한 명이 **첫 번째로 받은 후보**의 결과만 1차 비교에 쓴다.
- **순서 효과 통제:** 참가자를 6가지 순서(ABC · ACB · BAC · BCA · CAB · CBA)에 같은 수로 무작위 배정한다. 두 번째·세 번째 후보는 「선호·조작 부담」 같은 2차 자료로만 쓴다.
- **같은 조건:** 같은 운영 빌드, PC 1280×900 또는 1440×900, 같은 브라우저, 같은 안내문을 쓰고, 시작 전에 저장된 상태를 지운다(「이 후보 처음부터」). 정답·해설은 원하면 언제든 볼 수 있게 두고(강제 진행 없음), 공개를 먼저 고른 참가자도 정상 경로로 분석한다.
- **대상:** 한국 고등학생~성인 영어 학습자. 34번을 이미 풀어 본 사람은 따로 표시하고 1차 분석에서 뺀다.
- **규모:** 순서당 최소 2명(총 12명 이상)을 목표로 한다. 이 규모로는 차이의 방향만 탐색할 수 있다. 통계적 확정은 주장하지 않는다.

## 3. 과제 (세 후보 공통, 화면 문구 그대로 안내)

1. 발문이 판단하라고 하는 것을 확인한다.
2. 빈칸 앞의 부정과 If 조건을 원문에서 찾는다.
3. 1번과 3번을 빈칸에 넣어 보고 각각 「맞을 것 같다 / 아닐 것 같다 / 모르겠다」를 고른다.
4. 3번의 근거 문장을 원문에서 골라 연결한다.
5. (원하면) 정답·해설을 열고, 필요하면 판단을 고친다.

## 4. 측정 (자유서술은 채점하지 않는다)

| 무엇 | 어떻게 | 비고 |
|---|---|---|
| 원문 탐색 | 과제 4 완료까지 시간 · 연결한 문장이 6·7번을 포함하는가 | 자동 기록(닫힌 값) |
| 명제 비교 | 과제 3에서 1번·3번에 고른 값 · 공개 전/후 수정 횟수 | 맞힘 여부는 학습 효과가 아니라 과제 수행으로만 해석 |
| 조건 이해 | 과제 2 직후 닫힌 선택형 확인 1문항(「cannot be 가 부정하는 범위는?」 보기 3개) | 문항은 실행 전에 분석 v5 기준으로 검수 |
| 화면 이동 부담 | 원문↔선지/도구 전환 횟수 · 스크롤 거리 · 「판단하던 자리로 돌아가기」 사용 수 | 자동 기록 |
| 조작 가능성 | 막힘(30초 이상 무조작) · 오조작(누른 직후 되돌림) · 키보드만으로 완료 가능한지(키보드 사용자 하위 집단) | 관찰자 기록 + 자동 |
| 주관 부담 | 과제 뒤 5점 척도 2문항(찾기 쉬움 · 비교 쉬움) | 2차 자료 |

- 기록은 프로토타입 라우트 안에서만 하고 학습 기록·숙달·점수에는 넣지 않는다.
- 제품의 이벤트 테이블(`funnel_events`)에 남기려면 이벤트 이름 목록과 DB CHECK 제약을 함께 바꿔야 한다. 그 변경은 DB 승인 대상이라 이 계획에 넣지 않는다. 평가는 로컬 기록 파일로 한다.

## 5. 판정 규칙 (실행 뒤)

- 다섯 측정에서 한 후보가 다른 후보보다 일관되게 낮은 부담을 보이면 그 후보의 **구조**를 제품 설계 근거로 삼는다. 한두 측정에서만 앞서면 결정하지 않고 다른 유형 문항 2~3개로 다시 본다.
- 자동화 측정(COMPARISON §3)과 학습자 측정이 어긋나면 학습자 측정을 우선한다.
- 결과 보고에는 참가자 수, 제외 사유, 순서별 분포를 함께 적는다.
