# 기출 찾기 팝업 — 계약 · 실측 · QA

2026-10-13. 설계 `D:/workspace/vocaflow-csat-item-finder-design.md` · 지시 `D:/workspace/vocaflow-csat-item-finder-claude-instructions.md`(FND0~FND4). 결정 기록 [DECISIONS](./DECISIONS.md) 「기출 찾기 팝업」.

학습자가 지금 문항 · 장면을 떠나지 않고 다른 기출을 찾아 메타데이터로 확인한 뒤 탐구로 간다. 「기출 찾기」 는 도구다 — 상시 메뉴는 둘, 장면은 일곱 그대로.

## 1. 입구

| 자리 | 요소 | 시작 조건 | 다른 문항으로 갈 때 싣는 것 |
|---|---|---|---|
| `/csat/item/[slug]` 문항 머리(목록 링크 옆) | `item-finder-open-btn` | 문항의 서가 `ret` 조건(없으면 전체) | `scene=task` + 검증된 `ret` · `from=map` · `task/ws/step` |
| 비교 장면 — 검수 쌍이 없을 때 | `v3-compare-find` | 지금 유형(해제 가능) | 위와 같음 · `pair/back` 은 만들지 않음 |
| `/csat/browse` 도구줄 | `browse-finder-open` | 지금 서가 조건 + 목적 | `scene=task` + `ret=<팝업의 확정 조건>` |
| `/csat` 지도 홈 「기출 탐구」 입구 | `home-finder-open` | 전체 | `scene=task&from=map`(과제 문맥 없음) |
| 독립 확인 `check=1` | 없음 | — | — |

레일의 「기출 탐구」 링크는 `/csat/browse` 그대로. 자동으로 열지 않는다(첫 진입 · 장면 변경 · 정답 확인 · 저장 실패 · 종료 후 모두). 전역 단축키 없음.

## 2. 과정과 상태

`닫힘 → 열림/조회 중 → 목록 준비 → 조건 · 회차 · 문항 선택(요약만) → 탐구 열기(재검증) → 오버레이 이력 정리 → 이동`

| 상황 | 반응 |
|---|---|
| 조회 중 | 「목록을 받는 중…」 · 탐구 열기 비활성 |
| 판정 실패 · 목록 실패 · 연결 끊김 | 오류 문구(「0문항이라는 뜻이 아니에요」) · 다시 불러오기 · 바닥 상태 「목록을 받지 못했어요」 |
| 인증 만료(401) | 다시 로그인 안내(비밀값 요청 없음) |
| 검색 0 | 「이 조건에 맞는 문항이 없어요」 · 조건 지우기 — 오류와 구분 |
| 조건이 바뀌어 회차 · 문항이 결과에서 빠짐 | 그 선택과 요약 해제(`reconcilePick`) |
| 열기 직전 보류 · 삭제 · 판정 실패 | 이동하지 않고 이유 · 「목록 다시 불러오기」(새 목록을 받으면 다시 확인 가능) |
| 지금 문항 선택 → 탐구 열기 | 팝업만 닫힘 — 장면 · 근거 · 초안 · 주소 그대로 |
| 취소 · 닫기 · Esc · 배경 · 브라우저 뒤로 | 취소 — 주소 · 장면 · 선택 · 초안 · 스크롤 그대로 · 트리거로 포커스(스크롤 이동 없음) |
| 닫힌 뒤 도착한 응답 | 버린다(AbortController + 요청 번호) |
| 재열기(같은 자리 · 문항 · 시작 조건) | 마지막 조건 · 선택 · 열 스크롤 복원(탭 메모리) · 목록은 다시 받는다 |
| 강의 재생 중 열기 | 그 위치에서 멈춤 · 닫아도 자동 재개 없음 · 다른 문항은 새 강의 무대(`LectureStage key=문항`) |

이동은 공통 `useCloseOnBack` 의 `afterUnwindRef` 로 — 오버레이 표식 칸을 걷어낸 popstate 를 받은 **뒤** `router.push`. 타이머 대기 · back 두 번 없음.

## 3. 데이터 · 권한

- `GET /api/csat/item-finder` — 로그인 필요. 목록 = 학습자 클라이언트로 `csat_items_public`(서가 로더). 보류 = 요청마다 `loadRevealScope`(목록) · `itemRevealDecision`(재검증) — 기존 관문 함수의 서버 내부 service-role RPC 만, 새 RPC 없음. 판정 실패 503 `gate` · 목록 실패 503 `list` · 응답 `private, no-store`(오류 포함).
- 응답 키 allowlist: 문항 `id exam_id no type_id points lecture sec map` · 회차 `id label kind year month grade items` · 유형 `id name status items`. 회차 · 유형 개수는 보류 제외 뒤 다시 센다.
- 팝업 요약은 이 메타데이터만 — 원문 · 정답 · 해설 · 대본 미리보기 없음, `ItemPaper` · `AnalysisTheater` 를 마운트하지 않는다. 검색 · 요약 · 재검증은 학습 기록(열람 · 완료 · 진단)을 쓰지 않는다.
- 문항 라우트의 서버 관문이 여전히 권위 있는 관문이다.

## 4. 조건 모델

`FinderSelection = BrowseFilter + BrowsePurpose`(`lib/csat/item-finder.ts`). killer 는 필터 밖 목적(`killerTypeIds()` 제한), evidence · recent 별칭은 `status=map` · `from=RECENT_FROM` 으로 펼친다 — 서가 첫 상태와 같은 함수(`selectionFromParams`). 회차 조건은 팝업에서 회차 열의 선택으로 꺼내고(`splitExam`) 확정 때 다시 싣는다(`withExam`). 「조건 초기화」 는 목적까지 해제, 취소는 원래 주소 · 목적 유지, 「서가에 적용」 만 서가 주소를 바꾼다.

검색(`lib/csat/browse-search.ts`, 서가 `filterBrowse` 와 공유): 토큰 AND · 번호 정확 일치 · `2026#34`/`2026-34` = 그 문항 · 4자리 = 학년도 · 회차 id(`M2609` · `2014A` · `H2503G1`) · 꼬리말 `학년도/년/번/회` 제거 · 40자.
