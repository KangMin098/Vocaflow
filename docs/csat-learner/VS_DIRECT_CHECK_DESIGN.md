## 2. V 「문맥 속 낱말 뜻」

- **과제 키(안)** `vocab-context`. 단계 `vocab`, 라인은 A1 FIND(ord 4)다.
- **FIND:** 기출 30번 지문에서 문맥에 맞지 않는 밑줄 낱말 하나를 고른다(번호 5개).
- **틀렸을 때:** 고른 낱말이 앞뒤 문장과 어떻게 이어지는지 §13 1단계(문장 뜻) 질문을 보인다.
- **주석(합의):**
  - `{ itemId, skeletonSig, sentenceCount, targets: [{ no: 1..5, sentence }], answer: no, disputed: [] }`
  - 정답은 골격 앵커 ∩ 맹검 판정자 2명이다.
  - 원래 낱말 · 반대말은 2차(CHECK 확장)로 미룬다.
- **문항 풀:** 기출 29(직접 확인 2 + 다시 확인 2 이상을 충분히 채운다).
- **V vs 재진술 가르기(`V_VS_RE`)는 그대로 둔다.** 직접 확인은 「낱말을 몰라서인지」 를 한 원리로만 잰다.
- **주의(일화 경계):** 30번은 「문맥 판단」 이지 「낱말 뜻 지식」 이 아니다. 이 과제로 V 결손을 확정하면 R(관계)와 섞인다.
  - 그래서 직접 확인 문구는 「문맥 속 낱말 판단」 으로 한정한다.
  - 낱말 지식 자체의 확인은 사전 기반 확장(2차) 뒤에 연다.

## 3. S 「문장 뼈대 — 주어 · 본동사」

- **과제 키(안)** `sentence-core`. 단계 `sentence`, 라인은 A2 FIND(ord 4)다.
- **FIND:** 긴 기출 문장 하나에서 주어의 핵심 낱말과 본동사를 고른다(낱말 칩 탭 — 문장 원문이 화면에 필요하다).
  - 지금 E축 · 주장과 근거 과제는 지문 원문 없이 문장 번호만 쓴다(공개 문제지를 곁에 둔다).
  - S 는 낱말 단위라서 **원문 표시 정책 결정이 먼저**다. 결정 필요 D-9.
- **주석(합의):**
  - `{ itemId, sentence, skeletonSig, subjectHead: [start,end], mainVerb: [start,end], disputed }`(문자 위치 · 원문 없음)
  - 맹검 판정자 2명 + wink-nlp 초벌로 만든다.
- **CHECK:** 처음 보는 다른 긴 문장으로 같은 과제를 한다. 어법 29번 중 수일치 · 본동사 문항은 보조 CHECK 다.
- **문항 풀:** 2,910문장 중 조건(30어 이상 또는 삽입 · 관계절)에 맞는 것에서 표본 20을 먼저 만든다.

## 4. 학년별 자료(§15 — 잠금 아님)

- **초등 고학년 · 중등 중심 단계(V · S · R)의 확인 문항은 기출(고등) 지문뿐이다.** 그래서 학교급 권장은 「표시」 만 되고 「자료」 는 없다(MC-03 PARTIAL).
- **후보:** VRL `v_level` 낮은 기사 · 도서 문장이다. 저작권 · 원천 등급(source-check criteria)을 통과한 것만 쓴다.
  - 같은 과제 키를 쓰고, `audience.band` 로 학교급을 표시한다.
  - 판정 기준(curriculum `CRITERIA`)은 같다.
- **결정 필요 D-10:** 비기출 지문을 직접 확인 문항으로 써도 되는가. 정본은 「기출 근거」 중심이다.
