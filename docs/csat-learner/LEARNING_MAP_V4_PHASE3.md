## 3. TASK 학습계획 계약(`lib/csat/map/v4/plan.ts`)

TASK 한 줄 = 수행 목표 · 현재 근거(As-Is) · 목표 관련도 · 요구 유형 · 단계 · 연결 Workspace · 다음 활동 · **정량**(가용 · 계획 · 수행 · 남음 · 규칙 · 출처 · 조정 가능) · **정성**(학습자 기준 문장 · 확인된 성취 상태) · 풀리지 않은 것.

| 단계 | 계획량 규칙(출처 = 실제 가용 콘텐츠) | 수행 |
|---|---|---|
| 확인 | 안 본 확인 문항 + 이미 푼 확인 문항(같은 묶음) | 독립 첫 시도 문항 수 |
| 바로잡기 | 확정 · 다시 확인에서 막힌 문항 | 확정 뒤 그 문항 연습(서로 다른 문항) |
| 적용 | 확인 묶음 밖 실제 적용 문항 | 확정 뒤 적용 · 골격 과제 기록 |
| 다시 확인 | 독립 재확인 기준 2문항(서로 다른) | 확정 뒤 새 문항 시도 |

- 콘텐츠가 없으면 계획량 null(「계획할 수 있는 문항 없음」 + 이유) — 권장량을 만들지 않는다.
- 계획 진행 「수행 / 계획 문항」은 중심 TASK 만 센다(보조는 그 TASK 의 중심 묶음에서) — 숙달률 아님, 퍼센트 · 막대 없음.
- 학습자 조정(`applyDraft`) = 순서 · 계획량(0 ~ 가용량)만. 근거 · 성취 · 요구 칸 불변(테스트).
- 학습자 문장은 코드북 `learner_criterion`(설계 메모 `criterion` 분리) — 화면 검토에서 「R4 와 독립 관찰」이 노출된 결함을 고치고 내부 코드 가드를 넣었다.
