## 무엇을 적나

문항 하나에 아래 다섯 칸. 문장 번호는 **`splitSentences`(골격과 같은 분할기)의 0-기반 번호**다 — 화면의 지문 지도와 같은 번호여야 학습자 태그를 채점할 수 있다.

| 칸 | 값 | 설명 |
|---|---|---|
| `roles` | 문장 수만큼의 역할 배열 | 아래 **역할 9** 중 하나씩 |
| `pattern` | 구조 패턴 1개 | 아래 **패턴 9** 중 하나 |
| `selection` | 한국어 한두 문장 | 출제자가 **왜 이 지문을 이 유형에 골랐나** — 지문의 어떤 성질이 이 유형의 판단을 요구하게 만드는가 |
| `transform` | 변환 유형 1개 | 아래 **변환 8** 중 하나 — 순서 유형은 `cues` 를 대신 적는다 |
| `transform_note` | 한국어 한 문장 | 지문의 무엇이 정답 선지의 무엇으로 바뀌었나. **원문을 12자 넘게 인용하지 않는다**(저작권 경계 · 요약으로 말한다) |
| `cues` (R-ORDER 만) | 단서 유형 배열 | 아래 **순서 단서 6** 중 해당하는 것 전부 |
| `alternatives` | 역할 대안 `{index, role}` 배열 | 두 역할이 모두 옳다고 볼 만한 문장 — 학습자 채점의 **허용 대안 집합** |

## 역할 9 (roles)

| 값 | 뜻 |
|---|---|
| `topic` 주제문 | 글 전체가 뒷받침하는 핵심 주장·요지를 담은 문장 |
| `support` 근거 | 주제문을 논리적으로 뒷받침하는 이유·설명 |
| `example` 예시 | 구체 사례·연구·일화 — 빼도 주장은 서지만 이해를 돕는다 |
| `turn` 전환 | However·But 류로 흐름을 뒤집거나 초점을 바꾸는 문장 |
| `concession` 양보 | 반대 입장을 일부 인정하는 문장(Of course, Although …) |
| `conclusion` 결론 | 앞의 논의를 정리·재진술하며 맺는 문장 |
| `background` 배경 | 통념·상황·문제를 제시하는 도입(주장 아님) |
| `speech_act` 화행 | 편지·안내문에서 요청·통보·제안 등 **글쓴이가 하려는 행동**을 담은 문장 |
| `closing` 맺음 | 인사·감사·서명 등 내용 없는 맺음 |

규칙: 한 문장에 역할 하나. 주제문이 둘로 보이면 더 추상적인 쪽이 `topic`, 다른 쪽은 `conclusion` 또는 `support`. `speech_act` 는 목적 유형의 편지·안내문에서만 쓴다.

## 패턴 9 (pattern)

`myth_rebuttal` 통념-반박 · `general_specific` 일반-구체 · `problem_solution` 문제-해결 · `contrast` 대조 · `cause_effect` 인과 · `study_implication` 연구 소개-함의 · `request_letter` 요청 화행 편지 · `narrative` 서사(시간 순) · `other` 기타(이유를 `selection` 에 적는다)

## 변환 8 (transform)

| 값 | 뜻 | 예(요약) |
|---|---|---|
| `abstraction` 추상화 | 지문의 구체 표현을 상위 개념으로 | 사례들 → 일반 원리 |
| `paraphrase` 동의 재진술 | 같은 추상 수준에서 다른 말로 | 낱말·구 치환 |
| `negation_flip` 부정의 긍정화 | 부정·반대 표현을 긍정형으로(또는 반대로) | not A → B 의 B |
| `perspective` 관점 전환 | 주체·시점을 바꿔 같은 내용을 말함 | 학습자 쪽 → 교사 쪽 |
| `speech_act_verb` 화행 동사화 | 편지의 화행 문장을 「~하려고」로 | would like to ask → 요청하려고 |
| `compression` 압축 | 여러 문장의 내용을 한 구로 | 원인+결과 → 명사구 |
| `inference` 추론 복원 | 지문에 없는 연결 고리를 논리로 채워야 정답 | 빈칸 앞뒤 논리로 복원 |
| `none` 해당 없음 | 순서 유형 등 선지가 지문 표현 변환이 아닌 경우 | — |

## 순서 단서 6 (cues · R-ORDER 만)

`pronoun` 지시어·대명사 · `connective` 연결어(However, Therefore …) · `article` 관사(a → the) · `time` 시간·순서 표지 · `logic` 논리 전개(주장→근거, 문제→해결) · `repetition` 어휘 반복·재진술 고리

- 파일럿 6문항(유형당 2) → 사람이 눈으로 확인 → 기준 수정 → v1 확정 뒤 대량.
- 대량 전에 유형당 1청크를 **두 번째 판정자**가 따로 채워 `roles` 일치율(문장 단위)을 잰다. 0.8 미만이면 기준을 고친다.
- import 는 빈 값·목록 밖 라벨·문장 수 불일치를 넣지 않고 **건너뛴 수를 출력**한다.
