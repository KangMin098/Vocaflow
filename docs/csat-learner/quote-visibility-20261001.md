# PR #130 — 학습자 인용 표시 전수 대조

측정 기준 시각: 2026-10-01 09:15:32 KST. PR 최초 커밋 `6afe7791`의 표시 동작을 대상으로 측정했다. DB는 읽기만 했다.

## 결과

| 비교 집합 | 문항 | 인용 표시 | 인용 숨김 |
|---|---:|---:|---:|
| 전체 최신 발행 분석 | 802 | 785 | 17 |
| DB 지문에 전체 인용이 매칭됨 | 785 | **785 (100%)** | **0 (0%)** |
| DB 지문에 전체 인용이 매칭되지 않음 | 17 | **0** | **17 (100%)** |

기기 추출본 사용 때문에 추가로 숨겨진 DB 매칭 인용은 **0건**이다. 이 결과에서는 서버의 DB 지문 판정으로 바꿀 이유가 발견되지 않아 현재 표시 방어를 유지한다.

여기서 DB 매칭 집합은 리뷰의 「정상 785건」을 재현하는 **문자열 비교 기준**이다. 내용·정답 근거의 타당성을 785건 모두 검수했다는 뜻은 아니다. 반대로 DB 불일치 17건 모두가 의미적으로 잘못됐다는 판정도 아니다.

## 측정 방법과 범위

1. DB의 `csat_exams.organizer = kice` 회차와 `csat_items.in_scope = true` 문항을 직접 조회했다. 802건이었다.
2. 해당 문항의 `published` 분석 3,085개 버전을 키셋 페이지로 끝까지 읽고, 문항별 최대 `version` 한 건을 골랐다. 최신 발행 분석이 있는 문항은 802건이었다.
3. 좌표 색인의 SHA-256과 일치하는 **로컬 PDF 29개**를 모두 다시 읽었다. 기존 측정 도구의 `pdfPages`가 PDF.js legacy 빌드로 추출하고, 학습자와 공유하는 `fragsOfContent`·`hlinesOfOps`·`reflowExam`을 사용했다. **PR 브랜치의 `REFLOW_VERSION = 3`** 기준이며 다른 브랜치의 추출기를 섞지 않았다.
4. 추출된 802건 모두 `ok = true`였다. PDF·좌표·문항 누락으로 측정하지 못한 건은 0건이다. 문장 정렬 결과로 인용 성공을 추정하지 않았다.
5. `findQuote(DB passage, 전체 인용)`으로 비교 집합을 나눴다. 별도로 실제 `EvidenceQuote` 컴포넌트를 렌더해 표시 여부를 셌다. 40단어 표시 상한과 그로 인해 붙는 말줄임표도 로더와 같은 함수를 사용했다.
6. 원문·인용문은 보고서에 저장하지 않았다. [문항별 결과 JSON](./quote-visibility-20261001.json)에 문항 ID, 분석 ID·버전·수정 시각, 인용/양쪽 지문 해시, PDF 해시, 추출 상태, 매칭·표시 결과, 측정 코드 해시를 남겼다.

DB 지문과 추출본이 매칭 정규화 후 같은 문항은 **772건**, 다른 문항은 **30건**이었다. 따라서 두 텍스트가 항상 같다는 가정으로 통과시킨 결과가 아니다. 다른 30건도 실제 인용을 각각 대조했다.

이것은 색인에 등록된 원본 PDF에 대한 측정이다. 임의로 재가공한 PDF·스캔본·다른 파일 해시의 자동 좌표 탐지까지 검증한 결과로 확대하지 않는다. 브라우저 전체 UI를 802번 조작한 시험도 아니다. 브라우저 상태 전환(문제지 로딩·교체·문항 이동·추출 실패)은 최초 커밋의 별도 하네스에서 검증했다.

## 문제지 미확보 시 동작

**문제지 미확보 = 인용 미표시.** 올린 문제지를 아직 읽는 중이거나 문항 추출이 실패한 경우에도 대조할 수 없으므로 인용 블록을 숨긴다. 근거 설명·정답/오답 이유·풀이 절차는 유지한다. 위 785/785 결과는 정상적으로 읽은 원본 PDF가 있는 경우의 수치다.

## 재현

`apps/web`에서 실행한다. 환경 파일은 출력하지 않고 Node가 읽는다. 실행은 DB 읽기 전용이며 여러 번 실행해도 DB를 바꾸지 않는다. `--out` 보고서 파일만 갱신한다. PDF가 빠지면 분모에서 빼지 않고 `not-measured`로 기록한 뒤 실패한다.

```powershell
node --tls-max-v1.2 --env-file=D:/workspace/Vocaflow/apps/web/.env.local ../../node_modules/tsx/dist/cli.mjs --tsconfig scripts/tsconfig.harness.json scripts/csat-learner/quote-visibility-audit.mts --at 2026-10-01T00:15:32Z --out ../../docs/csat-learner/quote-visibility-20261001.json
```

새 측정에서는 `--at`에 해당 측정 시각을 넣는다. 최신 DB를 읽으므로 분석·원문이 바뀌면 결과도 달라질 수 있다. 원문을 추가로 보관하지 않는 대신 문항별 버전과 해시로 이번 집합을 식별한다.
