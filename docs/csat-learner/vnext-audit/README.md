### 화면 검증 조건
- 대상 서버: `localhost:3000`. 이 서버는 **`Vocaflow-map-vnext`(feat/map-vnext `981e75083`)** 워크트리의 개발 서버입니다.
- 비교 기준 `origin/main`(`6870e00d4`)과는 csat 관련 80개 파일이 다릅니다.
  - Workspace(`/csat/workspace/[id]`, 홈의 Workspace 탭)는 **map-vnext에만** 있습니다.
  - 두 상태는 [01-AS-IS §1](./01-AS-IS.md)에서 구분합니다.
- 계정: 검증 계정 `runtime-test-0705`(재방문 상태).
- 쓰기 차단: 모든 쓰기 요청(POST/PUT/DELETE)은 가로채 **기록하고 막았습니다.** DB에는 아무것도 쓰지 않았습니다.
- 캡처: 평가원 원문이 찍혀 있으므로 저장소 밖 `apps/web/test-results-csat-learner/vnext-audit/`(gitignore, D15)에 두었습니다. 문서에는 캡처 이름만 적습니다.
- **이 조사는 실제 학습자 검증이 아닙니다.** 실제 참가자가 0명이므로 합성 학습자와 에이전트로만 검증했고, 학습 효과에 대해서는 아무것도 말하지 않습니다.

## 결론

**부분 재설계가 필요합니다. 대상은 학습자 경험과 데이터 계약입니다. 공급 파이프라인은 보강만 하면 됩니다.**

ChatGPT 1차 판정(「전면 재설계」)의 방향은 맞습니다. 다만 실측으로 범위를 좁혔습니다.

- **분석·검수 자산은 버릴 이유가 없습니다.** 학평 2,606문항은 해시에 결속된 독립 3인 검수를 거쳐 발행되었습니다 [사실·DB].
- **재설계가 필요한 곳은 학습자 쪽 「상태」와 「끝」입니다.** 학습 상태는 기기의 IndexedDB 레코드 하나와 그 서버 사본(`csat_learner_state.record` jsonb)뿐입니다. 완료·재개·복습을 문항 단위로 다루는 계약이 없습니다 [사실·코드].

## 최종 보고 구분

### 확인된 사실 (요약)
1. **학습 상태 저장**
   - 학습 상태는 IndexedDB `vocaflow-csat` 레코드 하나에 있고, 서버 `csat_learner_state.record`(jsonb, 사용자당 1행)로 동기화됩니다.
   - 옛 시도·복습 표 `csat_session_attempts`·`csat_review_queue`를 쓰는 학습자 경로는 0곳입니다.
2. **해설 극장에는 완료·재개 개념이 없습니다.** 확정한 예측만 저장되고, 다시 열면 게이트가 열린 채로 보입니다 [사실·화면] C2.
3. **이벤트 공백**
   - 게이트 확정, 모르겠어요, 해부 결정, 공식 저장, 세트 완료, 서가 검색·필터, PDF 실패에는 이벤트가 없습니다.
   - 개발·테스트 계정과 실제 사용자를 가르는 표시가 없습니다.
   - 진단 조회 이벤트(`csat_dx_viewed`)는 dev에서 두 번 나갑니다 [사실·화면] E-all.
4. **평가원 쪽 결함**
   - 평가원 802문항이 모두 published 버전을 2개 이상 갖고 있습니다(3,140행).
   - 원문·단위 변경 보류 트리거는 학평 전용입니다.
   - 평가원 골격 JSON과 런타임 최신 분석을 맞대는 대조 장치가 없습니다.
   - 강의 데이터는 분석 버전에 결속되어 있지 않습니다.
5. **홈 화면**
   - 홈 머리에 「기출 802문항」이 표시됩니다. 평가원만 센 수치이고, 학평 2,606문항은 빠져 있습니다.
   - 홈 진단 카드가 「불러오지 못했어요」를 띄웁니다(503) [사실·화면] A2.
6. **해부 화면** 스킨이 옛 보라색 세리프입니다. 3B와 다르고, 개발용 로컬 PDF도 자동으로 읽지 않습니다 [사실·화면] D.
7. **서가** 무작위 문항 링크에서 hydration 불일치 경고가 납니다(서버와 클라이언트가 다른 href를 그림) [사실·화면] B.

### 미확인 사항
- 503 응답을 낸 자원의 정확한 경로(진단 카드로 추정).
- 해부 세트 추천의 실제 범위(`SessionRunner` 내부).
- 운영(프로덕션) 환경의 실제 동작. 개발 서버에서만 확인했습니다.
- `csat_map_task_toggled`가 한 번 클릭에 두 번 나가는지.
- map-vnext와 main의 80개 파일 차이 가운데 머지 예정인 범위.

### 외부 승인이 필요한 차단 요인
- **D17 법률 자문(미결)**: 브라우저에서 원문을 재조판하는 방식의 적법성. 원문 경계는 바꾸지 않았습니다.

- **실제 학습자 모집**: 효과 검증은 이것 없이는 불가능합니다.
