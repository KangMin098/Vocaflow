## A. 학습자 판단 활동

| ID | 규칙 | 근거 |

## B. 정답·해설 공개

사용자 결정 1(R14, 2026-10-24)을 정본으로 한다. R12 §4-A의 「잠김 → 답 선택 → 공개」 강제 순서는 폐기된 제안이다.

| ID | 규칙 |
|---|---|
| B1 | 공개 단계는 4개: `SOURCE_ONLY` · `LOCATION_HINT` · `RELATION_EXPLANATION` · `OFFICIAL_ANSWER`(v6 §4.2). 단계는 **학습자 선택으로만** 오른다. 강의 진행·자동 장면·타이머는 단계를 바꾸지 않는다. |
| B2 | 경로(근거 먼저·해설 먼저·강의 먼저)는 서로의 선행 조건이 아니다. 해설을 먼저 보아도 정상 학습 경로다. |
| B3 | **단일 공개 출처**: 화면 정답 표시 · 강의 음성/READ 텍스트 · 레일 역할 라벨(`evidence`/`trap`) · `reject:N` target id · 소거 순서 · 강조 순서 · 선지 색 · ARIA 이름/설명이 모두 같은 공개 상태를 읽는다. 하나만 숨기면 나머지로 샌다(R10 §2 · R02 CC-06). |
| B4 | 강의 cue의 콘텐츠 공개 수준은 5값 `NONE / HINT / DECISIVE / ANSWER / UNKNOWN`이며, 학습자 공개 단계(B1)와 **다른 축**이다. 수준별 제공 조건·fail-closed·런타임 누적은 [05 §3](./05_CUE_DISCLOSURE.md) 게이트 계약이 정본이다. 연구용 sidecar(G1 @`810a463ac`, 10,131 cue, 경계 전 2,849 cue 2인 검수)가 있으나 **제품 미승인·미적용**이다. 태그 없음·UNKNOWN·불일치·누적 불명은 안전 구간이 아니다. |
| B5 | 누적 공개: 소거 cue 누적(R7)뿐 아니라 **한 cue 안의 소거 완결 · 단일 지목 · 정답 속성 진술 · 순서형 역할 나열**도 정답을 확정한다(05 §2, 자동 경계보다 앞선 34 cue). DECISIVE는 `OFFICIAL_ANSWER`와 같은 경계. 누적은 사전 계산 prefix가 아니라 학습자가 실제 노출된 cue 집합으로 계산한다(05 §3 G1). |
| B6 | 공개 상한을 넘거나 UNKNOWN인 cue에 닿기 **전에** 알리고 `계속 / 이 구간 건너뛰기 / 여기서 멈춤` 중 학습자가 고른다(R14 R3). 강의 경험은 "A 원문부터 직접 분석"과 "B 정답 직접 안내 전까지 듣기"로 구별하며, B를 "정답을 알 수 없는 강의"라고 표현하지 않는다(05 §4). |
| B7 | UI 미표시는 보안 경계가 아니다. 정식 공개 기출의 공식 정답은 접근 권한자에게 서버가 제공할 수 있다(`csat_items_public.answer`의 authenticated 노출은 정책과 부합, 사용자 결정 2). 비공개가 필요한 범위(in_review·분석 없음·Pilot embargo)는 서버에서만 막는다. |
