# F08 사전 비교·선정 계약 v1.0 — 미선정

T-0136 R2, D2(P2). 상태 **PROTOCOL_PROPOSED / NOT_MEASURED**, 선택값 `null`. IMPROVE와 REPLACE를 모두 유지한다. 아래 규칙은 실제 로컬 PDF·사용성 측정 전에 고정한다. R1의 정적 공식 페이지 이미지·무음 어댑터 결과를 PDF 기능, 실제 TTS, 학습 효과의 결과로 대입하지 않는다.

## 공통 실험 조건과 기록

같은 원문·정답·보존 v3·승인된 콘텐츠 버전/해시, 같은 정답 공개 후 상태, 동일한 강의 cue/모드/재생 위치, 같은 초기 장면·스크롤·선택·근거를 두 후보에 주입한다. 실제 PDF 파일/worker 버전/권한, 브라우저/OS, 화면 1280×1000 및 1440×1000, 브라우저 확대 100%와 200%, 입력 장치를 기록한다. 한 쌍 중 데이터·공개·강의·과업이 다르면 해당 쌍은 INVALID이며 승패 근거에서 제외하고 원인을 보존한다. 문항별 성공을 합계로 상쇄하지 않는다.

과업 목록은 아래 12개로 고정한다. 원문·선지·비교 짝을 새로 생성하지 않는다. C1 승인 전에는 38번의 수정 설명을 검토 모드로만 시험하며, 일반 학습자 성공값으로 계산하지 않는다.

|---|---|

콘텐츠 검토자는 측정 전에 각 과업의 동시 대조 필요 범위를 `원문+판단`, `원문+근거+판단`, `순차 확인 가능`으로 분류하고 이유·서명·일자를 남긴다. 현재 분류값은 모두 미측정/미확정이다. 분류가 없는 과업은 비교를 진행하지 않는다. 동시 대조 필수 과업 비율은 `동시 대조 필수로 사전 분류된 수 / 유효 과업 수`로 기록한다. 이 비율 자체로 승자를 정하지 않고 해당 필수 과업 전부를 수행할 수 있는지를 관문으로 삼는다.

## 실제 사용성 비교와 선정 트리거

측정 전 고정 계획: 한국 고등학생 수준의 신규 사용자 2명과 기출 분석 경험자 2명, 총 최소 4명에게 같은 과업을 교차 수행시킨다. 각 집단에서 1명씩 IMPROVE→REPLACE, 나머지 REPLACE→IMPROVE 순서로 배정한다. 과업 순서·연습·중단 규칙은 첫 실행 전에 등록하고 변경 시 새 프로토콜 버전으로 전량 비교한다. 내용 검토자와 기술 검토자가 관찰 로그를 각각 판정한다. 이 소규모 시험은 사용성 결함 발견용이며 학습 효과 추론용이 아니다. 표본·동의·원문 권한 확보 전 실행하지 않는다.

1. 자료/승인/권한·실제 PDF·항목 1~6의 필수 조건 중 미측정 또는 미충족이 있으면 해당 후보의 최종 선정은 보류한다. 38 검토 과업 성공으로 학습자용 콘텐츠 승인을 대신하지 않는다.
2. 두 후보 중 하나만 모든 필수 조건을 통과하면 통과 후보를 해당 검증 범위의 권고안으로 제출한다. 다른 후보의 구체 탈락 조건을 함께 기록한다.
3. 둘 다 통과하면 과업별 오류·왕복 조작·시간·문맥 보존·중복과 비용을 원자료로 나란히 공개한다. 모든 측정 축에서 열세가 없고 적어도 한 축에서 관찰상 개선된 후보만 제한적 권고가 가능하다. 통계적/학습 효과 우위로 표현하지 않는다.
4. 상충·동률·불충분한 비용 증거라면 `UNSELECTED` 유지. 사후 가중치, 임의 종합점수, 특정 후보를 통과시키는 기준 변경을 금지한다. 추가 실험은 사전 버전을 올리고 범위를 명시한다.
5. 독립 검토자가 조건 동등성·실패·누락을 확인하고 수용 범위를 판정한 뒤에만 선택을 기록한다. 현재 측정값과 최종 선택은 전부 `null`이다.

현재 두 후보는 격리 상호작용을 수행했다는 근거만 있다. 정상 인증/RLS, 실제 PDF, 색 대비·전체 키보드·스크린리더, 실제 TTS, 비용, 사용성/학습 효과는 미검증이다. 이번 D2 산출물은 **선정 절차**이며 최종 승자나 제품 수용이 아니다.
