# T-0135 — T-0134 후속 S1 설계 선정

핵심 6개 기능은 **F01/F03/F05/F07 IMPROVE, F04/F08 REPLACE**를 선정한다. 선정 대상은 **정답 공개 후 부분 분석을 사용하는 판단·탐색의 상호작용 계약과 기본 배치**다. F02/F06/F09/F10은 불변 계약만 확정하고 구현 방식은 `BLOCKED_EVIDENCE`로 남긴다. 독립 검토 전 현재 상태는 `CORE6_SELECTED_FOR_INDEPENDENT_SCOPE_REVIEW`다. 전체 S1 제품 수용·내용 감수·학습 효과 PASS를 선언하지 않는다.

기준은 `b7fa848fdfdf2fd34c77ab42c1e3bd9483e7c572`. T-0134 COMPLETED 이력과 그 결과를 보존하고 연결 후속 **T-0135**, 동일 owner `csat-v4-s0`·동일 worktree/branch에서 수행했다. 공식 COMPLETED 재개 전이가 없어 완료 이력을 고치지 않았다. 새 제품 라우트·DB·main 통합·S2 전체 구현은 수행하지 않았다.

## 선정 방법과 증거 범위

먼저 학습자가 해야 할 판단, 내용 축의 정직성, 근거 신뢰성, 자유 탐색, 접근성, 유형 확장을 비교했다. 필수 계약 위반 후보는 탈락시켰다. 같은 계약을 충족한 후보 사이에서만 추가 상태·유지 대상·통합 위험을 정성 비교했다. 코드가 이미 있거나 새롭다는 사실 자체에 가점을 주지 않았다. 개발 시간·비용·효과 점수는 측정하지 않았다.

대안 이름은 **바꾸려는 책임**을 뜻한다. F04 REPLACE는 데이터 스키마 대신 판단 제시 구조를 교체한다. F08 REPLACE는 기본 작업면을 교체하며 기존 모든 Shell/라우팅을 폐기하는 결정이 아니다. NEW의 새 엔진·파서·원장은 구현하지 않았다. 같은 데이터 렌더에 설명만 더한 시연을 완성된 신규 아키텍처와의 성능 비교로 보고하지 않는다. 원래 구상과 실제 구현 차이는 [기능별 기록](./DECISIONS.json)에 남겼다.

기존 검증은 재실행하지 않았다.

기능별 코드 관계·비용/위험·남은 조건·독립 판정 필드는 [DECISIONS.json](./DECISIONS.json)에 모두 기입했다. 독립 판정은 작성자가 미리 PASS로 채우지 않고 고정 커밋에 대한 별도 영수증으로 결속한다.

**F01/F03/F05:** 기존 requirement/meaning_ids/sentences/claims.basis/limitation은 보존한다. 같은 출처 계약을 충족하는 개선·분할 대안 중 추가 상태가 적은 개선을 권고한다. 이는 이미 존재하는 코드를 반드시 사용한다는 제약이 아니다. 이후 다른 구현이 같은 계약을 더 잘 충족하면 교체할 수 있다. 조건 선택은 원문을 바꾸지 않는다. 근거 선택은 등록 참조를 보여 주며 타당성·숙달을 채점하지 않는다. F05의 경계 질문과 조건/한계 대조는 원리를 검토할 수 있게 하는 구조이며, 실제 다른 문항 적용·반례 학습 완료가 아니다.

**F04:** 동일 사례 비교를 위해 모든 후보에서①→③→②를 직접 선택했다. 기존 V3Judgment는 실제 내부 버튼을 조작했고, 다른 후보는 동일 원본 truth/fit/decisive를 썼다. 기존 패널도 내용 진위와 발문 적합성을 구별한다. 개선·교체의 차이는 **판단 내용을 나란히 유지할 수 있는가**다. 순차 확인 후보보다 동시 대조판을 선정하는 이유는 ①/③의 논리 차이를 현재 화면에서 확인할 수 있기 때문이다. 기억 부담 감소·정답률 개선은 측정하지 않았다. 실제 해설의 ‘독립 검수’ 배지는 기존 컴포넌트 출력이며 이번 내용 감수의 증거가 아니다.

**F07:** 기존45 core 테스트를 재사용하고, 새로 실제 `LecturePlayer`에 수동 Promise 완료·주입 clock의 무음 시험 adapter를 연결했다. cue0→1에서 scene/scroll/focus 불변, 재생 중 직접 장면 선택, pause/resume을 관찰했다. adapter `outcome.errors`와 Promise rejection은 **새 격리 Shell 오류 경계**가 받아 player를 취소하고 마지막 cue·선택·장면·스크롤·포커스를 유지했다. 실제 엔진이 자체 오류 복구를 했다는 검증이 아니다. READ만 대본을 보이고 SILENT/OFF는 숨긴다. OFF는 play/pause/resume/next를 막으며, 매체 선택만으로 시작하지 않고 명시적 재생 시 엔진을 다시 만든다. B/C/D는 같은 엔진·adapter를 쓴다. 별도 엔진/오케스트레이터의 아키텍처 동등성은 미검증이다. 실음성·rate/seek·visibility lifecycle·정상 공개 API가 남아 있다.

**F08:** 1280폭에서 판단 면적은 3면 시연619.922px, 선정2면755.391px, 좌우 반전2면751.516px였다. 이것은 실제 CSS 기하이며 가독성·인지 부하 점수가 아니다. 3면 후보는 실제 AnalysisTheater 패치가 아닌 **문서용 구조 시연**이다. 따라서 전체 기존 Shell 수정안과의 종합 우위는 주장하지 않는다. 선정은 기본 작업면 topology와 직접 탐색 계약까지다. 전문 PDF가 들어올 때의 가독성, 복귀 통합, 스크린리더, 3B 시각 일치는 추가 확인한다.

## 독립 검토·수용 경계
