# 강의·공개·사용자 제어 계약

원본 37 cue는 [LECTURE_CUES.json](./LECTURE_CUES.json)의 originalScript에 그대로 보존한다. 34 version2/12차례/196초 추정, 22 version2/13차례/182초 추정, 38 version3/12차례/185초 추정. cue est_sec 합과 total_sec_est는 서로 같은 실제 재생시간이라는 계약이 아니다. 분석 v5, 강의 version, proposal_revision, 원문/분석 contentHash는 서로 다른 결속 체계다. 현재 모든 cue가 최신 내용에 결속되었다고 입증하지 못했다.

## 공개 정책

path=EXPLORE|GUIDED|LECTURE, depth=KEY|EVIDENCE|ADVANCED, reveal=SOURCE_ONLY|LOCATION_HINT|RELATION_EXPLANATION|OFFICIAL_ANSWER, media=OFF|READ|TTS|SILENT. 경로/깊이/매체 변경으로 공개 동의가 자동 상승하지 않는다. 강의부터 시작은 허용하되 정답 포함 강의/힌트부터를 명시적으로 선택한다. 필수 퀴즈나 강제 순차 단계 없음.

| 공개 단계 | 허용 위험의 상한(설계 제안) | 보호 |
|---|---|---|
| SOURCE_ONLY | none | 원문 관찰만. 정답 라벨/관계·강조·음성·ARIA 감수 전 숨김 |
| LOCATION_HINT | strategic_hint | 위치 힌트 동의 후, 관계로 답이 암시되면 다음 수준 동의 필요 |
| RELATION_EXPLANATION | answer_implying | 답을 간접 암시할 수 있음을 알리고 요청 시 공개 |
| OFFICIAL_ANSWER | direct_answer | 공식 답과 해설 공개; 되돌려도 과거 도움 이력을 독립 풀이로 소급하지 않음 |

위험 분류는 원본37에 대한 보수적인 임시 검토다. none도 본문·UI 조합에서 안전하다는 확정이 아니다. 텍스트, 정답 숫자, 관계선, 강조 색/순서, 선택지 상태, tooltip, 음성, ARIA/숨겨진 DOM을 모두 같은 정책으로 필터해야 한다. 네 축 모든 조합은 아직 실행하지 않았다(AT10 BLOCKED). 공개 불가 cue는 대본 전문을 DOM에 숨겨 두지 않고 전달/표시 경계를 검증한다. 필터로 사라진 cue를 자동 건너뛰며 답을 암시하는 순서 변화도 검수 대상이다.

## 미디어와 상태 전이

| 동작 | 다음 상태 | 반드시 보존 |
|---|---|---|
| OFF | 음성 취소·임시 cue 강조 해제 | 학생 선택 장면/근거/스크롤/포커스/도움 이력 |
| READ 선택 | 선택 cue의 허용된 대본 표시; 자동 재생 없음 | 학생 탐색 위치 |
| TTS 시작/다음 cue | 허용된 대본만 발화; 현재 cue/재생 상태만 갱신 | 장면/스크롤/포커스 자동 이동 금지 |
| SILENT | 선택 cue의 허용된 근거 표시; 소리 없음 | 다른 패널 자동 열기·이동 금지 |
| 학생이 근거 열기 클릭 | 해당 근거로 명시적 탐색 | 돌아갈 위치·직전 문항 맥락; 호출 컨트롤로 복귀 가능 |
| TTS 오류/음성 없음/취소 | 현재 cue에서 일시 중지+짧은 상태 안내, 같은 공개 수준 READ 선택 제공 | 처음으로 리셋·공개 수준 상승·포커스 강탈 금지 |
| 경로/깊이/공개 변경 | 허용 집합 재계산, 불허 음성 취소 | 학생 선택 위치; 이미 받은 도움 이력 유지 |
| 닫기/복귀 | returnContext로 돌아감 | ACTIVITY만 남김, 숙달 변경 없음 |
