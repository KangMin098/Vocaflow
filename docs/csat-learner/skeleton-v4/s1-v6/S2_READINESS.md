# S2 착수 판단과 최소 순서

**전체 수직경험 S2 착수 승인: BLOCKED_EVIDENCE.** S0 입력은 수용되었지만 F01~F10 선정 근거가 아직 부족하며 정상 인증·원문 PDF·전체 선지·내용 감수·TTS가 미검증이다. S1 의사결정 문서 제출은 완료할 수 있으나 ‘최적안 선정 완료’는 아니다. 구현 파일 변경·DB 변경을 이 문서로 승인했다고 해석하지 않는다.

**제한된 대안 시연 준비: 가능.** 실제 확보된 부분 분석과 원본을 명시한 격리 환경에서 네 후보의 근거/판단/강의 배치를 비교하는 비공개 프로토타입은 다음 작업으로 가능하다. 가짜 원문·선지·비교짝·학생 결과를 채우지 않으며, 원문 없는 시연으로 내용/제품 PASS를 선언하지 않는다. 현재 T-0131는 문서 허용 경로이므로 제품 구현 전 기존 작업의 owner/allowed_paths를 적절히 amend해야 한다. 새 TASK/브랜치/PR는 필요조건이 아니다.

1. 정상 로그인·권한 확인: 비밀값을 문서로 옮기지 않고 실제 허용 계정과 원문 접근 경로를 사용한다. 실패 시 BLOCKED 유지; 인증 우회 금지.
2. 34의 합법 PDF·발문/선지 전문을 기기에서 읽고 분석 앵커와 대조한다. 공식답/관찰/추론/가설 출처와 hash/version을 구별한다. C/D 내용 감수로② 진위 미확정·If/Ideally/cannot be·①/③ 전체 명제를 검토한다.
3. F01~F08 네 후보를 같은 자료/공개 단계에서 비교. 제어 위반 두 후보는 제외. 판단 가능성·조건 보존·부담·유형 확장·접근성·정합성의 반례를 기록하고 통과 후보 사이에서만 개발/검증/유지비를 비교한다. 자료 없으면 UNDETERMINED 유지.
4. 34 수직 시연: 직접 탐색+한정+근거+선지+원리 경계+12cue. OFF/READ/TTS/SILENT·누출·오류·복귀·활동/숙달 분리 검증. pairs0는 자원 없음 그대로. 실제 학습자 관찰 가능 여부는 별도 기록한다.
5. 22/38로 반증: 부분 사실/전체 요지와 조동사, 앞뒤 접합/기존 연결 보존/넓은 these. 두 문항 비교짝은 양쪽 접근·결속·내용 검수 후 사용한다.
6. 듣기는 메타 등록만 준비됨. 원음·전사·화자·시간·권리가 확인되기 전 청취 증거 기능의 착수/수용은 BLOCKED_EVIDENCE다. 강의TTS로 평가 원음을 대체하지 않는다.

S2 수용에는 AT01~18/21~22를 실제 정상 환경에서 실행하고 FAIL/BLOCKED를 해소해야 한다. 학생 사용성 관찰, 이해 설명, 다른 실제 기출 독립 적용, 장기 성적 효과는 서로 다른 후속 평가다. 활동이나 강의 완주로 학습지도 숙달을 승격하지 않는다. 승인 없는 학생 개인정보 수집/DB 적재 없음.
