# 34·22·38 판단 시나리오 계약

아래는 실제 v3 분석과 원본 강의에 대한 **설계안**이다. 전문 원문/영문 선지를 복원한 자료가 아니다. 선택지에 대한 문구는 기존 분석의 요약이다. 공식 답 값은 현재 저장값이며 원문 PDF와의 독립 정답 대조는 NOT_VERIFIED다. 모든 연결 추론·원리·수정안은 내용 감수 대기다.

각 장면 데이터는 question / requiredQualification / sourceEvidenceRefs / inferenceRefs / optionalAction / feedbackByChoice / cueBindings / disclosureRisk / dataStatus / fallback / returnContext / provenanceAndRevision을 가진다. 질문과 필수 한정은 함께 보이고 상세만 접는다. 경로·깊이·공개·매체의 독립 조작은 [강의 계약](./LECTURE_CONTRACT.md)을 따른다. 의미 있는 선택/근거 연결을 제공하되 필수 퀴즈·자유서술 자동 채점은 없다.

## 2026-34 — 조건 안에서 완성 명제 비교

첫 질문: **이 조건에서 법을 자유의 구속으로 볼 수 있는가?** 필수 한정: 6번 Ideally/would freely choose, 7번 If/would not rationally choose to do anyway/cannot be. 1번 자유 보장과 대조한다. If/Ideally는 심화 접기 안에 숨기지 않는다.

학생이 6·7번 한정 구간을 직접 선택하면 관찰 범위만 강조한다. 연결 이유를 열면 ‘원래 이성적으로 하지 않을 일만 금지한다면 빼앗긴 선택인가’를 추론으로 제시한다. 그다음 ①/③의 전체 선지를 원문에서 확보했을 때만 완성 명제 대조를 연다. 현재 전문 부재 상태에서는 분석 요약과 부분 인용임을 표시한다. 부정어 뒤 반대말 선택 공식으로 바꾸지 않는다.

| 선택 | 현재 분석 구분 | 피드백 설계 |
|---|---|---|
| ① | content_truth=false / requirement_fit=fails | 제한 자체와 합리성을 혼동하는 지점을 완성 명제와 근거로 대조. 모든 현실 법에 대한 판정으로 확대 금지 |
| ② | content_truth=unknown / requirement_fit=fails | 칸트/법의 행위자와 요구의 연결을 확인. 지문으로 진위를 확정할 수 없으므로 거짓으로 단정 금지 |
| ③ | content_truth=true / requirement_fit=satisfies | 저장 정답 ③. 위 조건 안에서 법이 자유의 구속이라는 결론이 부정되는 연결을 설명 |

근거 index5는 화면 6번으로 변환한다. 분석 revision v5와 강의 version2를 별개로 표시한다. cue c1/c4/c12 수정안은 원본과 분리한다. 직접 비교 pairs=[]: ‘연결된 비교 문항 없음’; 원리 확인은 가능하나 직접 전이 완료·성공 표시 없음.

## 2026-22 — 부분 사실과 전체 요지

첫 질문: **경쟁 쏠림 진단이 글 전체 처방을 대표하는가?** 필수 한정: Often/may/might를 경향·가능성 그대로 보존. 정의 2번, 진단 7~8번, 조건부 처방 6·9·10번을 다른 역할로 표시한다.

학생이 ③과 전체 요지 영역을 번갈아 선택하면 그 선택지가 포괄하는 범위만 표시한다. ‘부분 사실이므로 정답’도 ‘오답이므로 거짓’도 피한다. ③은 content_truth=true / requirement_fit=fails; 저장 정답 ①은 전체 처방을 포괄하는지 근거를 요청해 확인한다. 맞춤 피드백은 관찰(경향 서술)→추론(중심성 부족)으로 나누며 내용 감수 대기 라벨을 유지한다. 지시 표지 뒤가 언제나 정답이라는 규칙을 만들지 않는다.

실제 짝 메타데이터: 2026#22~M2609#22, 2026#22~M2706#22. 진단/정의 등의 보조 내용을 전체 명제로 올리는 공통 오류가 비교 초점이다. 상대 문항 본문·선지·권한·양쪽 결속 검증 전에는 비교 활동을 제공했다고 보고하지 않는다. index5→6번. 분석 v5 / 강의 version2. c13 수정 제안은 원본 대체 아님.

## 2026-38 — 앞뒤 접합과 기존 연결 보존

첫 질문: **이 위치가 앞의 서사와 뒤의 정체성 예시를 함께 잇는가?** 필수 한정: these는 4~7번의 넓은 서사 형성 맥락으로 보고 6~7번 단독만을 유일 선행사로 못박지 않는다.

학생은 이동 버튼 또는 키보드로 ④/⑤ 위치를 선택한다. ④를 고르면 기존 6→7 대학 예시의 연결이 끊기는 부분, ⑤를 고르면 앞의 서사→주어진 정체성 진술→8번 For example의 양쪽 접합을 나란히 표시한다. 드래그를 요구하지 않는다. 새 위치 선택은 원문을 변조 저장하지 않는 보기 동작이다.

모든 위치의 content_truth=n_a. ①~④ requirement_fit=fails, ⑤ satisfies. 저장 정답 ⑤. 위치 부적합을 내용 거짓으로 바꾸지 않는다. ‘반복되는 예시 표지의 짝 없는 앞’이라는 만능 공식은 배제한다. index7→8번. 분석 v5 / 강의 version3. c1/c12 수정 제안과 넓은 these 맥락 감수 필요.

실제 짝: 2026#38~M2706#38(기존 일반-예시 연결), 2026#38~M2706#39(선행사·첫 실험 및 also 관계). 실제 상대 원문·권한이 확인되기 전 공개/전이 경험은 BLOCKED_EVIDENCE다.

## 화면·상태 및 복귀

1280/1440 중립 PC 화면에서 상단 문항/자료 상태, 핵심 질문+한정, 증거면, 판단면, 요청 시 교수 영역을 시연한다. 아직 구현 대안 네 개의 실제 비교는 없다. 현재 캡처를 새 설계의 화면 검증 PASS로 재사용하지 않는다.

원문 없음→기기에서 합법 PDF 선택 안내+준비된 분석 부분 표시. 선지 없음→완성명제 조립 비활성+분석 요약임을 명시. 의미 없음→원문 근거만 제공. 강의 없음→탐색 지속. 비교 없음→자원 없음. hash/version/문장 수 mismatch→관련 자원만 중단하고 재확인. 접근 거부→비공개 내용을 로컬 캐시로 대체하지 않는다. returnContext는 진입 item/TASK/Workspace/탭/선택 위치를 보존하며 누락 시 안전한 원래 목록으로 복귀한다. 종료·확인·재생은 ACTIVITY이며 MASTERY_DECISION을 만들지 않는다.
