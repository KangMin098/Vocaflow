# T-0148 사람 채점 키트 — 정리(formula) 블라인드 26

> 채점자: 사람 1명 이상(수능 영어 지도 경험자 권장). 이 표본이 과잉 일반화인지 정상인지는 **알려 주지 않는다** — 정답 키(`grader_regression_key.json`)는 채점이 끝날 때까지 열지 않는다. AI 채점 결과 파일(`grader_regression_scores*.json`)도 보지 않는다.

## 방법

1. 각 대본을 읽고, 필요하면 문항 ID 로 실제 기출(지문·선지·정답)을 확인한다.
2. 두 기준으로 각각 0~10 점을 매긴다.
   - **A = 현재 main 기준:** 「다음 같은 유형에 옮길 한 줄 규칙 + 첫 십 초에 할 일」
   - **B = v3 후보:** `GRADER_formula_v3_candidate.md` 의 판정 순서
3. 이 정리 규칙이 학습자에게 틀린 일반 규칙을 가르치는지 **예 / 아니오 / 모름** 으로 답하고, 예라면 반례 문항 ID 를 적는다.
4. 결과는 `human_scores_<채점자>.csv` 로 저장한다. 열과 2단계(반례 자료) 절차·판정 기준은 `../g/A_T0148_HUMAN_EVAL_CONTRACT.md` 를 따른다

## 판정 기준 (사람 채점 후)

- 정상 집단 평균 하락(A→B)이 0.5 이하이고, 과잉 일반화 집단 하락이 1.5 이상이면 v3 를 GRADER 에 넣는 근거로 삼는다.
- 「틀린 일반 규칙」 판정이 키와 어긋나는 대본은 키 자체를 다시 감수한다(AI 감사의 오판 가능성 — 2014A#32 사례).
