# formula(정리) 채점 기준 v3 후보 — 과잉 일반화와 올바른 원리 구별

> T-0148 보정 후보다. `GRADER.md` 에는 아직 넣지 않았다. 사람 채점 결과(`HUMAN_SCORING_KIT.md`)로 확인되기 전에는 적용하지 않는다.
> v2 의 문제(Codex REJECT P1) — 「표지 하나로 답」이라는 **형식**만 보고 깎았다. 그래서 원리가 참인 정상 정리(M2606#18 · M2109#23)는 깎였고, 반례가 있는 규칙(M2606#45)은 깎이지 않았다. v3 는 형식이 아니라 **규칙이 참인지(반례가 있는지)** 로 먼저 가른다.

## 판정 순서 (위에서부터, 처음 걸리는 칸)

| 단계 | 질문 | 점수 |
|---|---|---|
| 1 | 정리 규칙에 **반례**가 있는가 — 같은 지문의 다른 선지·밑줄, 같은 강의의 교정·설명, 또는 문항 ID 로 댈 수 있는 다른 기출 | 있으면 **0~4**. 같은 지문·강의 안의 반례면 `factual_error: true` |
| 2 | 반례가 없고, 규칙이 **이 문항의 우연한 속성**(부정어가 든 선지·회사 이름·따옴표 형용사 등 — 유형 정의와 무관한 것)을 답의 조건으로 삼는가 | **3~5** |
| 3 | 반례가 없고 원리가 유형 정의상 참이지만, 확인 단계 없이 「~가 답」으로 끝나는가 | **6~7** (구체성은 깎지 않는다) |
| 4 | 반례가 없고, 표지 → 범위 → 내용 확인 순서이거나 「이 문항에서는 / ~인지 확인」으로 적용 조건을 밝혔는가 | **8~10** |

- 「다음에는 첫 십 초에」 행동이 strategy 와 다르면 1점을 깎는다(기존 규칙).
- 지문에 맞춘 구체적 확인 절차는 깎지 않는다. 일반론은 기존 보정대로 낮게 준다.
- 반례를 댈 때는 **문항 ID 와 위치**를 `fixes` 에 적는다. 댈 수 없으면 1단계에 넣지 않는다 — 「반례가 있을 것 같다」만으로는 깎지 않는다.
