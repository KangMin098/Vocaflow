## 3. 정리 규칙 계약 (생성기 수정 후보 — 이 브랜치의 WRITER·GRADER 변경)

1. 정리가 옮기는 것은 **답을 정하는 표지가 아니라 확인 순서**다(표지 → 범위 → 내용 관계).

3. 조건이 있어야 성립하는 규칙은 조건을 앞에 말한다. 이 문항에서만 통한 요령은 「이 문항에서는」으로 시작한다.
4. 같은 지문의 다른 선지·밑줄과 같은 강의의 교정에 대 본다. 어긋나면 `factual_error` 다. 다른 기출 반례는 `fixes` 에 ID 와 함께 적고 이 항목에서 깎는다(독립 검증 P3 반영 — 채점 재현성).
5. intro·strategy 는 같은 행동을 말하되 정리의 결론을 미리 말하지 않는다.
6. GRADER `formula`: 조건 없는 단정 규칙은 6점 이하.
7. WRITER 실패 표에 연결어→방향 규칙 · 대동사 규칙 · 35번 「N 번 문장」 target 행을 추가했다.

적용 범위: 앞으로 생성·재생성하는 강의의 지침이다. 기존 강의 원본은 일괄 수정하지 않는다.
