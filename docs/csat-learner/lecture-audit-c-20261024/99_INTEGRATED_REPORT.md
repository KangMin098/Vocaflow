## 4. 패턴 — 원리 적용 한계

1. **마무리 cue(c13·c14)의 규칙 과일반화가 22건 중 13건이다.** 개별 문항의 우연한 속성을 유형 규칙으로 올리는 일이 반복된다. 예: 부정어 선지, 회사 이름 문장, 같은 낱말 뒤집기, 세미콜론의 방향, 따옴표 형용사. drain D2의 「표지 하나 → 답」 반례와 뿌리가 같다. 새 반례는 2025#35④, 2026#35④, 2019#29의 정도 비교다. 생성 규칙에 「마무리 규칙은 이 문항 한정 표현 + 확인 절차」를 강제하는 것이 가장 큰 단일 레버다.
2. **35번 무관 문장 3건(M2106·M2206·M2209)은 정답 근거 cue의 target이 도입 문장을 가리킨다.** B 범위의 서수 −1 어긋남과는 형태가 다르다. 그러나 같은 생성기 결함일 수 있다. 35번 전체를 기계적으로 전수 대조하는 것을 권한다(이번에는 하지 않음). B owner와도 대조해야 한다.
3. **논리 연결어를 방향 규칙으로 바꾸는 오류가 있다.** thereby, 세미콜론, can't…without, not A but B가 그 예다. 「연결어 → 방향」이 아니라 「연결어 → 범위 → 내용 확인」 순서로 가르쳐야 한다.
4. **오답 소거 근거의 사실 오류는 드물다(2건: M2506#31, 2025#33).** 정답 성립 논리와 정답 번호는 632건 전부 이상이 없었다.
