## 4. 교육 효과 — 미검증 · 검증 계획

실제 학습자가 없다. 클릭 · 체류 · 노트 수 · 완주는 효과의 대리지표가 아니다. 효과를 말하려면:
1. **동의**: 미성년 포함 시 보호자 동의 · 기록 범위(노트 원문은 연구용 별도 동의).
2. **독립 평가 과제**: 탐구 전/후, 해설 없이 같은 유형의 **처음 보는** 기출 문항에서 근거 문장 · 선지 성립 조건을 쓰게 한다(탐구 화면과 분리된 세션).
3. **루브릭**: 근거 위치 정확도 · 요구 조건 진술 · 바뀐 성분 식별 · 원리의 적용 경계 진술 — 두 채점자(에이전트 + 사람 1) 일치도 0.85 이상만 사용.
4. **지연 전이**: 1주 · 4주 뒤 다른 유형(교차) 문항으로 재측정.
5. **비교군**: 탐구 장면 없이 기존 해설만 읽은 조건과 비교. 효과 크기와 신뢰구간으로 보고.

## 5. 남은 위험

- 실제 공개 교차 유형 비교 쌍 0 — 교차 유형 조회는 픽스처로만 검증.
- 보류(embargo) 문항의 실화면은 보류 데이터가 있어야 재현 — 단위(`embargo-gate*`)로만 검증.
- 로컬 메모리 부족으로 E2E 가 간헐 실패(`ERR_INSUFFICIENT_RESOURCES`) — 재실행으로 통과를 확인했고 실패를 통과로 세지 않았다.
