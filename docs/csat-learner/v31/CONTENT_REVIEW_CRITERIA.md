# 원문 이해 교수 설명 검수 기준 — meaning-support-v1.0

이 문서는 v3.1 구현용 **별도 콘텐츠 기준 설계**다. 기존 source corpus 보관 판정 기준이나 inquiry v3 검수 기준을 변경하지 않는다. 새 교수 설명의 공개 gate는 이 버전과 현재 contentHash/binding/revision의 명시 pass를 요구한다.

## 판정자와 입력

- 작성 세션과 분리된 에이전트 세션/검수 컨텍스트. 작성자의 자기평가·합리화·예상 검수 답을 받지 않는다.
- 입력은 원문·발문·선지·원본 시각 자료의 확인 상태·새 교수 설명 전체·현재 분석 버전/근거 결속이다. 기존 해설은 비교 자료이며 사실의 정답지로 사용하지 않는다.
- 공식 정답·원문 관찰·의미 연결 해석·설계 가설·설명용 비유를 구별한다. 실제 학습자 참여 유무는 콘텐츠 정확성 검수와 별개다.

## 판정 축

| ID | 확인할 내용 |
|---|---|
| MS01 | 주체·술어·대상·화자·수식/절 결합이 원문 문맥과 맞음 |
| MS02 | 쉬운 말이 주체·조건·부정·범위·가능성·시간·지시·비교를 보존 |
| MS03 | 구문 부분과 재결합 의미가 일치, 원문 오류와 교정 예를 구별 |
| MS04 | 두 명제의 연결과 실제 의미 변화가 설명됨; 라벨/접속사만으로 판정하지 않음 |
| MS05 | 전체 이해가 명제·관계·사건·예외와 일관; 유형에 다른 논리 구조 강요 없음 |
| MS06 | 명시 정보·연결 추론·외부 비유/확장의 근거와 한계 구별 |
| MS07 | 문항 성립/설계 연결의 실제 referent 확인; 출제자 속마음 단정 없음 |
| MS08 | 문장/구절/범위/중복 occurrence/읽기 순서 결속, 같은 길이 다른 원문 차단 |
| MS09 | 원본 도표 미확인 수치 보류, 서사 화자/층위·공유 지문·위치 선지 예외 처리 |
| MS10 | 새 영어 인용0·기존8단어 표현 재사용·범위 기반 표시·한국어 원문 재구성 권리 검수 |

## 판정 기록과 공개

`pass|revise|hold` + 이유/MS ID, item/schema/revision/binding/contentHash/criteriaVersion/writerRun/reviewerRun을 기록한다. 필수 근거 없으면 hold, 내용 오류면 revise. 모든 적용 항목에 문제 없을 때만 pass. 필요 없는 구문/오해 지원은 n/a 사유를 기록하고 빈 값으로 채우지 않는다. 동일 hash에 revise가 있으면 보수적으로 hold, 옛 pass를 재사용하지 않는다.

대표8문항은 전량 원문 재대조. 확대 회차는 유형/지원·검수 위험별 재대조 표본 manifest와 독립 판정 불일치를 기록한다. 일치율만으로 설명 정확성을 선언하지 않는다. 과거 검수 판정이 뒤집혀 반복되는 경우 다음 회차 후보로 비공개 보류한다.
