## 분석 중심 재설계 — Gate -1 (2026-09-17)

- Next.js 14.2 App Router / React 18 / Node 24 / pnpm 9, pnpm-lock.yaml 유지. 새 의존성 없음.
- KEEP: PDF.js reflow·좌표 색인·문장 정렬·IndexedDB PDF 캐시, 강의 엔진, 관리자 /admin/kice, RLS 인증, 기존 record/reveal API와 과거 풀이 데이터.
- MODIFY: SessionHome/SessionRunner/ItemScreen/ProgressView를 예측·대조·공식 경험으로 교체. 기존 세션 CSS와 PaperDrop 재사용. 셸의 풀스크린 경로·학습자 라우트 정본 동반 변경.
- MOVE: /csat/session → /csat/dissect, /csat/progress → /csat/formulas. 기존 분석 관리자 이동은 이미 끝났으므로 재이동 없음.
- REMOVE CANDIDATE: ItemScreen의 풀이 타이머·정오 채점 UI. import 조사 결과 관리자 문항은 이 컴포넌트를 사용하지 않는다. shared session/model/store/API와 ReflowPassage는 삭제하지 않는다.
- CREATE: 분석 준비도 판정·보기 생성·대조 세션 순수 모델, 버전 분리 기기 공식/전이 저장, 3수 자동 회귀, 데이터 채움률·시각 게이트 보고.
- /frontend-design은 설치되어 있지 않다. 기존 D1처럼 vocaflow-design 정본과 주묵 판면을 사용한다.
- 신규 예측 기록을 기존 정오 기록에 억지로 넣지 않는다. PDF와 새 기록은 기기에 보관하고 기존 서버 API 계약 및 과거 기록은 보존한다.
- 실측 802문항의 정답·의도·근거 설명은 모두 존재. 소재/공식/변형 이력의 전용 필드는 없다. 의미 검토한 분석·강의 wrapup에서 파생 메타데이터를 만들고, 준비도 미충족 문항은 제외한다. 빈칸을 임의 문자열로 채우지 않는다.
- 새 공식은 wrapup에서 도출한 출제 설계 규칙이다. 같은 규칙을 검토한 문항은 동일한 공식 한 줄을 공유하며 원래 wrapup 출처도 보존한다. 변형 카드는 확인된 동일 형식의 다른 문항을 근거로 한 가설임을 명시한다.
- 예측 보기 순서는 기기별 난수 seed로 안정적으로 셔플한다. 의도 보기의 길이 범위 ±20% 및 실제 유형·빈도에 근거한 함정 4개 조건을 충족하지 못하면 배포 후보에서 제외한다.
- 전이 큐는 같은 공식의 다른 문항만 허용한다. 3일 후 due 기준을 순수 함수로 검사한다. 같은 문항을 재출제하지 않는다.
- A3은 각 단계의 설명 텍스트를 조건부 미렌더로 지킨다. 정답은 처음부터 표시한다. 이전 D9의 정답 비공개는 이번 사용자 명세로 대체된다.
- Gate 1은 기존 측정 스크립트 재사용. Gate 2~4는 상시 Playwright 스펙에 375/768/1440·키보드·axe·스크린샷을 남긴다. 지문이 찍히는 이미지는 gitignore된 test-results 아래에만 둔다.

- 실제 브라우저에서 공유 골격의 검토 대상 앵커 누락을 확인했다. 공유 파일을 덮어쓰지 않고 로컬 PDF와 최신 published 분석으로 별도 dissect-anchors.json을 만든다. 문장 길이·SHA-256·근거 구간만 저장하며 인용 원문도 저장하지 않는다.
- 후보 배포: 802문항 전체 진단, 12문항 메타데이터 검토, 실제 동형 이력까지 있는 7문항 노출. 미검토 소재를 지어내지 않는다. 결함은 관리자 읽기 전용 목록에 표시하며 DB 스키마/원문은 바꾸지 않는다.
- 설계도에서 지문 반복을 접었다(375px 스크린샷에서 요약이 3,000px 아래에 밀림). 강의 UI는 관리자 공유 구현에 보존한다.
- 기존 reveal API는 사용자 API 계약 보존 지시로 유지한다. 정적 무호출 검사에 호환 사유를 명시한다.
- 전체 검증 중 피드 최신성 판정이 주입된 시각 대신 시스템 시각을 쓰는 날짜 의존 오류를 수정했다.
