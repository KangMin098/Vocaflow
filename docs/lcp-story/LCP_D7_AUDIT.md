## 10. 스크린리더·개인정보 실행 경계

기존 컴퓨터 사용 스킬로 설치/실행 상태를 확인했다. Narrator 실행 파일은 있었고 표준 NVDA경로는 없었다. 내레이터 실행 요청 중 물리 Escape로 Computer Use가 중단돼 실제 창/음성/점자 출력·Story 조작을 확인하지 못했다. 이후 사용자 지시 **‘내레이터는 스킵’**에 따라 추가 실행하지 않았다. 상태는 **NOT_RUN_USER_SKIP**, 실제 SR PASS나 제품 접근성 실패가 아니다(`E/screen-reader-status.json`). 기존 키보드/DOM/자동 검사 증거는 그 범위로만 재사용한다.

나중에 범위가 재개되면 실제 OS/브라우저/SR버전과 출력 관찰이 가능한 환경에서 탐색·본문·사전/W2·닫기/포커스·저장 알림·왕복·권한/오류를 확인한다. 개발자 AT 상호운용과 실제 숙련 사용자 사용성도 구분한다. 지금은 설치/새 엔진/다른 보조기술 실행을 추가하지 않는다.

실제 자료 수집 전 최소 데이터·가명과 식별자 대응표 분리·접근 역할·동의와 철회·보관/폐기 책임/기간·집계 공개 범위를 운영 주체가 기존 정책에 맞게 정한다. 참가자 원시 답·연락처/계정·녹화를 제품 이벤트나 AI 로그에 보내지 않는다. 단순 가명 코드는 완전 익명이 아니다. 제품 단어장/진도 삭제는 연구 참여 철회와 별도 기존 절차다. 보관 정책 미확인을 핑계로 임의의 개인정보 수집이나 법정 기간을 만들지 않는다.

## 12. 실제 외부 조건·다음 순서·종료 판정

1. 패킷 최종 비제작 내용 검토·근거 결속/문서 검사를 수용하고 기존 로컬 통합 경로로 반영한다. 실제 종료/최종SHA는 `E/integration.json`에 기록한다.
2. 실제 운영 주체가 동의/보관/접근·철회·참가자 조건을 확정한 뒤 모집/관찰한다. 이번 요청은 실제 모집/개인정보 수집 승인이 아니다. 준비 자료를 지정 비공개 운영 장소로 옮긴다.
3. C01 한 편으로 실제 읽기/이해/요청 도움/저장·왕복/같은 작품 재개를 관찰하고 거절·부적합·반례를 포함한다. 사람 데이터가 없으면 PILOT_NOT_RUN 유지.
4. 다음 작품 선택은 실제 적격 공급 후, C06은 별도 특정 권리 결정 후 기존 경로로만 진행한다. C01 파일럿을 그 결정까지 멈추지 않는다.
5. 독립 성장 연구는 미노출 평가형·보정·비교·지연 조건을 갖춘 뒤 별도로 실행한다. 실제 SR은 이번 사용자 SKIP을 유지한다.

**D7 감사·준비 완료 후보:** 제품 기본 여정은 구현/대표 기술 수용, 내용은 기존 독립 AI 검수, 관심/수준별 충분한 공급과 실제 사람의 자발 선택·이해·지속·독립 성장은 부분/미검증이다. 확인된 현 P0 없이 P1 실증/공급 조건과 P2 관찰 후보를 구분했다. 이는 전체 LCP 목표 달성이나 실제 연구 완료 선언이 아니다.
