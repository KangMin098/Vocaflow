## 사용 조건

- 문항은 C01 안의 이해 확인일 뿐이며 처음 보는 글의 독해 성장 · 교육 효과 증거가 아니다. 읽지 않은 범위는 `NO_OPPORTUNITY`, 전체 합산 점수 없음.
- u01 문항은 u02 첫 문장의 정정을 드러내지 않는다. u03 홈스의 결론은 인물의 주장으로 다루며 사실로 채점하지 않는다.
- 결측(읽지 않음 · 거절 · 무응답 · 「모르겠다」 · 기술 장애)은 모두 점수 null 로 수집 전에 고정 — 나중에 0 으로 바꾸지 않는다. 0 은 시도된 다른 뜻에만.
- 순서대로 뒤 단위까지 읽은 사람이 앞 본문에 근거해 답하면 정상 채점. 읽지 않은 줄거리 · 사전 친숙도 · 진행자 피드백에 기댄 답만 오염 표시. 읽기 거절 시 이해 문항 없음.
- 정답 피드백은 관찰 종료 뒤. 자연 오류가 없으면 `NO_OPPORTUNITY` — 오류를 주입하지 않는다.
- 열쇠 · Story 본문 · 정답을 Git · 학습자 화면 · 공개 소개에 두지 않는다. 런타임 폴더는 사람 자료용 승인 저장소가 아니다 — 운영 전 승인된 비공개 저장소로 옮기고, 참가자 자료는 그곳에만 둔다.
