| D6-E 독립 성장 | 미노출 영어 지문별 핵심 의미·인과·추론·새 문맥 적용. 사전/사후·지연, 동일 도움 조건·형 동등성·비교 조건·불확실성 보고 | Story 이해/재독·FSRS 기억 추정·단어 저장/완료 증가=전이 또는 인과 효과 |

초기 적합성 이해 코딩(4개 근거 단위): 각0=의미 오류/근거 없음,1=부분 이해·핵심 연결 일부 누락,2=핵심과 텍스트 근거 일치. 응답하지 않음·읽지 않은 범위는 별도 결측이다. 네 점수와 원인을 보며 합계8을 수준 합격선으로 쓰지 않는다. 도움 받은 설명은 지원 후 이해, 진행자 정답 암시 뒤 답은 오염으로 표시한다. 틀린 영어 문법을 이유로 의미 이해 점수를 깎지 않는다.

콘텐츠 검수 상태 `AI_REVIEWED`, `AI_INDEPENDENT_REVIEWED`, 실제 수행 시에만 `HUMAN_REVIEWED`, 기술 `TECHNICALLY_VERIFIED`, 효과 `EDUCATION_EFFECT_UNVERIFIED`를 구분한다. 새 DB 상태를 추가하지 않고 외부 평가 기록/정본에 대응한다. 권리의 특정 사용자 결정은 콘텐츠 사람 검수나 연구 동의를 대신하지 않는다.

## 5. 2단계 파일럿 프로토콜 v1

### 5.1 대상과 부담

D2의 **12~18명**을 초기 운영 가정으로 유지한다. 예를 들어6~9명씩 두 관찰 회차로 나누되 모집 가능성·발견된 문제에 따라 조정하고 회차별 제품/콘텐츠 버전을 고정한다. 이 수가 대표성·유의성·검정력을 보장한다는 주장은 없다. 여섯 유형 균등 할당이나 특정 CEFR 일괄 자격을 만들지 않는다. 영어 경험·독서 목적/장르·작품/영상/번역 친숙도·가용 시간·접근성 요구를 별도 확인한다.

우선 일반 PC 독서와 실제 보조기술 사용 관찰을 구분한다. 성인으로 먼저 운영 가능성을 확인할 수 있으나 청소년 결과로 일반화하지 않는다. 미성년자 참여는 해당 운영/연구 정책의 보호자 동의와 본인의 참여 의사를 충족할 때만 가능하다. 참여/거절을 성적·서비스 이용 자격과 결부하지 않는다.

### 5.2 시작 전 운영 준비

기존 [U4 시작 조건](./LEARNER_OBSERVATION.md#시작-조건과-개인정보)을 재사용한다. 신규 기술 승인 단계는 만들지 않는다. 실제로 필요한 항목만 확인한다.

- 평가 목적, 읽지 않기/중단/도움 요청의 자유, 녹화 여부, 수집 항목·보관/폐기 시점, 철회 방법, 비용/보상과 데이터 이용 범위를 이해 가능한 언어로 안내한다. 연구 참여/제품 이용/녹화 동의를 분리하며 미동의를 실패로 세지 않는다.
- 정상 본인 계정과 기기/브라우저 환경을 사용한다. AI 개발 계정·공유 관리자·다른 참가자 계정으로 사람을 대체하지 않는다. 기존 회원은 본인 동의 범위로만 기록을 대조한다. 연락처나 계정 매핑이 꼭 필요할 때만 지정 운영자가 별도 보호한다.
- C01 현재 권리·발행·주의 안내·정확한 revision/본문 해시와 실제 읽을 범위를 확인한다. 철회/권리 변동이면 제공 중단, 원인 기록, 승인된 다른 콘텐츠가 없으면 해당 독서 과제만 보류한다. 연구를 위해 철회·재발행/권한 변경을 하지 않는다.
- 아래 이해 문항의 근거·허용 답·다른 해석·오독 기준을 고정 본문과 대조해 잠근다. 아직 실제 참가자용 검증 문항 묶음/답안은 제작·보정하지 않았으므로 이 조건은 **준비 필요**다. 원문·정답은 공개 소개/HOOK에 넣지 않는다.
- 실제 자료의 비공개 저장소·접근 담당·보관 기간·철회 창을 운영 정책에 맞게 확정한다. 이 문서는 법적 동의서나 승인된 수집 정책을 대신하지 않는다. 해당 운영 주체가 연구 심의 등 적용 여부를 확인하며 AI가 법적 면제를 선언하지 않는다.

### 5.3 세션 순서 — 자유 관찰을 먼저, 요청 과제를 나중에

45~60분은 **예약 부담 가정**이며 독서 할당량이 아니다. 참가자가 더 일찍 끝낼 수 있다. 구두 동시 사고 발화는 독서를 방해할 수 있어 연속 독서 중 강제하지 않고 자연스러운 중단 후 회고한다. 진행자는 “단어를 저장해 보세요” 같은 요구를 자유 구간에 하지 않는다.

| 순서 | 진행자 안내·과제 | 남길 관측 |
|---|---|---|
| 0 동의·기준 맥락(약5~10분) | 동의 확인, 목적/경험/작품 친숙도/자기 시간 확인. 비밀 로그인 입력은 관찰·녹화하지 않음 | 동의 버전·참여 조건, 직접 식별 없는 기초 맥락. 유형은 가설 태그 |
| 1 Discover/Start 자유 구간 | “소개를 보고 읽을지 정해 주세요. 읽지 않아도 괜찮습니다.” 대체 작품 없는 사실을 고지 | 소개 이해, 선택/거절 이유, 로그인 마찰, 실제 읽기 시작. 관찰자의 제안 여부 |
| 2 Read/Help 자유 구간(본인이 정한 약10~20분 이내 제안) | 기존 R2를 원하는 만큼 읽고 필요하면 도움 사용. 도움/저장/완료를 유도하지 않음 | 실제 읽은 범위·도움 전후 흐름·중단 원인·자발 낱말 선택. 시간은 결과의 보조 맥락 |
| 3 자연 중단 후 적합성 면담(약5~10분) | “무슨 일이 있었나요?”, “왜 그런 행동을 했다고 보나요?”, “어디가 막혔나요?”, “계속/그만 읽고 싶은 이유는?” | 읽은 범위의 핵심/근거/인과, 흥미·불편 직접 응답. 해석/정답을 먼저 말하지 않음 |
| 4 D5 요청 과제(약5~10분, 별도 표시) | 본인이 원하면 관심 낱말 하나 저장→단어장→Story 복귀. 필요하면 중복 안내를 다시 봄. 자연 사용이 없었음을 실패로 만들지 않음 | 무도움/힌트/직접 개입 단계, 저장 상태 이해, 왕복 후 맥락, 단위 첫머리 재탐색. 자유 구간과 분리 |
| 5 선택·종료(약5분) | “이제 어떻게 하고 싶나요?” 계속 읽기/그만하기 모두 허용. 다른 Story는 현재 없음 | 선택 이유, 같은 작품 계속 읽기와 같은 세션 체류 분리. 다른 작품은 `NO_OPPORTUNITY` |
| 6 후일 관측(제안7일 창) | 이 기간 독서 알림·과제·점수 보상 없이 이용 선택. 기간 종료 뒤에만 동의된 확인 질문 | 지시 없는 실제 재개와 이유. 종료 질문으로 유발된 새 읽기는 그 뒤의 요청 행동으로 분리 |

12~18명/분량/7일은 계획 값이며 실측 수치가 아니다. 연락 실패·관측 거부·제품 오류·시간 부족·내용 거부를 구분한다. 7일 안에 돌아오지 않은 사실과 읽을 기회가 없었던 사유를 함께 남기며 장기 습관으로 일반화하지 않는다. 연구자가 요청한 중단/복귀 과제는 복구 사용성만 평가한다. 결말을 이미 아는 사람과 첫 독자는 같은 ‘서사적 놀라움’ 표본으로 묶지 않는다.

세션 안의 자유 선택도 연구 참여라는 맥락이 있다. 이를 평소 서비스에서 자연 발생한 선택과 구분하고, 관찰 밖 재개의 지시·알림·학교 과제를 함께 확인한다. 참여 보상이 있다면 완독·저장 수·재방문 여부와 결부하지 않는다. 연구 참여 동의가 관찰 밖 모든 개인 학습 기록의 무제한 수집을 뜻하지 않는다.

### 5.4 이해 문항 제작 틀 — C01에 적용할 범위

실제 참가자가 읽은 구간에서만 핵심 의미1·인과1·인물/화자 추론1·새 상황 적용1을 준비한다. 고정 R2 u08은 D3의 보존 항목/근거 앵커를 재사용할 수 있지만, 앞 단위 맥락 없이 u08만 보여주고 전체 Story 이해를 채점하지 않는다. 자유 독서에서 그 구간까지 읽지 않으면 다른 검증 문항이 없을 때 `NO_OPPORTUNITY`다.

예시 질문 틀은 “무슨 일이 있었는가/누가 무엇을 주장했는가”, “앞 사건 때문에 뒤 행동이 어떻게 달라졌는가”, “이 인물의 반응을 뒷받침하는 문장은 무엇인가”, “조건 하나가 바뀌면 같은 결론을 내릴 수 있는가, 왜인가”다. C01의 관찰·홈스의 추론/시대적 가정을 사실로 혼동하는지 확인하되 현대 편견에 동의하는 답을 정답으로 강제하지 않는다. 이 틀은 아직 원문 대조·독립 검토된 실제 문항/답안이 아니다.

한국어 설명·구두 답·근거 지목을 허용해 영어 말하기/작문 부담을 독해와 분리한다. 같은 세션 안에서 질문 반복/힌트 후 개선은 도움 효과 탐색이며 독립 성장 점수가 아니다. 관찰자가 답을 교정하면 시점과 범위를 기록하고 이후 문항 오염을 표시한다. 초기 소수의 이해 응답은 전부 독립 이중 코딩해 불일치·해결 근거·미해결을 남긴다. AI가 초안을 돕더라도 사람의 응답·정당한 해석·적합성 판단을 자동 숙달 처리하지 않는다.

|---|---|---|

가설 수정은 관찰된 반복 난점, 참여자 직접 이유, 재현 가능한 경로, 반례를 함께 검토한다. 단일 일화나 저장 수 증가로 영구 출처/문장 북마크를 필수 기능으로 승격하지 않는다. 자료가 부족하면 `DEFER_OBSERVATION`이다. FSRS 안정도/기억 확률은 복습 스케줄링 추정이며 어휘 습득의 평가 점수가 아니다. 어휘 유지가 별도 질문이 되면 새 문맥의 뜻/사용 이해와 실제 복습 노출을 분리한 작은 평가를 따로 설계한다.

## 7. 3단계 독립 독해·유지·전이 설계

### 7.1 측정할 구성개념과 자료 적격성

주평가 후보는 **처음 보는 영어 지문을 외부 뜻/번역 도움 없이 이해하는 정도**다. 영어 글을 보며 다시 확인하는 것은 허용하고 속도는 주평가가 아니다. 기존 SR 등 접근 편의는 유지하되 음성 읽기로 측정 양식이 달라지면 조건을 명시하고 시각 읽기와 무조건 합산하지 않는다. 학습 중 요청형 도움을 쓰는 것은 허용한다. 평가의 지원 후 이해는 독립 점수와 별도다.

자료는 적법한 원천·정확한 판/본문/문항/답안/루브릭 해시, 참가자별 노출 이력이 필요하다. Story/원작/번역/영상으로 이미 안 내용, 제품 미리보기·수업·단어 예문·다른 평가형을 통해 노출된 내용도 대조한다. 지문만 바꿔 같은 정답/줄거리 구조를 반복하지 않는다. 노출 원장을 못 읽었거나 친숙도를 모르면 `UNKNOWN`이며 미노출로 통과시키지 않는다.

기존 CSAT `assessment-exposure.ts`의 **exposed/unseen/unknown·같은 지문 다른 문항·예약 평가의 연습 제외** 원칙을 재사용할 수 있다. 현재 코드는 CSAT 원장에 결속되므로 LCP 전체 노출을 자동 검증한다고 주장하지 않는다. 우선 보호된 외부 평가 자료대장과 참가자의 사전 친숙도 확인으로 준비하고, 증거가 불충분하면 해당 지문은 독립 효과 분석에서 제외/민감도 보고한다. 이번에 엔진·데이터 연결을 구현하지 않는다.

### 7.2 평가형 청사진 v1 — 제작·보정 전

사전 A·사후 B·지연 C의 세 병렬형을 준비한다. 각 형은 처음 보는 서사1편과 정보/설명 글1편, 각 글4개 의미 단위(핵심·인과·추론·새 문맥 적용)로 **8문항×0~2점=16점**을 초기 설계 후보로 둔다. 세 형의 순서는 참가자/비교 조건 안에서 균형 배정해 형 난도와 시점이 항상 겹치지 않게 한다. 이것은 문항 제작 청사진이며 동등한 검사나 검증된 점수 척도가 아니다.

| 맞춰야 할 특성 | 검토·보정 방법 |
|---|---|
| 언어 | 길이·빈도/다의어·비유·절/종속 구문·지시/담화 연결을 따로 기록. CEFR 편집 라벨만으로 동등 판정 금지 |
| 서사·인지 | 등장인물/관계 수, 시간 이동, 단서 의존, 추론 단계, 배경 전제, 정서 부담·친숙도 대조 |
| 문항 | 요구 추론/근거 수, 정답 노출·선택지 단서, 한국어 응답 부담·채점 난도 대조. 근거 있는 다른 해석 허용 |
| 경험적 형 차이 | 본 연구와 다른 독자의 인지 면담·예비 반응으로 바닥/천장·모호함·형 차이 확인. 공통 훈련 지문을 사전/사후에 반복하지 않음 |
| 채점 |0/1/2 허용 답·근거 앵커·오독 예를 사전 고정. 평정자는 익명 답안으로 시점/조건/개발자 기대를 가능한 한 모르게 독립 채점 |

각 영역 문항 수가 작아 영역별 능력을 정밀 진단한다고 하지 않는다. 합계는 형 보정·채점 일치가 확인된 뒤에만 변화 비교에 쓴다. 형이 동등하지 않거나 바닥/천장이 크면 문항을 보정하고 효과 판정을 유보한다. 정답/피드백 공개는 지연 평가와 보완 창 종료 뒤로 미뤄 후속 측정 오염을 줄이고 그 제한을 동의 안내에 포함한다. AI 생성 문항·AI 독립 검토만으로 검사 타당성·동등성 확보를 선언하지 않는다.

### 7.3 시점·비교 조건·해석 범위

| 조건 | 운영 설계 후보 | 허용되는 결론·한계 |
|---|---|---|
| 단일 집단 탐색 | 사전→자율 독서 관측→사후→미노출 지연형 | 기술된 기간의 개인별 변화·실행 가능성. 연습/일반 학습/선택 편향 때문에 LCP 인과 효과 아님 |
| 선호한 비교 설계 | 준비되면 기초 이해/작품 친숙도 등을 고려해 LCP 접근 vs 비교 독서 접근 무작위 배정. 평가 접촉·기간·시험 조건을 맞춤 | 자율 선택을 보존한 ‘접근 제공’ 효과를 배정 기준으로 분석. 실제 많이 읽은 사람만 골라 인과 효과로 보고하지 않음 |
| 대체 비교 | 무작위가 불가능하면 사전 동등성·일반 영어 학습/관심·시간 등을 기록한 비교집단 | 잔여 교란·자기 선택을 명시한 연관성. 단순 사전/사후 차이만으로 동등성/인과성 확정 금지 |
| 지원 기능 분리 비교 | 충분한 표본·독립 질문이 생길 때 후속 | 현재 계획은 Story 경험 전체 평가. 저장/단위 복귀의 단독 효과나 각색의 우월성으로 결과를 분해하지 않음 |

초기 운영 후보는 독서 관측4~6주, 종료 후2~4주 지연 평가다. 이는 학습 효과가 보장되는 기간이 아니며 콘텐츠 공급/참가자 시간/예비 자료로 실행 전에 확정한다. 그 사이 다른 영어 수업·시험·동일 소재 노출·복습·지원 사용을 최소 부담으로 기록한다. 지연형의 새로운 글 이해는 시간 경과 후 전이 수행이지 같은 문항 기억 유지와 동일하지 않다. 같은 Story의 내용 기억이 별도 질문이면 그 결과를 따로 측정한다.

비교 조건의 권리·길이/장르·기본 읽기 지원·가용 콘텐츠를 기술한다. 현재 한 Story만으로 충분한 반복 독서량이나 다양한 전이 훈련이 가능하다고 가정하지 않는다. 전체 LCP 효과를 평가할 콘텐츠/노출량이 부족하면 3단계 실행 조건 미충족이며, 한 편의 단기 적합성 연구로 범위를 줄여 명칭/결론을 바꾼다.

표본 수는 주평가·실질적으로 의미 있는 변화·기준 변산·탈락·배정 단위/교실 군집을 근거로 계획한다. 지금 효과크기·검정력·유의성 목표 수치를 발명하지 않는다. 분석은 주평가 하나와 보조 영역을 실행 전 고정하고, 비교 설계에서는 사전 점수/형/배정 단위에 맞는 분석과 효과 추정의 불확실성을 보고한다. 표본 부족이면 기술통계/범위·개별 변화·한계만 보고한다. 탈락 이유/시점·집단별 결측을 공개하고 미실시를0점으로 바꾸거나 완료자만의 증가로 결론 내리지 않는다. 사후 문항 제외·채점 수정·계획 변경은 이전판·이유·민감도 결과를 남긴다.

## 8. 실제 스크린리더 평가 계획

현재 상태는 **실제 SR NOT_RUN**이다. D4/D5의 키보드·DOM/자동 접근성 증거는 재사용하며 전부 다시 실행하지 않는다. 실제 낭독/상호작용이 없는 접근성 트리 캡처만으로 SR 완료라고 하지 않는다.

실행 시 Windows·브라우저·SR의 실제 제품명/버전, 한국어/영어 음성·언어 전환·가상 커서/초점 모드를 기록한다. 우선 현재 PC에서 지원 가능한 Narrator+Edge 또는 NVDA+Chrome 한 조합을 실제로 확인하고, 설치/환경 변경이 필요하면 기존 환경 정책을 따른다. AI 작업자가 실제 음성/점자 출력을 확인할 수 없다면 그 부분은 미실행으로 남긴다. 숙련된 실제 보조기술 사용자의 동의 관찰과 개발자의 AT 상호운용 테스트도 구분한다.

| 시나리오 | 실제로 확인할 결과 |
|---|---|
| 소개→로그인→선택 Story | 링크 이름·편집 목표/주의 읽기 순서, 로그인 폼 이름/오류·선택 판본 복귀, 이전 개인 정보가 낭독되지 않음 |
| 본문→단어 도움 | 낱말 선택/대체 단추의 발견, 열린 비모달 도움 이름·상태·뜻의 읽기 순서, 배경 본문 접근을 적절히 유지 |
| W2 시대 맥락 | 접힌 summary 이름·펼침 상태, 해당 단위 설명 순서, 닫은 뒤 본문 찾기. 강제 선노출/스포일러를 점검 |
| 저장·중복·자연 오류 | 명시 저장 조작·busy/saved/already/error의 알림이 누락/과잉 반복되지 않음. 포커스·가상 커서 분리 기록 |
| Escape·단어장·복귀 | 도움 종료 후 실제 조작 위치/읽기 위치를 다시 찾을 수 있음, 단어장 복귀 바의 제목·단위 첫머리 의미, 안전한 로그인/철회 안내 |

기술 AT 확인은 비식별 승인된 개발 데이터/격리 오류 시나리오로 할 수 있다. 사람 관찰에 실패를 강제로 주입하지 않는다. 실패가 실제 발생하지 않으면 오류 안내의 사람 사용성은 미관찰이다. 성공은 독립/도움 필요/불가와 실제 낭독 증거로 기록하고, 한 조합 통과를 모든 SR/WCAG 적합 인증으로 일반화하지 않는다. PC1440/1280 배치 비교는 기존 결과를 재사용하되 SR/줌으로 새 문제가 발견된 해당 범위만 재확인한다.

## 9. 교사·학부모 가치와 권한

교사/학부모 화면을 만들지 않는다. 기존 교사 학급·과제 자산의 존재와 LCP Story 개인 진도 공유 권한을 구분한다. `class-actions.ts`/`assignment-actions.ts`는 정상 인증·본인 학급/RLS 경계를 사용하지만 Story 연구 자료의 추가 열람 권한을 주지 않는다. 학부모와의 관계를 확인하지 않고 개별 기록을 제공하지 않는다.

초기에는 실제 학생 데이터 대신 비식별/명시적으로 가상인 사례를 사용해 “어떤 작품을 권하고 싶은가, 왜인가”, “언어/배경/흥미 중 어떤 지원이 필요한가”, “이 정보로 무엇을 **알 수 없는가**”를 묻는다. 이는 지원자 정보 이해 평가이며 학생의 흥미/효과 증거가 아니다. 실제 학생/자녀의 정보가 필요할 때만 기존 권한·동의 범위로 최소 정보를 제공한다.

교사 추천/과제로 읽은 행동과 자유 선택을 나누고 학습자의 거절·다른 작품 선택을 허용한다. 학부모가 완료/저장/FSRS만 보고 이해·성장을 확신하는 오해를 반증 사례로 기록한다. 개별 발언/단어장/서사 취향을 보호자에게 일괄 공개하지 않는다. 이런 관찰 없이 관리자 대시보드·감시 기능을 선제 추가하지 않는다.

실제 평가 데이터는 **지정된 비공개 저장소**에서만 보관한다. 저장소 Git/runtime·제품 analytics·AI 프롬프트 로그에 참가자의 이름/UID/이메일·연락처·원시 답변·녹화·민감한 취향을 넣지 않는다. 참가자 코드는 익명이 아니라 재식별 연결 가능성이 있는 가명으로 취급한다. 동의 기록/연락처 대응표·답안·집계 자료를 분리하고 최소 담당자만 접근한다. 문서/개발 에이전트에는 식별을 제거한 승인 집계와 필요한 오류 재현만 전달한다. 원시 응답을 외부 AI에 제공할 근거/동의가 없다면 전송하지 않는다.

보관은 세션 원시 자료·동의/연락 대응표·비식별 집계 각각의 필요성을 따져 기간/삭제 책임자를 수집 전에 정한다. 기본 정책이 확인되지 않은 현재 임의의 법정 보관 기간이나 자동 삭제를 설정하지 않는다. 철회 가능한 시점과 이미 익명 집계된 뒤 제외의 한계를 사전에 알린다. 철회/중단이 제품 단어장·독서 기록의 자동 삭제를 의미하지 않으며, 제품 데이터 삭제는 본래 사용자 권리/승인 절차를 따른다. 동의 없는 범용 로그의 연구 전용을 하지 않는다.

## 11. 기록 양식 — 채워지지 않은 운영 틀

기존 U4 양식을 확장 설명할 뿐 새 데이터베이스 스키마가 아니다. 실제 답안/개인 매핑은 이 문서에 채우지 않는다.

```text
운영 고정표:
프로토콜 판·고정일 / 제품 commit / release·edition·본문/정책 해시
모집 범위·자유/과제 조건 / 동의 안내 판·동의 항목 / 보관 장소·접근자·기간·철회 창
읽을 수 있는 작품·지원/접근성 조건 / 문항·정답·루브릭 판/근거 / 운영 변경 이력

관찰 행:
가명 코드 / 확인된 사람·AI개발·불명 / 동의 범위 확인
유형 가설·목적·영어 경험·사전 친숙도 / 첫독서·재독 / 소개 순서
행동 단계·읽은 범위 / 자발·교사과제·진행자요청·알림·불명 / 개입 내용
OBSERVED·DECLINED·NO_OPPORTUNITY·TECH_BLOCKED·NOT_OBSERVED
선택/중단/복귀 이유 / 난점 원인 / 도움 전후 / 저장 안내 이해·왕복 맥락
동의된 짧은 직접 응답의 비공개 참조 / 관찰 사실 / 관찰자 해석(분리)

이해/독립 평가 행(서로 다른 평가 유형):
가명 코드 / 형·시점·지문/문항/루브릭 해시 / 노출 known-unseen·exposed·unknown

평정자별0·1·2·미관측 / 근거 / 불일치·해결 또는 유보 / 피드백 노출 시점
```

결과는 모집→동의→소개 노출→선택/거절→실제 읽기→이해 관측→자발 재개 기회→다른 작품 기회→평가 추적을 실제 수로 보고한다. 첫 회차 후 바뀐 UI/문항으로 두 번째 회차를 진행하면 버전별 결과를 구분하고 전후 차이를 개선 효과의 인과 추정으로 보고하지 않는다. 탈락·선택 거절도 중요한 결과이며 ‘실패한 참가자’로 제거하지 않는다.

## 12. 대표 한 편과 여러 작품이 필요한 질문

| 지금 C01 R2 한 편으로 설계/조건부 관찰 가능 | 공급·조건 때문에 보류 |
|---|---|
| 소개의 선택/거절 이유, 로그인 후 선택 유지, 실제 본문 이해·난점, 요청 도움, D5 저장/중복/왕복, 동일 release 단위 재탐색, 같은 작품 자발 재개 | 서로 다른 장르/길이에서 선택 적합성, 자발 다음 **다른 작품** 선택→실제 시작, 다음 독립 에피소드 선택, 다양한 반복 독서의 장기 효과 |

| 미노출 독립 평가의 청사진·루브릭 준비 | 실제 적격 지문/문항·형 보정·참가자·비교/지연 자료가 없는 독해 성장 판정 |

C06은 Saki의 *The Open Window*, [고정 원천 준비](./C06_SOURCE_PREPARATION.md)와 D3의 최소 현대화1판 전략을 유지한다. 특정 source_text 권리 결정 전 제작·발행 HOLD다. C06이 없어도 C01 사용성 준비/관찰은 가능하다. C06 권리 결정이 생겨도 자동으로 학습자 평가 자료나 비교군이 되는 것은 아니며 실제 판본/언어·서사·주의·발행 적격성을 따로 확인한다. 이 문서는 그 작업을 중단하거나 새 권리 승인을 만들지 않는다.

## 15. 방법론의 근거와 적용 범위

2026-10-27 공개 1차 자료 확인. 아래 원칙을 LCP에 적용한 설계 판단이며 이 서비스의 효과가 입증됐다는 인용이 아니다.

- [Council of Europe: Reading comprehension](https://www.coe.int/en/web/common-european-framework-reference-languages/reading-comprehension)은 독해 평가에서 텍스트·독자·맥락·목적과 과제 특성을 함께 보도록 설명한다. 적용: 편집 CEFR/어휘 비율 하나로 실제 적합성·형 동등성을 확정하지 않는다.
- [CONSORT pilot/feasibility extension, Eldridge et al., BMJ 2016](https://www.bmj.com/content/355/bmj.i5239)은 파일럿 목적에 맞는 실행 가능성 지표를 구분한다. 적용: 작은 사용성 관찰을 효과 검정으로 부르지 않는다. 본 비무작위 관찰을 CONSORT 인증 연구라고 주장하지 않는다. 검색에서 원문 요약을 확인했고 직접 페이지 열기는403이었다.
- [IES WWC: attrition and baseline equivalence](https://ies.ed.gov/ncee/wwc/reviewresources2)는 탈락과 비교집단의 사전 유사성을 구분한다. 적용: 비교/탈락/결측·일반 학습을 보고하고 단일 전후 증가를 인과 효과로 쓰지 않는다. 이번 설계가 WWC 기준 통과 연구라는 뜻은 아니다.
- [W3C APG: Browser and Assistive Technology Support](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#browser-and-assistive-technology-support)는 실제 브라우저/보조기술 조합의 시험을 요구한다. 적용: 자동 검사와 실제 SR/보조기술 사용자 관찰을 구분한다.

**설계 완료 판정:** 평가 질문·A/B/C/D 증거·유형별 반증·지표/분모·파일럿 순서·D5/AT/지원자 관찰·독립 독해/지연/전이 청사진·데이터 한계·최소 owner/의존성과 D7 인계가 마련됐다. 실제 연구·학습자 가치·독해 성장의 완료 판정은 아직 없다.
