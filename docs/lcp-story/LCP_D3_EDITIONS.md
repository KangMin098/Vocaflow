| 축 | 확인할 구체 근거 | 현재 자산·보완 방법 |
|---|---|---|
| 어휘 | 실제 본문 토큰/lemma, 다의어·관용구·구동사, 이름·시대어, 동일 단어의 문맥 의미 | `surfaceMetrics`는 단어 수일 뿐이다. 후속 분석은 사전/list 버전·토큰화·미등재 비율·이름 처리·다의어 한계를 함께 남김. 사전 미등재를 쉬운 단어로 간주하지 않음 |
| 구문 | 절 관계·삽입·부정·조건·대화의 생략·지시 대상, 길이가 비슷해도 해석이 갈리는 문장 | 평균 문장 길이는 경보 자료. 짧게 쪼갰을 때 주체/시간/원인 연결이 더 불분명해지는지 원문과 직접 대조 |

| 서사·인지 | 사건 경로, 인물의 목표/믿음, 인과 고리, 정보 비대칭, 단서 재해석, 아이러니 | 기존 `cognitive.demand/note`와 preserve.causality/foreshadowing/tone_devices 재사용. ‘문장 쉬움/추론 높음’처럼 프로필로 기술; 인지 점수로 CEFR 환산하지 않음 |

| 정서·연령·목적 | 위해·차별·불안·조롱·도덕적 갈등, 독자의 회피 의사 | cautions/민감 표현 handling 재사용. 짧거나 어휘가 쉽다고 저연령에 적합하다고 하지 않음. 비판 맥락과 읽기 거절 선택 확인 |

언어 판정 기록은 **판본 해시·분석한 범위·방법/도구 버전·목표 CEFR 근거·어려운 문장/표현·미측정 항목·검토자·시각**을 갖춘 로컬 편집 자료로 시작한다. 기존 strict JSON에 임의 키를 추가하지 않는다. 단어 수·읽기 공식·AI 판단·사람 관찰을 각각 표시하며 서로를 ‘검증된 수준’으로 승격하지 않는다.

기존 원본 LCP의 `analyze/cefr-detect.ts`는 어휘 분포·가독성·선택 LLM을 결합한다. 이를 새 엔진으로 복제하지 않는다. 다만 알려진 어휘가 없으면 B1로 돌아가고, 미등재 어휘를 분모에서 제외하며, 앞부분 표본과 가중 평균을 사용한다. confidence는 시그널 간 거리로 만든 값이므로 학습자 성공 확률이 아니다. Story의 B2를 이 결과로 덮어쓰거나 검증 라벨로 쓰지 않는다. 필요 시 `skipLlm`과 기존 lemma/사전 자산의 비변경 분석 재사용부터 검토한다.

외부 근거와 제품 결정은 다음처럼 구분한다.

- [Council of Europe 독해 설명](https://www.coe.int/en/web/common-european-framework-reference-languages/reading-comprehension)은 텍스트·독자·맥락·목적 및 과제 특성이 이해 평가에 영향을 준다고 설명한다. [2020 Companion volume §2.8~2.9·독서 척도](https://rm.coe.int/16809ea0d4)는 참고 틀이며 자동 텍스트 등급 인증기가 아니다. **설계 적용:** 쉬운 단어 비율만으로 B2 적합성을 확정하지 않는다.
- [Yano·Long·Ross(1994), 출판사 초록](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1467-1770.1994.tb01100.x): 일본 대학생483명·13개 지문·선다 문항 연구에서 단순화와 상세화의 결과 및 문항 종류에 따른 차이를 보고한다. **설계 적용:** 상세화도 비교 후보가 될 수 있다. 한국 학습자의 전체 Story 흥미·장기 독해 성장이나 상세화의 우월성을 입증한 자료로 사용하지 않는다.
- [Nation(2006), 저자 소속 대학 저장소](https://openaccess.wgtn.ac.nz/articles/journal_contribution/How_large_a_vocabulary_is_needed_for_reading_and_listening_/12552221)의 어휘 커버리지 논의는 참고 근거다. **설계 적용:** 커버리지의 단어군/lemma 정의와 실제 독자의 지식을 구분하며, 98%를 모든 작품의 발행/선택 합격선으로 도입하지 않는다.

## 5. 원작 의미·흥미·변경 허용 기준

제작 전에 작품별로 ‘지워지면 다른 이야기가 되는 요소’를 원문 앵커와 required_in에 정한다. 사건·동기는 필수 배열이지만 인과·복선·어조 배열은 현재 비어 있어도 구조상 통과할 수 있다. 반전/추리 작품에서는 중요한 항목을 실제로 작성한다. 새 전역 최소 개수 규칙을 만들지는 않는다.

| 대상 | 유지해야 할 것 | 허용 변경·검수 시 거부할 변화 |
|---|---|---|
| 사건·인물 | 누가 무엇을 했는지, 목표·장애·결과 | 부차 묘사 축소는 이유 기록. 인물 합치기·핵심 사건 삭제·새 해결 사건 추가는 초기 범위 밖 |
| 인과 | 원인→행동→결과의 연결과 단서를 얻는 이유 | 문장 구조/지시 표현 조절 가능. 우연을 계획으로, 추정을 확인된 사실로 바꾸면 재작업 |
| 정보와 목소리 | 당시 독자/인물이 아는 범위, 발화자의 주장, 화자 관점 | 베라의 이야기를 실제 죽음으로 확정하거나 반전을 먼저 해설하면 거부. 홈스의 확신도 ‘홈스가 내린 결론’으로 귀속 |
| 긴장·유머·문학성 | 질문이 생기는 순간, 단서의 반복·간격, 인물 특유의 말투·아이러니 | 낯선 어휘만 현대화할 수 있으나 유머를 설명문으로 치환하지 않음. 마지막 문장의 효과를 단순한 정답 요약으로 없애지 않음 |
| 시대·민감 표현 | 무엇이 시대의 편견/묘사인지 독자가 구분할 맥락 | 기존 retain_with_context/revise_with_note/omit_with_note 및 learner_note 적용. 편견을 현대 과학의 사실로 자연화하거나 민감 장면을 더 자세히 그리지 않음 |
| 추적 가능성 | 원천·policy·target·edition·activities 해시와 변경 이유 | 단위/원문 앵커·변경 목적·유지/손실 위험을 기록. omit도 원문 앵커 필요. 새 판단이 생기면 새 revision과 현재 결속 검수; 기존 파일/DB 행을 덮지 않음 |

구조 검증은 인용 일치·순서·보존 요소 참조·문단 범위·변경 타입을 검사한다. 모든 문장 변경의 기록 완전성, 의미·흥미·영어 자연스러움은 자동 증명하지 않는다. 직접 대조 검수에서 ‘기록은 있으나 결과가 다름’도 결함으로 다룬다. AI 합계 점수가 높아도 핵심 사건/인과/반전이 훼손되면 통과시키지 않는다.

## 7. 최소 표본 비교 계획 — 범위와 기준을 먼저 고정

**계획 확정 범위:** C01의 원문 0-based 문단 **79~97 포함**, 현재 R2 `u08`(Mr. Henry Baker)과 정확히 같은 범위다. 원문763단어·기존 u08 759단어(Story `surfaceMetrics`의 영문 단어 정규식 기준). 분량을 줄였다는 성공 주장이나 CEFR 추정으로 쓰지 않는다. 이 구간은 등장 이유→잃은 물건을 찾지 않은 이유→먹었다는 말에 대한 반응→대체 거위 수락/잔해 거절→입수 경로→홈스의 결론과 다음 조사를 함께 담는다.

| 표본 | 자료/변환 | 새로 만드는 것·목적 |
|---|---|---|
| S0 원천 기준 | 위 고정 snapshot의79~97문단 그대로 | 새 원문 제작 없음. 짧은 중립 상황 설명이 필요하면 모든 조건에 동일 제공하며 해설/정답 제외 |

| S2 언어 단순화 | Easy Reader용 새 로컬 초안1개, B1 편집 가설 | 낮은 빈도 표현/중첩 구문과 비핵심 묘사 조절. 인과 연결·대화 반응·핵심 증거는 남김 |

이는 **표본 계획**이다. 이번에 S2/S3 텍스트를 생성하거나 세 개의 전작/DB 자리를 만들지 않았다. 실행 시 기존 source/plan/validate/export와 별도 로컬 편집 메모를 재사용한다. 판본 형식으로 검증한다면 새 로컬 policy revision의 `coverage=excerpt`, 범위79~97, 기존 kind/transformation/operation을 쓰고 원작 전작 완료로 세지 않는다. S3를 새 transformation 값으로 직렬화하지 않는다. production snapshot이나 source identity는 표본마다 새로 꾸미지 않는다.

비교 기준은 다음 순서로 적용한다.

1. **의미 보존:** Baker가 광고하지 않은 경제적 이유/도난 추정, 처음의 당황과 대체품에 대한 안도, 잔해에 무관심한 반응, 거위 클럽에서 입수했다는 진술, 이를 근거로 한 홈스의 결론·추적 전환이 남는가. 주체/시간/발화 귀속과 관찰·추론을 구분한다.
2. **언어·담화:** 원문의 어려운 표현을 어떻게 바꿨는지, 쪼갠 문장이 연결되는지, 영어 대화가 자연스러운지 직접 대조한다. 길이·사전 빈도는 보조 자료다.
3. **서사 경험:** 의심을 시험하는 대화와 작은 긴장·유머가 살아 있는지, 설명이 독자가 판단할 순간을 빼앗는지 검토한다.
4. **상세화 비용:** 추가한 설명이 실제 난점에 대응하는가, 반복/총 읽기 부담이 늘었는가, 원문에 없는 사실·답을 주입했는가. 도움은 별도 제공과 본문 명시화를 나누어 평가한다.
5. **추적/판정:** 앵커·변경 이유·누락 위험·목표 근거·현재 해시를 확인한다. 기존 검수 checks와 issue severity로 approve/changes_requested/hold를 기록한다. 기준별 판단을 평균으로 지우지 않는다.

S2와 S3는 동일 목표와 보존 기준으로 비교하지만 실제 문장/분량/개인 지식이 달라질 수 있다. S0/S1/S2의 CEFR 목표 차이를 ‘전략 자체의 인과 효과’로 해석하지 않는다. 이 표본에서 이해 가능해도 전작의 후반 추리·정서 부담까지 적합하다는 결론을 내리지 않는다. 핵심 손실 없이 한 방법을 고를 수 없으면 전작 생산을 진행하지 않고 이유/대안을 남긴다.

| 독립 콘텐츠 검수 | 제작 텍스트에 참여하지 않은 Codex 세션 우선 | 원문 전문·최종 표본/판본·정책·해시를 직접 읽고 첫 판단을 작성. 제작자의 평가/이전 approve/다른 검수 결론은 첫 판단 전 복제하지 않음. 공통 수용 기준 공유와 판단 복제는 구분 |
| 언어·서사/민감 쟁점 추가 검토 | 실제 쟁점이 있으면 제작 비참여 모델/세션 | 원문·최종 결과·쟁점의 직접 근거. 이름만 바꾼 동일 세션을 독립 검토로 세지 않음. 미실행을 AI_INDEPENDENT_REVIEWED로 표시하지 않음 |
| 사람 콘텐츠 검수 | 실제 수행 자료가 있을 때만 | HUMAN_REVIEWED를 AI 세션·개발 계정으로 만들지 않음. 새로운 실제 사람 배정을 기본 차단 조건으로 추가하지 않음 |
| 권리 결정/기술 기록 | 기존 §14의 실제 사용자 결정·정상 admin 기록 | 특정 source/자산·근거·결정자와 AI 기술 기록자 구분. 제작/검수 권한이나 개발 계정 준비로 대체하지 않음 |
| 기술 검증 | 구현에 따른 Claude 검사·Codex 수용 | 구조/권한/현재 해시/화면 검사 = TECHNICALLY_VERIFIED. 원작 의미·사람 적합성·교육 효과와 분리 |

검수는 원작 의미·사건, 어휘/구문·자연스러움, 인물/인과 이해 가능성, 흥미 장치/문학적 가치, 수준 근거, 편집 추적성을 모두 다룬다. 기존 checks의 `note`와 `issues`에 직접 구간 근거를 남기고 새 전역 enum을 추가하지 않는다. source/target/판본/활동/정책이 바뀌면 기존 검수의 current 결속을 다시 확인한다. DB의 서로 다른 활성 staff UID 조건도 그대로 유지한다.

실제 독자 검증은 [기존 관찰표](./LEARNER_OBSERVATION.md)를 따른다. 다음은 D3에 필요한 관찰 초점이며 새 제품 평가 기능이 아니다.

- **적합성:** 배경/원작을 이미 아는지, 읽기 목표·체감 언어 부담·도움 필요를 확인한다. 분류 근거 없는 B1/B2 자기보고만으로 CEFR 집단을 확정하지 않는다.
- **이해:** 사실 재구성과 인물 주장/실제 관찰·인과 추론을 별도로 확인한다. 동의된 짧은 직접 응답은 비공개 외부 자료에서 다루고 제품 자유서술 채점/이벤트에 넣지 않는다. 사전에 기준과 정답 근거를 정하고 가능한 한 제작 비참여 평가자가 확인한다.
- **흥미·리듬:** 어떤 질문/갈등을 계속 알고 싶었는지, 설명이 도움/방해였는지 확인한다. AI의 ‘흥미로움’ 판정·페이지 체류·완료 클릭을 대신 쓰지 않는다.
- **자발 지속:** 읽지 않기·중단을 허용하고 지시/보상 여부를 기록한다. 나중의 자발 재개, 서가 이동, 다른 작품 시작을 구분한다. 현재 한 작품뿐이므로 다음 작품 선택은 관측 기회가 없다.
- **비교의 오염:** 동일 반전 작품의 여러 판본을 연속 읽으면 기억·정답 노출이 생긴다. 사람 비교를 실행한다면 첫 노출 조건과 순서를 설계하고 반복 독서는 별도 해석한다. 참가자 수·성공률/합격선은 기준선 없이 임의 확정하지 않는다.
- **성장:** 익숙한 표본 이해는 성장 증거가 아니다. 미노출 지문·독립 채점·비교/지연 조건은 D6 준비가 충족된 뒤 평가한다. 이번 결과는 계속 `PILOT_NOT_RUN / EDUCATION_EFFECT_UNVERIFIED`다.

## 10. Claude Code 인계 — 최소 실행 단위·순서

아래 W1~W4는 **설계상의 단위 ID**이며 생성된 TASK가 아니다. 기존 브랜치/세션·작업 관계를 먼저 대조한다. 실제 공식 역할 분담/범위가 필요해질 때만 중앙 정책으로 등록하고 완료 T-0187을 재개하지 않는다. 새 DB 계약이 없어도 가능한 로컬 준비를 중단하지 않는다.

| ID·우선순위 | 기존 자산·변경 이유/학습자 가치 | owner·의존성 | 최소 수용·검증/화면 |

| W4 P2 — 판본별 편집 근거 정리 | 기존 surfaceMetrics·lemma/사전/원본 분석·검수 note·관찰표. 수준 표기의 근거와 실제 도움 필요를 구분 | Claude 필요한 로컬 비변경 분석, Codex 근거/한계 검토. W1/W3의 고정 본문과 질문 선행. 유료 API·새 진단 엔진을 선행 조건으로 하지 않음 | 분석 범위/버전·미등재/다의어 한계·대표 난점과 target 근거를 sidecar 보고. 결과를 ReadingTarget의 measured로 바꾸지 않음. 파일/구간 결속·표면 계측 재현성 확인. 제품/UI/DB 변경 없음; 사람 관찰 자료는 별도 비공개 동의 경로 |

우선순위는 W1의 편집 비교와 W2의 기존 맥락 공백 보완, 병행 가능한 W3 원천 준비다. W4의 전면 지표화는 선행 게이트가 아니다. W2는 승인 전 SQL 준비·로컬 화면/격리 검사까지 진행할 수 있으나 이번 설계가 SQL 적용 승인은 아니다. 다중 판본 선택·추천과 실제 파일럿은 D2 U3/U4 이후 조건에 연결하며 D4~D7 전체 설계를 확정하지 않는다.
