### 시작까지의 마찰

실제 익명 서가에서 ‘로그인하고 읽기’ → 로그인 제출 → 서가 복귀 → ‘판본 열기’ → 작품 입구다. 이후 ‘처음부터 읽기’는 위치 저장 성공 후 단위로 이동한다. 로그인 제출을 한 행동으로 세면 본문까지 **4회 활성화**(입력/타이핑 제외), 이미 로그인한 서가에서는 **2회**다. 앞의 세 행동은 새 실제 브라우저로 확인했고 마지막 쓰기/이동은 현재 코드·기존 S7/격리 증거로 확인했다. 이번에 네 행동 전체를 새 dev 쓰기로 재실행한 것은 아니다. 직접 판본 로그인 복귀는 이미 해당 작품을 유지하므로 공통 Auth 재구현 대신 **서가 CTA의 목적지 보정**으로 한 번의 재선택을 없앨 수 있다. 로그인 후 진단·퀴즈·프로필 입력을 Story가 강제하지 않는다.

익명 공개 경계는 현재 `story_catalog`/`story_release_guidance`의 허용 필드다. 목차·본문·원문 앵커·W2·개인 진도는 정상 인증과 현재 발행 권한 뒤에만 보인다. 로그인 전 새 본문 미리보기나 전체 목차 공개는 이번 설계의 선행 조건이 아니다. 판본 선택은 존재하는 공개본에 한정한다. 작품이 여러 개가 될 때만 장르/주제 등 실재 메타를 쓰며 개인화 점수·검색/필터 확장을 선제 구현하지 않는다.

### 본문·도움의 계층

1. **필수**: 현재 단위명/본문, 작품으로 복귀할 맥락, 이전/다음과 명시 읽음의 다른 뜻, 저장 상태. 본문19px·1.75·현재 약610px 폭은 유지 시작점이다.
2. **필요 시 도구**: ‘단어 뜻 보기’, 해당 단위에 있는 도움 진입. 기본 일반 텍스트 유지; 도움 모드를 켜지 않아도 계속 읽는다.
3. **요청 추가 정보**: 실제 단어 뜻·예문/관련어·원문 대응·W2 설명·원천 판본 전문·목차 상세. 하나를 열었다고 다른 학습 과정을 시작하지 않는다.
4. **낮추거나 제거**: 본문마다 큰 작품명 반복, 이미 있는 자료 내비 중복, 장식 banner, 상시 긴 사용법·운영 용어·개인화 없는 추천 문구. 저장/실패 알림과 필수 주의·범위 구분은 제거하지 않는다.

도움 공통: 열기 전 스포일러 없는 이름·유무만 표시, 본문 텍스트/줄바꿈은 불변, 원문 추적은 **이 단위의 근거**임을 명시. W2의 새 진입점은 기존 `contextNotes`의 성공·현재 release/unit 결속과 인증 same이 확인됐을 때만 생긴다. 오류/미적용/invalid를 ‘설명 없음’으로 바꾸지 않는다. 설명 텍스트는 기존2개 그대로다. 본문 중 특정 문장 옆에 새 note를 임의로 연결하지 않는다(현재는 unit_ids만 있음). 첫 개선은 단위 도구의 jump/focus이며 문장 수준 anchor는 후속이다.

단어 도움은 뜻을 먼저 보이고 기존 관련어/예문을 필요 시 연다. Story 전용 opt-in으로 dialog의 이름/초점·닫기/Esc·원래 낱말 복귀를 확인한다. 비모달 도구를 modal이라고 선언하거나 본문에 focus trap을 강제하지 않는다. 로빙 화살표/Home/End와 하나의 본문 tab stop은 보존한다. 좁은 인라인 낱말은 공백 확대만으로 해결하지 않고 큰 도구/선택 낱말 컨트롤과 키보드 대안을 함께 제공할 안을 검증한다. 실제 SR 읽기 순서/알림은 NVDA 등으로 **별도 미검증**이며 DOM 이름·role·axe 통과로 대체하지 않는다.

### 이어읽기의 세 가지 의미

## 5. PC 레이아웃·시안과 현재 화면 비교

[클릭 가능한 설계 시안](./design/d4-story-proposal.html)은 제품 밖 HTML이다. 다섯 탭은 **설계 검토용 내비**이며 실제 학생 화면에 추가할 단계 메뉴가 아니다. 네트워크·Auth·storage·이벤트·저장 API를 호출하지 않는다. 현재 메타/불연속 발췌와 명시된 가상 진도/완료·소개 문구를 사용하며 실제 발행본/진도를 수정한 결과가 아니다. 원문 전문이나 W2 전문을 새로 제작하지 않고 실제 화면 증거와 병행 검토한다.

| 화면 | 1440px 설계 | 1280px 설계 | 주요 행동·상태 |
|---|---|---|---|
| 탐색 | max1200, 단일180px 자료 레일+40px 간격, 작품/판본 보조열240px | max1150, 레일160+32px 간격, 보조열220px | 작품/첫 장면→범위·목표→작품 열기. 영어 HOOK 전문은 선택 열람. 한 작품에 검색/추천 carousel 없음 |
| 상세·시작 | max1040, 내용660+48px+260 레일 | 내용최대640+40px+240 | 핵심 목표/주의가 CTA 앞, 원천 상세/긴 도움 사용법은 뒤의 선택 펼침. 익명은 안전한 로그인 복귀; 인증 후 같은 판본 시작/이어읽기 |

수치는 **구현 전 시작 명세**이며 관찰로 입증한 최적 배치가 아니다. 이후 실제 앱 수용은 1440×1000/1280×1000에서 시작 CTA가 y620 이내, 첫 영어 본문이 y360 이내를 목표로 한다(현재826/453 대비 정보 계층 검토용). 제목·주의·폰트 확대 때도 정보 누락 없이 재검토한다. 시안 상단의 검토 banner/5탭 높이는 제품 레이아웃에 포함하지 않는다. 단위 길이·예상 시간·기억 점수 같은 수치를 꾸며 목표를 맞추지 않는다.

실제-제안 비교는 **`E/compare.html`**에서 단계/뷰포트를 바꿔 나란히 볼 수 있다. 실제 화면은 위 actual 폴더, 시안은 `E/proposal-run1/`의 다섯 화면×두 크기다. `proposal-verification.json`은 렌더10장·넘침0·도움 열기/초점/Esc/맥락 이동·예외 전환 검사이며 제품/사람 UX 검증이 아니다. Codex가 현재 탐색/시작/본문/도움/철회/마지막 단위와 시안의 탐색/시작/본문 이미지를 직접 열어 비평했다.

참조는 기존 `DESIGN.md`·`packages/design-tokens/src/skins/{tines,learner-pc}.css`, Petrona/Hahmlet/IBM Plex Sans KR·기존 컴포넌트다. 새 외부 디자인을 채택하거나 Tines 현재 사이트와 픽셀 일치를 주장하지 않는다. Story 전용 golden은 없고 own-portfolio는 빈 템플릿이므로 두 비교는 **기준 없음**이다. 가장 큰 차이는 시작 전 정보 순서이며 본문 글꼴/인쇄면을 새 테마로 교체하지 않는다. 시안 검토에서 익명 CTA와 인증 목차가 섞인 표기를 ‘로그인 후 시안’으로 보정했고 실제 learner-pc 중립선 토큰을 재사용했다.

## 9. D4-06 관찰·교사/학부모·D5/D6 인계

새 파일럿을 중복 만들지 않고 [관찰표](./LEARNER_OBSERVATION.md)에 아래 과제/질문을 대응한다. 실제 참가자·동의·자료 취급 조건이 없어 **PILOT_NOT_RUN**이다. 모집/동의/평가를 가짜로 완료하지 않으며 개발 계정 자료는 사람 실증에서 제외한다.

| 성과 | 최소 관찰 | 기존 보조 기록·성공으로 바꾸지 않을 것 |
|---|---|---|
| 발견·자발 시작 | “읽거나 읽지 않을 것을 자유롭게 골라보세요.” 선택 이유/난도 이해·거절/로그인 마찰 기록 | catalog/기존 start. 노출·클릭·위치 저장=흥미/실제 읽음 아님 |
| 이해·흥미·몰입 | 자연스러운 중단에 사건/동기/인과를 자기 말로 설명, 궁금함/부담/멈춘 이유 | 동의된 직접 피드백. 완독·체류 시간=이해 아님. 첫 반전을 반복 노출해 조건 비교하지 않음 |
| 도움의 효과 | 어려운 순간 도구를 스스로 찾는가, 뜻/맥락 후 오독이 풀리는가, 흐름 중단/과잉 해설은 없는가 | 기존 source_open+직접 관찰. W2/단어 사용 성공 이벤트는 없음. 횟수 감소=성장 아님 |
| 재개 | 나중에 자발 복귀/지시 여부, 복구된 단위에서 맥락을 회복하는지 | resume/본인 context, 문장 위치 미저장 별도. 기술적 재로그인≠자발 복귀 |
| 다음 자발 독서 | 같은 단위/같은 작품/다음 에피소드/다른 작품을 구분 | 현재 다른 Story 없음은 `NOT_RUN_NO_ALTERNATIVE`. Books 이동은 다른 서비스 선택으로 별도 기록 |
| 독립 이해 | 새로운 미노출 글·독립 채점·비교/지연 조건 | D6 준비 후 평가. 익숙한 Story/AI검수/기술 테스트로 전이 추론 금지 |

기존 `story_catalog_viewed`와 `story_reader_action`의 닫힌 속성만 재사용한다. 작품 식별·주관 응답·W2/단어 도움 성공·개발 traffic 자동 제외가 현재 완비된 계측은 아니다. 이벤트 부재를 행동 부재로 세지 않는다. 새 이벤트/표/대시보드·성장점수는 만들지 않았다. 직접 응답은 동의 범위의 비공개 관찰 자료로 처리하고 저장소/개방 이벤트에 넣지 않는다.

교사의 추천/과제와 학습자의 자발 선택은 외부 관찰 맥락에서 분리한다. 현재 Story에 teacher/parent용 개인 진도 공유 계약을 추가하지 않는다. 부모에게 독서 시간/개인 도움/이해 답변을 자동 제공하지 않으며 동의·역할·최소 공개가 먼저다. 학습자 독서 화면에 관리자 검수·교사 점검 버튼을 끼우지 않는다.

**D5 인계:** Story release/unit/source anchor를 기존 VCP·듣기·교재 기능에 전달할 때 실제 실행 지원 여부·라이선스·판본/정책 해시·계정 권한·개인 기록의 별도 의미를 확인한다. `texts`로 자동 변환/등록하거나 기존 원문 리더의 GET 학습 활성화를 그대로 연결하지 않는다. source_open은 sentence 정밀 대응이나 학습 과제 완료가 아니다. 시리즈 편성과 실제 공급, 공통 셸의 Story 맥락도 D5/D7과 조정한다.

**D6 인계:** 위 관찰과 독립 이해를 별도 평가로 설계. 참가자·동의·평가 자료·독립 채점/비교 조건·유효한 기준선 없이 효과 수치를 발표하지 않는다. 파일럿의 표본 수/통과율/체류 목표를 근거 없이 확정하지 않는다. 불가피한 결측은 실패/0/PASS가 아닌 미관찰로 남긴다.
