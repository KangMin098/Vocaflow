## 1. 최종 판단

**기존 LCP를 교체하기보다 ‘어떤 학습자가 왜 이 이야기를 선택하고 계속 읽는가’를 작품 선정과 제공에 연결해야 한다.** 일반 도서는 수집·분석·발행·학습 도구 연결이 있고, Story는 원천·의미 보존·검수·권리·발행·인증 독서가 작동한다. 부족한 것은 수집기가 아니라 선정 근거, 서로 다른 독자를 위한 소수의 실제 선택지, 선택 전에 필요한 정보, 사람의 반응 자료다.

원작의 유명함, 쉬운 어휘, 생성 성공, AI 승인, 완료 클릭은 각각 다른 사실이다. 이 중 어느 하나도 흥미·이해·자발적 지속·독립 독해 성장을 대신하지 않는다. 모든 고전을 쉬운 영어로 바꾸거나 모든 독자에게 원문 비교를 요구하는 전략은 권고하지 않는다.

| 현재 접근 | D2 권고 | 바뀌는 의사결정 |
|---|---|---|
| 수집 가능한 PD·라이선스 작품을 처리 | 독자가 선택할 이유·부담·주의가 다른 후보를 먼저 비교 | 수집량보다 아직 충족하지 못한 독서 경험을 기준으로 다음 한 편 선정 |
| 수준 신호·분석 confidence·산출물 준비로 발행 | 기존 발행 안전 조건은 유지하고 별도로 흥미·언어·서사·지속 가설 평가 | ‘발행 가능’과 ‘제공할 가치’를 분리 |
| 대표 B2 한 편의 기술 여정 | 짧은 반전·모험·현대 관심사·쉬운 서사를 비교 | B2 한 편의 성공을 모든 학습자에게 일반화하지 않음 |
| 장/단위 완료와 클릭 | 선택 이유·이해·중단 이유·다음 자발 선택을 별도 관찰 | 오래 머물거나 전부 클릭한 것을 이해/몰입으로 해석하지 않음 |

이번 제안은 기존 발행 게이트의 대체나 추가 자동 승인 절차가 아니다. 편집자가 후보를 선택할 때 사용하는 작은 의사결정 기록이며, 실제 변경은 §7 작업으로 분리한다.

기존 절차의 복잡성은 원천/권리/검수/증인이라는 서로 다른 책임에서 생긴다. 이를 일괄 삭제할 근거는 없다. 이미 확인한 자료를 다시 묻는 운영, 중복 업로드, 불필요한 원문 비교/퀴즈를 학습자 진입 조건으로 추가하는 것은 줄인다. 실제 각 단계 소요/실패 빈도를 재지 않았으므로 ‘비용이 크게 감소한다’고 예측하지 않는다.

### 2.4 화면·기존 검증 재사용

이번에 main을 실제 브라우저로 다시 관찰한 범위는 **공개 서가와 로그아웃 독서 입구 × 1440/1280, 4화면**이다. 최종 관찰 실행에서 변경 요청을 차단해 analytics POST 등6건을 보내지 않았다. 공개 첫 장면·편집 목표·로그인 안내를 확인했고 1280에서 제목/진입 장면이 더 길게 줄바꿈되지만 CTA는 보였다. 주의/흥미 필터는 보이지 않았다. 참고 이미지는 위 runtime의 `corrected-public-check-v2/catalog-1440.png`, `catalog-1280.png`, `logged-out-reader-1440.png`, `logged-out-reader-1280.png`다.

최초 검사에서 ‘비로그인 서가에 release 직접 링크가 있어야 한다’고 가정해 2화면 FAIL(exit1)이 났다. 실제 코드는 로그인 후 서가로 돌아가는 링크이므로 검사 가정을 고쳤다. 중간4/4 결과의 본문 부재 검사가 실제 DOM 속성과 다른 선택자를 썼음을 추가 확인해, 최종 v2에서 실제 `data-story-body`·목차/진도 부재와 `signed_out` 상태를 함께 검사했다. 최종 결과는4/4·exit0이며 원래 실패/중간 결과도 보존했다. 이 공개 관찰은 본문/저장/계정 격리의 새 인증 E2E가 아니다. 그것은 같은 Story 런타임 main의 기존 S7 실제22/0 표적 재개·7/0 읽기 전용 증거를 재사용한다. 원 S7의 실패2회도 그대로 남아 있다. 모든 과거 PASS를 이번 실행 수로 더하지 않는다.

### 4.2 선정 기록과 판정

처음에는 이 문서의 후보표를 **DB 밖 편집 기록**으로 쓴다. 새 enum·추천 모델·마이그레이션은 필요 없다. 기존 snapshot/policy/target/review를 참조하고, 새 선정 정보는 별도 메모에 연결한다. 엄격한 기존 `EditorialPolicySchema`에 임의 키를 넣거나 policy hash를 설명 없이 바꾸지 않는다.

선정 단위는 제목 하나가 아니라 **작품 × 사용할 원천 판본 × 제공 방식 × 대상 독서 상황**이다. 기록할 최소 정보:

- candidate/work/source/edition 식별, 확인한 URL·날짜·실제 확보 범위, 텍스트/판본 해시(미확보면 없음), 원작/번역/각색/그림/오디오 각각 권리 상태와 근거.
- 관심사·선택 이유 가설·연령/목적 고려, 언어와 서사 프로필, 스포일러 없는 시작 이유, 주의와 화면 전달 필요.
- 원작 보존/현대화/각색/회차/신규 중 제안 방식, 기존 사용 가능한 자산, 추가 검수 부담과 현재 불확실성.
- AI 편집 판단, 독립 AI 검수, 기술 확인, 사람 콘텐츠 검수, 실제 참가자 관찰을 각각 출처와 함께 구분. 익명 또는 식별 불가 자료를 사람 검수 완료로 바꾸지 않음.

권리·법적 이용 조건·안전한 발행은 기존 독립 필수 조건을 그대로 따른다. `권리 미확인`을 흥미 점수로 상쇄할 수 없다. 아래 루브릭은 발행 자동 승인기가 아니라 **후보 비교를 설명하기 위한 편집 초안**이다.

| 평가 차원 | 확인할 질문·증거 | 우려 또는 보완 판단 |
|---|---|---|
| 1 흥미·주제 | 구체 독서 상황에서 궁금할 질문/선택이 있는가? 실제 독자의 선택 이유와 대조 | 유명 작품/장르 태그만 있으면 가설 미지원 |
| 2 서사 매력·완성 | 인물의 원함→방해→선택→결과가 추적되는가? 결말은 앞의 사건과 연결되는가? | 사건 나열·교훈만 있거나 반전 근거가 사라지면 수정 |
| 3 영어 이해 가능성 | 실제 판본의 어휘·구문·결속·관용 표현과 도움 필요를 볼 수 있는가? | 제목/문장 길이만으로 CEFR 확정 금지 |
| 4 언어/사고 균형 | 쉬운 영어에 연령에 맞는 동기·추론이 있는가? 복잡한 서사에 지원이 있는가? | 낮은 영어 수준을 낮은 사고 능력으로 취급하면 수정 |
| 5 연령·내용 | 폭력·상실·차별·성/종교 등 실제 본문 근거와 안내가 있는가? | 주의가 데이터에만 있고 독자에게 전달 안 되면 제공 전 보완 |
| 6 자발적 지속 | 한 회의 보상·멈출 지점·다음 선택 이유가 있는가? | 강제 cliffhanger·보상/숙제만으로 읽으면 자발 지속 근거 아님 |
| 7 독해 교육 가치 | 인과·근거·관점·지시어 등을 자연스럽게 읽을 수 있는가? | 매 단위 퀴즈로 바꿔야만 가치가 생긴다는 주장은 재검토 |
| 8 판본/각색 품질 | 의미 보존·현대 영어·생략 이유·AI 독립 검수의 현재 결속 | 샘플 표본 검수와 전체 의미 검수 구분 |
| 9 원천/권리 | 원작/판본/번역/자산·관할·수정/표시 조건을 실제 자료로 확인했는가? | 별도 기존 필수 조건. UNKNOWN/HOLD는 ‘안전’으로 환산 불가 |
| 10 운영 가능성 | 기존 경로에서 출처/본문/주의/완료/다음 이동을 정확히 제공할 수 있는가? | 새로운 계약을 숨겨 기존 타입에 끼워 넣어야 하면 보류 |

정량화 제안: 편집 평가1~8·10은 `U(미평가) / 0(명확한 부적합) / 1(우려·근거 약함) / 2(직접 본문 근거가 있는 타당한 가설) / 3(강점이 구체적이며 관련 반례까지 검토)`를 쓰고 사유/앵커를 필수로 적는다. **3도 실제 선호·효과 확인이 아니다.** 별도 evidence 열에 `source_inspection / ai_editorial / ai_independent / learner_observed`를 기록한다. 현재 후보표에는 임의 점수를 채우지 않았다.

판정 순서: 기존 권리·안전 조건 확인 → 의도한 독서 상황에서 명확한 부적합/핵심 의미 결함 확인 → 비교 후보 중 경험의 차이를 가장 잘 드러내고 기존 경로에서 검증 가능한 소수 선정 → 실제 관찰로 재판정. 총점 평균·가중합 하나로 선택하지 않는다. `비교 검증 우선 / 보완 후 재검토 / 권리·계약 대기 / 이번 대상 제외`는 편집 결론이며 새 DB 발행 상태가 아니다.

### 4.3 언어·서사 난도와 의미 보존

| 프로필 | 기록 내용·방법 | 확정할 수 없는 것 |
|---|---|---|
| 언어 | 어휘 빈도/커버리지, 비유·관용성, 절/삽입·구문, 문장 길이 분포, 지시어·연결, 읽기 유창성 요구. 기존 VRL·CEFR-J·Story text 계측 재사용 | 코퍼스상의 어휘 비율을 개인 어휘 지식으로 간주하지 않음. 기존 CEFR와 새 편집 목표를 같은 실측으로 합치지 않음 |
| 서사·인지 | 인물/관계, 시간 전환, 사건 수·인과 연결, 목표/동기, 암시·반어/화자 신뢰도, 배경지식, 문학적 의미. 각 축 낮음/중간/높음과 근거 장면 | 이 프로필로 실제 독자가 어렵다고 느낀 정도를 대신하지 않음 |
| 정서·내용 | 직접 동물 위해·죽음/상실·차별·위협, 표시할 주의, 스포일러를 줄인 표현 | 아동 고전이라는 이유로 모든 연령 안전이라고 하지 않음 |

현대 영어 리라이팅은 **번역도 요약도 아니다**. 같은 사건의 사실·순서·인물 목표/동기·핵심 인과·갈등·결말의 의미를 추적할 수 있어야 한다. 쉬운 판은 비핵심 묘사를 줄일 수 있으나 필요한 단서/동기를 없앤다면 별도 재검토한다. 목소리·반어·상징·시대 맥락을 바꾼 부분은 이유와 남은 한계를 기록한다. 기존 preserve 앵커와 change_log로 직접 대조하고, 자동 완전성 검사를 의미 보존 판정으로 승격시키지 않는다. 상세 제작 공정/알고리즘은 D3 소유다.

## 5. 대표 후보와 초기 포트폴리오

### 5.1 원천 전략·권리 상태 표기

**PD 원작 후보, 공개 라이선스 현대 서사, 신규 창작 기획을 비교하되 지금15편을 생산하는 계획은 아니다.** 작품 전체가 아니라 실제 사용할 판본·단편/회차의 범위를 먼저 결정한다.

- `CONFIRMED(existing source)`는 현재 《푸른 석류석》 source_text의 특정 결정만 뜻한다. 다른 작품·번역·삽화·오디오로 전파하지 않는다.
- `PUBLIC_SOURCE / RIGHTS_PENDING`은 원출처 메타/본문을 찾아 비교할 수 있으나 현지 이용·판본/자산 확인·§14 결정은 완료되지 않았다는 뜻이다. PG의 “미국 PD”는 세계 권리 확인이 아니다.
- `OPEN_LICENSE_CLAIM`은 제공자의 CC 표시를 확인했다는 뜻이다. 실제 영어 파일의 고정 revision/크레디트·수정 표시·제3자 자산을 확인해야 하며 자동 confirmed가 아니다.
- `CONCEPT_ONLY`는 본문/권리/품질 미확보 기획이다. AI 창작=법적 권리 확보 또는 품질 통과가 아니다.

SE 본문 자체의 기존 편집/전사와 새 학습용 현대화를 구분한다. 기존 Books 행에 있는 라이선스 라벨/권리 boolean은 조사 출발점일 뿐 이번 Story 권리 결정이 아니다. 아래는 후보 **15개: 실제 원작/공개 서사13개 + 신규 기획2개**, 12~18 후보 요청 범위다.

### 5.3 독자·전략·난도·이어읽기 비교

모든 CEFR 범위는 **제공하려는 판본의 편집 목표 가설**, 원작의 검증 수준이 아니다. 길이는 제작 목표이며 실제 단어수/분은 제작 후 기존 계측으로 산출한다. 비용 낮음/중간/높음은 검수 구조 비교이고 실제 견적이 아니다.

### 5.4 우선 비교 검증5개와 포트폴리오

다음은 **검증 우선순위**이며 신규 발행 승인이나 실제 학습자 선호 순위가 아니다. 작품 수 목표 대신 서로 다른 가설을 검사할 최소 비교군을 만든다.

|---|---|---|
| 1 C01 기존 《푸른 석류석》 | 기술·권리·AI 검수가 확보된 긴 추리 B2 기준 사례. 추가 대량 생산 없이 기존 제공 정보/반응의 기준점 | 기존 판본 유지, 사전 주의 전달 설계·실제 읽기 관찰 준비 |

초기 검증 포트폴리오는 추리/반전·모험·환경 서사·현대 협력, 짧은 완결/긴 단편/조건부 회차, A1~A2/B1/B2 **목표**를 포함한다. 배경·서사 부담과 정서 주의도 따로 비교한다. C15가 계약 대기여도 C01·C06·C08·C13의 비교 준비는 계속 가능하다. C04는 짧은 관계 서사 대체 후보이고, 다른 고전만 추가해 C15의 ‘현대 생활 관련성’ 비교가 충족됐다고 하지 않는다. 현재 C01에서 재사용할 수 있는 것은 S5의 요청형 원문 앵커 추적 UI다. C01 r3에는 Deep Reading 산출물3개가 있지만 Original Bridge 활동은 없고, 양쪽 활동 실행 UI도 S6 후속이다. 비교 활동을 하려면 기존 스키마/검증기를 재사용해 필요한 활동 자료·화면 연결만 별도로 구현한다. 포트폴리오 전원의 의무가 아니다.

## 8. 실증 검증·평가 계획

### 8.1 초기 파일럿: 결과를 만들지 말고 관찰 가능하게 준비

검증 질문은 발견→자발 시작→이해/지원→몰입→자발 다음 선택으로 나누고, 기술 안정성·콘텐츠 품질·UX·흥미·지속·독해 성장을 별도로 기록한다. 적합한 사람이 없으므로 이번 파일럿은 **NOT_RUN**이다.

초기 모집 규모는 예를 들어12~18명의 다양한 독서 목적/언어 수준을 포함한 **실행 가능성 가정**으로만 제안한다. 이 수로 효과 검증력이 확보됐다고 하지 않는다. 학년/R1~R6별 균등 할당을 강제하지 않고 관측 가능한 연령·영어 경험·독서 취향·목적을 따로 적는다. 미성년자 동의/개인자료 접근이 실제 필요한 경우 해당 절차를 따른다. 이미 승인된 AI 검수자를 사람 참가자로 대신 세지 않는다.

1. 권리·언어/서사 검수와 사전 주의가 준비된 서로 다른 작품/판본을 제시한다. 과제 점수/보상·교사 지시 여부를 먼저 기록한다. 읽지 않기·다른 이야기 고르기·중단하기도 가능한 선택이다.
2. 처음부터 모든 변수를 바꾸지 않는다. **작품 선택 연구**는 다양한 장르/길이 소개의 선택 이유를 보는 탐색으로, 작품마다 달라지는 난도까지 통제한 인과 실험으로 해석하지 않는다. 소개 순서를 교차해 위치 편향을 기록한다.
3. **판본 이해 연구**는 한 작품의 현대화/각색을 비교하되 같은 내용을 먼저 읽은 학습 효과를 기록한다. 한 참가자가 같은 줄거리를 두 번 읽은 결과를 난도 효과나 전이로 단정하지 않는다. 가능하면 다른 참가자에 판본을 교차 배정하고 사전 수준·주제 경험을 대조한다.
4. 편하게 읽게 하고 이후 짧게 선택 이유·체감 난도·핵심 사건/동기/인과를 확인한다. 매 단위 정답 퀴즈는 부과하지 않는다. 요청 도움·이탈·중단 이유는 이해 실패/지루함/시간 부족/정서 부담/기술 문제를 구분해 해석한다.
5. 직후 다음 회/다른 작품/종료 중 선택과 선택 이유를 관찰한다. 나중의 실제 복귀·새 작품 시작도 별도 확인한다. 조사자의 ‘다음 것도 읽어주세요’ 지시 뒤 클릭은 자발 지속 분자에 넣지 않는다.

실제 데이터가 생기기 전 성공률·목표 전환율·‘효과크기’를 채우지 않는다. 결측/중도 중단·기술 오류·관측 기회 부재를0 또는 성공으로 덮지 않는다. 저표본에서 유형별 순위를 확정하지 않고, 같은 문제가 여러 자료에서 반복되는지와 반례를 함께 보고 후보/지원 가설을 수정한다.

### 8.2 독립 독해 성장: D6로 넘길 평가 계약

본문 이해나 재독 익숙함과 별개로, 읽지 않은 영어 지문의 사실·인과/추론·관점 이해를 측정한다. 훈련 작품/미리보기/문항 정답/직접 유사 줄거리를 평가에 재사용하지 않는다. 언어·길이·장르·배경 부담이 비교 가능한 사전/사후 병렬형, 미노출 지문, 평가자 기준·채점 일치·지연 평가를 D6에서 구체화한다. 비교 집단/기간·표본 규모는 기대 변화·변산·탈락을 근거로 설계해야 하며 D2에서 임의 확정하지 않는다. 자발 독서 선택 편향·학교 수업/별도 학습·시험 반복 효과를 기록한다. 참가자와 자료가 확보되기 전에는 `EDUCATION_EFFECT_UNVERIFIED`를 유지한다.

## 10. 다음 실행 지시와 D3·D4·D6·D7 인계

Claude Code LCP는 기존 작업 공간/세션에서 다음 순서로 한 단위씩 진행한다. 아래는 실행 가능한 작업 지시이며 **이번 회차가 후속 구현·권리 결정·발행을 완료했다는 뜻은 아니다**.

1. **U1부터:** `schema.ts`의 실제 target/learner_note와 S5의 DTO/RPC allowlist를 나란히 비교하고, 사전 주의·부담·지원 중 공개할 최소 필드를 제안한다. 관리자 검수/정답/개인정보를 보내지 않는다. 기존 hook·B2 편집 목표·본문/진도 UX를 유지한다. UI로만 가능한 범위와 RPC 변경 필요 범위를 구분해 작성하고, 필요 SQL은 전문·해시·영향·복구안을 준비하되 승인 전 적용하지 않는다.
2. **U2 하나만:** C06 원천을 특정 판본으로 고정하고 source/권리 자료·reason_to_read·보존 요소/주의·현대화 목표를 기존 제작 형식으로 준비한다. 새 전권 수집기/동일 작품 다수 수준 제작은 하지 않는다. 제작 후에는 비제작 세션이 실제 전체 원문/판본을 직접 읽어 검수한다. 권리/발행은 기존 조건과 승인을 따른다.
3. **U4 준비 병행:** §8을 짧은 관찰표로 구체화하고 개발/교사 지시/자발 맥락을 구분한다. 참가자/평가 자료 없는 상태는 그대로 남긴다. 기존 analytics 규칙과 충돌하는 자유 문자열 추가는 하지 않는다.
4. 둘 이상의 **실제 발행 가능한 작품**이 생겼을 때만 U3의 다음 이야기 양성 화면 검증을 한다. 지금 없는 추천/다음 에피소드를 예시 제목으로 제품에 넣지 않는다.
5. 일반 Books의 U7/U6은 실제 영향 범위를 다시 확인한 좁은 수정부터 하며, 다른 파이프라인 공통 계약을 바꾸는 부분만 Master와 조정한다.

## 11. 최소 후속 인수 — T-0187 / 2026-10-26

2026-10-27 후속 [D3 편집 정책·시스템 대응](./LCP_D3_EDITIONS.md)은 이 설계/후보를 재선정하지 않고 C01 한 구간 비교와 C06 필요 최소 판본의 제작 기준을 구체화했다. 새 각색/권리 확인/발행은 미실행이며 U2 전체 완료로 올리지 않는다.

위 설계·15후보·우선비교5·§7의 담당/의존성/수용 기준을 유지한다. 아래는 같은 D2의 실행 상태이며 전략 재선정이나 D3~D7 전체 구현이 아니다. [실행·검증 결과](./D2_S7_FOLLOWUP.md).

| 기존 ID | 현재 인수 상태 |
|---|---|
| U1 사전 선택 정보 전달 | 기존 Story 서가·입구의 공개 필드 allowlist·접힌 주의·편집 판단 부담·실제 도움 안내 구현. 코드/격리 검사·승인 v2 DB 적용·실제 dev 30건·1440/1280 화면·로컬 main 통합 완료. 진도 쓰기는 기존 S7 증거와 격리 회귀로 구분 |
