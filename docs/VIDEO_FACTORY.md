# 영상 공장 (Video Factory)

> `packages/video-factory` — **플랫폼 구성요소를 영상으로 찍어 내는 공장.**
> 학습자 화면 임베드 · 광고 · YouTube 채널이 같은 설비에서 나온다.
> 최초 작성 2026-09-12. 여기 있는 수치는 전부 그날의 실측이다.

---

## 0. 한 줄 요약

영상 47편이 **어디에도 손으로 적혀 있지 않다.** 있는 것은 규칙 여섯이고,
플랫폼이 자라면 편수가 같이 는다.

```
설계도 47편 × 규격 3 = 컴포지션 141개
  소개 1 · 장점 3(=DIFFERENTIATORS) · 커리큘럼 1 · 시리즈 3(=SERIES_CATALOG)
  · 유형 13(=TYPE_GUIDE) · 활동 26(=framework/registry)
```

시리즈를 하나 만들면 코드 한 줄 안 고쳐도 영상이 **3개**(가로·세로·정사각) 는다.
회귀 `src/__tests__/factory.test.ts` 가 그 약속을 잠근다 — 구성요소가 늘었는데 영상이 안 늘면 실패한다.

## 1. 왜 Remotion 인가 (그리고 그 값)

| 후보 | 라이선스 | 한계 |
|---|---|---|
| **Remotion 4.0.524** ✅ | 오픈소스 + **4인 이상 법인은 유료** | 프레임마다 브라우저 스크린샷 — 느리다 |
| Motion Canvas | MIT | Canvas 2D — **제품 컴포넌트·CSS 토큰을 못 쓴다** |
| Revideo (Motion Canvas 포크) | MIT | 같은 한계. 렌더 API 가 붙어 있을 뿐 |

**고른 이유는 미감이 아니라 자산이다.** 이 공장의 값어치는 "제품이 실제로 쓰는 색·서체·계산"을
그대로 영상에 올리는 데 있다(`@vocaflow/design-tokens` 를 그대로 import 한다). Canvas 2D 도구를
고르면 디자인 시스템을 **한 벌 더** 구현해야 하고, 그 순간부터 제품과 광고가 갈린다.

⚠️ **라이선스**: Remotion 은 **3인 이하 팀은 무료**, 4인 이상 영리 법인은 좌석당 월 \$25(Creators)
또는 렌더당 \$0.01(Automators, 월 최소 \$100). 팀이 넷이 되는 날 정산 대상이다.
([remotion.pro/license](https://www.remotion.pro/license) · 2026-09-12 확인)
그래서 **설계도(`src/spec/`)에는 Remotion 이 한 글자도 없다** — 엔진을 바꿔도 설계도는 산다.

## 2. 3단 드레인 (CLAUDE.md §🤖 와 같은 구조)

| 단계 | 명령 | 하는 일 | 재실행 안전 |
|---|---|---|---|
| ① 원료 | `pnpm video:source` | DB 실측 → `work/source-bundle.json` | **안전** — 같은 DB면 같은 파일 |
| ② 음성 | `pnpm video voice [<id>]` | Edge TTS 나레이션 + 낱말 타임스탬프 | **안전** — 문장·음성이 같으면 건너뛴다 |
| ③ 렌더 | `pnpm video render <id>` | mp4 (`out/<규격>/<id>.mp4`) | 덮어쓴다 |

보조: `pnpm video list`(목록·길이·음성 진척) · `pnpm video check`(설계도 검사) ·
`pnpm video:studio`(브라우저 미리보기).

`work/` 와 `out/` 은 **커밋하지 않는다.** 번들에는 그날의 재고가 박혀 있어서, 묵으면
틀린 수치로 광고를 찍게 된다. 다시 뽑는 데 30초다.

## 3. 원료 — 무엇이 영상에 들어가는가

`apps/web/scripts/video-source.mts` 가 뽑는다. **앱이 뽑아서 패키지에 넘긴다** —
패키지가 앱을 import 하면 의존이 거꾸로 선다.

| 항목 | 출처 | 2026-09-12 실측 |
|---|---|---|
| 커버리지 증명 | `lib/marketing/hero-demo.ts` (랜딩 히어로와 **같은 지문·같은 계산**) | 61 러닝워드 · 초등고 67% → 적정 7레벨 |
| 유형 재고 | `textbook_shelf_inventory()` RPC | 유형 13 · 표본 10 |
| 시리즈 단 재고 | 같은 RPC를 **단의 V레벨로 좁혀** 합산 | reading 1단 0 … 6단 185,296 |
| 실제 문항 | `csat_dcp_items` 중 **가장 짧은 것** | payload 5계열 정규화 |
| 활동 | `lib/framework/registry.ts` | 26 |
| 플랫폼 수치 | 테이블 카운트 | 사전 49,244 · 발행도서 312 · 문항 879,830 |

### 쓰지 않는 것

- **`getDuration()` / `estimatedDuration`** (Edge TTS) — 4.4초 mp3 를 **0.37초**로 답한다.
  길이는 **마지막 낱말 경계의 끝**에서 구한다.
- **`count ?? 0`** — 없는 테이블도 head 요청엔 `count=null` 로 답한다. 0 과 구분이 안 된다.
- **유형만으로 센 재고** — 그러면 한 시리즈의 **모든 단이 같은 수**를 보고한다(실측으로 겪었다).

## 4. 품질 규칙 — 타입과 회귀가 강제하는 것

| 규칙 | 강제 방법 |
|---|---|
| 모든 컷에 자막 | `SceneBase.caption` 이 **필수 필드** — 자막 없는 컷을 만들 수가 없다 |
| 모든 수치에 출처 | `Evidence.source` 필수 + `validateSpec` 이 빈 값을 막는다 |
| 지어낸 숫자 0 | 회귀가 화면 수치를 **번들 안 실재 값과 대조**한다 |
| 색은 토큰만 | 회귀가 `remotion/` 전체에서 hex 리터럴 0 을 확인 |
| 한글에 Lora·이탤릭 금지 | `voiceFont()` + 회귀. 한글은 **왼쪽 세로선**으로 "사람 목소리"를 표시 |
| 한글 `keep-all` | 틀(`Frame.tsx`)이 깔고, 회귀가 확인 |
| 닫는 컷 = 다음 한 걸음 | `validateSpec` 의 `no-closing` |

### 자막·컷 길이의 근거

Netflix Timed Text Style Guide (2026-09-12 확인) — 자막 **최소 5/6초 · 최대 7초**,
읽기 속도 **성인 17 CPS · 아동물 13 CPS**. 학습자 영상은 초등까지 내려가므로 **13 CPS 를 바닥**으로,
광고는 17 CPS 를 허용한다. 음성을 구운 뒤에는 **실측 길이가 이 계산을 덮는다.**

### 영상 모션 예산은 화면 예산과 다른 표다

CLAUDE.md §모션 예산의 "총 1초 초과 금지"는 **학습 중 화면**의 규칙이다. 영상은 존재 자체가
모션이므로 그 숫자를 그대로 쓰면 아무것도 못 만든다. 대신 **성질을 물려받는다** —
같은 이징(`cubic-bezier(.4,0,.2,1)`) · 진입 300ms · 퇴장 200ms · 스태거 50ms ·
`transform`·`opacity` 만 · **폭죽·트로피·콘페티 금지** · 정지 구간은 완전 정지.

## 5. 음성 (Edge TTS)

키 없이 무료로 한국어 신경망 음성 3종을 쓴다 — `ko-KR-SunHiNeural`(여) ·
`ko-KR-InJoonNeural`(남) · `ko-KR-HyunsuMultilingualNeural`(남).

| 쓰임 | 음성 | 속도 | 왜 |
|---|---|---|---|
| 학습자 | SunHi | **-6%** | 새 개념을 설명하는 소리다 (학습원칙 6 Cognitive Load) |
| 광고 | InJoon | 0% | 스크롤 경쟁에서 느린 소리는 넘겨진다 |

얻는 것이 소리만이 아니다 — **낱말 경계 타임스탬프**가 컷 길이를 실측으로 정하고,
앞으로 자막을 낱말 단위로 동기시킬 수 있다.

## 6. 컷 9종

| 컷 | 무엇을 보여 주나 | 어떤 자산이 필요한가 |
|---|---|---|
| `hook` | 여는 물음 | — |
| `coverage` | **지문 위에 아는 낱말이 칠해진다** | 사전 49,244 + 커버리지 계산 |
| `decay` | `R(t)` 곡선이 두 임계를 지난다 | FSRS 상태 |
| `ladder` | 7단이 아래에서 차오른다 | 단별 재고 |
| `shelf` | 권이 하나씩 꽂힌다 | 시리즈 카탈로그 |
| `item` | **실제 문항**이 풀린다 | `csat_dcp_items` |
| `stat` | 실측 수치 + 출처 | 테이블 카운트 |
| `statement` | 장점 + 근거 | `DIFFERENTIATORS` |
| `closing` | 다음 한 걸음 | — |

`coverage` · `decay` · `item` 셋이 **경쟁사가 못 만드는 그림**이다. 나머지는 누구나 만든다.
