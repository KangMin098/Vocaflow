# 영상 공장 (Video Factory)

> `packages/video-factory` — **플랫폼 구성요소를 영상으로 찍어 내는 공장.**
> 학습자 화면 임베드 · 광고 · YouTube 채널이 같은 설비에서 나온다.
> 최초 작성 2026-09-12. 여기 있는 수치는 전부 그날의 실측이다.

---

## 0. 한 줄 요약

영상 73편이 **어디에도 손으로 적혀 있지 않다.** 있는 것은 규칙 여덟이고,
플랫폼이 자라면 편수가 같이 는다.

```
설계도 73편 × 규격 3 = 컴포지션 219개
  소개 1 · 장점 3(=DIFFERENTIATORS) · 커리큘럼 1 · 시리즈 3(=SERIES_CATALOG)
  · 유형 28(=TYPE_GUIDE) · 활동 26(=framework/registry)
  · 학습방법 7(=총론 1 + FACETS 6) · 권장안 4(=STAGES 이동)
```

**실제로 두 번 그렇게 자랐다** — 2026-09-13 에 유형 설명 15종을 채우자 코드 한 줄 안 고치고
설계도가 47 → **62편**이 됐고, 같은 날 프레임워크(단계·면·처방 임계)를 번들에 실으니
규칙 둘이 더해져 62 → **73편**, 컴포지션 186 → **219개**가 됐다.

⚠️ 학습방법·권장안이 그때까지 **한 편도 없었던 이유는 규칙이 아니라 원료였다** —
번들에 단계와 임계값이 안 들어 있었고, 공장은 번들에 있는 것만 만든다. 「무엇을 더 만들까」를
물을 때 규칙부터 보면 답이 안 나온다. **원료를 먼저 본다.**

시리즈를 하나 만들면 코드 한 줄 안 고쳐도 영상이 **3개**(가로·세로·정사각) 는다.
회귀 `packages/video-factory/src/__tests__/factory.test.ts` 가 그 약속을 잠근다 — 구성요소가 늘었는데 영상이 안 늘면 실패한다.

## 2. 큐 — 이게 없어서 「파이프라인」이 아니었다 (2026-09-13)

영상 62편을 찍어 발행했는데 **그 과정이 어디에도 남지 않았다.** 진행은 오직 **파일의 존재**로만
표현됐다(mp4 가 있으면 찍은 것). 그래서:

| 없던 것 | 무슨 일이 생기나 |
|---|---|
| 작업 단위 | 어느 편이 어느 단계인지 모른다 — Admin 이 manifest 와 파일을 **비교해 추론**했다 |
| 실패 기록 | 렌더 실패가 콘솔에 한 줄 찍히고 **사라진다**. 다음 사람은 실패가 있었는지도 모른다 |
| 이력 | 언제 찍었는지 모른다 — 수치가 얼마나 묵었는지의 근거가 없다 |

이 저장소의 다른 파이프라인(`book_quiz_jobs` · 큐레이션 잡)은 전부 이걸 갖는다.

```
video_jobs  — 편당 한 행
  stage: queued → voiced → rendered → packaged → published   (+ failed)
```

**단계는 앞으로만 간다.** 그냥 UPDATE 를 허용하면 늦게 끝난 단계가 먼저 끝난 단계를 덮어써
뒤로 돌린다(렌더를 두 번 돌리면 실제로 그렇게 된다). 그래서 순서를
`video_job_advance()` 한 곳에서만 정의하고, 낮은 단계로 가는 호출은 **조용히 무시**한다.

### 큐가 본 작업을 인질로 잡지 않는다

기록은 곁가지다. 그래서 큐 클라이언트는:

- 호출마다 **8초 타임아웃** — 이게 없으면 망이 느릴 때 기록 한 줄이 렌더를 멈춰 세운다
  (실측 2026-09-13: DB 가 응답하지 않는 동안 `enqueue` 가 10분을 넘겨도 안 끝났다)
- **한 번 막히면 그 실행 동안 끈다** — 없는 것은 다음 호출에도 없다. 62편에 62번
  타임아웃을 기다리지 않는다
- 예외를 **던지지 않는다** — 실측: 큐가 통째로 막힌 상태에서 렌더 1편 34.9초·실패 0

## 3. 3단 드레인 (CLAUDE.md §🤖 와 같은 구조)

| 단계 | 명령 | 하는 일 | 재실행 안전 |
|---|---|---|---|
| ⓪ 큐 | `pnpm video enqueue` | 설계도를 `video_jobs` 에 올린다 | **안전** — 단계를 되돌리지 않는다 |
| ① 원료 | `pnpm video:source` | DB 실측 → `work/source-bundle.json` | **안전** — 같은 DB면 같은 파일 |
| ② 음성 | `pnpm video voice [<id>]` | Edge TTS 나레이션 + 낱말 타임스탬프 | **안전** — 문장·음성이 같으면 건너뛴다 |
| ③ 렌더 | `pnpm video render <id>` | mp4 (`out/<규격>/<id>.mp4`) | 덮어쓴다 |

보조: `pnpm video list`(목록·길이·음성 진척) · `pnpm video check`(설계도 검사) ·
`pnpm video stale`(**발행본 ↔ 설계도 어긋남**) · `pnpm video thumbs`(썸네일) ·
`pnpm video:studio`(브라우저 미리보기).

### `stale` — 이 공장의 마지막 구멍

`out/` 을 커밋하지 않으므로 저장소에 남는 것은 manifest 한 장이다. 그래서 설계도의 문구를
고쳐도 **이미 올라간 mp4 는 옛 내용을 말하고, 아무도 안 알려 준다** — 화면은 멀쩡히 뜨고
영상만 거짓말을 한다. `stale` 이 셋을 가른다:

| | |
|---|---|
| 없어진 편 | manifest 에 있는데 설계도에 없다 → 화면이 죽은 링크를 그린다 |
| 안 올린 편 | 설계도에 있는데 manifest 에 없다 → 새 영상이 화면에 안 뜬다 |
| 낡은 편 | 제목·부제가 다르거나 길이가 어긋난다(문구를 고치면 음성 길이가 바뀐다) |

⚠️ **재고 수치가 달라진 것은 낡음으로 세지 않는다.** 영상은 찍은 날의 스냅샷이고 화면에
출처와 날짜가 함께 박혀 있다. DB 가 자랄 때마다 186편을 다시 찍을 수는 없다.

`work/` 와 `out/` 은 **커밋하지 않는다.** 번들에는 그날의 재고가 박혀 있어서, 묵으면
틀린 수치로 광고를 찍게 된다. 다시 뽑는 데 30초다.

## 4. 품질 규칙 — 타입과 회귀가 강제하는 것

| 규칙 | 강제 방법 |
|---|---|
| 모든 컷에 자막 | `SceneBase.caption` 이 **필수 필드** — 자막 없는 컷을 만들 수가 없다 |
| 모든 수치에 출처 | `Evidence.source` 필수 + `validateSpec` 이 빈 값을 막는다 |
| 지어낸 숫자 0 | 회귀가 화면 수치를 **번들 안 실재 값과 대조**한다 |
| 색은 토큰만 | 회귀가 `remotion/` 전체에서 hex 리터럴 0 을 확인 |
| 한글에 Lora·이탤릭 금지 | `voiceFont()` + 회귀. 한글은 **왼쪽 세로선**으로 "사람 목소리"를 표시 |
| 한글 `keep-all` | 틀(`Frame.tsx`)이 깔고, 회귀가 확인 |
| 닫는 컷 = 다음 한 걸음 | `validateSpec` 의 `no-closing` |

### 자막·컷 길이의 근거

Netflix Timed Text Style Guide (2026-09-12 확인) — 자막 **최소 5/6초 · 최대 7초**,
읽기 속도 **성인 17 CPS · 아동물 13 CPS**. 학습자 영상은 초등까지 내려가므로 **13 CPS 를 바닥**으로,
광고는 17 CPS 를 허용한다. 음성을 구운 뒤에는 **실측 길이가 이 계산을 덮는다.**

### 영상 모션 예산은 화면 예산과 다른 표다

CLAUDE.md §모션 예산의 "총 1초 초과 금지"는 **학습 중 화면**의 규칙이다. 영상은 존재 자체가
모션이므로 그 숫자를 그대로 쓰면 아무것도 못 만든다. 대신 **성질을 물려받는다** —
같은 이징(`cubic-bezier(.4,0,.2,1)`) · 진입 300ms · 퇴장 200ms · 스태거 50ms ·
`transform`·`opacity` 만 · **폭죽·트로피·콘페티 금지** · 정지 구간은 완전 정지.

## 5. 음성 (Edge TTS)

키 없이 무료로 한국어 신경망 음성 3종을 쓴다 — `ko-KR-SunHiNeural`(여) ·
`ko-KR-InJoonNeural`(남) · `ko-KR-HyunsuMultilingualNeural`(남).

| 쓰임 | 음성 | 속도 | 왜 |
|---|---|---|---|
| 학습자 | SunHi | **-6%** | 새 개념을 설명하는 소리다 (학습원칙 6 Cognitive Load) |
| 광고 | InJoon | 0% | 스크롤 경쟁에서 느린 소리는 넘겨진다 |

얻는 것이 소리만이 아니다 — **낱말 경계 타임스탬프**가 컷 길이를 실측으로 정하고,
앞으로 자막을 낱말 단위로 동기시킬 수 있다.

### 음량 — 이 공장에서 유일하게 「시중」과 같은 자로 잴 수 있는 축

「시중 광고보다 우위」는 대부분의 축에서 **측정이 성립하지 않는다** — 경쟁사의 카피·구성·색을
우리가 관측할 수 없고, 볼 수 있는 것은 그들의 결과물뿐이라 비교값이 아니라 인상이 된다.
음량만은 다르다. **YouTube 가 규격을 공개했고 재생 시점에 강제한다.**

| 항목 | 값 | 출처 |
|---|---|---|
| 통합 음량 | **-14 LUFS** | YouTube 라우드니스 정규화 (2026-09-13 확인) |
| 트루 피크 | **-1 dBTP** | 같은 규격 |
| 허용 오차 | ±1.0 LU | `loudnorm` 2패스의 실측 재현 오차 |

결정적인 성질 하나: **큰 소리는 줄이지만 작은 소리는 키워 주지 않는다.**
목표보다 조용하면 같은 피드에서 **실제로 작게 재생된다** — 소리를 키우려 손이 한 번 더 가는
사이에 넘겨진다.

**실측 (2026-09-13, 186편 전량)**

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 규격 안 | **0 / 186** | **186 / 186** |
| 통합 음량 범위 | -16.4 ~ -19.6 LUFS | -14.0 LUFS |
| 편끼리 편차(최대-최소) | **3.4 LU** | **0.0 LU** |

편차가 더 아팠다 — 우리 영상 두 편을 이어 보면 음량이 튀었다.

**어떻게** — `pnpm video loudness [--fix]`. 2패스(먼저 재고, 그 값을 필터에 넣어 다시 건다.
한 번만 걸면 실시간 추정이라 목표를 1~2 LU 빗나간다). 영상 스트림은 `-c:v copy` 로
**다시 그리지 않는다** — 90분짜리 렌더를 되풀이하지 않고 소리만 고친다.
재실행 안전: 이미 규격 안인 편은 건드리지 않는다(다시 인코딩하면 세대손실만 쌓인다).

⚠️ **포장(`package`)보다 먼저** 돌린다 — 포장이 manifest 에 바이트 수를 적는데,
뒤에 음량을 고치면 파일이 바뀌어 그 수가 틀어진다.

판정 규칙은 `packages/video-factory/src/render/loudness.ts`(순수부)에 있고 회귀 16종이 잠근다. 붙이는 동안
**같은 종류의 사고를 세 번** 겪었고 셋 다 회귀로 박았다:
① 템플릿 리터럴에서 `\s` 가 `s` 로 줄어 정규식이 아무것도 못 맞혔다(186편 전부 「못 잼」) ·
② `execFileSync` 는 성공하면 stdout 만 주는데 `loudnorm` 요약은 **stderr** 로 나온다 ·
③ 같은 출력의 `Output Integrated` 를 읽으면 **무엇을 재도 합격**한다(그 값은 필터를
통과시켰다면 나왔을 값이라 늘 -14 근처다).

## 8. 성능 실측

| 항목 | 값 |
|---|---|
| 헤드리스 셸 최초 내려받기 | 113MB (1회) |
| 번들 | 약 20초 (캐시 후 빠름) |
| 렌더 (24.8초 · 1920×1080 · 음성 포함) | **43~46초** · 2.55MB |
| Edge TTS 한 문장 | 약 0.4~1초 |

⚠️ **종료코드를 믿지 않는다.** 다른 세션의 dev 서버가 3000 을 잡고 있으면 렌더러가
그 앱을 자기 번들로 착각하는데 **exit 0** 으로 끝난다. 그래서 CLI 는 끝난 뒤
**파일 존재와 크기**를 직접 확인한다.

⚠️ **포트는 고정하지 않고 찾는다.** 한 번호로 못 박았더니 앞 렌더를 중단한 직후 그 포트가
아직 붙들려 있어 **186편이 전부 즉시 실패**했다(2026-09-13). 더 나쁜 것은 그 다음이다 —
빈 포트를 찾는 코드를 넣었는데 `127.0.0.1` 로만 시험해서, **0.0.0.0 로 잡힌 포트를
"비었다"고 답했다**(Windows). 렌더러가 잡는 방식과 같은 방식(호스트 미지정)으로 시험해야 한다.

## 9. 학습자에게 닿는 길 (2026-09-13 추가)

찍은 것이 화면에 없으면 **공급만 늘린 것**이다(§D). 그래서 전달까지를 공장의 일로 본다.

```
video render-all → video package → video publish → (manifest 커밋) → 화면
```

| 단계 | 명령 | 내는 것 |
|---|---|---|
| 포장 | `pnpm --filter @vocaflow/video-factory package` | 포스터 jpg(mp4 에서 ffmpeg 로 추출) · **WebVTT 자막** · 설명글(YouTube 설명란용) · `apps/web/src/lib/video/manifest.json` |
| 발행 | `pnpm --filter @vocaflow/video-factory publish` | Supabase Storage 공개 버킷 `video` 업로드 + manifest 에 `baseUrl` 기록 |

**재실행 안전**: 포장은 이미 있는 포스터를 건너뛰고, 발행은 **같은 크기**로 올라간 파일을 건너뛴다.

### 화면에 붙는 자리

| 자리 | 무엇 |
|---|---|
| **`/admin/video`** | **운영 콘솔(VFP)** — 밀린 것·유실·재생 실적. 탭 3. [ADMIN_CONSOLE.md](./ADMIN_CONSOLE.md) |
| **`/video/[id]`** | **편별 페이지 62개** — 자막 전문 서버 렌더 + `VideoObject` JSON-LD. 색인 가능 면 1 → **63** |
| `/video` | 영상 서가 — 종류별 전체 목록 (공개) |
| `/about` | 소개 1편 + 장점 3편 (그 전까지 처음부터 끝까지 산문이었다) |
| `/pricing` | 커리큘럼 1편 + 시리즈 3편 — "얼마인가" 다음 질문이 **"무엇을 사는가"** 다 |
| `/library/textbooks/[series]/[step]` | 그 단원의 **첫 유형** 영상 한 편. 유형 28편이 닿는 자리 |
| `/` (랜딩) | **영상을 넣지 않는다** — 첫 화면의 자리는 작동하는 증명(CoverageHero)이고 영상은 말하기다(I1). 헤더·푸터 링크로만 잇는다 |
| `/library/textbooks/[series]` | 그 시리즈 영상 한 편 (`ShelfScreen`, 420px 카드) |
| 마케팅 헤더 · 랜딩 푸터 | `/video` 링크 |

`components/video/ComponentVideo.tsx` 한 곳이 모든 자리를 그린다 —
**자동재생 없음 · 반복 없음 · `preload="none"` · 자막 기본 켜짐 · 재생 버튼 64px**.

### 발행 실적 (2026-09-13)

| | |
|---|---|
| 설계도 | **62편** · 규격 3 = **186 컴포지션** · 총 **14분** |
| 렌더 | **186/186 성공 · 실패 0** · 175.8MB · 편당 25~45초 |
| 음성 | 62편 결번 0 (Edge TTS · 낱말 타임스탬프로 컷 길이 실측) |
| 썸네일 | 62장 (1280×720) |
| 발행 | **558개 파일** → `video` 버킷. 공개 URL 200 확인(mp4·jpg·vtt 전부 올바른 MIME) |
| baseUrl | `…/storage/v1/object/public/video` |

`out/` 과 `dist-media/` 는 커밋하지 않는다. 커밋되는 것은 **manifest 한 장**뿐이고,
그게 화면이 보는 전부다.

### 발행 전에는 아무것도 안 그린다

`manifest.baseUrl` 이 `null` 이면 모든 조회가 `null` 을 돌려주고 컴포넌트가 **아무것도 렌더하지 않는다.**
"영상 준비 중" 자리를 만들지 않는 이유: 지키지 못할 약속을 화면에 두지 않는다.
`/video` 만 예외로 **다음 한 걸음**(`/fit`)을 보여 준다(D5 — 막다른 화면 금지).

### id 규칙은 한 곳에만 있다

`@vocaflow/video-factory/ids` — 공장이 짓는 id 와 앱이 찾는 id 가 **같은 함수**에서 나온다.
두 곳에 적으면 갈리고, 갈려도 **오류가 안 난다**(영상만 조용히 사라진다).
회귀 `apps/web/src/lib/video/__tests__/catalog.test.ts` 가 앱 쪽에 id 문자열이 다시 적히는 것을 막는다.
