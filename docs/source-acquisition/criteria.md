# 원문 확보 판정 기준 — G0~G3

**작성 2026-09-24** · 근거 태그: `[측정: 파일/쿼리]` · `[문헌: 링크]` · `[추론]`
**`[추론]`은 통과·탈락 판정에 쓰지 않는다.**

> 판정 단위는 **원천**(책·장·문서)이다. 조각(지문) 단위 판정은 가공 단계의 일이다.
> 2026-09-23 에 토막 160건을 조각 단위로 판정해 usable 0 이라는 잘못된 결론을 낸 적이 있다 —
> 그때 틀린 것은 원문이 아니라 판정 단위였다.

## 사용자 결정 (기준의 전제)

| 항목 | 값 | 확인 |
|---|---|---|
| **상업 이용** | **있다** — 유료 교재·유료 서비스로 내보낸다 | 2026-09-24 |
| **저작권 제한분 처리** | **재저작 파이프라인(LLM)으로 돌린다** — 예외 조항에 기대지 않는다 | 2026-09-24 |

두 값이 G0 의 모양을 정한다. 바뀌면 G0 을 다시 짠다.

## G0 · 법적 적격 — **탈락이 아니라 경로 배정**

라이선스는 통과/탈락이 아니라 **어떤 경로로 쓸 수 있는가**를 정한다.
2026-09-23 에 "CC면 개작 가능"으로 뭉뚱그렸던 것을 개별 조건으로 편다.

### G0-1. 라이선스를 원천 단위로 개별 기록한다

**컬렉션 라벨을 그대로 믿지 않는다.** 실측 근거:

| 실측 | 값 | 출처 |
|---|---|---|
| OLH 라이선스 문자열 절단 | 4,000건 중 **1,168건**이 `censes/by/4.0/` 꼴 — `short_name` 만 세면 CC BY 가 36% 과소 집계 | `[측정: sources-window-supply.md G-c]` |
| OLH 전권보유 혼입 | 329건(8.3%) | `[측정: G-d]` |
| OLH `name` 마저 `"Imported License"` | 30편 중 1 — `url` 을 함께 봐야 한다 | `[측정: G-l]` |
| EconStor 표준 약관 **항상 병기** | 30/30 · CC 전용 0편 | `[측정: G-m]` |
| SciELO BY-NC-ND 저널 | 350개 중 41개 · 편당 라이선스가 없어 `v541` 로 저널 단위 판정만 가능 | `[측정: G-n]` |
| 현재 재고의 라이선스 변종 수 | plos 3종 · elife 4종 · voa 2종 — 한 소스 안에서도 갈린다 | `[측정: library_articles 전수]` |

기록 필드(원천마다): `license_raw` · `license_url` · `license_class` · `author` · `year` · `source_url`

### G0-2. 경로 배정표 (상업 이용 = 있다 기준)

| 라이선스 | 표현 그대로 | 개작 | 경로 | 비고 |
|---|---|---|---|---|
| **PD · CC0** | ✅ | ✅ | **R0** | 표기 의무 없음(CC0). PD 는 관할별로 다르므로 원천 연도 기록 |
| **CC BY** | ✅ | ✅ | **R1** | 출처·저작자·라이선스·변경사실 표기 |
| **CC BY-SA** | ✅ | ⚠️ | **R2 → 재저작** | 개작물을 **같은 SA 로 공개**해야 한다. 유료·독점 교재와 양립 불가 → 재저작으로 돌린다 |
| **CC BY-NC / NC-SA** | ❌ | ❌ | **R3 재저작** | 상업 이용 불가. 표현을 쓰지 않는다 |
| **CC BY-ND / ND 계열** | ⚠️ | ❌ | **R4 재저작** | 개작 명시 금지. 재고 71편(the_conversation)이 `display_only=true` 로 표시돼 있다 `[측정]` |
| **ARR · 미확정** | ❌ | ❌ | **R4 재저작** | |

> **R0·R1 만이 "원문 확보"다.** R2~R4 는 원문을 쌓는 것이 아니라 **논지를 읽고 새로 쓰는
> 입력**이다. 재고 집계에서 둘을 섞지 않는다 — 섞으면 "확보 편수"가 실제로 쓸 수 있는 양을
> 부풀린다.

### G0-3. 재저작 경로(R2~R4)의 측정 가능한 가드

재저작은 **표현을 쓰지 않고 사실·논지만 취해 새로 쓰는 것**이다. 그 경계는 문장으로 선언해서는
지켜지지 않으므로 **숫자로 건다.** 이미 작동한 실적이 있다:

| 가드 | 임계 | 실적 |
|---|---|---|
| 원문과의 n-gram 중복 | **0건** (6~8-gram) | args.me 재저작 398편 전량 0 `[측정: 각 청크 보고]` |
| 원문 문장 재사용 | 0 | 같은 자리 |
| 고유명사·수치의 그대로 옮김 | 제거 후 재확인 | 같은 자리 |
| 게이트 통과 | 100% | `argsme-gate.mts` 재검사 398/398 `[측정]` |

⚠️ **가드가 덮지 못하는 것**: 선택·배열(어떤 사실을 어떤 순서로 고르는가)의 모방.
n-gram 은 이것을 못 잡는다. 창작성이 높은 원천(소설·에세이)일수록 위험이 크고, 사실 위주
원천(교과서·보고서)일수록 낮다 `[추론]`. **이 `[추론]`은 통과 판정에 쓰지 않는다** —
대신 원천의 창작성 등급을 기록만 하고, 법률 판단은 사용자 소관으로 남긴다.

### G0-4. 탈락 조건 (경로 배정과 무관하게 탈락)

- **출처 추적 불가** — 저자·연도·URL·라이선스 원문 넷 중 하나라도 확인 못 하면 탈락
- **라이선스 원문 URL 이 죽어 있음** — 라벨만 있고 조문을 못 읽으면 탈락

## G1 · 목적 적합 — **핵심 게이트**

### G1-1. 채우는 슬롯이 0개면 탈락

[demand-model.md](./demand-model.md) §4 의 결손 지도를 분모로 쓴다.

| 슬롯군 | 결손 가중치 |
|---|---:|
| A 추론형 (설명·논증) | **0.00** — 과잉 |
| B 정보·실용형 (실용문·데이터·서사) | **1.00** |
| C 장문 서사형 (서사·전기) | **0.51** |

**원천 가치 = Σ(채울 수 있는 슬롯 × 그 슬롯의 결손 가중치)**

A 무리만 채우는 원천은 가치 0 이다 — 탈락은 아니지만 **수확 우선순위가 없다.**

### G1-2. 시대·문체

- **출판 연도를 기록한다.** 기록 불가면 G0-4 로 탈락.
- 고어체·구식 과학·낡은 사실 여부를 본다. 판정 근거는 표본 문단 읽기이며, 기계 지표가 아니다.
- 실측 참고 `[측정]`: 1900년대 초 PD 도서 40,518편 판정에서 `bias` 3,092 · `pseudoscience`
  1,339 · `obsolete-fact` 1,306 · `doctrine` 1,450 = **7,187편(47%)** 이 내용 사유로 거절됐다.
  **이 비율은 그 시대 도서의 것이지 「도서 일반」의 것이 아니다** — 현대 원천에 그대로 대면 안 된다.

### G1-3. 갈래·주제가 슬롯 목표 분포에 맞는가

슬롯별 목표 문체 `[측정: demand-model.md §1]`:

| 슬롯군 | 어수 중앙 | 고유명사/100어 | 앞 문맥 지시어 시작 | 주된 구조 표지 |
|---|---:|---:|---:|---|
| A 추론형 | 148~169 | **0** (0개인 지문 52~79%) | 0~3.6% | 대조 65~87% |
| B 정보·실용형 | 91~136 | **2.26~15.63** | 0~10.7% | 시간순 28~61% |
| C 장문 서사형 | **334** | 4.25 | 0% | **시간순 89.7%** |

## G2 · 가공 가능성 — **샘플에 실제로 가공을 시도해 잰다**

선언이 아니라 실행으로 판정한다. 원천마다 **문단 3개**를 골라 가공을 시도하고 수정량을 센다.

| 항목 | 재는 법 | 합격선 |
|---|---|---|
| 논지를 한 문단 단위로 떼어낼 수 있는가 | 문단 하나가 주장 또는 완결된 설명을 담는 비율 | ≥ 2/3 |
| 고유명사 제거 후 논지 유지 | 고유명사를 일반명사로 바꾼 뒤 논지가 남는가(사람 판독) | 3/3 |
| 앞 문맥 의존 제거 가능 | 지시어·전방참조를 풀 수 있는가 | 3/3 |
| 어휘를 목표 대역으로 내려도 내용 유지 | off-list 낱말을 쉬운 말로 푼 뒤 내용이 남는가 | 3/3 |
| **수정량** | 가공 전후 낱말 수 대비 바뀐 낱말 비율 | 기록만 — 비용 추정에 쓴다 |

**가공 비용 등급**: 수정량 <20% 경 · 20~50% 중 · >50% 중(사실상 재저작).

## G3 · 기계 지표 — **보조. 이것만으로 합격·탈락을 정하지 않는다**

등급(A/B/C)을 매기는 데만 쓴다. 측정 도구는 이미 있다:

| 지표 | 도구 | 비고 |
|---|---|---|
| 영어 본문 여부 | `prose-gates.judgeEnglishBody` — 라틴문자 ≥0.70 **그리고** 영어 기능어 ≥0.15 | 선언 필드를 안 본다. 27편 전수에서 간격이 비어 있다 `[측정]` |
| 길이·창별 산출 | `source-doc-inspect.mts` · `chopToWindow` | 창 넷을 겹쳐 센다 |
| 고유명사 밀도 | `(?<=[a-z,;:]\s)[A-Z][a-z]{2,}` /100어 | 대리 지표임을 명시 |
| 자족성 | 인용부호로 시작 · 앞 문맥 지시어로 시작 비율 | |
| 정제 잔존율 | `source-doc-inspect` 의 `keep_pct` | 표·서지를 걷어낸 뒤 산문이 얼마나 남는가 |
| 어휘 대역 | NGSL+NAWL 밖 비율 | **로더가 CSV 전 칸을 읽는지 확인할 것** — 첫 칸만 읽어 목록이 12,700→3,767 로 줄었던 사고가 있다 `[측정]` |

⚠️ **G3 만으로 합격시키지 않는 이유 (실측)**: 2026-09-23 에 어휘 게이트가 버그였을 때, 생성
산출물이 어휘 0.7%로 통과하면서 be동사 밀도 0.00/100어(정상 영어 3~5)였다 — **지표를 통과했지만
영어가 아니었다** `[측정: argsme-gate]`. 기계 지표는 **피해 갈 수 있다.**

## 판정 절차

1. **G0** 원천 단위로 라이선스를 개별 확인 → 경로(R0~R4) 배정. 출처 추적 불가면 탈락.
2. **G1** 결손 지도에 대 본다. 채우는 슬롯 0개면 우선순위 없음. 연도·갈래 기록.
3. **G2** 문단 3개에 실제 가공 시도 → 수정량 기록 → 비용 등급.
4. **G3** 기계 지표로 등급 부여.
5. **원천 가치 = Σ(슬롯 × 결손 가중치) ÷ 가공 비용 등급** 으로 줄 세운다.

## 이 기준이 막는 앞선 실수

| 실수 | 막는 자리 |
|---|---|
| 기준 없이 수확부터 (gutenberg 1,810권 → 40,519조각) | G1-1 — 채우는 슬롯이 0개면 우선순위 없음 |
| 추론을 측정처럼 말함 | 모든 항목에 근거 태그 · `[추론]`은 판정 금지 |
| 라이선스를 뭉뚱그림 | G0-1 원천 단위 개별 기록 · G0-2 경로표 |
| 분류 오류 (Standard Ebooks 를 현대 단행본으로) | G1-2 **출판 연도 기록 필수**, 기록 불가면 탈락 |
| 비교군 오염 | G1-3 슬롯군별 목표 문체 — 평균 하나로 안 본다 |
| 선별 효과와 가공 효과 혼동 | G2 가 **실제 가공 시도**로 잰다. 기출 지문의 문체는 출제자의 선별 결과이기도 하므로 목표치이지 원문의 합격선이 아니다 |
| 법적 주장을 통념으로 댐 | G0-3 — 가드는 숫자로, 법률 판단은 사용자 소관 |
