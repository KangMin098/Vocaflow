## 2. G0-1 이 옳았다 — **컬렉션 라벨은 네 번 다 틀렸다** `[측정]`

criteria.md 는 "컬렉션 라벨을 그대로 믿지 않는다"를 G0-1 로 못 박았다. 파일럿이 그 조항 하나로
**네 건의 오분류를 막았다.**

| 원천 | 라벨이 말한 것 | 실측 |
|---|---|---|
| **punctum** | DOAB publisher-level: *"All punctum titles carry a CC **BY-NC-ND** license"* | ACTIVE 472 중 **95.8%가 BY-NC-SA** · ND 는 20권뿐 |
| **OpenStax** | 업계 통념 + 저장소 어댑터 주석: "모든 OpenStax 교과서는 CC BY 4.0" | **live 영어 73권 중 70권(95.9%)이 CC BY-NC-SA 4.0** · CC BY 는 3권 |
| **ANU Press** | DOAB: CC 언급 없음 / 카탈로그: OA | **2018 이전 전부 ARR** `[문헌: press.anu.edu.au/faqs/conditions-use]` — 연도를 안 보면 ARR 을 OA 로 받는다 |
| **DOAB 메타** | `dc.rights = "open access"` (600건 중 410) | 라이선스 필드가 **없다.** `xoai` 의 `bitstream#rightsuri` 에만 있다 |

그리고 **메타데이터가 옳아도 책이 다른 말을 한다**: DOAB 본문 확보 14권의 판권장을 직접 읽어 대 보니
**4권 불일치**(Cornell UP·ANU·Amsterdam UP 가 메타는 CC BY-NC-ND 인데 판권장은 **All rights reserved**).

**문자열 함정 둘도 실측됐다** — Taylor & Francis 판본은 라이선스 문자열에 **제로폭 문자**가 박혀
(`CC-B​ Y-N​ C-N​ D`) 정규화 없이는 **BY 로 읽힌다**(OLH 절단 사고와 같은 종류). De Gruyter 는 전문
검색 시 **위키백과 사진 크레딧의 CC BY-SA** 가 책 라이선스로 잡힌다 — 판권장만 봐야 한다.

> **criteria.md 에 더할 것**: G0-1 에 「판권장(앞 15k자)을 읽어 메타와 대조」와
> 「유니코드 정규화 후 판정」을 절차로 넣는다.

B 무리는 고유명사 밀도가 **높아야** 정상이다(안내문 15.63 · 내용일치 13.93 · 목적 7.55 · 도표 5.13).

|---|---|---:|---:|
| Federal Register 공고 | 안내문 일치 | 15.63 | **15.46~17.92** |
| gov.uk 보도자료 | 내용 일치(글) | 13.93 | **13.01** |
| OWID | 도표 | 5.13 | **6.15** |
| Eurostat Statistics Explained | 도표 | 5.13 | **5.59** |

**공급량 하한** `[측정: 90일 창]`: Federal Register "Public Meeting" 공고 **206편** · 전체 NOTICE
**5,299편** · gov.uk 보도자료 **840편** · gov.uk guidance 25,283편. 현재 B 재고가 **11편**인 것과 대비된다.

### ★ B 무리는 고유명사를 **지우면 안 된다** `[측정]`

실제 기관명을 일반명사로 바꾸자 밀도가 **10.23→6.43**(gov.uk) · **6.88→3.17**(Eurostat)로 떨어져
목표에서 **더 멀어졌다**. **가상의 고유명사로 갈아 끼워야 한다.**

> **criteria.md 에 더할 것**: G2 의 "고유명사를 일반명사로 바꾼 뒤 논지가 남는가"는 **A·C 무리 전용**이다.
> B 무리는 「가상의 이름·날짜·금액으로 치환해도 안내문으로 읽히는가」로 바꾼다.

### 못 잰 것 — **심경·분위기(수요 3.5%)**

R0·R1 후보가 없었고, 받으려던 Global Voices 가 연결 실패했다. **「불가」로 잰 것이 아니라 못 잰 것**이다.

### 새로 드러난 법적 사실 둘

- **World Bank 블로그는 CC BY 가 아니다** — 약관 원문 *"You may use the Site only for lawful, personal
  and non-commercial purposes."* CC BY 4.0 은 Open Knowledge Repository(발행물)에 붙는다 → **R3**.
- **「정부 자료 = 자유」는 미국에만 해당한다** — Parks Canada·Canada.ca 는 비상업 복제만 무허가 → **R3**.

## 7. ★ 이 파일럿 밖에서 드러난 것 — **gutenberg 퇴출이 미완이다**

Phase 0 감사가 `csat_dcp_items` 의 고아를 찾았고, 내가 전수로 귀속했다 `[측정]`:

| | 값 |
|---|---:|
| `kind='article'` 문항 전체 | 879,534 |
| 원천이 사라진 고아 문항 | **46,031** |
| 그 고아가 가리키는 서로 다른 글 | **9,672** |
| **그중 내가 지운 gutenberg** | **9,672 (100%)** |

**고아는 못 쓰는 문항이 아니다 — 그게 더 나쁘다.** `payload` 에 지문·문장이 들어 있어
**원천 없이도 렌더된다**. 표본으로 확인한 실제 내용:

> `"Cowards die many times before their deaths; The valiant never taste of _____ but once."`
> `"Mother.--\"What! you mean to kill and bury them before the _____ return."`

셰익스피어 대사, 19세기 대화문 — **퇴출 사유에 정확히 해당하는 글이 교재 문항으로 남아 있다.**
원천은 지웠는데 산출물은 남았다. 전체 article 문항의 **5.2%** 다.

`payload` 에 `passage` 를 담은 유형은 368개뿐이고(content_match 149·title 95·blank 76·summary 48),
나머지 45,663개는 문장 단위 유형(`blank_word` 9,557 · `grammar_fix` 7,960 · `word_order` 5,589 ·
`unit_vocab` 9,607 · `vocab_choice` 5,754 · `unit_grammar` 4,531 · `grammar_choice` 2,365)이다.

**조치하지 않았다** — 46,031행 삭제는 또 하나의 되돌릴 수 없는 작업이고 사용자 결정이다.

### 그 밖에 퇴출이 안 닿은 자리 `[측정: Phase 0 감사]`

- `csat_source_registry` 가 아직 **gutenberg 를 `active=true`** 로 갖고 있다 → 소싱 화면이 그린다
- DB 표 `csat_source_snapshots` 가 2026-09-23T18:20Z 에 굳어 **gutenberg 40,519편을 그대로** 담고 있다.
  크론 `20 */6 * * *` 인데 **2026-09-24 00:20·06:20 UTC 실행분이 없다**
- 저장소 스냅샷 **10개가 STALE** — 특히 `source-inventory-snapshot.json`(2026-09-19)은
  scanned 109,043 vs 실제 68,604

## 8. 이 파일럿이 못 잰 것

- **심경·분위기 슬롯**(수요 3.5%) — R0·R1 후보를 못 찾았고 Global Voices 연결 실패
- **어휘 대역(NGSL+NAWL 밖)** — 8개 파일럿 전부 미측정. 추정으로 채우지 않고 비웠다
- **모든 비율이 n=20 의 값이다.** 95% 구간이 ±20pp 다 — 어떤 비율도 단독 계획 근거로 쓰지 않았다
- **곱셈 추정을 하지 않았다** — StoryWeaver 「권당 2.2창 × 6,064편」, gutenberg 「논픽션 서사에서 몇 편」
  둘 다 **미측정으로 비웠다**(책당 산출이 18~1,011편으로 50배 벌어져 외삽이 성립하지 않는다)
- **법률 판단은 하지 않았다** — 조문 원문과 URL 만 적었다. 제휴 전재의 CC 전이, DOAB 메타/판권장 불일치의
  법적 의미, 한국 보호기간 산술은 전부 사용자 소관
- 고유명사는 **문중 대문자 대리 지표**다 — 독일어 명사, 대화 속 화자 이름을 과대 계상한다
- 앞 문맥 지시어 정규식은 **오탐이 많다**(저장소 실측: 문항 지문 10건 중 7~8건). 다만 기출 기준값도
  같은 자로 잰 것이라 **비교는 성립한다**

## 9. OBP 가 얹은 것 — 예상은 맞았지만 근거가 달랐다 `[측정: 547권 전수 + 본문 17권]`

**카탈로그 규모 정정**: 과제 지시문 "303권" → **단행본 547권**(MONOGRAPH 296 · EDITED_BOOK 203 · TEXTBOOK 48).

### ★ CC BY 는 닫힌 집합이다 — 연도 × 라이선스 전수

| 기간 | CC BY | 비율 |
|---|---|---:|
| 2016–2021 | 158/176 | **89.8%** |
| **2022+** | **20/254** | **7.9%** |

OBP 가 2022년에 정책을 바꿨다. **신간이 늘어도 R1 재고는 거의 안 는다 — 220권이 사실상 상한이다.**
이 축(연도 × 라이선스)은 다른 원천에도 대 봐야 한다.

### 문체는 A 가 아니라 C 와 겹치는데 **기제가 다르다**

| 축 | OBP 150어 창 | A 기출 | C 기출 |
|---|---:|---:|---:|
| 고유명사/100어 | 4.43 | **0** | 4.25 |
| 고유명사 0개 지문 | **2.3%** | 52~79% | **0%** |

수치는 C 와 거의 일치한다. **그러나 C 의 고유명사는 사람·사건이 시간을 따라 움직여 생기고, OBP 의
고유명사는 학자·사본·지명을 *인용*해서 생긴다**(330어 창의 28.4%가 「이름+연도」 꼴).
criteria.md G3 의 "기계 지표는 피해 갈 수 있다"가 그대로 나온 자리다 — **지표가 맞아도 갈래가 다르다.**

### 🔴 가장 아픈 결과 — 이 가공은 어느 쪽에도 못 선다

G2 로 가공한 9문단 중 **6개가 원문과 6-gram 을 1~9건 남겼다.** criteria.md G0-3 의 재저작 가드는
**6-gram 0건**이다. 즉 수정량은 이미 재저작 수준(64.0%)인데 **재저작 가드는 통과하지 못한다.**
CC BY(R1)의 이점을 쓰려면 "원문 + 얕은 손질"이어야 하는데 그게 안 된다.

> **criteria.md 에 더할 것**: G2 의 결과를 「경/중/재저작」 3등급이 아니라
> **「R1 얕은 손질 가능 / 재저작 가드 통과 / 어느 쪽도 아님」** 3판정으로 바꾼다.
> 세 번째 칸이 실제로 나왔고, 지금 기준에는 그 칸이 없다.

**수확한다면 전기 CC BY 14권만**(권당 20창 상한 → 약 280편). 판정: **낮음**.

### 접근 경로 `[측정]`
Thoth GraphQL 은 **POST 로 작동**하지만 **본문을 안 준다**(`fullTextUrl` 이 202·size 0 / 429).
본문 실경로는 **OAPEN REST**(ISBN → uuid → `.pdf.txt`) · 미러율 17/20 = 85%.
⚠️ **하이픈 넣은 ISBN 으로 OAPEN 을 조회하면 다른 책이 1순위로 온다** — 하이픈을 빼고 제목을 대조할 것.

## 10. `/admin/csat/` 에 더할 항목 제안 (구현은 승인 후)

파일럿이 드러낸 것 중 **화면이 지금 못 보여 주는 것**만 적는다.

### ① 라이선스 세분 — 지금은 한 칸도 없다

현재 소스 화면은 `license_class` 를 안 그린다. 파일럿에서 **네 번 다 컬렉션 라벨이 틀렸으므로**
원천 단위 세분이 화면에 있어야 한다.

| 칸 | 값 | 근거 |
|---|---|---|
| 라이선스 세분 | BY / BY-SA / BY-NC / BY-NC-SA / BY-ND / BY-NC-ND / CC0 / PD / ARR / 미확정 | G0-1 |
| 경로 | R0 / R1 / R2 / R3 / R4 | G0-2 |
| **원문 확보 vs 재저작 입력** | R0·R1 합계 / R2~R4 합계를 **따로** | 섞으면 확보 편수가 부풀어 보인다 |
| 판권장 대조 | 일치 / 불일치 / 미대조 | DOAB 14권 중 4권 불일치 |
| 연도 × 라이선스 | 원천별 추이 | OBP 2022년 정책 변경을 이 축이 잡는다 |

### ② 슬롯 기여도 — 지금은 「편수」만 보인다

| 칸 | 값 |
|---|---|
| 슬롯군 | A / B / C / 없음 |
| 결손 가중치 | 0.00 / 1.00 / 0.51 |
| **원천 가치** | Σ(슬롯 × 가중치) — 정렬 기본값을 편수가 아니라 이것으로 |
| 가공 비용 | 경 / 중 / 재저작 / **어느 쪽도 아님** |

### ③ 결손 대비 진척률

슬롯군마다 `현재 재고 ÷ 목표`. 목표는 기출 출현 빈도 가중. **A 는 이미 100% 를 넘으므로
"더 넣어도 안 오른다"가 화면에 보여야 한다** — 지금은 총 편수가 늘면 좋아 보인다.

### ④ 신선도 배지 — **가장 급하다**

소스 화면은 **저장소 스냅샷 파일**을 읽는데 그 사실이 화면에 없다. 지금 10개가 STALE 이고,
`source-inventory-snapshot.json` 은 **없는 재고 40,519편을 보여 준다.**

각 패널에 `measuredAt` 과 **DB 와의 차이**를 배지로 띄운다. `loadEligibilityDrift` 가 적격 패널에
이미 하고 있는 것을 **나머지 패널로 넓히는 것**이다.

### ⑤ 퇴출 원천 추적

`csat_source_registry` 가 아직 gutenberg 를 `active=true` 로 갖고 있고, 그 원천에서 나온 문항
**46,031개**가 재고에 남아 있다. 원천을 내리면 **그 산출물이 몇 개 남는지** 화면이 말해야 한다.
