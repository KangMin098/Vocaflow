# /csat 학습자 니즈 조사 (2026-09-24)

> 과제: 「/csat 메인 화면 구성 재설계」 1·2단계 산출물. 설계는 [ia-design.md](./ia-design.md).
> 태그: **[측정]** 수치·통계 근거 · **[문헌]** 연구·공식자료 · **[커뮤니티]** 학습자 글(관찰, 수치 아님) · **[추론]** 직접 근거 없음.
> 빈도 = 그 니즈를 **실제로 확인한 출처 수**. [추론]만으로 설계하지 않는다(ia-design 에서 [추론] 항목은 「보류」 또는 「계측 후 결정」으로만 쓴다).

## 0. 조사 범위와 한계

- 웹 검색 12회 · 본문 확인 9건. 오르비 · 디시(수능 현강 갤러리) · 교육 매체 · 교재 후기 · 공부법 블로그 · 앱 스토어 · 학술 문헌.
- **수만휘(네이버 카페) · 에펨 · 더쿠는 검색에 잡히지 않아 빠졌다.** 커뮤니티 표본이 오르비에 치우쳐 있다(상위권 편향 가능).
- 빈도는 1~4로 작다. 순위가 아니라 **존재 확인**으로 읽는다.
- 우리 쪽 실측 수요: `funnel_events` 의 csat_* 이벤트는 전부 **1~2명**(개발·검증 계정으로 추정)에게서 나왔다. **실제 학습자 사용은 사실상 0**이다(§5).

## 1. 현황 분석 (코드 · DB 실측)

### 1-1. 라우트와 이동 경로

```
사이드바 · 허브 포털 · 상단 내비 푸터 ─► /csat (3B 메인, SpaceScreen)
                                          ├─► /csat/browse (전체 서가) ─┬─► /csat/item/[slug] ⇄ 같은 유형 item
                                          │                            └─► /csat/dissect?resume=1
                                          ├─► /csat/dissect (오늘의 해부: 예측 → 대조) ⇄ ?item= ─► /csat/formulas
                                          ├─► /csat/formulas (내 공식) ─► /csat
                                          └─► /csat/item/[slug] (표 줄을 펼친 안)
/csat/space ─ redirect ─► /csat
```

| 문제 | 근거 |
|---|---|
| `/csat/item` 은 **막다른 화면**이다. 서가 · 메인 · 해부로 돌아가는 링크가 없다(같은 유형 item 만) | `AnalysisTheater.tsx` 의 링크 전수 |
| `/csat` 메인에 **이어서 하기 · 복습 예정이 없다.** resume 은 서가 안에만 있다 | `SpaceScreen.tsx` · `CsatWorkspace.tsx:216` |
| Today · 다른 학습 모듈에서 `/csat` 으로 들어오는 길이 0 | `/csat` grep |
| 고아 컴포넌트 4: `SessionHome` · `CsatLibrary` · `PatternMap` · `PatternComparison` | import 0 |
| `/csat/browse` 가 해설 극장 판을 빌려 써서 메인과 결이 다르다(사용자 지적 「극장 스타일 아님」) | 2026-09-24 대화 |
