# FYM 사람 평가 프로토콜 — 2차 초안

2026-10-05 사용자 운영안 반영. **사람 책임자 검토용이며 승인·사전 등록·평가가 완료되지 않았다.** 기존 4쌍×중1/고1의 8편은 평가 시스템의 calibration set이다. 플랫폼의 각색 성능이나 학년 적합성을 대표하는 표본으로 해석하지 않는다. 현재 실제 전문가/학생 결과는 0건이다.

## 이번 회차에서 확인할 것

전문가가 같은 평가 항목을 다르게 해석하는 위치, 원 연구 문맥이 충분한지, 학생 문항의 애매성, 측정별 분산·누락·피로 영향을 확인한다. 평가자 일치와 정답률을 각색 성능 하나로 합치지 않는다. 목표 학년·모델·기존 관찰 판정은 의미 평가자에게 숨긴다. 책임자만 원천 UUID/해시·연구 DOI/해시·opaque ID의 대응을 보관한다.

## 전문가 의미 평가

초안은 4점 척도를 사용한다. 사람 책임자가 척도 문구와 항목별 anchor를 확인한 뒤 전체 회차에서 같은 척도를 쓴다. 3점으로 바꾸려면 데이터 수집 전에 새 문서/양식/해시로 등록한다. 미평가는 점수 밖의 null로 둔다.

| 점수 | 평가 anchor |
|---|---|
| 1 | 원문의 중요한 의미가 바뀌었거나 중대한 왜곡의 근거가 있다 |
| 2 | 중요한 누락·모호성·추가로 항목의 보존을 확신할 수 없다 |
| 3 | 의미는 보존되며 경미한 표현 문제만 있다 |
| 4 | 해당 의미와 한정이 명확히 보존된다 |

각 지문마다 독립 전문가 최소 2명이 먼저 평가한다. 8항목별 점수·각색 인용·원 연구 근거·이유·critical 여부·왜곡 코드를 각각 남긴다. critical은 점수와 별도 기록이며 데이터 수집 전에 항목별 치명 오류 anchor를 확정한다.

수기/별도 파일 기록에는 [독립 평가 빈 양식](../scripts/textbook/frym-validation/expert-rating-2.blank.json)을 사용한다. 사람 책임자가 등록 manifest·opaque ID·본문 hash를 붙여 배정하고 평가자가 실제 ID·시각·판정을 채운다. 원 연구 문맥과 각색문은 v2 expert 자료에서 준비하며 이전 관찰 결과는 보여주지 않는다. 빈 값은 실제 판정이 아니며 완성된 양식을 봉인 manifest의 response batch에 넣어 수집한다.

| 항목 | 반드시 대조할 것 | 분해 결과 |
|---|---|---|
| 핵심 주장 보존 | 누가/무엇에 대해 어떤 결과를 주장하는가 | claim_preserved |
| 인과 방향 보존 | 원인/결과 방향, 상관과 인과의 구분 | relation_preserved |
| 비교·대조 관계 보존 | 집단/비교 대상, 결과의 방향 | relation_preserved |
| 조건·범위 보존 | 모집단, 지역, 시점, 조건, 분모 | scope_preserved |
| 불필요한 추가 없음 | 지원되지만 의미 파악을 방해하는 정보의 추가 | 별도 항목으로 보존 |
| 근거 없는 추가 없음 | 원 연구가 지원하지 않는 사실 | no_hallucinated_content |
| 필수 정보 삭제 없음 | 빠지면 핵심 의미가 달라지는 정보 | claim_preserved |
| 추론 강도 보존 | 가능성/확실성, 규모, 일반화 수준 | epistemic_strength_preserved |

제안 통과 기준은 **최종 8항목 모두 3점 이상, 미평가 없음, 중대한 왜곡 0건**이다. 평균점수는 기술 통계로만 사용한다. 핵심 주장·관계·범위·강도 중 어느 차원에서든 전문가가 critical을 표시하면 현재 버전은 즉시 탈락하며 다른 항목 점수로 상쇄하지 않는다. 다른 항목의 1/2점도 전 항목 최소점 기준에 따라 통과하지 못한다.

불일치는 점수·critical·왜곡 코드·통과 판정 중 하나라도 다를 때로 정의한다. 제3 adjudicator는 처음 두 판정을 보기 전에 같은 원 연구 문맥과 각색문을 blind로 독립 평가한다. 그 판정을 저장한 뒤 최초 두 평가를 공개하고 근거를 비교한다. 비치명 불일치는 항목별 최종 판정과 이유를 기록한다. 미해결 불일치는 학생 검증/승격으로 넘기지 않는다. **critical이 있는 현재 버전은 제3 평균이나 다수결로 구제하지 않는다.** 오판 가능성도 calibration 발견으로 남기고, 내용/평가 문구를 수정할 때는 새 버전·새 사전 등록·재평가를 한다. 원 평가와 중재 기록은 삭제하지 않는다.

제3자의 첫 판정은 같은 독립 평가 양식에 보관하고, 그 hash를 [중재 빈 양식](../scripts/textbook/frym-validation/adjudication-2.blank.json)에 연결한다. 최초 두 판정의 공개 시각 이후에 항목별 최종 점수·근거·이유·미해결 여부를 기록한다. 최초 평가, 독립 제3 평가, 공개 후 중재 기록을 각각 보존한다.

제3 adjudicator는 처음 두 평가자와 다른 사람이며 각색 작성에 참여하지 않는다. 학생 문항 채점자로도 등록할 수 있지만 의미 중재와 학생 채점 기록은 구분한다.

책임자는 각 평가자의 작성 참여와 기존 pilot/관찰 판정·모델·목표 학년의 사전 노출 여부를 확인한다. 노출된 자료와 시점을 기록하고 blind 평가자로 배정할 수 있는지 사전 기준으로 정한다. 다른 평가자의 결과를 공유하지 않았다는 확인도 보관한다.

## 학생 pilot 배정과 측정

중1·고1 각각 15~30명의 초기 pilot을 계획한다. **초안 목표는 학년당 24명, 최소 유효 참여자는 학년당 15명**이다. 이 수는 설계 제안이며 통계적 대표성이나 검정력을 인증한 값이 아니다. 모집/제외 기준과 결측 시 처리 방식을 책임자가 사전에 확정한다.

의미 기준을 통과한 지문만 학생에게 제시한다. 같은 학년의 학생은 해당 학년 버전만 읽고 한 pair의 두 버전이나 동일 지문을 반복해서 측정하지 않는다. 네 pair의 순서는 네 가지 균형 순서로 배정한다. 예시 순서는 ABCD/BDAC/CADB/DCBA이며 각 지문이 각 순서 위치에 한 번씩 온다. 학년별 배정 ID·순서·지문/문항 hash를 결과 전에 기록한다. 두 지문씩 두 세션으로 나눌지는 책임자가 정하고 모든 참여자에게 같은 계획을 적용한다.

지문별 기준을 판단할 때는 **해당 버전의 완전한 유효 측정 최소 15건**을 제안한다. 학년별 모집 수만 충족하고 어떤 지문의 유효 측정이 15건 미만이면 그 버전을 통과시키지 않는다. calibration에서 일부 지문이 의미 탈락하면 해당 버전은 학생에게 보여주지 않고, 평가 대상 감소와 배정 변경을 기록한다. 이후 모집 부족이나 결측을 사후에 다른 학생/학년으로 메워 기준을 바꾸지 않는다.

| 측정 | 단위/방식 | 보고할 분산·결측 |
|---|---|---|
| 읽기 시간 | 질문을 보기 전 시작/끝, 초 | 중앙값·사분위범위·유효 n |
| 이해도 | 명시 정보 문항 정확도, 0~1 | 학생별 값·평균·유효 n |
| lexical_level | 문맥 어휘 문항 정확도, 0~1 | 학생별 값·평균·유효 n |
| syntax_level | 문장 의미 문항 정확도, 0~1 | 학생별 값·평균·유효 n |
| reasoning_level | 근거/조건/한계 추론 정확도, 0~1 | 학생별 값·평균·유효 n |
| 어휘 부담 | 미지어 등장 비율과 1~5 자기보고 | 분포·중앙값·유효 n |
| 문장·추론 부담 | 각각 1~5 자기보고 | 각각 분포·중앙값·유효 n |
| 체감 난도 | 1~5 자기보고 | 분포·중앙값·유효 n |

정확도 세 축을 학년 공인 척도나 V-Level로 환산하지 않는다. 학생 응답은 가명 ID로 보존하고, null/무응답은 0점으로 만들지 않는다. 제외된 기록과 이유도 남긴다. 문항별 반응·평가자 일치·지문/학년별 유효 표본·순서 영향을 별도로 보고한다. 참여 설명·철회·실명 대응과 데이터 보관은 사람 책임자가 운영 계획에 확정한다.

## Pass band 사전 봉인

[pass-bands-2.draft.json](../scripts/textbook/frym-validation/pass-bands-2.draft.json)은 사람 책임자가 채울 설계 양식이다. 중1/고1의 10개 측정 각각에 최소·최대와 선택 근거를 확정한다. 현재 모든 band는 null이며, 기존 v1의 같은 초기 범위를 복사하지 않았다. 집계량(시간/부담 중앙값, 정확도 평균), 최소 유효 n, 제외·결측·이상값 규칙도 함께 등록한다.

봉인 순서는 다음과 같다.

1. 사람 책임자가 척도/anchor·통과 기준·critical·중재·표집/배정·제외/결측·밴드와 근거를 확정한다.
2. 프로토콜·평가 양식·문항/채점 기준·지문·원 연구 증거·배정 계획의 정확한 파일 목록과 SHA256 manifest를 만든다. calibration/validation/재현 회차 사이의 지문·원천·원 연구·학생·전문가 중복 허용 단위와 평가자의 사전 노출 확인도 포함한다. opaque ID 대응은 책임자 전용으로 보관한다.
3. 평가와 응답 열람 **이전**의 등록 시각·책임자 ID·증빙 참조와 manifest SHA256을 별도 사전 등록 기록에 남긴다. 해시만으로 등록 시각이나 사람 신원이 입증되는 것은 아니다.
4. 이후 변경은 봉인 파일을 덮지 않고 새 revision·이유·새 등록으로 기록한다. 변경 전후 데이터는 다른 회차로 분석한다. 기존 파일을 다시 해시하는 것으로 사후 기준 변경을 숨기지 않는다.

Calibration 결과를 본 뒤 수정한 문항이나 band는 **후속 새 validation 표본**에서 검사한다. 같은 8편/같은 학생으로 다시 맞춰 얻은 결과를 독립 타당도 검증으로 보고하지 않는다.

이 초안의 후속 validation은 calibration의 원천 기사 UUID·연구 DOI·각색 본문과 학생 참여자를 재사용하지 않는 것으로 제안한다. 단순히 기존 지문의 이름이나 문장만 바꾼 판은 새 표본으로 세지 않는다. 전문가의 재참여는 허용 여부를 사전 등록하고, 기준 개발 참여와 자료 노출을 기록해 해석한다. 사람 책임자가 확정한 표본 정의로 실제 중복을 대조한다.

## 상태와 일반화 범위

| 상태 | 필요한 증거 |
|---|---|
| candidate | 원천과 버전이 고정된 미검증 지문 |
| expert_validated | 독립 평가/필요한 중재 완료, 항목별 통과, critical 없음 |
| student_validated | 의미 통과 이후 실제 목표 학년 측정이 사전 band/유효 n을 충족 |
| gold | 별도 validation set에서 위 기준 + 중대한 왜곡 0 + 완전 provenance/high 연결 충족 |
| DB seed | gold 이후 기존 권리/내용/DB 절차를 충족한 명시적 적재 |
| production | gold·발행 조건에 더해 다른 주제와 다른 원천의 독립 재현 증거 확인 |

이번 8편은 calibration이므로 expert/student 평가 결과가 좋더라도 gold나 DB seed로 자동 승격하지 않는다. production 재현의 새 주제·새 원천·표본 수·성공 기준 역시 재현 데이터를 보기 전에 별도 등록한다. 다른 글을 만들었다는 사실이나 published 상태만으로 재현이 충족되지는 않는다.

## 실행기 v2와 사람 확정

v2는 위 4점/8항목·핵심 critical 거부·독립 제3 판정 후 중재·완전 측정 15명·봉인 manifest·단계/재현을 연결했다. 기존 v1 파일은 그대로 읽지만 새 DB seed에는 사용하지 못한다. [명령·복구](../scripts/textbook/frym-validation/README.md)와 `protocol-2.draft.json`이 실행 계약이며 `pass-bands-2.draft.json`은 사람 검토용 양식이다. 3점 척도 변경은 현재 v2 실행기에서 지원하지 않으며 새 계약을 데이터 전에 등록해야 한다.

사람 책임자가 band·근거·운영 규칙·문항·expert_assignment·experts의 자격/사전 노출 확인·participants의 학년/균형 순서를 확정하고 `register --prepare`로 manifest를 준비한다. 외부의 실제 사전 등록 증빙과 시각을 `--approval`로 제공해야 봉인된다. 등록 후 정확한 bundle에서 새 패킷을 생성하며 수집/평가에서 packet_hash를 대조한다. 초안 패킷에 대한 응답을 새 봉인 결과로 인정하지 않는다. JSON/hash는 사람 인증이나 신뢰할 수 있는 외부 등록 시각을 대신하지 않는다. 실제 8편은 여전히 band 20개 null·책임자/배정/등록 없음·사람 응답 0이다.

최초/제3 리뷰와 중재는 각각 보존한다. 왜곡은 major/minor로 구분하고 중재에 `final_distortions`를 명시한다. 핵심 critical은 언제나 탈락이며 비치명 불일치는 중재로 최종 판정할 수 있다. 학생은 의미 통과 지문만 읽고, 앞 지문 생략은 확정된 의미 실패에만 허용한다. 시작/종료 중 하나가 없는 부분 기록도 보존하지만 측정에 포함하지 않는다. 보고서는 학생별 축 정확도 n/사분위, 문항별 응답, 순서 위치, 전문가 항목별 일치를 분리한다.

후속 validation/replication의 제외 명세는 `--calibration-results`의 실제 완료 파일에서 산출한다. 완료는 지문마다 확정 의미 탈락 또는 완전 학생 표본이다. band 밖 측정도 calibration의 완료된 발견이며 통과는 아니다. 미해결 중재나 학생 0명 상태를 완료로 인정하지 않는다. 새 source UUID/DOI/본문/학생을 써야 하며 전문가 재사용 여부는 미리 봉인한다. production 확인에는 gold 결과 이후 등록된 다른 주제/원천의 gold 재현과 현재 published 행/저장 인증 대조가 필요하다. 실제 사람 승인/평가·DB seed·발행은 수행하지 않았다.
