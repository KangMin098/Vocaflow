## 이견이 남은 것

없음 — 18건 모두 근거가 코드 위치로 확인 가능해 수용했다. 다만 다음은 **Codex 도 Claude 도 확인하지 못한 미해결**이다.

- DB 수치(texts·funnel·library 분포)는 Claude 쪽 SELECT 결과뿐이다 — Codex 는 DB 를 보지 않았다.
- DB 에만 있는 마이그레이션 234 의 출처 브랜치 개별 확인.
- 화면 실행·e2e(전부 not_run) — 「코드상 도달 가능」 은 사용자 경험 검증이 아니다.
- 실제 학습자 검증 없음(가입 4). AI 시뮬레이션으로 대체하지 않는다.
- 운영 배포가 Actions 밖(Vercel 대시보드 연결 등)에 있는지 — 사용자 확인 필요.
