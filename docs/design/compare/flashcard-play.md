## 하한선 (A)

- 학습 화면 모션 7종 — 카드 뒤집기 유지, 곡선은 **모션 없이** 상태가 바뀐다(정지 그래픽). 완료 화면의 `celebrate` 1s 회전 제거.
- 평가 버튼의 날짜 = **FSRS 미리보기**(세션이 실제로 적용하는 스케줄러) — SM-2 간격을 보이던 불일치를 닫는다. `srsV2` 가 없는 카드(목업·스코프 단어 일부)만 기존 표시.
- FSRS 변수(D/S)는 숫자로 보이지 않는다(§17 안티패턴 2) — 선의 모양과 "N일 뒤" 말로만.
- 색 단독 금지 — 오늘 점은 상태색 + 말(알아요/익숙해요/흐릿해요/처음 만나요).
- 한글 이탤릭 제거 · 무한 펄스 제거(재생 중 표시는 정지 상태 색).
