## 현재 (감사 2026-09-18 · 2026-09-19 재확인)

- 첫 시선 = 텍스트/파일/URL **같은 폭 선택 카드 3개**(`InputModeTabs`, 3열 균등) · 제목 3번(상단 바 「새 스크립트 추가」 · 킥커 「— 새 스크립트 추가하기」 · 두 줄 h2) · 그림자 세그먼트 토글 · 빈 입력칸.
- 파일·URL 은 **준비 중**인데 상단 바는 「직접 입력 · 파일 · URL」 이라고 말한다.
- 예시 글 5개(`SampleScripts`)가 **지어낸 수치**를 단다 — 「280단어」 인 예시의 실제 본문은 40낱말 남짓, 「쉬움/보통/어려움」 은 상수(I5).
- 저장하면 새 글이 아니라 `/text` 로 돌아간다 — 방금 만든 글을 다시 찾아야 한다.
- 정적 신호 21 · 렌더 1280 `0/3/0/6/4/0` · 390 `1/3/0/0/1/0`.

## B4 선택

(1) 새 데이터: A·D 0 · B 판면 조립 · C 조회 1. (2) 앞 화면과 같은 몸짓: **A**(칠해지는 입력칸 = `/fit`·`/signup`·`/diagnostic` 의 한 몸짓). (3) A 통과. → **A**.

**함께 고치는 것(브리프 제약)**: 준비 안 된 파일·URL 탭을 걷는다(말하지 않는 기능은 보이지 않게) · 예시 글의 지어낸 단어 수·난이도 상수 제거(실제로 칠해지면 커버리지가 말한다) · 저장 후 **새 글로** 이동 · 3열 선택 카드 제거.
**관측**: `text_created { coveragePct: number; chapters: number }` — 칠하지 못한 채 저장하면 `coveragePct = -1`. 브리프의 `forClass` 는 이 화면이 학급 맥락을 받지 않아(`/teacher` 링크에 인자 없음) 알 수 없는 값이다 — 지어내지 않고 뺐다. DB 허용 목록은 같은 승인 대기 파일에 한 줄.
