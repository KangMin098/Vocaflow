## 현재 화면의 평균 회귀 (06-workflow 비평 (b))

- 첫 시선 = 필터 칩 줄 + 표지 격자. 표지를 가리면 **어느 전자책 서점과도 구별되지 않는다**(비평 (a) 익명성 불통과).
- 이 제품만 가진 값(내 레벨에서의 커버리지 %)은 표지 모서리의 **작은 칩**으로만 존재한다 — 자산이 데이터로만 쓰이고 골격이 아니다(N4 불통과).
- 평균 신호 라쳇 기준 이 화면 계통(`components/library/**`)이 `backdrop-blur` · `bg-gradient-to-` 를 쓰고 있다(칩 위 흐림 배경 등).

## 에이전트 의견 (결정은 사람)

**A 를 권한다.** 새 데이터 작업 0, 로그인 없이 증명(N2)이 되는 유일한 안이며, 랜딩의 채색 지문과 **같은 몸짓**(레벨을 옮기면 세계가 움직인다)이라 제품 전체의 서명이 하나로 묶인다.
B 는 가장 강력하지만 로그인 뒤에서만 산다 — A 를 고른 뒤 로그인 상태의 **두 번째 층**(책등 호버 → 고스트 곡선)으로 흡수할 수 있다.
D 는 교사 경로(렌즈 6)에 가장 가깝지만 CSAT↔V-Level 대응 드레인이 먼저다.
