## 현재 (2026-09-18 캡처 · 판정 평균)

- 첫 시선 = 라벨 + H1 「이 지문, 우리 반에 맞을까?」 → **산세리프 무채색 textarea**(첫 뷰포트 절반, 영어에 산세리프 — 금지) → 예시/지우기 버튼 → 결과 박스 머리.
- 결과 = 한국어 **이탤릭** 판정 문장(금지) + 학년별 **막대 목록**(「60.2%」 를 CTA 와 같은 빨강으로).
- `@form 채색 지문` 선언(2026-09-18 앞선 세션)과 렌더 불일치. 부제 「바/로」 쪼개짐(I7).

## 에이전트 의견 (결정은 사람)

**A 를 골격으로, B 를 결과의 두 번째 면(인쇄·공유)으로 권한다.**
- A 는 새 데이터 작업이 **응답 확장 하나**뿐이고, 랜딩이 이미 검증한 서명(슬라이더 → 칠 200ms)을 도구에 그대로 옮겨 **광고와 도구의 간극**(이 화면이 1위인 이유)을 정확히 닫는다.
- B 는 데이터가 전부 있고 교사 경로(렌즈 6)에 가장 직접적이다 — 다만 첫 시선이 "종이" 라 도구의 즉시 조작(I3)이 약하다. A 의 결과를 「학급에 나눠 줄 한 장으로」 버튼 뒤에 두면 두 장점을 모두 갖는다.
- C 는 가장 새롭지만 공개 화면에서 "일반 모형" 수치를 보여 주는 표시광고 위험(우선순위 1위 규칙 — 법·표시광고)이 있다 — 로그인 뒤 `/text/new` 쪽 발산에서 다시 쓰기를 권한다.
