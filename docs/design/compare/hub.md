## 하한선 (A 에 적용)

- 학습 화면 모션 7종 — 허브는 학습 중 화면이 아니라 진입면이지만 같은 예산으로: 선·권점 전환은 `opacity`·색 200ms 만, 경로 모핑은 하지 않는다(두 선을 겹쳐 두고 실선만 교체). reduced-motion 에서도 페이드는 남는다.
- 색 단독 정보 금지 — 밑줄은 두께(3/2/1px)와 dotted(new)로 이중 부호화, 곡선은 실선/점선 + 문장(h1)이 같은 수를 말한다.
- 수치는 전부 계산값(I5) — 기준선은 `forecastMemory`, 실선은 같은 카드에 "오늘 Good 한 번" 을 FSRS 로 적용한 값. 추적 0 인 학습자는 **모아 둔 새 낱말**로 같은 계산(지어낸 학습자 없음). 모아 둔 낱말도 0 이면 곡선을 그리지 않고 다음 한 걸음(D5)만.
- 미진단 학습자의 1차 행동은 `/diagnostic` 유지(D7 · 브리프 제약). 곡선은 진단과 무관하게 그린다.
