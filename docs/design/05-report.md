## 5-2. 의뢰서의 진단 — 셋 다 맞았다. 내가 한 번 틀렸다

> "흰 카드 + **연보라 포인트**, 균일한 라운드, 시스템 폰트"

처음에 「연보라는 틀렸다」고 적었다. 학습자 표면에 `purple-*` 6회 · `violet-*` 0 · `indigo-*` 0 —
보라는 `/admin` 전용 액센트라고 봤다. **그 판단이 틀렸다. 클래스 이름만 세고 토큰을 안 봤다.**

보라는 토큰 뒤에 있었다:

| 토큰 | 값 | 어디에 |
|---|---|---|
| `--learn-mastered` / `-ink` | `#8B5CF6` / `#7C3AED` (violet-500/600) | 학습 단계 "정복" — 학습자 표면 **30곳** |
| `--level-c` | `#8B5CF6` | CEFR C 칩 — `/wordvault/browse` 행마다 |
| 하드코딩 | `#8B5CF6` | `/settings` 「외형」 액센트 · `RecentActivity` 모듈색 2건 |

그중 **둘은 파랑 → 보라 그라데이션**이었다(`wordvault/ListenPanel` · `StudyMode`,
`linear-gradient(90deg, var(--learn-fresh), var(--learn-mastered))`). 「AI-보라 그라데이션」은
`vocaflow-design` §2 가 **이름 대어 금지**한 바로 그것이다.

> **교훈**: 이 저장소는 「색상 하드코딩 금지」를 잘 지켜서 색이 전부 토큰 뒤에 있다.
> 그래서 **grep 으로는 색이 안 보인다.** 실행 중 화면의 `getComputedStyle` 로 재야 한다 —
> `measure-identity.mjs` 가 소스가 아니라 그려진 결과를 보는 이유다.

**조치**: 학습 단계 5색 · CEFR 3색 · 모듈색 8건을 지면 팔레트로 옮기고("정복" = 가장 깊은 잉크
`--p`), 파랑→보라 그라데이션 2곳을 단색 채움으로. 형광 핑크 `#EC4899`·시안 `#06B6D4` 도 같이.
떠돌이 indigo `#6366F1`·`#4F46E5` 5곳은 그 전에 제거했다.
(만화 표지 장르색 `components/comic/StyleSwatch.tsx` 의 보라는 **아트워크**라 남긴다 — UI 크롬이 아니다.)

「균일한 라운드」와 「시스템 폰트」도 맞았고, 후자는 생각보다 훨씬 심각했다(§5-1).

### 5-3-3. 측정을 두 번 놓친 이유 — 환경이었지 앱이 아니었다

로그인이 **인증 200 직후 멎는** 구간이 있었다. 추정하지 않고 DB 에 직접 물었다:

```
pg_stat_activity — 최장 쿼리 25,816초(≈7시간) · idle in transaction 2 ·
                   active 4가 전부 shared_dictionary 조회(wait_event = DataFileRead / BufferIo)
```

**다른 세션의 드레인이 공유 dev DB 를 점유하는 중**이고, 로그인 마지막 단계(`user_profiles`
조회)가 거기 줄을 선다. dev 로그에도 `canceling statement due to statement timeout` 이 남아 있다.
계측기는 그 라우트를 "재지 못함" 으로 적고 **분모에서 뺀다**(통과로 세지 않는다).
DB 가 한가해진 창에서 위 표를 얻었다.

재실행:

```bash
node scripts/design/measure-identity.mjs --all --out docs/design/identity-after.json
node scripts/design/measure-identity.mjs --public   # DB 가 바쁠 때도 되는 경로
```

### 5-3-4. 캡처에 보이던 «1 error» 배지 — 코드 결함이 아니었다

후반 캡처에 Next dev 오류 표시가 모든 화면에 떴다. 편집을 오래 이어 간 dev 서버의
**HMR 잔재**였다(로그: `__webpack_modules__[moduleId] is not a function` ·
`Invalid hook call` — 전형적인 stale-chunk 증상). **깨끗하게 재시작한 뒤 실측**:

```
/pricing | 에러배지: 없음 | 콘솔에러 0
/fit     | 에러배지: 없음 | 콘솔에러 1 (RSC prefetch 중단 — 빠르게 이동할 때 나는 dev 잡음)
/signup  | 에러배지: 없음 | 콘솔에러 1 (같음)
```

`shots/after/` 의 배지는 그 잔재가 찍힌 것이다 — **화면은 정상이고 배지만 남았다.**

## 5-5. 지침을 고친 것 — 무엇을, 왜 (의뢰서 필수 기록)

### ① `.claude/skills/vocaflow-design/SKILL.md` §2 — 「폰트 4종 고정」

```diff
-| 폰트 자유 선택 (Geist / Satoshi / Cabinet Grotesk) | 8개 스킬 공통 | 폰트는 SSoT 다
-| Plus Jakarta Sans · DM Sans · Lora · JetBrains Mono **4종 고정** |
+| 폰트 자유 선택 (Geist / Satoshi / Cabinet Grotesk) | 8개 스킬 공통 | 폰트는 SSoT 다
+| **v07 개정**: Hahmlet(한글 디스플레이) · IBM Plex Sans KR(UI·본문) · Lora(영어 원문) ·
+  JetBrains Mono **4종 고정**. ⚠️ 이전 4종은 **전부 latin subset** 이라 한글 UI 를 OS
+  기본꼴로 두고 있었다 — 화면 글자의 48~75%(실측). 이 칸은 "폰트를 마음대로 고르지 말라"
+  는 뜻이지 "한글을 폴백에 맡기라" 는 뜻이 아니었다. |
```

**왜**: 이 규칙은 외부 취향 스킬이 Geist·Satoshi 를 들이려는 것을 막으려고 만들어졌다.
그 목적은 그대로 유효하다. 다만 고정된 4종에 **한글 글리프가 없다는 사실을 아무도 재지 않았고**,
그래서 규칙이 의도치 않게 "한국어 UI 는 OS 기본값" 을 규정하고 있었다.
고친 것은 *고정한다는 원칙*이 아니라 *무엇을 고정했는가* 다.

### ② `docs/DESIGN_SYSTEM.md` §타이포 시그니처 — 사실 정정

v06.39 문서는 "한글 표시 → DM Sans 산세리프" 라고 적고 있었다. **실현된 적이 없다.**
DM Sans 에는 한글이 없다. 문단을 지우지 않고 **경고 블록을 붙여 남겼다** — 지우면
"왜 그때 그렇게 적었나" 가 사라지고, 같은 착각이 다시 생긴다.

### ③ `CLAUDE.md` — 고치지 않은 것

「한글에 Lora · 영어에 산세리프」 금지는 **그대로 유효하다.** Hahmlet 은 Lora 가 아니라
한글을 위해 설계된 세리프이므로 이 규칙을 어기지 않는다. 「정답률 빨간 글씨 압박 금지」도
그대로이고, 이번 작업은 **토큰이 그 규칙을 허용하고 있던 구멍을 막은 것**이다.

## 5-10. 작업 중 만난 함정 (다음 사람을 위해)

| 함정 | 증상 | 교훈 |
|---|---|---|
| Git Bash 경로 변환 | `--routes /hub` 가 `C:/Program Files/Git/hub` 로 바뀌어 캡처 실패 | Windows 에서 슬래시 인자는 `MSYS_NO_PATHCONV=1` |
| heredoc 이 `[\\/]` 를 접음 | 스윕의 admin/game 제외가 **조용히** 무력화 | 스크립트는 파일로 쓰고 경로를 `/` 로 정규화 |
| 템플릿 리터럴 안의 `[\s\S]` | 정규식이 `[sS]` 가 되어 검사가 "못 찾음" | 테스트에서 정규식을 조립하지 말고 문자열로 자른다 |
| Supabase 로그인 한도 | 캡처마다 로그인 → "로그인 중…" 에서 멎음 | 로그인 상태를 파일로 재사용(25분 TTL) |
| 로그인 후 이동 지연 | 인증은 200 인데 `/hub` 첫 컴파일이 15초+ → 45초 한도 초과 | 한도를 150초로. **인증 실패가 아니라 컴파일 대기였다** |
| 회귀가 토큰 문자열을 봄 | `--p` → `--ju` 로 바꾸자 CTA 검사가 0을 세고 실패 | 검사는 형태가 아니라 **의도**를 잡아야 한다 |
| **토큰만 고치면 토큰 쓰는 데만 바뀐다** | `--r-*` 를 2~8px 로 내렸는데 화면에 **12px 이 남았다** — 그 자리는 Tailwind 기본 `rounded-xl` 을 쓰고 있었다(학습자+공개 표면에 `rounded-xl` 35 · `rounded-lg` 30 · `rounded-md` 54) | 기본 스케일 자체를 같은 램프로 재정의한다. **안 쓰는 곳은 조용히 옛 값으로 남는다** |
| Tailwind 설정 변경이 dev 에 안 붙는다 | 설정은 맞는데 브라우저는 계속 12px | `npx tailwindcss -c … --content …` 로 **설정만 따로 빌드해 확인**(`rounded-xl → var(--r-xl)` 확인) 후 dev 재시작. 재시작 뒤 5px 실측 |
| **일괄 치환이 주석의 hex 까지 바꿨다** | `// #6366F1 4.28 로 미달이었다` → `// var(--p) 4.28 로 미달이었다`. 어떤 색이 왜 탈락했는지가 사라진다 | 이 저장소에서 주석은 **측정 기록**이다. `//`·`/* */`·`{/* */}` 를 먼저 가려낸 뒤 코드만 치환한다 |
| **색을 한 색으로 접으면 정보가 사라진다** | 보라를 전부 `--p` 로 접었더니 PosBadge 의 품사 8색 구분과 sidebar 그룹 6색 구분이 무너졌다 | 분류 팔레트는 **개수를 보존하는 1:1 매핑**으로 옮긴다. 자리가 모자라면 토큰을 하나 더 만든다(`--accent-plum`) |
| **canvas 는 `var()` 를 못 읽는다** | `ctx.strokeStyle = 'var(--x)'` 은 조용히 무시되고 기본 검정으로 그려진다. 오류도 안 난다 | canvas·`fillStyle`·`strokeStyle` 자리에는 **실제 hex** 를 두고 그 이유를 파일에 적는다 |
| **캡처 하네스가 실패를 통과로 셌다** | 저장된 로그인 상태가 죽은 채 재사용되자 다섯 라우트가 전부 `/login` 으로 갔는데 `✓` 로 적고 **멀쩡한 after 캡처를 로그인 화면으로 덮어썼다** | 튕기면 **찍지 않고 기존 파일을 보존**한다. 그리고 상태 파일은 나이가 아니라 **한 번 열어 보고** 믿는다. 같은 원칙(`분모에서 뺀다`)을 `measure-identity` 는 처음부터 지키고 있었다 |
