## 5-2. 의뢰서의 진단 중 **틀린 것 하나**를 먼저 고쳤다

> "흰 카드 + **연보라 포인트**, 균일한 라운드, 시스템 폰트"

학습자 표면 실계수: `purple-*` 6회(3파일) · `violet-*` **0** · `indigo-*` **0**.
보라는 `/admin` 전용 액센트(`--admin: #8B5CF6`)였다. 카드 면도 흰색이 아니라 크림(`#FBFAF6`)이었다.

**맞는 것은 「균일한 라운드」와 「시스템 폰트」였고, 후자는 생각보다 훨씬 심각했다.**
이 확인 없이 "연보라를 걷어내는" 작업을 했다면 시간을 통째로 버렸을 것이다.
(떠돌이 indigo `#6366F1`·`#4F46E5` 5곳은 실제로 있었고 제거했다.)

### 5-3-2. ⚠️ 학습자 라우트 측정은 이번 창에서 완주하지 못했다

`/hub` 등 로그인 화면은 **로그인이 인증 200 직후 멎어서** 재지 못했다. 원인을 추정하지 않고 DB 에
직접 물었다:

```
pg_stat_activity — 가장 오래된 쿼리 25,816초(≈7시간) · idle in transaction 2 ·
                   active 4가 전부 shared_dictionary 조회(wait_event=DataFileRead/BufferIo)
```

**다른 세션의 드레인이 공유 dev DB 를 점유하는 중**이고, 로그인의 마지막 단계(`user_profiles`
조회)가 거기 줄을 선다. 앱 결함이 아니라 **환경**이다 — 그래서 계측기는 그 라우트를
"재지 못함" 으로 적고 **분모에서 뺀다**(통과로 세지 않는다).

재실행 명령(그대로 복사해서 쓰면 된다):

```bash
node scripts/design/measure-identity.mjs \
  --routes "/hub,/dashboard,/flashcard/play,/wordvault/browse,/settings" \
  --out docs/design/identity-after.json
```

다만 **화면 자체는 캡처로 확인했다** — `shots/after-s4/hub@390.png` ·
`shots/after-s5/flashcard_play@390.png` 에 주묵 CTA·망각 밑줄·한글 세리프 제목이 보인다.

## 5-5. 지침을 고친 것 — 무엇을, 왜 (의뢰서 필수 기록)

### ① `.claude/skills/vocaflow-design/SKILL.md` §2 — 「폰트 4종 고정」

```diff
-| 폰트 자유 선택 (Geist / Satoshi / Cabinet Grotesk) | 8개 스킬 공통 | 폰트는 SSoT 다
-| Plus Jakarta Sans · DM Sans · Lora · JetBrains Mono **4종 고정** |
+| 폰트 자유 선택 (Geist / Satoshi / Cabinet Grotesk) | 8개 스킬 공통 | 폰트는 SSoT 다
+| **v07 개정**: Hahmlet(한글 디스플레이) · IBM Plex Sans KR(UI·본문) · Lora(영어 원문) ·
+  JetBrains Mono **4종 고정**. ⚠️ 이전 4종은 **전부 latin subset** 이라 한글 UI 를 OS
+  기본꼴로 두고 있었다 — 화면 글자의 48~75%(실측). 이 칸은 "폰트를 마음대로 고르지 말라"
+  는 뜻이지 "한글을 폴백에 맡기라" 는 뜻이 아니었다. |
```

**왜**: 이 규칙은 외부 취향 스킬이 Geist·Satoshi 를 들이려는 것을 막으려고 만들어졌다.
그 목적은 그대로 유효하다. 다만 고정된 4종에 **한글 글리프가 없다는 사실을 아무도 재지 않았고**,
그래서 규칙이 의도치 않게 "한국어 UI 는 OS 기본값" 을 규정하고 있었다.
고친 것은 *고정한다는 원칙*이 아니라 *무엇을 고정했는가* 다.

### ② `docs/DESIGN_SYSTEM.md` §타이포 시그니처 — 사실 정정

v06.39 문서는 "한글 표시 → DM Sans 산세리프" 라고 적고 있었다. **실현된 적이 없다.**
DM Sans 에는 한글이 없다. 문단을 지우지 않고 **경고 블록을 붙여 남겼다** — 지우면
"왜 그때 그렇게 적었나" 가 사라지고, 같은 착각이 다시 생긴다.

### ③ `CLAUDE.md` — 고치지 않은 것

「한글에 Lora · 영어에 산세리프」 금지는 **그대로 유효하다.** Hahmlet 은 Lora 가 아니라
한글을 위해 설계된 세리프이므로 이 규칙을 어기지 않는다. 「정답률 빨간 글씨 압박 금지」도
그대로이고, 이번 작업은 **토큰이 그 규칙을 허용하고 있던 구멍을 막은 것**이다.

## 5-9. 남은 것 (다음 작업 목록)

### A. 화면 단위 — 토큰·글꼴은 닿았지만 **배치는 아직 옛 카드 스택**
우선순위 순. 각 화면에서 할 일은 같다 — 카드 나열을 **괘선 + 섹션 번호 + 스케일 대비**로 바꾸기.

1. `/dashboard` — 카드 10장이 세로로 같은 무게로 쌓여 있다(실측 글자색 94% 단일 잉크). 가장 큰 잔여물
2. `/wordvault/browse` — 390px 전체 높이 **5,154px**. 밀도만 높고 위계가 없다 → 02-directions 의 **C(도구함) 표 문법**을 여기에 한정 적용
3. `/library` 계열 5화면 — 표지 자산이 없어 그리드가 비어 보인다
4. `/csat/*` 8화면
5. `/settings` · `/plan` · `/reports`
6. `(auth)` 4화면 — 로고만 바꿨고 폼 자체는 그대로
7. `/play/*` 19 아케이드 — **의도적으로 제외**(별도 축)

### B. 시스템 잔여
- `components/ui/*` 프리미티브 20개가 여전히 shadcn 형태다(그리고 거의 안 쓰인다).
  **지우거나 press 로 흡수**해야 한다 — 남겨 두면 다음 사람이 그걸 집는다
- 아이콘: lucide 220종 유지 중. 핵심 20개 커스텀은 미착수
- 다크 테마에서 주묵 판면을 눈으로 확인하지 못했다(캡처는 라이트만)
- `--memory-risk #9C3A30` 과 주묵 `#C0392B` 이 색상환에서 가깝다. 쓰임(표식 vs 망각도)과
  두께로 구분되지만, **한 화면에 둘 다 크게 나오는 배치**가 생기면 다시 봐야 한다

### C. 계측 잔여
- 폰트 전송량을 끝내 못 쟀다 — 측정 스크립트는 만들었으나(`scratchpad/fontcost.mjs`)
  dev 서버 재시작·로그인 한도와 겹쳐 완주하지 못했다. **`preload` 링크 0개 확인이 다음 1순위**
- axe 전수(`10-a11y-sweep`)를 새 팔레트로 다시 돌리지 않았다
