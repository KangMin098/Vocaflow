# 3B 팝업 패턴 조사 → 학습 지도 적용

> 참조 앱(`neon-currant.3b.dev`)은 인증 SPA 라 에이전트가 직접 열 수 없다. 사용자가 준 **팝업 캡처 7장**(Skill 설정 · Space 설정/접근 · Group 설정/접근 · Member 멤버십/접근 · 역할 상세 Space editor)에서
> 모든 팝업의 공통 구조와 부품을 정리했다. 크기(680×760 · 머리/바닥 56 · 카드 폭 646 · 간격 18)는 측정값([spec.json](./spec.json) `modal`),
> 부품 크기(배너 높이 · 검색창 높이 · 행 높이 · 칩 높이)는 캡처 눈대중이라 **추정**이다 — 캡처 PNG 가 파일로 오면 `ref-measure` 로 확정한다.

## 공통 골격

| 부분 | 패턴 | 우리 구현 |
|---|---|---|
| 모달 | 가운데 · 반경 16 · 흰 면 · 배경 회색 막(16%) · 안쪽 스크롤(얇은 스크롤바) | `popup.module.css` `.modal` / `.overlay` / `.body` |
| 머리 | 왼쪽 아이콘 타일(32, 노드 종류별 색) + 이름 · 가운데~오른쪽 알약 탭(아이콘 + 글자, 활성 = 옅은 회색 면) · 맨 오른쪽 아이콘 ✕ | `.head` `.tabs` `.close` |
| 바닥 | 오른쪽 정렬 · 검은 알약 「Done」 하나(보조 알약 「View …」가 왼쪽에 붙기도 함) | `.foot` `.pillBtn` |
| 시스템 항목 | 이름 옆 자물쇠 아이콘(편집 불가 표시) | 필요 시 `Lock` 칩 |

## 본문 부품 (팝업마다 조합)

| 부품 | 참조에서 본 곳 | 형태 | 우리 부품 |
|---|---|---|---|
| **배너 카드** | Group · Member 의 Access 탭 첫 카드 | 옅은 면 한 줄 · 제목 + 2줄 설명 · 오른쪽 흰 알약 버튼(「View on access map」) · 바탕에 옅은 노드 사각형과 점선 곡선 | `Banner` (+ `BannerArt`) |
| **카드** | 전부 | 옅은 면(#fbf9f7) · 1px 옅은 테두리 · 반경 12 · 안쪽 여백 크게 · 제목 12.5/500 + 설명 11 회색 | `Card` |
| **검색창** | Members · Access · Groups 카드 | 흰 면 · 반경 10 · 돋보기 아이콘 + 회색 placeholder · 높이 ≈48 | `SearchBox` |
| **목록 박스(표)** | Members · Access · Groups · Permissions | 흰 박스 · 줄로 나뉜 행 · (선택) 머리 줄(Name · Role) · 행 = 아이콘 타일/아바타 + 이름(13) + 보조(11 회색) + 오른쪽 칩들 | `ListBox` `ListRow` |
| **칩** | Role · Space editor · Skill user · # General | 둥근 알약 · 옅은 회색 · 11px · 앞 아이콘 · (선택) 뒤 ▾ | `Chip` (톤: 중립 · good · warn · bad · ink) |
| **키-값 행** | Member 카드(Profile picture · Name · Email) | 흰 박스 · 왼쪽 라벨 · 오른쪽 값(읽기 전용 회색 상자) | `ListRow` 의 right 칩 |
| **토글 행** | Group Tenant roles · Space Discoverability | 라벨 + 설명 · 오른쪽 스위치 | (지도에는 해당 없음 — 목표 설정 줄이 대신) |
| **위험 카드** | Delete group / Delete skill | 옅은 면 · 오른쪽 분홍 알약 버튼 | (해당 없음) |
| **추가 행** | API keys | 제목 + 설명 · 오른쪽 `+` | (해당 없음) |
| **하위 라벨 + 행** | 역할 상세 「Assigned to」 | 카드 안 소제목 + 목록 박스 | 카드 안 소제목(출처 · 연결선) |

## 탭별 구성 (지도 노드 팝업)

| 탭 | 구성(위 → 아래) |
|---|---|
| 목표 | 배너(**경로 보기** — 팝업을 닫고 지도에서 경로 강조) → 목표율 카드(큰 숫자 + 칩) → (목표 < 100) 경고 → 기준 시험 목록 박스(타일 + 「반드시 N문항 · 점」 + 칩) → 반드시 맞혀야 하는 문항(검색창 + 목록 박스: 번호 타일 · 시험 · 배점/오답률 칩) |
| 달성 | 현재 성취율(큰 숫자 + 상태 칩 + 큰 막대 + 눈금) → 근거 데이터 목록(관측 · 기록 전체 · 진단 범위) → 추세(준비 중 칩) → 과제 완료(진행 막대) |
| 현 상태 | 목표와의 차이(큰 %p + 칩 · 습관 신호 칩) → 과제 목록 박스(체크 + 타일 + 제목/방법/완료 기준 + 주기 · 기출/본질 칩) 또는 먼저 볼 라인 목록 |
| 근거 | 분류 이유 카드 → 출처와 연결선 카드(검색창 → 출처 목록(타일 + 서지 + 확인됨/검토 필요 칩) → 연결선 목록(근거 유형 칩)) |

## 그래프(지도) 쪽 패턴 — 같은 참조의 Access map 화면

| 패턴 | 우리 구현 |
|---|---|
| 판 안의 판 · 머리 줄(열 이름) + 구분선 · 노드 줄 | `.panel` `.heads` `.cols` (viewport 높이의 스크롤 패널, 머리 줄 고정) |
| 노드 = 아이콘 타일 + 이름 + 보조 줄 · 선택하면 검은 1px 테두리 | `.node` `.nodeSel` |
| 이어진 경로만 **검은 실선**으로 강조(직접 = 실선 · 상속 = 파선 · 가능 = 점선) | `.edgeOn` (+ 근거 유형별 선 모양) |
| 하단 왼쪽 떠 있는 요약 알약(선택 이름 + 개수 + ⋮) | `.dock` 왼쪽 — 이름 · 영역/라인/원리/트랙 수 · 자세히 · 해제 |
| 하단 오른쪽 범례 알약(Collapse · Direct · Inherited · Available) | `.dock` 오른쪽 — 접기 · 직접 근거 · 추론 · 보류 |
| Collapse = 선택한 경로만 보기 | 접기(`colsCollapsed`) — 경로 밖 노드를 숨기고 다시 배치 |
