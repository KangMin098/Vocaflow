## 골격 · 서명

- **골격(G1)**: 채색 지문 — 입력칸이 곧 결과. 원문(Lora) 위에서 고른 학년이 처음 만나는 낱말이 주묵 옅은 면(`--ju-wash`) + 1px 주묵 밑줄로 칠해진다.
- **서명**: 학년 슬라이더(8단, 눈금 = 학년별 커버리지 %) 이동 → 낱말 면 색이 200ms(`--dur-normal`) 에 바뀐다. 랜딩 히어로와 같은 몸짓.
- **출력 면(B)**: 시험지 사물 — 2단 판면, 처음 만나는 낱말에 권점(CSS `text-emphasis: open circle`), 난외 번호 풀이, 머리에 적정 학년 도장. 별도 화면이 아니라 버튼 뒤에 펼쳐지고 인쇄 첫 장이 된다.
- 버린 안: C 「일주일 뒤의 이 글」(망각) — **보류**(로그인 후 개인 기록 기반으로 재검토) · D 「지문 지도」(주묵 문법) — A 확정 후 추가 여부 재검토. [DECISIONS](../DECISIONS.md) DD-19.
