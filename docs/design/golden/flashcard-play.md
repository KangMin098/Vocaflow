## 골격 · 서명

- **골격(G1)**: 망각 — 카드 바로 아래 **이 단어의 기억선**. 왼쪽 35% = 지난 복습 → 오늘의 R(t), 오른쪽 = 앞으로(제곱근 축). 0.95 · 0.70 문턱은 판면 괘선처럼 옅게.
- **서명**: 평가에 손을 얹으면(hover·focus, 터치 기본 = 「기억나요」) 그 평가의 **다음 곡선과 다음 만남 눈금**이 선다 — 모션 없이 즉시(학습 화면 7종 밖 모션을 만들지 않았다). Anki 의 네 버튼은 날짜만 말한다.
- **약속을 맞췄다**: 버튼이 보이던 날짜는 **SM-2 간격**이었고 실제 스케줄은 FSRS 였다 — 이제 버튼 = `applyReview` 미리보기. 3일 이상은 「약」(스케줄러 흔들림 `enable_fuzz` 때문에 누른 순간 하루쯤 다를 수 있다).
- **완료**: 허브 골든과 같은 곡선(점선 = 오늘 안 봤다면 · 실선 = 오늘 본 뒤 · 옅은 면) + 「오늘 잘 마쳤어요 …」. 기대값이 1 미만이면 "약 0개" 대신 곡선이 말하는 사실(며칠 안에 한 번 더).
- 버린 안: B 「원문 한 줄의 빈칸」(조인 필요 · 12% 폴백) · C 「오늘의 한 장」(N4 약함) · D 「흐려짐 지층」(자산 없이 흉내 가능).

## 남은 것

- 런타임 계정의 흐려진 낱말은 안정도가 거의 0(2026-09-05 이전 스케줄러 결함 흔적)이라 지난 선·다음 곡선이 계단처럼 떨어진다 — 데이터 그대로다. 새 계정·새 낱말은 매끈한 곡선(골든 rating 면).
- 페이지에 h1 이 둘(셸 `ResourceContext` 「플래시카드」 + 완료 문장) — 이전부터. 셸 범위.
- 완료 화면의 추천 카드(`NextActionCard`)는 공용이라 그라디언트가 남았다 — 공용 교체 후보.
- 새 관측 없음 — 세션 완료는 `scores` 행으로 파생된다(D4).
