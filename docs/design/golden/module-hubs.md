- **골격(G1)**: 망각 — 카드가 나오는 순서의 **낱말 줄**(`QueueLine`), 밑줄 = 기억 상태(`DecayUnderline` — 색 + 굵기 + 범례 3중).
- **서명**: 세션 길이를 고르면 앞 N개에 권점이 옮겨 찍힌다(200ms 색만) — `/hub` 골든과 같은 몸짓. 세션 밖 낱말은 흐리게.
- 공용 머리(ModuleHero) = 판면 머리(두꺼운 괘선 · 26/32px 제목) · 1차 행동 = 주묵 하나 · 선택지 = 글자 탭.
- 걷은 것: 4열 숫자 타일 · 전폭 회색 막대 · 시작 카드 상자·그림자 세그먼트·떠오르는 CTA · 모듈별 CTA 색 · 한글 이탤릭 2 · 기록 0 인 「최근 기록」 의 첫 화면 자리.
