## 골격 · 서명

- **골격(G1)**: 채색 지문 — `/signup` 골든 6호와 같은 두 단(`AuthSpread` → `SignupProof` → `PaintedPassage`). 화면마다 왼쪽 첫 문장만 다르다(로그인 · 「다시 들어오면, 이 글은 내 수준으로 칠해져 있어요」 · 「메일의 링크를 누르면 진단부터」).
- **서명**: 학년을 옮기면 칠이 바뀐다(200ms) — 랜딩·`/fit`·`/signup` 과 같은 몸짓.
- **고친 결함**: 주소를 모를 때 활성처럼 보이던 잠긴 재발송 버튼(→ 버튼을 두지 않고 이유 + 다시 가입) · 44px 미만 하단 링크(재설정 화면 3개) · 아무것도 말하지 않는 안심 문구 · 세 화면에 탭 제목(메타데이터)이 없던 것(클라이언트 페이지라 못 냈다 → 서버 페이지로 나눔).
- 걷은 것: 그림자 카드 5벌 · 아이콘 타일/원 3개 · 가운데 정렬 제목 · 두 줄 H1 · 번호 원 · 정보색 상자.

## 수정 이력 (0회)

첫 캡처에서 가장 나쁜 것이 없었다 — 세 화면 모두 칠해진 지문이 첫 화면 안(390 은 두 줄), 1차 버튼이 첫 화면 안, axe 0, 넘침 0.

## 남은 것

- 재설정의 **새 비밀번호** 상태(메일 링크로 진입)는 복구 세션이 있어야 보여 캡처하지 않았다 — 같은 모양 규칙(`AUTH_H1` · `AUTH_PRIMARY`)으로 바꿨다.
- `SignupProof` 가 `signup/` 폴더에 있는데 인증 4화면이 같이 쓴다 — `(auth)/` 바로 아래로 옮기면 이름과 자리가 맞는다(동작 변경 없음).
