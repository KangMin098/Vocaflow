**장부 상태(읽은 챕터가 있는 학습자)는 캡처하지 않았다** — 두 검증 계정 모두 읽은 챕터가 0 이다. 그 상태는 렌더 계약 테스트(`queue-ledger.test.tsx`)와 코드로 고정했다: 다음 한 걸음(읽고 오래된 챕터 · 주묵 「확인 시작」) · 책 괘선 행 · 펼치면 챕터 번호 링크, 확인 안 한 번호에 권점 · 확인함은 체크 + 글자.

## 골격 · 서명

- **골격(G1)**: 망각 — 읽고 시간이 지난 챕터부터 확인하는 괘선 장부(사이를 둔 인출).
- **서명**: 확인 안 한 챕터 번호에 권점 — 이번에 확인할 것(허브·모듈 허브·게임 허브와 같은 표식).
- 빈 상태가 주인공이 되지 않게: 퀴즈가 준비된 책의 **실제 목록**(카탈로그 — 지어낸 예시 아님).
- 걷은 것: 반짝이 아이콘 점선 상자 · 그림자 카드 · 책마다 테두리 카드 + 앰버 아이콘 칩 · 챕터 테두리 칩 · 앰버 CTA(hover scale) · 번역 토글 카드.
