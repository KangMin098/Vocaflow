## 골격 · 서명

- **골격(G1)**: 망각 — 첫 시선이 **7일 기억 곡선**. 세로 = 곡선 아래 낱말들 중 기억에 남을 단어 수의 기대값 Σ R(t), 점선 = 그대로 두면, 실선 = 오늘 N개를 다시 보면, 사이의 옅은 면(`--memory-stable`, fill-opacity .16) = 오늘 한 일이 일주일 뒤에 남기는 것.
- **서명**: 「오늘 다시 볼 단어」 슬라이더 → 실선·면이 새로 서고(페이드 200ms) 낱말의 권점(`text-emphasis` open circle, `--ju`)이 앞 N개로 옮겨 찍힌다(색 200ms). `/fit` 골든의 「슬라이더 → 낱말 표면 200ms」 와 같은 몸짓.
- **재료**: 낱말(Lora) + 지금 상태의 밑줄 두께 3/2/1px · dotted(new) — 씨앗 S2 `DecayUnderline`. h1 = 계산된 한 문장(Hahmlet, 「약 N개」 — 기대값이라 반올림).
- **약속**: 곡선 아래 낱말 순서 = `/flashcard/play` 세션 큐 순서(같은 함수 `fetchStudyVocabularies`). 「이 N개 …」 는 `?limit=N` — 보여 준 N개가 곧 만날 N개다.
- 버린 안: B 「내 기억으로 칠한 오늘의 글」(채색 지문 — 미진단 학습자에게 골격이 없다) · C 「차오르는 서가」(실제 계정이 전부 risk 라 서가가 빈다) · D 「오늘의 한 장」(N4 약함).
