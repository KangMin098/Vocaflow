## 판정 규칙

- **(a) 익명성**: 로고를 가리고 (1) 앱 종류 (2) **이 제품인지** — (2)는 제품 고유 형태(채색 지문 · 3/2/1px 밑줄 · R(t) 곡선 · 주묵 관계선 · 레벨별 커버리지 지형 등)가 첫 뷰포트에 보일 때만 통과. 글꼴·색만으로는 불통과.
- **(b) 평균 회귀**: 보이는 것을 위치와 함께.
- **N4**: 첫 뷰포트 골격이 G1 축인가(자산 없이 못 그리는가), 카드·표·격자·폼인가.
- **등급**: 평균 = N4 불통과 ∧ (a) 불통과 · 서명 있음 = N4 통과 ∧ (a) 통과 · 경계 = 그 밖.
- 렌더 신호 = 첫 뷰포트 DOM 계수(3열 균등 격자 / 선 아닌 그림자 / radius≥12 / 그라디언트 / 카드형 블록 / 120×60 이상 svg·canvas). **1280 의 gradient 약 6 은 데스크톱 사이드바 몫**(390 에서 0) — 화면 결함으로 세지 않았다. 정적 = 그 화면 import 트리의 평균 신호 8종 합(평균 신호 라쳇 정규식). 씨앗 S2 표시는 `components/ui/press` import 만으로도 잡히는 **과대 계상**(도구 한계).
