## 권고 (에이전트)

**A 「원고지」** — 이유 셋:
1. **무대가 내용이 된다.** 상한 ②로 들여온 모눈이 Tines 에서는 배경이지만 A 에서는 원고지 칸이다 — 같은 L2 를 가장 많이 쓰면서 가장 덜 닮는다.
2. **제품 서명과 같은 몸짓.** 랜딩 · `/fit`(골든 1호)의 「칠해지는 지문」을 삽화가 되풀이한다 — 서명 옆자리에서 서명을 강화한다(DD-25 조건 1).
3. 측정상 유일하게 (a) 두 판정이 모두 ○ 이면서 (b) 0 인 안이 A · C 인데, C 의 교정 획은 `/csat` 한 도메인의 문법이라 단어장·서가 빈 상태까지 넓히면 뜻이 억지가 된다(E 의 「첫 낱말」 쪽지).

버릴 것 · 가져올 것: C 의 **Hahmlet 난외 뜻**(한국어가 삽화 안에 들어가는 자리)은 A 에도 옮길 수 있다 — 고른 뒤 2회 수정 때 검토. B·D 는 (a) △ 라 권하지 않는다.
