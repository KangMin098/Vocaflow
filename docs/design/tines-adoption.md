## 동작과 검증

카탈로그는 WebGL 없이 서버에서도 실제 표지·제목·상세 버튼을 제공한다. ←/→·Home/End 및 실제 2열/4열 위치에 따른 ↑/↓ 이동을 지원한다. 상세 표본 조회·추가/해지·분류 기능을 유지한다. DB·URL·학습 기록·FSRS·점수 계약은 변경하지 않았다.

`93-tines-adoption.spec.ts`는 PC 1440/1280px × 라이트/다크에서 단어장 키보드/상세/카테고리, 받아쓸 자료 탭, Letter Forge 진입/일시정지/재개와 버튼 대비·가로 넘침·이미지 실패를 확인한다. 상세를 열고 닫으며 구독이나 학습 완료 저장은 실행하지 않는다. 학습 화면 4건은 운영 빌드, 관리자 4건은 기존 개발 검증 환경에서 통과했다. 검증 계정의 운영 관리자 권한이 없어 환경을 구분했으며 권한은 변경하지 않았다. 기존 `92-reference-design`의 1440px 라이트/다크와 두 디자인·팝업 검사 2건도 통과했다. SSR·행 이동·관리자 메뉴/색·두 스킨·일시정지 기존 회귀는 6파일 50검사 통과. 운영 빌드는 263개 페이지 생성과 타입 검사를 통과했고 기존 lint 경고 11건이 남았다.

실제 PC 캡처를 열어 비평하고 소품 경로 오류, 중복 허브 배너, 다크 세션 출처색을 수정했다. PC 캡처는 `tmp/tines-adoption/flows/` 및 `after-1440-light/`에 있다(이미지/중간 계측은 gitignore). 범위 정정 전 모바일 캡처는 완료 근거로 세지 않는다.

상단 바 추가 후 기존 사전 상세 패널/섹션 내비의 `sticky top-0`가 가려지는 문제는 PC 공통 헤더 높이 변수로 교정한다. 상세 패널의 최대 높이와 섹션 앵커 여백도 조정하며 내부 스크롤 표의 `thead`는 그대로 둔다. 관리자 검사에는 실제 단어 선택 → 스크롤 → 패널 위치/최대 높이 → 닫기 회귀를 포함한다.

학습 화면 검사에는 Word Orrery의 진입과 조작 안내/점수 대비 회귀도 포함한다. 그라데이션 선언값 대신 실제 캡처의 글자 옆 배경 픽셀과 렌더 전경색의 대비를 검사한다. HUD 점수/콤보에는 불투명 테마 통계 면을 제공해 게임 캔버스의 독립 팔레트에 글자 대비를 의존하지 않는다. 관측·정답·결과 저장은 실행하지 않는다.

운영 관리자 검사를 실행할 때는 관리자 전용 storageState 파일의 경로를 `PLAYWRIGHT_ADMIN_STORAGE_STATE`로 전달한다. 미제공 상태에서 관리자 접근이 막히면 4건은 명시적으로 skip하며 통과로 세지 않는다. 전용 관리자 세션을 제공한 경우 리다이렉트/화면 오류를 skip으로 숨기지 않는다. 이 세션 없이 운영 관리자 검증을 완료했다고 주장하지 않는다.

## 아직 완료로 세지 않는 범위

- 전 라우트 스캔의 `rendered`는 로딩/오류/로그인 이동과 구별하기 위한 상태다. Tines 디자인 심사 통과를 뜻하지 않는다. 전체 170개 기능·중간/결과·취소·오류·모든 팝업 검증 완료로 세지 않는다.
- PairFlip의 개별 카드/설정/결과와 Pirate Quest의 독립 HUD, Word Orrery 등 게임별 고정 전경/배경은 후속 개별 변환 대상이다. Word Orrery의 밝은 전경을 유지한 채 공통 배경만 밝히면 대비가 무너지므로 이번 변경의 배경 교체를 철회하고 기존 배경 계약을 유지했다. 공통 결과/일시정지 부품 변경을 게임 전체의 변환으로 세지 않는다. 게임별 전경·배경·반투명 패널은 함께 측정/변환/검증해야 한다.
- 동적 경로의 실제 ID 미확보·접근 실패·빈 본문·로딩은 정상 화면으로 세지 않는다. 3B 신규 인증 상태의 모든 하위 화면도 이번 Tines 변환에서 확보했다고 쓰지 않는다.
- 개발 서버의 전 화면 동시 컴파일에서 발생한 모듈 로딩 실패는 검증 통과로 처리하지 않는다. 빌드와 기존 CSAT 검사는 위와 같이 별도 통과했다.

재실행: `node scripts/design/tines-adoption-audit.mjs --phase <회차> [--width 1280|1440] [--dark]`는 서버 방문 없이 소스 목록만 저장한다. 확인한 허브 캡처는 `--base <로컬URL> --only /admin/analytics,/library/vocab`처럼 명시한다. 미검토 경로는 거부한다. 검증 계정 storageState는 기존 `92-reference-design`이 생성하며 비밀값을 출력하지 않는다. 기존 전량 렌더 실험은 DB 읽기 전용 검증 근거로 삼지 않는다(`/text/[id]` 등은 GET 렌더에도 학습 기록을 쓴다). 전량 렌더를 재개하려면 서버·브라우저 DB 경계의 쓰기 차단과 로그 검증이 먼저 필요하다. 재실행은 해당 회차 결과 파일을 덮는다.
