## 목적과 완료 기준

목적: 학습자가 공개 메인부터 학습 세션까지 **같은 Tines 계열의 한 제품**으로 느끼게 한다(색 교체가 아니라 골격·위계·부품·팝업·삽화·동작).
단계 완료 기준(모든 단계 공통):
1. 변경 화면마다 감사 표의 **R·I·V 칸을 날짜·커밋 SHA·캡처 경로·대조표로 채운다** — 캡처 없는 「완료」 금지, 로그인/오류/로딩 캡처는 증거 아님.
2. `pnpm turbo run lint typecheck test` 통과, 기존 학습 e2e(스모크) 통과.
3. 학습 기능 회귀 0: 채점·FSRS 기록·기억 4색 계산(동적 R(t))·권한 경로는 diff 대상 밖이거나 테스트로 고정.
4. 접근성: 44px · 보이는 focus · 색만으로 정보 금지 · `break-keep` · reduced-motion 낮추기.

## S3 실행 규칙 (사용자 지시 2026-10-18 반영)

1. **수정 전 측정** — 화면마다 현재 화면과 대응 Tines 화면을 **같은 PC 뷰포트(1440·1280)**로 캡처하고 구조(골격·열·레일 유무·순서)와 치수(폭·높이·간격·모서리·서체)를 잰다. 레일·세션 구성을 미리 정하지 않는다 — **현재 기능 ↔ 참조 근거를 대조해 채택/기각 이유를 남긴다.**
2. **팝오버 6종도 시각 검증 대상** — S2 의 12px·라벤더 테두리는 **우리 구현값**이다. 참조 측정 전에는 Tines 규격이라 쓰지 않는다. 역할이 다른 팝오버(목록형 메뉴 · 내용형 카드 · 설정 패널)에 같은 규격이 맞는지 따로 판정한다.
3. **순서 유지: 서가 → 단어장 → 학습 세션 → 읽기.** 화면 하나마다 **본문 · 열린 팝업 · 핵심 동작**까지 검증한 뒤 다음으로 넘어간다.
   - 단어장 머리 정리 시 **제목 · 자료 정보 · 학습 조작** 세 역할을 보존한다(줄이는 것은 중복이지 역할이 아니다).
   - 세션은 **종료 · 복귀 · 설정** 같은 공통 조작을 일관되게, 모듈별 학습 방식(카드 뒤집기 · 철자 입력 · 듣기 등)은 유지한다.
4. **범위 밖 차이는 원인별로** — 위치(영역)와 원인을 확인한 것만 「무관」으로, 확인 못 한 것은 **미확인**으로 적는다.
5. **결과 표(화면·부품마다)**: 대상 URL·상태 / 참조 URL·상태 / 측정 항목 / 참조값 / 적용값 / 차이·의도 / 전후 캡처 / 남은 문제.
6. **분모 유지** — 상호작용 시나리오 수와 확인된 고유 화면 수를 따로 적는다. 기능 테스트·상호작용 통과는 시각 대조(V) 완료로 세지 않는다.
