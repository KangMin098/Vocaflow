# 학습자 `/hub` — Tines 정밀 적용

2026-10-03 사용자 요청: 메인과 여러 하위 화면을 정확히 분석해 `/hub`의 색감·구성·디자인 요소를 더 동일한 스타일로 적용. PC 웹만 대상이며 모바일 제외, 관리자/CSAT의 3B 앱 기준은 유지한다.

## 직접 확인한 근거

기존 인증 정상 `/hub`를 1440×900으로 캡처했다. Tines [홈](https://www.tines.com/)·[3B 제품 웹사이트](https://www.tines.com/3b/)·[University](https://www.tines.com/university/)도 같은 뷰포트로 다시 렌더하고 계산 스타일/구획을 추출했다. 3B 제품 웹사이트는 관리자/CSAT 참조인 3B 인증 앱과 구별한다.

- 참조 캡처: `tmp/hub-tines/{home,product,university}-1440.png`, `home-section.png`, `product-section.png`.
- 계산값: `tmp/hub-tines/{home,product,details}.json`. University의 본문은 다른 DOM 구조이므로 `details.json`에서 제목/프레임을 직접 확인했다.
- 변경 전: `tmp/hub-tines/before-1440.png`, `before-full.png`, `before.json`.
- 구현 후: `tmp/hub-tines/after-1440.png`, `after-full.png`, `hub-{garden,product-frame,platforms,solution,reading,why}.png`.
- PC 4조건: `tmp/hub-tines/qa/*-{1440,1280}-{false,true}.png`(`false` 라이트·`true` 다크).

원본 앱의 사업 기능·로고·고객 추천 문구를 제품에 옮기지 않는다. 이미지/서체는 기존 자체 그림과 무료 대체 서체를 사용한다.

## 관찰과 대응

| 참조 실물 | 이전 허브의 차이 | PC 적용 |
|---|---|---|
| 홈 본문 x=40, 큰 제목 64px/67.2px, 다색 꽃 삽화 띠 | x=80, 우측이 비어 있는 작은 표현 범위, 다색 띠 없음 | x=40과 제목 행 높이 보정, 자체 책/단어 정원 띠, 실측 고전 제목 줄을 유지 |
| 홈의 실제 제품 액자·5색 팀 탭 | 제품 액자와 탭은 이미 있었음 | 실제 오늘/기억/예보/새 도서 액자 보존, 화면 폭 확장, 탭 곁의 큰 자체 삽화 추가 |
| `/3b/`의 라벤더 지면 위 흰 벤토, 48px/30px/24px, 14px 카드 | 서가 규모·학습 원리 전체가 한 보라색 면 | 라벤더 구획 위 흰 벤토, 네 학습 원리를 라벤더·초록·복숭아·청록 면/잉크 짝과 삽화로 구별 |
| University 24px 선 격자와 큰 세리프 제목 | 읽을거리와 시리즈가 기본 지면 위에만 있음 | 복숭아 선 격자 구획 + 흰 읽기 액자 + 기존 다색 주제 목록. 실제 제목/수치/읽기 오류 상태 유지 |
| 홈 USP의 제목 곁 큰 삽화, 4개 보라 카드, 세리프 24px/28.8px | 제목 곁 그림 없음, 카드 본문 25px | 큰 기억 소품 및 24px/28.8px 보정. 기존 진단/단어/듣기/학급 이동 유지 |

정원 높이 460px·삽화 300px·읽을거리 패딩/색 조합은 학습 콘텐츠에 맞춘 대응이다. 전체 원본 픽셀 일치나 동일 세로 길이를 주장하지 않는다. 원본 상용 서체 대신 기존 Figtree/Petrona/Pretendard/Hahmlet을 사용하며 다크는 기존 Tines 토큰의 대응 면/잉크다.

## 기능 보존과 검증

`ProductFrame`·오늘의 흐름·기억 4색·발행 게이트·통계 조회·모델·학습 링크는 유지한다. 기존 `PromoLink`/`PortalArticles`와 셸의 이벤트를 재사용하며 새로운 기록/DB 쓰기·라우트·인증 동작을 추가하지 않았다. PC 스타일은 `min-width:768px`의 `.tines-hub` 아래에만 있고, 추가 그림도 모바일에서는 숨긴다.

- 관련 단위 회귀 14/14: 제품 액자의 흐름/실측 모델·라우트 스킨 경계·CSS 선택자.
- 기존 허브 동작 3/3: 도서가 실제 발행 행인지 DB 대조, 액자와 셸의 진행 동일, 제목 흐름 멈춤.
- 새 PC 검사 4/4: 1280/1440 × light/dark에서 정상 화면, 다색 면 렌더/삽화 디코딩, 본문 대비 4.5 이상·큰 제목 3 이상, 5개 탭/방향키, 1차 CTA 키보드 포커스·실제 이동, 가로 넘침. 최종 프로덕션 빌드에서도 같은 4/4 통과. 프로그램 포커스를 키보드 포커스로 간주하던 초기 테스트 문제는 실제 Tab 입력 후 표시를 검사하도록 바로잡았다.
- 최종 프로덕션 빌드 종료 코드 0. 프로덕션 서버의 참조 대조 15/15, 에이전트 설정 11/11. 사용자 `localhost:3000/hub` 정상 렌더에서도 64px 제목·가로 넘침 0·깨진 표시 이미지 0을 확인하고 `tmp/hub-tines/live-3000-1440.png`를 확보했다. 사용자 서버는 재시작하지 않았다.

직접 캡처를 연 비평에서 가장 나쁜 문제는 벤토의 타일 묶음이 줄바꿈되고 늦게 읽힌 그림이 빈 면처럼 보이는 것이었다. PC 타일 크기를 줄여 한 줄로 보정하고, 이미지 디코딩 뒤 캡처했다. 허브 전용 골든과 자기 포트폴리오 비교 기준은 없다. 개별 학습 세션의 모든 완료/저장/실패 상태, 모바일 디자인, 타 플랫폼 화면 전량은 이번 적용 검증 범위가 아니다.
