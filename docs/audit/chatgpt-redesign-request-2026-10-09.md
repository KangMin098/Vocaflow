## Goal Context Packet

### P1. 원래 목표(정본 · 사용자 승인)

`docs/csat-learner/LEARNING_MAP_VNEXT.md` rev2.1(2026-10-04 사용자 승인), 이후 2026-10-07 학습자 화면 · 2026-10-08 목표 중심 · 2026-10-09 E11 순환이 덧붙었다.

- **영역(학생이 보는 축):** V 어휘·표현 의미 / S 문장 이해 / R 글 이해 / E 근거·선지 판단 / L 듣기 / X 실전
- **학습 순서:** LP1 Lexical Access → LP2 Sentence Meaning → LP3 Local Coherence → LP4 Discourse Structure → LP5 Central Meaning → LP6 Evidence Judgment → LP7 Timed Integration. LP 는 축을 가로지르는 겹층이고, mastery 노드도 점수도 아니다. 평가원 ORM 2024-79-3 의 성취 위계를 참고한 **자체 처리 모델**이다 — 정본은 두 순서가 다르며 LP 를 공식 위계라고 쓰지 말라고 명시한다(VNEXT :183).
- **학생 화면:** 읽기 길 7단계(어휘·표현 → 문장 이해 → 문장 관계 → 글 구조·핵심 → 본문↔선지 → 근거 판단 → 시간 내 통합) + 듣기 보조 4단계(소리 인식 → 문장 이해 → 정보 유지 → 응답 판단)
- **학년별 권장 노출(잠금 아님):** 초등 고학년 V+S · LP1–2 / 중등 S+R · LP2–4 / 고등 R+E+X · LP3–7. 실제 경로는 진단 근거로 정한다.
- **진단:** 관찰 → 진단 필요 → 직접 확인 → 처방. 처방은 verified_diagnosis 일 때만 낸다.
- **과제 생애주기:** FIND(확인하기) → REPAIR(고치기) → TRANSFER(옮기기) → CHECK(확인)
- **표시 원칙:** 데이터가 없으면 수치를 보이지 않는다. 숙달률 · 퍼센트 · 「취약」은 금지다.
- **목표 중심 화면:** 목표 → 현재 위치 → 필요한 능력 → 지금 할 일 → 변화 확인. 목표 달성률 · 점수 약속은 금지다.
- **승인된 보류:** 하위 능력 DB · mastery, 듣기 세부 정의(v0.2-listening)

(요청자 표기 「여섯 층위: 어휘 · 문장 구조 · 문장 의미 · 문장 간 관계 · 글 구조 · 선지 판단」은 정본에 그대로 있지 않다. LP1–6 과 가장 가깝다. 정본은 「문장 구조」와 「문장 의미」를 LP2 하나로 본다.)

### P2. 실제 구현(main ecbe02bf4 · 코드 근거)

- 읽기 길 11단계가 정의돼 있다. Phase 1 설계대로 단계 상태를 축에서 빌린다. 그래서 relation↔structure(R) · option↔evidence(E) 는 관찰값이 같고, 과제 묶음만 다르다(승인된 단계적 설계 · Phase 2 에서 가를지가 질문). 「문장 의미」는 정본상 S(LP2)의 일부다.
- 진단은 전부 rule_proxy(문항 유형 → 역량 기본값 상속)다. verified 를 만드는 경로가 없다 → 생애주기는 FIND 만 열린다.
- 문항에 연결된 FIND 는 2곳뿐이다.
  - B6-3 글 구조: claim-support. 실행 가능한 확인 문항 9개(모두 20번 유형) · 노출 중 · 학생용 Practice 는 20번 주석 문항뿐(주제 · 제목 전이는 관리자 미리보기만) · 복습 예약
  - A3-4 문장 관계: cohesion-link. 1문항 · 빌드됨 · 노출 승인 대기
- 기록: G2 서버 계약(세션 · 시도 · 요청 원장 · 첫 시도 뷰 · 시각 불확실 보류 · 합성 분리 · 추가 전용)이 적용됐고 실제 DB smoke 를 통과했다.
- 결과 환류: 확인 · Practice · 복습이 지도 결과 줄에 반영된다. **진단 · 단계 상태에는 반영되지 않는다.** 재평가는 새 기출 기록 링크다.
- 학년: 고교 수능 전용이다. 등급은 절대평가 10점 구간이고, 목표 계산은 평가원 시험만 쓴다. 학습자 학년은 저장되지 않는다. 초등 · 중등 자료가 없다.
- 듣기: NO_DATA 고정, out_of_scope.
