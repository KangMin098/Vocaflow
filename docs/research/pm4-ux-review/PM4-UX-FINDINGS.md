## PM4-P2-01 — 1280 기본 지도에서 영역명 잘림

- 재현: /csat/diagnosis?tab=map, 1280 기본 보기, R5 선택. 목표 없음에서도 보인다.
- 증거: [ready 1280](../../csat-learner/v62/evidence/pm4-learner-20261015/13-B-ready-1280.png), [목표 없음 1280](../../csat-learner/v62/evidence/pm4-learner-20261015/01-A-no-goal-1280.png). Claude 캡처를 Codex가 직접 열람했다.
- 기대: 상위 영역의 의미를 코드를 외우지 않고 읽을 수 있어야 한다.
- 실제: V 어휘…·S 문장…·E 근…선…·L 듣…처럼 상위 탐색 이름이 잘린다. Inspector 폭 360을 제외한 관계도에 6열을 유지한다. colName은 nowrap/ellipsis이고 영역 버튼 title은 전체 이름 대신 질문이다.
- 영향: 새 학습자가 영역 이름을 읽기 위해 추가 클릭/hover/탐색이 필요하다. 경로 단절·오답 유도·가로 넘침을 주장하지 않는다.
- 최소 수정: 기존 colHead/colName 토큰을 재사용해 두 줄 제목 또는 읽을 수 있는 압축 명칭을 확보한다. 이름을 먼저 보장하고 코드/개수/보류를 배치한다. 전역 글자를 축소하지 않는다. 1280에서 전체 이름·선택·보류를 동시에 캡처한다.

## PM4-P2-02 — 과거 보기의 편집 가능 범위 미표시

- 재현: /csat/diagnosis?tab=map&asof=<기준일>.
- 증거: [기존 과거 화면](../../csat-learner/v62/evidence/pm4-learner-20261015/11-F-past-1440.png), acceptance.test.tsx의 historical header probe. 합성 기록 09-13/입력 09-14를 실제 asIsMap 기준 09-01로 제외시킨 유효 입력이다.
- 기대: 보기 전용 범위와 지금 시점의 변경 행동을 구별해야 한다.
- 실제: 지도에는 보기 전용 설명과 학습 링크 차단이 있지만 상단 목표 바꾸기/기출 기록하기는 그대로 활성 표시다. GoalRecordBar는 past를 받지 않는다. GoalBar useGoal.apply에는 현재 목표 PUT 경로가 있으며 과거 여부 검사는 없다. 실제 서버 쓰기를 실행한 증거는 아니다.
- 영향: 어느 영역이 읽기 전용이고 어느 시점의 목표를 편집하는지 불명확하다. 기존 테스트는 상단 버튼 범위까지 확인하지 않았다. 데이터 손상·권한 우회를 주장하지 않으므로 P1으로 올리지 않는다.
- 최소 수정: past를 상단에도 전달해 편집을 막고 현재 기준으로 돌아가 변경하게 하거나, 현재 설정 영역임을 명시적으로 분리한다. 허용 범위를 명문화하고 목표/기록/PLAN/학습 시작을 함께 검증한다.
