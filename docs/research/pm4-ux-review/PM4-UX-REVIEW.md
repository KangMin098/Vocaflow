## 직접 확인한 증거

PNG 20장을 모두 직접 열어 시각 검토했다. 지도 13장은 1440×900/1280×900이고 R5 7장은 폭 360의 Inspector 크롭이다. 후자는 390 반응형 검증이 아니다. 기존 learner 결과는 12 PASS/1 SKIP, R5는 6 PASS이며 새 독립 실행과 합치지 않는다.

독립 Vitest는 **122/122 PASS**: 새 합성 반례·SSR 6건과 기존 회귀 116건. 실제 공급·rank·계획·자격 함수를 사용했다. SSR은 네트워크 부속을 일부 대체했으므로 레이아웃·포커스·저장 성공을 증명하지 않는다. [회귀 보고](PM4-UX-REGRESSION.md), [수용 원장](data/acceptance-ledger.json)을 함께 읽는다.

브라우저 도구의 enabled surfaces는 apps/browsers 모두 빈 목록이었다. iab 생성은 “Browser is not available: iab”로 실패했다. 독립 실제 캡처는 0장이다. 이를 우회하는 브라우저 조작이나 실제 계정 쓰기를 하지 않았다.

## 학습 정보 판정

목표 미설정은 미설정으로 표시한다. 원점수는 최근 실제 기록 하나이며 다른 시험의 평균·합산 점수가 아니다. 전체/진단 활용/기준일 뒤 제외를 나누고 근거 부족·보류를 약점으로 확정하지 않는다.

FocusStrip은 ActionRank 상위 세 개, 지도 우선 표시도 같은 ActionRank, Inspector는 선택 TASK의 DTO를 사용한다. 카드 제목 선택과 학습 링크는 별도다. 두 번째 TASK 선택 후 첫 추천의 검은 CTA가 남는 것 자체를 데이터 불일치로 판정하지 않았다.

PLAN 수행량과 성취 조건은 분리된다. 확인→바로잡기→다른 글 적용→다시 확인을 설명하고 단계 잠금을 표시한다. 연구 관계와 승인된 구성 관계, 사람 검수 전 AI 관련 사례도 구분한다. 공식 출제자의 실제 사고나 학습 효과가 증명됐다고 해석하지 않는다.

화면은 factoryStock=null을 전달한다. 재고를 직접 조회했다는 허위 표시도 없다. 후보 재고와 생산 명세는 주문/납품과 다르고 원장을 읽지 못하면 주문 여부를 표시하지 않는다. 실제 공장 연결은 이번 검토로 실행·승인되지 않는다.
