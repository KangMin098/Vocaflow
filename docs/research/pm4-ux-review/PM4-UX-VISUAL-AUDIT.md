## 증거 범위

지도 13장은 1440×900/1280×900이다. R5 7장은 360×969(6장)/360×544(1장)의 Inspector 크롭이다. JSON의 브라우저 설명과 PNG 실제 크기를 구별한다. 크기·해시는 input-manifest.json에 있다. 기존 캡처는 목표 없음/기록 없음/ready/선택/PLAN/문항 진입/복귀/V2/S5/과거/목표 변경을 포함한다. 새 독립 촬영으로 표시하지 않는다.

| 크기·보기 | 실제 자료 | 판정 |
|---|---|---|
| 1440 기본 | 기존 11장, 문항 화면·PLAN 스크롤 포함 | 목표→Focus→지도/Inspector 위계 확인. 첫 행동·선택 구별 가능 |
| 1280 기본 | 기존 2장 | 상단 카드 균형 유지. 관계도 영역명 잘림(P2-01) |
| 전체 펼침 | 해당 독립 캡처 없음 | 스크롤 발견·기본 보기 복귀 HOLD |
| 1024 | 없음 | HOLD, 별도 범위 |
| 390 | 없음 | HOLD, 별도 범위. 폭 360 크롭을 대용하지 않음 |

## 시각 관찰

목표/기록 카드 아래 FocusStrip을 배치해 첫 행동을 드러낸다. 검은 CTA·숫자 순서·선택 테두리는 구별된다. 두 번째 선택은 카드/지도 테두리와 Inspector 제목을 바꾼 기존 증거가 있다. 색 외에도 순서·문구·테두리·보류 표시가 있다.

1440 첫 화면에서 FocusStrip이 높이를 차지해 Inspector의 단계/학습량은 아래로 내려간다. 정보 누락은 아니며 시작 링크는 상단에도 있다. 1280에서는 검색/전체 펼침 버튼이 다음 줄로 내려가고 6열 영역명을 온전히 읽기 어렵다. 탐색 정보 손실을 P2로 판정했다.

Inspector는 현재와 목표→학습 경로→공급 상태 순서가 분명하다. PLAN 편집은 넓은 관계도 아래에 열린다. 기본 연구 사례 목록은 남으므로 상세 근거 접힘을 모든 연구 정보가 접힌다는 뜻으로 해석하면 안 된다. 폭 360의 조건 문장이 여러 줄로 이어지지만 심한 학습 실패는 측정하지 않아 확정 P2로 만들지 않았다.

기존 이미지에서 텍스트 겹침이나 페이지 외부 가로 넘침은 발견하지 못했다. 기존 JSON overflow=0도 지지하나 모든 보기/확대율의 보증은 아니다. 실제 대비 비율·DOM 클릭 영역·Tab 순서는 미측정이다. CSS focus-visible만으로 접근성 PASS를 주지 않는다.

## 3B 대조·측정표

검토한 reference 디렉터리에는 source access-map-page.png 원본이 없었다. 브라우저도 없어 3B를 새로 캡처하지 못했다. **참조 충실도 HOLD.** 토큰이나 아래 정본 수치만으로 참조와 같다고 결론 내리지 않는다.
