# v1.4 기존 bounded 원리의 가용성 및 보류 키

2026-10-14. [가용성 원장](./data/v14/principle-availability.json)은 기존110개를 다시 검증 완료로 세지 않는다. 110행 endpoint를 연도·기관 메타데이터로 재계수하면 양끝2014–2024 평가원 본시험/모평인 쌍2, 그중 본시험1, 해당 과거 범위 밖 endpoint를 포함한 쌍108이다. 이는 범위를 정한 가용성 감사이며 모든108쌍의 원문 파일을 전세계에서 찾았다는 뜻이 아니다.

기존 `2014A#36~2014B#37`의 v1.3 양쪽 원문·동일형 키 검증1쌍을 역사적 근거로 유지했다. v1.4 신규 bounded 원리 검증은 **0쌍**이다. 누적 상태는 완전 원문/키 확인1, 보류1, 미시도108이며 첫 판정과 해시를 수정하지 않았다.

보류 `M2206#37~M2306#36`에 대해 지난 EBS 서비스 페이지 추출과 다른 **KICE CDN 과거 학년도별 정답 파일 경로**를 한 번 조사했다. M2206은2021-06-03 시행2022학년도, M2306은2022-06-09 시행2023학년도다. 추정한 `22suneung-06mo/22suneung-06mo_3a.pdf`와 `23suneung-06mo/23suneung-06mo_3a.pdf`는 웹 도구에서 접근 불가, 별도 HTTP HEAD에서 각각404였다. 공식 정답 행은 확보하지 못했고 `partial_defer_key`를 유지한다. 실패 URL을 반복하거나 DB⑤를 원래 정답표로 대체하지 않았다. 두 추정 경로의404는 다른 위치에 공식 키가 없다는 증거가 아니다.

새 교차 유형4비교는 [별도 원장](./data/v14/principle-cross-review.json)이며110개 분자에 합산하지 않는다. 실제 두 원문/발문/5후보/제시/각주와 같은 형 키 이미지를 다시 읽은8문항의 개발 재분석이다. 자세한 성립 조건과 비재현은 [교차 유형 결과](./V14-CROSS.md)에 분리했다. 인간 전문가 검수·공개 권리/내용 심사·학생 전이/지연·교수 효과 증거는 없다.
