# 수능 본시험 우선 확대 결과 — v0.2

2026-10-14. 사용자 요청에 따른 소규모 확대 단계이며 전수 연구 최종판이 아니다. [v1.1 규칙](./PROTOCOL-v1.1.md)·선정 코드·입력/정답 hash를 commit `a3a32f405`로 등록한 뒤 새 AI 문맥 두 개가 독립 분류했다. 이전32문항과 첫 판정은 유지했다. DB·공개 v3·학습자 UI를 변경하지 않았다.

## 무엇을 확대했는가

- 2014~2024학년도 수능 본시험12책자에서 새32문항·25유형·32공유지문 후보를 선정했다. 각 책자2~3문항, 2014 A/B 별도. 모평 추가0.
- 누적 독립 분석 대상64문항 중 본시험56·모평8이다. 코드북과 표본이 달라64개를 같은 척도의 통합 분포로 계산하지 않는다.
- 이전 표본의 공유지문·정규화 동일 본문·기록된 사전 노출을 제외했다. 고정2026-10-12 snapshot을 재사용했으며 2026-10-14 현재 DB를 재감사한 결과가 아니다.
- 최근2025~2026의 본문/정답은 이번에 열지 않았다. 인간 전문가 검수·학생 과정/효과 실험은 실행하지 않았다.

선정 분모는 메타데이터 적격287개다. 공개 v3 여부는 운영 입력 조건으로만 썼고 v3 분석 내용은 독립 입력에 넣지 않았다. 보류 문항·최근 검증 집합을 채워 넣지 않았다. 목적 표집이므로 연도·유형별 모집단 비율을 추정하지 않는다. 26유형 중 과거 표본/공유지문 제외 후 남은25유형만 포함했다.

## 원문 확인 결과(O)

모든32문항의 실제 문제 PDF와 해당 홀수/짝수형 정답표를 직접 대조했다. ‘직접 대조를 수행했다’와 ‘저장된 연구 입력이 전체 원문과 완전히 일치한다’를 분리했다.

| 필드 | 완전성 complete | 결함이 남은 partial |
|---|---:|---:|
| 본문 | 11 | 21 |
| 발문 | 30 | 2 |
| 다섯 보기 | 27 | 5 |
| 제시 표시/구조 | 8 | 24 |
| 동일형 정답표 | 32 | 0 |

정답은32/32 저장값과 일치했다. 전체 필드의 완전성 기준을 모두 충족한 입력은8개다: **2014B#42, 2022#18, 2015#18, 2017#25, 2022#35, 2016#23, 2020#37, 2024#28**.

원장에는 연구 입력의 어휘 각주 누락20개, 발문 말미 잘림2개, 보기 범위/쪽수/각주 혼입5개를 기록했다. 결함은 중복될 수 있으므로 합산하지 않는다. 2019#25는 실제 표의 국가·수치24행과 보기 대응을 확인했지만, 고정 입력의 행/열 평탄화는 별도 partial이다. 이 자료를 수치 오답 또는 원래 문항의 오류로 판정하지 않았다.

각주 누락은 특히 어휘·언어 복잡성을 해석할 때 중요하다. 원래 응시자는 각주 도움을 받는데 연구 입력은 그 도움을 주지 않았을 수 있다. 이번 고정 입력 밖의 DB 필드/원천에 각주가 보관돼 있는지는 확인하지 않았으므로 ‘DB에서 영구 소실’이라고 단정하지 않는다. 일부 보기 조각은 독립 명제가 아니라 밑줄 위치/삽입 위치이며, 오염된 조각을 정상 선지로 그대로 교육에 쓰지 않는다.

로컬 PDF의 KICE 표지·형·페이지·해시는 확인했으나 공식 다운로드 거래/버전 계보는 재구성하지 못했다. 인간 검수와 법률적 권리 확정도 별도다. source complete는 입력 완전성 판정이며 해설의 학문적 타당도까지 뜻하지 않는다.

## 최초 독립 분류의 실제 결과(O)

두 분류자의 첫 완성32행을 답 공개 전에 해시 동결했다. 8행씩 부분초안도 보존했다. 같은 설정을 상속한 별도 AI 문맥이므로 인간 전문가 간 독립성이나 모델 사전학습 미노출은 보장하지 않는다. 표2019#25의 같은 문제지3·4쪽 추가 접근은 허용 입력으로 기록했다.

배경 관계 Jaccard55.21%, 명제 성분52.92%, 언어 복잡성75.00%도 따로 보존했다. 보기160쌍의 content는139/160=86.88%(κ=0.810), fit160/160=100%(κ=1), failure135/160=84.38%(κ=0.814)이다. fit 일치는 같은 답을 고른 결과와 밀접하므로 내용 판정의 독립 타당도 증거로 읽지 않는다. 160개는32문항 내 종속 관찰이다.

전체9축/보기/전략 중 일부 차이를 포함하면32문항 모두 차이가 남으며, 담화·요구·결정관계·추론·전략만 세면24문항에 차이가 있다. 합의로 지우거나 모두 오답으로 처리하지 않았다. 원장에 최초 판정과 불일치를 그대로 남겼다.

사후 기술용 지문 군집 bootstrap1,000회(seed20261014)에서 결정관계 구간은62.50~84.90%다. 목적 표집이므로 모집단/미래시험의 신뢰구간이 아니고 점추정의 문턱 통과를 확정하는 통계도 아니다. 이전65.25%와 새74.48%는 표본·기관 구성·코드 정의가 모두 달라 개선의 인과 효과로 해석하지 않는다.

**전체 확인적 확대는 아직 허용하지 않았다.** 대립 축의 수치 기준 실패, 입력 완전성8/32, 충분성 기준의 해석 결함이 남는다. source가 완전한8개만으로 어휘·어법·도표가 중요하지 않다고 일반화하는 것도 금한다.

## 후속 반증이 드러낸 방법론 결함

답 공개 뒤 A/B가 각자8문항을 검토했고, 별도 AI가 source완전8개와 경계2개를 검토했다. 다른 쪽 판정은 자기검토 단계에 제공하지 않았다. 어떤 검토도 인간 전문가 검수로 표시하지 않았다.

1. **정답 탐지와 전체 선지 검수의 충분성이 혼용됐다.** v1.1은 제한된 읽기로5후보를 모두 판별하는 조건인데, 2017#25·2024#28·2019#25 등은 한 정답의 직접 근거만으로 applicable로 분류했다. 실제 시험의 유일 정답 관행을 전제로 한 전략과 각 선지를 독립 검증하는 연구 기준을 다음판에서 분리해야 한다. 최초 상태를 사후에 고쳐 수치를 높이지 않았다.
2. **내용 판정의 기준 문맥이 모호하다.** 명사구 자체/빈칸 삽입 후 명제, 후보를 포함한 제시문/후보를 제외한 주변 글, 실제 세상의 참·거짓은 서로 다르다. 2022#35의 제거 문장이 본문에 있다는 사실만으로 주변 흐름의 지지를 인정하거나, 주제 이탈을 사실적 모순이라고 해서는 안 된다.
3. **anchor가 허용 읽기 범위 전체를 보장하지 않는다.** 짧은 인용 외에 실제 문장/행/열의 시작·끝, 사용한 구문 의존과 지시 대상을 기록해야 한다. 특히2023#29는 외부 자기표현 맥락이 국소 구문 판단에 유입됐을 가능성이 남았다.
4. **있는 관계와 필요한 관계가 다르다.** 2015#18의 명시 요약으로 후보를 구분하는 경로와 전체 논증을 확인하는 경로, 2016#23의 지표 용도 설명이 필요한지 여부를 구분해야 한다. 복수의 충분 경로는 강제 합의 대상이 아니다.

이 결함은 독립 AI의 높은 일치만으로 방법론 검증을 완료할 수 없다는 결과다. 해석 검토는 별도 원장이고 최초 일치도에는 덮어쓰지 않았다.

## 교수 모델과 Vocaflow 제안(H/E 미검증)

학생 설명은 ‘이것이 누구/무엇에 대해 어떤 조건에서 참인가 → 앞뒤의 무엇과 연결해야 하는가 → 발문이 어떤 판정을 요구하는가 → 지금 읽은 범위로 무엇까지 확정되는가’로 구성하는 가설을 유지한다. 이번 자료는 마지막 질문의 중요성을 더 분명하게 했다.

학생에게 한 항목으로 정답을 찾게 하는 연습과 다섯 보기의 성립 조건을 설명하게 하는 연습은 서로 다른 과제로 설계할 수 있다. 공저/단독, 수량 상한, 결합 후보의 한 절 오류, 대명사 동일 지시를 이용해 주체·범위·관계를 설명하게 하되 효과는 학생 실험 전까지 미검증으로 둔다.

Vocaflow에는 어휘 각주·밑줄 구간·도표 행/열·주어진 문장·공유지문을 원래 제시형과 결속하는 데이터, 내용 성립/과제 적합성의 별도 판단, 정답 탐지/전체 검수의 구별을 제안한다. 먼저 연구용 입력 복원본을 별도 버전으로 만들고 동일형 PDF와 대조해야 한다. DB/v3/UI를 임의로 바꾸는 구현 권고가 아니며 실제 구현을 이번에 수행하지 않았다.

## 다음 소규모 단계

우선순위는 새 문항 수보다 **이번24개 불완전 연구 입력의 별도 복원**이다. 원본 hash·최초판정을 보존하고 각주/발문/표시/보기 경계를 보완한 연구용 새 입력을 만든다. 기존 원천의 각주 필드 보관 여부부터 확인한다. 그 뒤 v1.2 후보의 정답 탐지/전체 검수·기준 문맥·명시 읽기 범위를 고정하고 새 본시험 발견 표본에 재검증한다. 이미 본32개에서의 수정 검토는 탐색으로만 보고한다. 최근2025~2026은 원리 고정 후 검증에 사용한다.

## 재현과 원장

- `data/main-20261014/manifest.json`, `registration.json`: 선정 분모·ID·버전·고정 입력·첫 제출 hash 및 실행 순서.
- `rater-a.json`, `rater-b.json`: 최초32행, 수정 없음.
- `source-audit.json`:32개 전체 대조 상태·PDF/형/쪽/hash·완전성 결함.
- `agreement.json`: 최초 코드의 축별 통계·불일치·작업 gate. 부가 bootstrap은 사후 기술 구간.
- `post-key-a.json`, `post-key-b.json`, `interpretation-review.json`: 답 공개 후 자기/독립 검토, 조정으로 덮지 않음.
- 원문·PDF·부분초안은 ignored `scripts/research/csat-reading/local/main-20261014/`에만 보존.

```powershell
node --test scripts/research/csat-reading/agreement.test.mjs scripts/research/csat-reading/main-agreement.test.mjs
node scripts/research/csat-reading/main-agreement.mjs
```

선정 스크립트는 등록된 run을 덮지 않고 재실행을 거부한다. 재계산은 고정된 protocol/선정 코드/snapshot/manifest/입력/키/최초분류/source hash가 같을 때만 허용된다. 다른 환경에는 원문 snapshot과 해당 PDF가 필요하며 metadata로 원문 전문을 복원할 수 없다.
