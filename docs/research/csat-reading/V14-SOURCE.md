# v1.4 원문 입력·연구 노출 감사

2026-10-14. 이 문서는 source 역할의 메타데이터 적격성과 후속 원문 복원을 구분한다. 이전 판정·입력·노출 원장을 덮어쓰지 않는다.

## 의미 분류 전 적격성 보수화

최초 메타데이터 초안은 독립 분석 91문항(이전 80+v1.3 적격 11), 공유지문·정규화 동일 본문, 기록된 인접 문항·원리 검토 페이지를 제외한 176개 후보를 계산했다. 그러나 이전 원문 감사에서 전체 페이지를 열었을 때 함께 보이는 문항도 source 역할이 접했을 수 있다. 초안의 적격성은 완전한 프로젝트 미노출을 보장하지 않았다.

후속 메타데이터 감사는 v1.2 파일의 16개 전체 렌더 페이지, v1.1 본시험 32문항 원문 감사 페이지, 최초 감사에서 명시적으로 시각 대조한 7문항의 페이지에 속하는 후보를 보수적으로 제외했다. 기존 bounded 원리 110개를 재진술할 때 노출된 2014~2024 본시험 endpoint 23개도 제외했다. 원문 문장을 의미 판단하거나 정답을 표시하지 않고, 프로그램이 snapshot 본문의 접두부와 PDF 문자층의 위치를 대응시켰다. 이 대응은 원문 완전성 검증을 대체하지 않는다.

최종 메타데이터 후보는 **97개**다. 유형 순서를 주제·제목·빈칸·순서·삽입·무관·어휘·요약으로 고정하고, 이미 선택된 같은 책자 수를 최소화한 뒤 `SHA256(csat-v14-20261014:+ID)` 순으로 골랐다. 사전등록 전 초안 수정이고 결과에 따른 표본 교체가 아니다. 서로 다른 8책자에서 8문항을 선택할 수 있다. 원문·정답 복원 실패 시 해당 원분모에 보류를 남긴다.

초안 파일 `source-availability.json`, `source-availability-v2.json`, `source-availability-v3.json`을 보존한다. v2는 v1.1 감사의 단일 `pdf.page`를 배열 `pdf.pages`와 함께 읽지 못했다. v3에서 이 경계를 바로잡았으며, v4에서 최초 시각 대조 페이지를 더했다. v4의 선정 ID는 v3와 같다. 최종 기록은 [source-availability-v4.json](./data/v14/source-availability-v4.json)이다.

source 역할이 읽은 정답표 전체 페이지와 문제 페이지의 노출은 독립 분류자에게 전달할 입력과 별도로 기록한다. 새 분류자에게 정답을 주지 않는 절차는 프로젝트 전체 또는 모델 사전학습의 완전한 미노출과 다르다. 인간 전문가 검수·공식 다운로드 계보·권리 확정·학생 노출과 효과 검증도 별도다.

## 원문 복원 상태

원문 의미 입력은 사전등록 동결 뒤에만 복원한다. 현재 메타데이터 단계에서 원문 완전성이나 정답 대조 완료를 선언하지 않는다.
