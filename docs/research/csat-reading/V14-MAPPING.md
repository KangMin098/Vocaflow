## 지지·반례와 확보하지 못한 범주

R5는 주제와 빈칸에서 중심 범위가 사용되는 경로를 확인하고 생애의 한 사실 비교는 원래 중심 생성 요구와 구별했다. 순서는 전역 내용의 지원을 설명하되 선행 정보·질문과 답변 같은 대안 경로를 인정했다. E3는 도표·심경 변화·주제·목적에서 의미 대응을 확인했으며 고립 어법 표시를 자동 E3 직접으로 연결하는 문제를 기록했다.

S5는 비교·결합·시점·부정의 실제 사용을 확인하고 어법이라는 유형명만으로 범위 TASK를 직접 연결하지 않았다. V2는 문맥 비유 표현의 해석과 문맥에 맞는 반대 표현 선택을 구별했다. 어휘 문항이라고 해서 다의 문맥 선택 V2가 직접 관찰되는 것은 아니다. 이 구별은 V4·E3와의 혼동 사례를 제공한다.

자동 직접 후보와 실제 직접 판정이 달랐던 사례, 후보 밖 `unknown`에서 직접 관련이 확인된 사례를 JSON에 문항/TASK별로 기록했다. 후보 `unknown`은 원래 관련 없음 판정이 아니므로 이를 오분류율이라고 부르지 않는다. E3 규칙은 후보 다섯 개가 있는 모든 문항을 연결해 후보 밖 표본이 없다. 따라서 E3 누락률을 0으로 계산할 수 없다.

각 TASK의 직접·간접·과잉·누락·무관·보류·혼동·교차 유형 8범주를 감사했지만 새 표본에서 전부 확보하지는 못했다. R5의 자동 과잉 연결, E3의 후보 밖 누락·무관, 모든 TASK의 보류 등은 확보하지 못한 상태로 남긴다. 범주 목표를 채우기 위해 무관·보류 사례를 제조하지 않았다. 다른 유형의 공통 수행 후보는 학생의 교차 유형 전이 관찰과 다르다.

관련성의 `direct`는 원래 문항의 한 실제 판단 경로에서 고유 수행을 설명할 수 있다는 뜻이다. 모든 충분 경로의 필수 능력·학습자 결손·공개 자격·직접 평가 자격을 뜻하지 않는다. 새 교육 질문을 만들 수 있다는 사실도 원래 문항–TASK 직접 관련과 분리한다. 목적 표집 수치와 제한 프레임 감사를 전체 시험의 정확도·누락률·인과 관계로 일반화하지 않는다.
