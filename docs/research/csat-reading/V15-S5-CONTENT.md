분석 버전 주의: 아래 첫 연결은 DB published version3의 내용이다. 별도 [최신 published revision 대조](data/v15/v3-latest-connection.json)에서8행의 최신4~6 revision도 실제 읽었다. 2014A#32 최신5 설명은 수치 계열 혼동을 다루도록 달라졌으므로 아래 version3의 읽기 시간/후보 간 판단 위험을 최신 설명의 결함으로 전가하지 않는다. 기존 콘텐츠·Gold·첫 원장을 덮지 않았다.

2026-10-14. `s.form_scope` / `ws.grammar-scope`. v14 revision3의 3활동·12facet와 실제 Gold는 변경하지 않았다. **2023#20** 원문 전체를 읽고 기존 source-complete 원장·동일형 정답표에 결속한 다른 지문 활동 하나를 overlay로 추가했다. 새 원문 수는 0이고 다른 TASK에서 이미 쓴 개발 노출 지문이다.

새 전이의 정보 범위는 원문 s3~s7이며 부정·비교·시점의 실제 대상 범위를 정확히 결속했다. 원문을 최소 변경한 부정 유무·비교/최상급 대조는 **합성 변형**이며 실제 인쇄문이나 새로운 과학 사실로 표시하지 않는다. 완전·부분·동등·잘못·보류 응답과 4facet의 실제 기준은 비공개 `local/v15/content-packages.json`에 보존한다.

| 필수 요소 | 실제 다루는 범위 | 남는 한계 |
|---|---|---|
| 부정 | 길이 상한, 제거 부정과 관리 개선의 분리 | 복합 부정 체계 전반을 포괄하지 않음 |
| 양화 | 개인별 최대 수와 전체 제한의 구별 | 중첩 전칭·존재 양화는 미포함 |
| 조건 | 즉각 위험 없는 조건과 조건 밖 미결정 | 조건의 역을 강제하지 않음 |
| 비교 | 동일 지표·연도·단위, 비교와 최상급 대조 | 전 대안 방법의 순위는 자료 없음 |
| 제한 | 학생별 적용 대상 | 공동 작품의 추가 규칙은 미결정 |
| 시점 | 현재까지 결과와 미래 영구 주장 분리 | 시제·상 전체 재고는 미포함 |
| 최소 대조 | 경계 안/밖, 같음/다름, 부정 유무, 비교 강도 | 합성 예는 원도표의 새 사실이 아님 |

S3 수식 부착, S4 구조 연결, S-O1 문장 전체 통합과 S5 범위 산출물을 분리한다. 어법 정답률이나 구조 라벨만으로 S5 숙달을 확정하지 않는다. 같은 연결을 유지해도 적용 대상·조건·강도·시점이 어떻게 달라지는지 설명해야 한다.

현재 v3의 2014A#32는 후보 간 일관성 추론과 읽기 시간 주장을 포함한다. 다른 보기의 참을 가정하여 도표 수치를 확정하거나 읽기 시간 효과를 입증했다고 하지 않는다. 이 패키지는 실제 복원된 파생 셀과 원도표의 접근을 구별한다. 2015#21의 조건절·빈도 표현도 무조건·필연으로 강화하지 않는다. 실제 v3 필드·행 hash는 [후보 원장 revision1](./data/v15/content-candidates-revision1.json)에 기록했다. 원천 형·파일·필요 범위를 보완한 새 원장이고 첫 원장과 Gold는 덮지 않았다.

8종 합성 응답은 기존 직접 확인 활동의 4facet로 구성했다. 일부 맞는 절이 있어도 지표 혼합·결합 강화·잘못된 근거는 명시적 결함으로 기록하고, 설명이 없는 facet는 자동 부분점으로 주지 않는다. 의미와 복사·노출의 절차 자격은 별도다. 공개 적격·직접 평가 적격·실제 학생 관찰·효과 승인은 0이다. 기존 AI 명세 검토, 새 작성자 명세, 후속 독립 합성 채점은 서로 다른 검수 단계다. [패키지](./data/v15/content-packages.json) · [역할 overlay](./data/v15/content-roles-revision1.json).

첫 독립 내용 QA는 S5 새 전이의 동등 응답이 비교 한계를 빠뜨린 점과 최상급의 비교 집단을 모든 가능한 방법으로 확장한 점을 수정 요청했다. revision2는 완전·동등 응답 모두 문맥상 비교 집단 내 최고와 원문이 집단 목록·전체 순위를 주지 않음을 설명하도록 맞췄다. 부정 유무와 비교 강도의 두 변형은 모두 합성이라고 명시했다. 대비 역할은 실제 A/B 합성 응답 입력과 숨겨진 해설을 분리하고, 지도 역할에는 조건절 식별 → 빈도·가능성 표시 → 조건 안/밖 사례 → 최종 설명의 단계와 순차 힌트를 넣었다. 첫 원장·v14 Gold·합성 채점 입력은 그대로 보존했다. [revision2](./data/v15/content-revision2.json)는 후속 독립 내용 검토 전까지 수정 완료와 내용 수용을 구별한다.

후속 내용 QA가 첫 4개 요구의 해결을 확인했지만 지도 역할의 지원·Gold 공개 순서가 두 필드에서 다르게 적힌 CR-H01을 발견했다. [delivery revision3](./data/v15/content-delivery-revision3.json)는 초기 시도 봉인 후 필요한 단계 힌트를 선택적으로 제공하고 노출·후속 시도를 기록한 뒤, 최종 지도 응답을 봉인하고 나서만 Gold·해설을 공개하도록 맞췄다. 지도 지원이 가능한 응답은 assisted guided이며 무지원·독립 확인 성공으로 계산하지 않는다. 질문·Gold·활동 수·16합성 응답은 그대로 유지했고 이 전달 계약의 독립 재검토는 별도로 기록한다.
