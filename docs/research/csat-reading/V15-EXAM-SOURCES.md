2026-10-14. 읽기 전용 DB 실측, 로컬 파일 hash·정답표 내용 구별, 제한된 공식 경로 확인이다. 새로운 전체 시험의 원문·정답을 모두 검증한 연구가 아니다. [기계 원장](./data/v15/exam-sources.json)에 시험별 ID·학년도·월·수준형·문제지 형·배점·DB 키 source·파일 hash를 보존했다. 원문과 실제 정답값은 공개 원장에 없다.

## 30/27/3의 정확한 분모

`to_regclass`와 컬럼 조회 후 `csat_exams.organizer='kice'`를 직접 읽고 `csat_items`, `csat_dx_answer_key`를 ID로 연결했다. 30시험 중 29시험에 독해 본문 카탈로그가 있고 27시험은 키 1–45번·45행·배점 100점·빈 답 배열 없음이다. 5시험의 `diagnosis_ready=true`는 운영 상태이며 교육 효과나 연구 정본 검증 상태가 아니다. 이 분모에는 2027학년도 6월 모평과 무효 M2009도 있다. 2014–2026 연구 핵심 범위와 같은 집합이라고 하지 않는다.

## 파일명과 실제 내용의 구별

30시험의 명명 경로에 문제지 파일 자체는 모두 존재한다. 그러나 M2009는 위 중복이고 나머지 파일 존재도 전체 원문 완전성이나 적법한 공개 자격을 뜻하지 않는다. 수능의 대체 파일명(2015/2016 홀수, 2017–2022 짝수, 2025 짝수형)을 찾아 실제 hash를 연결했다. 2025 DB `paper_form='단일'`과 파일명 짝수형의 차이는 머리글 직접 대조 전까지 불일치 후보로 남긴다. 2025–2026 본문은 열지 않았다.

정답표 명명 파일 30개를 CID 텍스트로 구별했다. 22개는 해당 머리글의 정답표·45행·100점으로 해독됐고, 7개는 **듣기평가 대본**, 2025 한 개는 이 해독기로 판정하지 못했다. 22는 공식 다운로드 확인 수, 전체 원문 대조 수, DB 키와 45개 실제 값 일치 수가 아니다. 2014 A/B 키 표 이미지는 별도로 직접 확인했다. 2025 키는 `decode_unresolved`이며 문제지라고 판정하지 않는다.

오명명 대본 7회차는 **M2109, M2206, M2209, M2306, M2309, M2406, M2409**다. 이 7개 DB 키 source는 `mock-answers-kice.json`이고 원 파일의 source에는 평가원 공식 모평 게시판이 적혀 있다. 하지만 DB 키 테이블에는 원 PDF hash·개별 다운로드 URL·판본 계보 필드가 없으므로 파일명 source만으로 공식 동일형 키 확인을 승격하지 않는다. 실제 대본 표지는 2022·2023학년도 6월 두 회차를 이미지로 확인했다.

파일명 `202106`은 여기서 **2021학년도 6월(M2106)**이며 2022학년도라는 뜻이 아니다. 감사 중 첫 이미지 산출물 이름에 M2206이 붙은 오명명을 보존하고 실제 머리글이 M2106 정답표임을 기록했다. M2206의 실제 `202206_...정답표.pdf`는 듣기 대본이다. 처음 경로 규칙을 단순화한 draft0 원장도 비공개에 그대로 보존했다. 최종 원장은 실제 대체 파일명을 사용하며 `--check`로 재계산한다.

## 공식 확보 경로와 미해결

평가원 [수능 기출 게시판](https://www.suneung.re.kr/boardCnts/list.do?boardID=1500234&m=0403&s=suneung), [모평 기출 게시판](https://www.suneung.re.kr/boardCnts/list.do?boardID=1500236&m=0403&s=suneung&searchStr=)을 실제 열었다. 목록의 문제·정답 제공과 권리 안내는 확인했지만 이번 세션에서 2014 A/B 및 M2009의 개별 첨부 거래와 로컬 PDF 판본을 결속하지 못했다. 역사 게시물·페이지의 일부 접근은 도구에서 실패했다. 신규 공식 PDF 다운로드 **0**, 공식 계보 복원 **미해결**이다. 특정 URL 접근 실패를 인터넷 전체에 원천이 없다는 주장으로 바꾸지 않는다.

이전 v1.4의 조건부 원리 110쌍 중 1 complete·1 key-defer·108 unattempted는 수정하지 않았다. M2206/M2306은 최신 DB에 전체 키가 있다는 사실과 **원 정답표를 직접 확보해 그 두 문항을 확인했다는 사실**이 다르다. 새 원키 검증 0이며 이전 보류 쌍을 이번에 검증 완료로 합산하지 않는다.

## L/X 별도 입력 계약

L은 동일 시험·형의 음원 hash·출처·권리, 문제지·시각 보기, 대본/힌트 이전 실제 응답, 재생 구간·속도·반복과 접근 조건을 요구한다. 관찰 대상은 음원 구간에 결속된 이해·판정과 응답이며 대본을 읽은 결과는 별도다. 읽기 분석에서 청취 처리 속도나 듣기 오답 구별 능력을 추정하지 않는다.

읽기 전용 파일 계측에서 `scripts/csat/data/listening-all.json`은 16시험·272대본 항목(수능 7·모평 9)을 담고 있다. 이는 저장된 대본 공급 수이며 음원 신규 검증이나 실제 청취 수행 수가 아니다. 파일 hash와 입력 계약을 기계 원장에 함께 기록했다. 새 음원 대조 0·학생 청취 응답 0이다.

X는 실전 운영 TASK를 뜻하며 기존 장문 문항 코드 X-*와 구별한다. 전체 시험 체제·동일형 키와 전 문항 응답 순서·시각·수정, 남은 시간·누락·재방문, 듣기 방송 일정, 힌트/사전 노출·중단·시험 조건을 필요로 한다. 정확도와 속도·누락을 함께 보고 여러 회차 안정성을 따로 관찰해야 한다. 28개 독해 문항과 63점만 갖춘 자료를 전체 45문항·100점 실전 수행으로 간주하지 않는다. 학생 수행 자료·L/X 적격 판정·효과 증거는 이번에 **0**이다.

## 재현·노출·권리

`node scripts/research/csat-reading/v15-source-audit.mjs --check`는 고정 DB metadata 입력, 로컬 PDF hash·머리글/표 분류와 공개 원장을 대조한다. live DB를 자동 다시 질의하거나 적재하지 않는다. 비공개 입력 `local/v15/source-db-metadata.json`의 SHA-256은 `49da536963aee78032c41f05a24f23139c7b0ecbedbdf21878351eaf9a768715`다. 첫 draft0의 hash는 `14fcaf386d2f4fee6761322cd3251aa894fa7575212e0b19fffb49bad198990b`다. 연구용 이미지와 첫 입력은 ignored local에만 있다.

원천 감사 문맥에는 2014 A/B 전체 키 각 45행, M2106 전체 키와 듣기 보기 1–12번, M2206/M2306 대본 1번이 보였다. 30개 키 명명 파일 텍스트 해독은 이 문맥의 사후 원천 감사 노출이며 새로운 독립 학습자 평가 입력으로 쓰지 않는다. 기존 개발·홀드아웃 노출 원장을 덮지 않는다. 전체 시험 원문 source_verified 신규 확정 0·인간 전문가 0·실제 학생 응답 0·권리 확정 0이다.
