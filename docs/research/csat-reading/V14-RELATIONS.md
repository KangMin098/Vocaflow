# 관계의 존재·사용·필요성 및 교육 TASK 관계

새 8문항에서 두 분류자가 기록한 37개 관계와 32개 풀이 경로를 독립 AI가 원문 결속 검토했다. 관계가 글에 있다는 판정, 특정 풀이에서 썼다는 판정, 그 경로에 필수라는 판정은 다르다. 이번 74개 필요성 기록 중 다른 명제 정보를 보존한 유효 단독 제거 검사는 0이다. 본질적으로 내용과 분리할 수 없는 관계는 `not_identifiable`로 남기며, 단어 삭제로 명제를 바꾼 결과를 관계 필수성의 증거로 쓰지 않는다. [실제 집계](data/v14/logic-review-summary.json)

여기서 R2/R4/R5는 TASK `r.relation`/`r.discourse_structure`/`r.central_meaning`이다. 콘텐츠·평가·학습자 증거 수준을 나타내는 R2/R3/R4/R5와 혼동하지 않는다.

| 교육 관계 후보 | 설명 가능한 산출물 | 아직 확정하지 않는 관계 |
|---|---|---|
| R2 명제 간 관계 → R4 글 구조 | 지시·예시·대조·조건이 어느 명제/문장을 연결하는지 설명하고 글의 위치·위계를 구성 | 모든 글 구조 과제가 같은 국소 연결을 먼저 요구한다는 고정 인지 순서 |
| R4 글 구조 → R5 중심 의미 | 주장·근거·부연을 구별해 중심 주장과 범위를 구성 | 구조도가 맞으면 중심 의미도 정확하거나, 구조도만으로 언제나 충분하다는 주장 |
| R5 중심 의미 → E3 후보 대응 | 중심 내용과 후보의 주제·주장·범위를 비교하는 주제/제목/빈칸 경로 | 사실·안내·국소 어법을 포함한 모든 후보 판단에서 전역 중심 생성이 필수라는 주장 |
| R2/R4 → E3 후보 대응 | 순서·삽입·제거 과제의 연결 제약과 후보 위치를 비교 | 위치 후보가 독립 참/거짓 명제이거나, 담화 부적합이 세상 사실의 거짓이라는 주장 |

이 표는 교육적 지원 관계의 조건부 재구성이다. 같은 경로에 등장한 TASK가 인과적 선수 관계라는 뜻은 아니다. 원래 문항이 직접 요구한 수행, 연구자가 추가한 설명 질문, 풀이 지원 수행을 분리한다. 본문에서 직접 비교하는 대안 경로가 있으면 중심 생성이나 구조도를 강제하지 않는다.

여덟 독해 전략은 [strategy-information.json](data/v14/strategy-information.json)에 허용 정보·연산·숨은 전제·AI/FOV·반례를 보존했다. 주어진 문장·요약 문장·복제 후보도 의미 정보를 공급하므로 읽기 비용 합집합에 포함한다. 한 후보의 직접 반증은 유일 정답 관행을 전제한 탐지 경로를 지원할 수 있으나 다른 네 후보의 검증을 대체하지 않는다. 순서/삽입 연산을 쓴 경로를 제시 순서 읽기 단독 성공으로 기록하지 않는다.

이 결과로 학습자에게 특정 사고 순서를 의무화하거나 읽기 속도·학습 효과·필요 총문항 수를 계산할 수 없다. 학생의 실제 수행 및 대안 경로 관찰, 독립 채점, 관계 조작의 식별 가능한 설계가 추가로 필요하다.
