## 4. 학생 자료 없이는 해결하지 못한 범위

인간 내용/Gold·권리·실제 응답 독립 채점·학생 미노출/힌트·전이/지연·교수 효과가 보류다. 학생 결손·숙달·예상 점수·필요 총문항 수·자동 NeedRank 승격을 산출하지 않는다. 지연 간격은 설계 예시이며 최적 효과 간격의 증거가 아니다. 지도 힌트를 받은 답을 무도움 독립 확인으로 표시하지 않는다.

L은 음원·대본·버전·재생 조건·청취 응답, X는 전체 시험 체제와 시간·순서·중단·수정·도움 로그가 필요하다. 읽기 분석은 듣기·운영 능력의 대체 자료가 아니다. v14의 판단 대상/지지/필요성/제한 읽기 실패는 새 자료 수로 통과시키지 않았다. v3의 실제 연결은 기존 AI 해석의 관찰이며 공식 출제 의도·읽기 속도·교육 효과의 확정 근거가 아니다.
