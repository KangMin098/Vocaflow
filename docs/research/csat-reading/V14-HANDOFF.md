# v1.4 → v6.2 교육 엔진 전달

기계판독 패킷은 [handoff.json](data/v14/handoff.json), 분모·지원 공백은 [coverage.json](data/v14/coverage.json), 연구 축별 보류는 [final-gate.json](data/v14/final-gate.json)에 있다. 공개 패킷에는 원문 전문·정답·개별 Gold를 넣지 않았다. 실제 교수 문항과 상세 채점 예시는 ignored local의 별도 버전이며 권한 있는 연구 검토용이다.

| 패킷 | 전달 내용 | 적용 경계 |
|---|---|---|
| A | R5/E3/S5/V2 수행 정의, 구별·중복·반례, 14개 계약씩 | 정의와 선수 관계 후보는 학생 결손이나 인과적 선수 관계의 증거가 아니다 |
| B | 새 8문항의 판단 대상, 지지/적합성 분리, AI/FOV 경로, 정보 비용, 관계 검토 | 최초 의미 보존 실패와 필요성 미확정을 보존한다. 사후 새 계약으로 최초 통과율을 올리지 않는다 |
| C | 실제 활동 12개·facet 48개, 교수 방법 40칸, 자료 역할 24개, 버전별 검토 | 교육 설계 명세이며 공개 콘텐츠·R3 평가 자격·학생 효과는 별도 보류다 |
| D | 새 매핑 24건, 두 판정과 불일치 6건, 누적 검토 기회 98건 | 98개 확정 관계나 6,310개 검증 완료를 뜻하지 않는다 |
| E | 금지 해석 | 학생 숙달/결손, 점수 상승, 필요 문항 수, 자동 NeedRank 승격, 교수 효과를 산출하지 않는다 |

v6.2에서 바로 참고할 설계는 후보를 원래 뜻대로 재현하는 단계와 본문의 지지 판정 단계를 분리하고, 정답 탐지 연습과 전체 후보 검수 연습을 구별하는 것이다. 의미 수행 점수와 AI-first/FOV 노출 순서 로그도 분리한다. 모델링·안내 연습·독립 확인 후보는 자료 역할을 다르게 표시한다. 같은 지문을 이미 본 학생의 수행을 새 지문 전이로 해석하지 않는다.

원문·권리·Gold 콘텐츠 검수 후에는 해당 활동의 공개 가능 여부를 판단할 수 있다. 실제 응답에 대한 독립 채점자 일치 검증 전에는 루브릭을 능력 판정 도구로 쓰지 않는다. 새로운 학생·새 지문·지연 확인 자료 없이는 숙달과 전이를 주장하지 않는다. 효과 검증은 비교 연구가 필요하다.

Claude의 별도 v6.2 작업에 연구 후보를 주입하지 않았다. `Vocaflow-map-v62`의 P-M0/P-M1·가용성 문서를 읽기만 했으며 UI나 제품 테스트를 이 연구에서 다시 검증한 것은 아니다. DB·공개 v3·제품 UI·MAP·PLAN·Workspace·main 변경은 0이다.
