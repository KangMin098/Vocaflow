# 수능 영어 독해 연구 사전 규칙 v1.0

고정일: 2026-10-12(한국). 담당: Codex. 원문 의미 분류 시작 전 등록. 연구 목적은 `.agent-goal.md`와 사용자의 연구 요청을 따른다. 기존 자산의 존재·메타데이터 감사와 대표 데이터 계약 확인은 사전 작업이다. 사전 열람한 최근 문항 2026#34·2026#19·M2606#19·M2609#18은 확인적 검증에서 제외한다. 이 규칙은 데이터에 맞추어 조용히 고치지 않는다. 수정은 별도 버전·이유·영향 집합을 기록하고 수정된 원리의 이미 본 검증 사례는 탐색으로 전환한다.

## 질문과 경쟁 설명

RQ1: 정확한 독해에 필요한 언어 처리(어휘·구문), 명제 구성(주체·술어·대상·극성·시점·조건·양화 범위), 문장 간 결속과 전체 의미 통합은 어떤 관계인가?
RQ2: 문항을 논리적으로 해결하기 위해 필요한 근거와 실제 수험생이 사용하는 인지 과정은 어떻게 구분되는가?
RQ3: 유형 내부와 유형 사이에서 반복되는 구조는 무엇이며, 그 반복은 시험 편집·소재·형식·공유 지문으로 설명될 수 있는가?
RQ4: 대립 찾기·핵심문장·직독직해·구문독해·선택적 읽기 각각의 성공 조건과 반례는 무엇인가?
RQ5: 원문-발문-선지-정답의 관계에서 도출한 교수 모델은 무엇이며, 어떤 학습 효과는 별도 실험이 필요한가?

경쟁 설명: (a) 하나의 담화 관계로 전 유형을 설명할 수 있다, (b) 공통 의미 처리 위에 과제별 판정이 결합된다, (c) 문항 종류에 따라 다른 읽기 체계가 필요하다. 어느 설명도 사전 채택하지 않는다. `대립 없음`을 원리의 실패로 억지 코드화하지 않는다.

## 범위·분할·단위

- 평가원, 2014~2026학년도, 읽기 in_scope. 본시험 핵심, 모평 비교 집합; 학평 제외. 2027은 외부 확장 후보로만 별도 집계.
- 학년도는 ID 정본으로 해석하며 시행연도는 학년도-1. 2014 A/B는 별도 층화한다. 홀수/짝수 선지 순서를 공식 정답표의 형과 맞춘다.
- 발견 집합: 2014~2024. 검증 집합: 2025~2026. 메타데이터·해시 감사는 검증 집합에도 가능하나 의미/정답/기존 v3를 발견 단계에 열지 않는다. 기존 v3는 전 기간을 보았으므로 이 분할은 새 연구 내의 전향적 분할이며 자료 자체의 완전한 신규성이나 사전학습 미노출을 보장하지 않는다.
- 사전 노출 2026#34는 확인적 검증 제외. 검증 문항을 본 후 원리 수정 시 해당 문항은 탐색 사례로 표시한다. 새 미노출 시험으로의 재현은 후속 연구다.
- 문항 단위: 발문·보기·정답의 판정 요구. 지문 단위: 실제 공유 본문. 장문 묶음은 동일 시험의 묶음 ID를 부여하고 원문 정규화 SHA256으로 대조한다. 반복 본문은 문항 수만큼 복제된 지문으로 세지 않는다. 도표/안내문은 단순 문장 분할에 강제하지 않는다.
- 필수 입력: 원문·발문·전체 보기·정답 출처/형·원문 버전·수리 이력. 본문 없음, 손상, 답 미확인, 시각자료 미확인, 공식 원문 대조 미완료는 각기 별도 상태. 텍스트가 저장되어 있다는 사실과 공식 PDF 대조 완료는 다른 수준이다.
- 16보류는 기존 상태와 이유를 보존하고 유형·연도별 누락 편향을 감사한다. 기존 게이트를 연구자가 우회하지 않는다. 새 연구 분류 가능 여부와 공개 승인 여부는 별도다.

## 검수와 확장 조건

1. 입력 감사: 저장 원문/DB 비교, 원문 전문은 로컬 전용. 정본 PDF/정답표의 직접 확인 수준을 원장에 적는다. 기존 v3·분석을 독립 분류 입력에서 제거한다.
2. 파일럿: 발견 집합에서 26유형을 가능한 한 포함하는 결정적 ID 선택, 2014 A/B와 실용/설명/서사/자료/어법 포함. 희귀 유형을 과대표집했으므로 빈도 추정에 쓰지 않는다.
3. 독립 분류: 최소 두 별도 AI 문맥이 같은 입력을 각자 읽고 기존 정답 해설/v3 없이 분류; 공식답은 별도 열람 단계가 이상적이며 이미 전달된 경우 `answer_blind:false` 기록. 각자의 최초 결과를 보존한 뒤 판정. 같은 모형/프롬프트인 경우 그 의존성을 밝힌다. 인간 전문가의 검수와 구분한다.
4. 수치: 단일 범주 축은 원시 일치율+Cohen kappa와 교차표; 다중 범주는 항목별 Jaccard+각 코드 이진 일치, 판단 불능/결측을 분모 밖으로 숨기지 않는다. 합의 후 원장으로 일치도를 계산하지 않는다. 표본이 작으면 구간과 kappa의 유병률 문제를 설명한다.
5. 확장: 문항 원문 결속/필수 필드 오류 0, 파일럿에서 최소 담화·요구 축 원시 일치율≥0.80 및 근거 누락 0. 이 수치는 연구자가 정한 작업 기준이며 학문적 타당도 기준이 아니다. 실패 축은 재정의·재파일럿 후에만 확장하며 실패 자체를 보고한다. 관계/추론/전략 축은 분류 불안정 상태에서 전수 통계로 승격하지 않는다.
6. 반례: 대립 없는 글, 두 관점의 우열 없는 비교, 대립이 있어도 답과 무관한 글, 한 문장으로 경쟁답 배제 안 되는 글, 국소 사실 확인만으로 끝나는 문항, 단일 문장이나 구문 문제, 복수 근거·공유 장문·자료 판정. 지지 사례만 골라 관계도를 만드는 것을 금한다.
7. 최근 검증: 코드/조건 고정 후 2025~2026에 적용, 본시험과 6/9월 별도; 원문 최초 분류와 원리의 지지/실패/조건외/미해결을 보존한다. 이미 v3를 본 연구자는 진정한 블라인드가 아니다. 원리마다 적용 가능 분모·성공 분모·반례 ID를 따로 적는다.
8. 통계 해석: 유한한 기출 집합의 관찰 분포, 모집단 전형성/미래 예측은 별도. 문항 난도는 공식 응답자료나 학습자 실험 없이 단어 길이·3점·AI 등급에서 확정하지 않는다. 연도·기관·유형을 통제하지 않은 연관은 설명적 상관이다. 반복 지문에는 군집화가 필요하다. 미해결을 누락하지 않는다.

## 이론·교수 효과·출처 검증

실제 원논문/기관 자료를 확인하고 full/abstract/metadata/not_accessed를 기록한다. CI·상황모형·L2 읽기·응집/일관성·구조 지도·ECD·KICE 공식 안내·국내 실증 연구를 비교한다. 원논문 미확인 통계는 인용하지 않는다. 강사와 교재는 공식 본문/직접 확인 영상만 주장 자료이며 인기도와 효과는 별개다.

교수 모델은 가설이다. 검증하려면 동등 시간·내용의 비교 교수, 사전 수준 층화·무작위 배정, 미학습 기출 또는 권리 확보 평행 문항, 지연 전이·속도/정확도·인지 과정·도움 사용 기록을 사전 등록한다. 실제 학생 응답·교사 독립 검수가 없으면 완료로 표시하지 않는다.

## 의미 분류 전 독립 AI 방법 검토에 따른 보완

검토자 `/root/protocol_critic`은 v1.0 초안을 읽고 8개 방법 결함을 보고했다. 이는 인간 전문가 검수가 아니다. 아래는 분류 결과를 보기 전에 반영한 v1.0 등록 보완이며, 원래 초안은 git/검토 기록에서 추적한다.

- 확인적 문항 결론은 문제 PDF·사용한 형의 정답표·해당 시각자료의 직접 대조가 완료된 경우에만 허용한다. DB 결속만 확인한 의미 분류는 탐색 결과이다. 저장본 전수 감사와 기간 전체 기출 전수를 구별한다. 공식 일정에서 예상 시험 목록과 미수집 목록을 별도 작성한다.
- 파일럿 최소 32문항·26유형, 최소 24 독립 지문. 발견 집합을 대상으로 정답 공개 전 독립 최초 분류를 저장한다. 답 공개 후에는 다섯 보기 전부를 성립/배제/미해결로 기록한다. 모든 경쟁 보기 배제를 확인하지 못한 근거는 `candidate_evidence`이며 “최소 충분 근거”라 부르지 않는다.
- 축별 확대: 담화·요구 각각 원시 일치≥0.80, 관계 Jaccard 평균≥0.70, 추론 Jaccard 평균≥0.70, 전략별 exact 일치≥0.80, 해당 축 unresolved 비율≤0.10, 결속/근거 누락 0. 각각 통과한 축만 확대한다. 실패 축의 수정은 v1.1과 새 미열람 발견 표본으로 재파일럿한다. 전수 의미 분석은 적격 전 문항의 실제 분류·근거·결측 원장이 있을 때만 표시한다.
- explicit은 직접 표현/일상적 환언으로 대응하며, local은 하나의 국소 논리 연결, global은 서로 분리된 명제의 통합 또는 범위/위계 판정, contextual은 표현 의미·태도·함축 판정의 성격이다. local/global은 근거 범위, contextual은 과정의 성격이므로 중첩 가능하다. cause(A→B)는 원인 강조, result(A→B)는 결과 강조이며 같은 연결에 무분별하게 둘 다 부여하지 않는다. concession은 기대 X와 실제 Y가 어긋나지만 X를 수용하고, contrast는 동일 차원에서 A/B를 비교한다. 표지어와 의미 관계는 별도 기록한다.
- 전략 행동: 대립 단독은 대비하는 양쪽 명제와 방향만 사용; 핵심문장 단독은 선정한 하나의 완성 명제와 발문/보기만 사용; 직독직해는 제시 순서대로 절 의미와 지시어를 누적 갱신; 구문독해 단독은 국소 문법 의존/범위로 판단; 선택적 읽기는 발문에 따른 후보 위치에서 시작해 필요한 범위를 넓힌다. 마지막 전략은 확대 범위를 기록하며 전체 읽기가 필요하면 “부분만 읽기 성공”으로 세지 않는다. 다른 전략 추가는 결합 전략으로 기록한다. 실제 학생 실행 없이 속도/정확도 성공을 관찰했다고 하지 않는다.
- 독립 입력 허용 필드: id,binding,passage_group,passage,stem,choices,type_id,source_status,visual_required,answer_blind. 기존 분석·공식답·해설·v3·최근 본문을 상속하지 않는 `fork_turns:none` 문맥 두 개를 사용한다. 사전 노출 문항의 공유/의미 중복 지문은 함께 검증에서 제외한다. 입력 생성과 최초 답 제출·답 공개의 실제 순서를 별도 원장에 남긴다.
- 공유 지문은 시험 번호 묶음+정규화 본문 일치로 후보를 만들고, 장문 PDF의 묶음 표기를 직접 확인해 확정한다. 같지 않은 해시는 변형/추출 오류/다른 본문으로 판정될 때까지 묶지 않는다. 서로 다른 시험의 동일 본문은 별도 출제 사건으로 남기고 본문 군집을 함께 기록한다.
- 불일치 처리: 제3 판정 가능/코드북 결함/복수 타당/미해결을 구분한다. 최초 결과를 고치지 않으며 조정본은 별도 파일로 쓴다. 관계·전략 해석에 원문상 복수 타당 해석이 남으면 강제 합의하지 않는다.
