# v1.4 핵심 네 TASK 교수·평가 패키지

2026-10-14. 기존 30프로필과 v1.3의 네 패키지·40방법·24자료 역할을 재사용했다. 이번에 **실제 기출에 결속한 구체 과제 12개와 분석적 루브릭 48facet**을 추가했다. 문항별 학생 질문, 자체 의미 Gold, 부분 답, 의미 동등 대안, 오답, 판단 보류, 채점 경계, 혼동 TASK와의 최소 대조를 작성했다. 이 명세의 완료는 학생 평가 도구의 자격이나 교수 효과 검증 완료를 뜻하지 않는다.

[공개 계약 JSON](./data/v14/education-packages.json)은 TASK별 14계약, 노출·자료·승격 상태와 비공개 상세 원장의 경로·SHA256을 제공한다. 실제 기출별 질문·Gold·부분 답·오답·채점 경계는 ignored `scripts/research/csat-reading/local/v14/education-packages.json`에 보관한다. 공개 Git에는 실제 기출 답안과 상세 Gold를 넣지 않는다. 공개 파일의 합성 최소 대조는 연구자가 새로 작성한 예이며 기출 원문이 아니다.

| TASK | 모델 설명 | 지도 연습 | 직접 확인 후보 | 응답의 핵심 |
|---|---|---|---|---|
| R5 중심 의미 | 2023#20 | 2015#21 | 2024#23 | 보기 없이 주제·중심 서술·범위·근거와 부연을 구성 |
| E3 본문·선지 대응 | 2017#25 | 2024#28 | 2015#24 | AI 한 후보 탐지와 FOV 다섯 후보 검수를 별도로 제출 |
| S5 형태·의미 범위 | 2024#28 | 2015#21 | 2014A#32 | 부정·조건·수량·비교의 적용 대상과 경계 안팎 사례 |

표의 **직접 확인은 자료 역할 후보**다. 연구자에게는 모두 노출된 개발 자료이고, 학생별 노출·인간 Gold 검수·채점자 일치·권리·공개 자격을 확인하지 않았다. 적격 독립 평가 재고는 0으로 유지한다. 같은 2024#23을 R5 수업에 사용한 학생에게 V2의 새 미노출 평가라고 배정할 수 없다. 한 지문의 여러 TASK 또는 다섯 보기·네 루브릭 facet을 독립 학생 관찰 수로 복제하지 않는다.

## 산출물과 채점 경계

R5는 보기 없는 첫 중심 응답을 확정한 뒤 근거·조건·부연을 설명하게 한다. 보기 선택 결과를 풀어 쓴 응답은 이 수행과 다르다. R4의 구조도는 지원 산출물이며 구조를 맞혔다는 이유로 중심 범위를 보존했다고 판정하지 않는다.

E3는 후보를 의미 명제로 정규화하고 본문 지지와 발문 적합성을 분리한다. AI 근거가 있는 응답이라도 다른 네 후보의 근거가 없으면 FOV 전체 완료로 기록하지 않는다. 주체·극성·강도·수량·조건·시점의 변형은 각 후보의 대응 기준으로 기록하며, 근거 위치 E2만 찾은 응답과 구별한다. R-A의 동일 대상·의미 판정이 미해결이면 해당 후보의 Gold는 자동 확정하지 않는다.

S5는 문법 명칭이나 수식 화살표만으로 충족하지 않는다. S3의 부착 대상을 동일하게 유지한 상태에서 조건 안/밖, 경계 포함/제외, 전체/일부 부정, 비교 단위와 결합 절의 의미를 설명하게 한다. 도표 값 접근 실패와 영어 비교의 의미 실패는 별도 관찰이다.

V2는 단어가 인쇄됐다는 사실을 직접 수행 요구로 세지 않는다. 본문 표현과 후보를 삽입한 표현은 입력 자격을 다르게 표시한다. 2024#34의 지도 활동은 후보 표현이 제공된 활동이며 원래 빈칸의 독립 정답 탐지나 R5 생성 성공으로 전환할 수 없다. V4의 표현 간 의미 관계와 E3의 후보 적합성은 추가 과제다.

루브릭은 facet별 의미 충족/부분/결함/보류를 기록하는 설계 후보이며 숫자 가중치·절단점은 정하지 않았다. 부분 답과 자연스러운 의미 동등 대안을 보존한다. 불완전 입력·불명확한 의미 대상·접근 지원의 불명확성은 원인 TASK의 확정 진단 대신 보류로 남긴다. 실제 학생 오류 빈도는 측정하지 않았다.

[초안 반증 원장](./data/v14/education-logic-notes.json)은 V2 한 대안 표현이 대응 관계를 인과로 강화할 수 있다는 모호성을 보류했다. 최초 상세 바이트는 수정하지 않았다. 원문 결속과 구체 Gold의 존재만으로 의미 동등 대안까지 검증된 것은 아니다. 이 과제의 해당 대안은 후속 독립 의미 검토 전 채점에 자동 적용할 수 없다.

## 방법과 자료의 자격

구문 해부, 의미 단위, 직독직해, 대조, 중심 문장, 명제·관계, 글 구조, 본문·선지 비교, 오답 의미 변형, 자기 설명·반례의 **10방법 × 4 TASK 비교를 보존**했다. 우선 여덟 독해 전략을 포함한다. 방법별 목표 행동·원문 사례·선행 접근 조건·한계·반례와 독립 확인 조건을 기록했다. 모든 효과 상태는 `not_tested`이며 이 40셀은 40실험이나 효과 크기가 아니다. 방법 이름 사용과 실제 산출물의 질을 따로 관찰해야 한다.

원문 분석·모델 설명·지도 연습·직접 확인·미노출 전이·지연 재확인의 여섯 역할은 별도 상태를 갖는다. 앞의 네 역할은 원문 또는 구체 명세가 있으나 공개·채점 자격은 보류다. 미노출 전이와 지연 재확인은 조건 계약만 있으며 적격 재고나 실제 성공 사례를 만들지 않았다. 전이는 다른 본문·주제·유형·구조의 변경 조건과 학생 노출을, 지연은 실제 경과·중간 학습·도움·반복 노출을 수집해야 한다.

v6.2는 이 계약과 합성 대조를 교육 설계에 참고할 수 있다. 기출별 상세 과제는 권한·권리·콘텐츠·Gold 검수를 통과한 뒤 사용할 수 있다. R0 설계와 R1 원문 결속을 학생 결손·숙달·NeedRank·점수 상승·학습량으로 자동 승격할 수 없다. 인간 전문가 검수 0, 학생 자료 0, 교수 효과 실험 0, R3 승격 0이다.

재현에는 ignored 원문 및 상세 입력이 필요하다.

```powershell
node scripts/research/csat-reading/v14-education.mjs --check
```

검사는 비공개 첫 패키지의 바이트를 보존하고 공개 계약의 재생성 일치를 확인한다. 명세 재현 통과는 채점 신뢰도나 교육 효과의 통과를 뜻하지 않는다.
