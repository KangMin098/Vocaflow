# v1.5 교육 콘텐츠·직접 확인·지원 공백 전달

Claude의 제품 P-M2b/P-M3와 별도 연구다. 제품 코드·DB·공개 v3·학습자 기록에 주입하지 않았다. [기계 전달 패킷](data/v15/handoff.json)은 현재 콘텐츠 개정과 검토 결과를 가리킨다.

| 패킷 | 실제 공급 | 아직 승인하지 않은 용도 |
|---|---|---|
| 교육 콘텐츠 | 기존 V2/S5 6활동에 다른 지문 2활동, TASK별7역할 총14역할, 실제 source/v3 결속 | 권리·공개 콘텐츠·학생 숙달·교수 효과 |
| 직접 확인 | 두 기존 확인 후보의4facet씩, 16합성 응답/64facet의 첫 독립 채점과 경계 원장 | 실제 학생 채점 타당도·임계점·점수·자동 NeedRank 승격 |
| 지원 공백 | S-O1/R2/R6 원문 연결 질문3개, 실제 Workspace 재고, 시험30/27/3와L/X 입력 계약 | 새 Workspace 구현, 듣기·실전 능력의 읽기 자료 기반 추정 |

실제 프롬프트·Gold·대조 응답·지도 단계·합성 채점 입력은 비공개 결속 경로에 있다. 연구 세션의 읽기 권한을 확인했지만 외부 공개 권리가 확인됐다는 뜻은 아니다. 공개 JSON의 hash와 버전을 결속하여 권한 있는 콘텐츠 검토자가 같은 파일을 확인할 수 있다.

제품 구현자는 자료 역할/검수 단계와 의미 응답/독립 노출 자격을 분리하는 계약을 참고할 수 있다. 구체 문항은 권리·인간 내용/Gold 검수와 추가 콘텐츠 QA가 필요하다. 실제 응답 독립 채점 및 학생 노출·새 지문·지연 자료 전에는 직접 평가 자격, 숙달·결손, 추천 승격, 예상 점수와 학습량을 산출할 수 없다.

v14의 판단 대상·본문 지지/발문 적합성·관계 필요성·제한 읽기 충분성 실패를 이번 콘텐츠 수로 해소하지 않았다. 관련 주장에는 기존 보류를 전파한다. 비교·최상급의 모집단을 원문 밖으로 넓히거나 잘못된 인과를 Gold에 넣지 않으며, 기존 v3의 의도/시간 주장은 AI 해석 후보로만 연결한다.

검토 순서: 최신 콘텐츠 개정의 source/Gold 및 실제 제공물 → 인간 내용·권리 검수 → 새 합성/실제 응답 채점 규칙 검토 → 학생 노출·무도움·전이·지연 관찰 → 허용되는 범위에서만 제품 적용 검토. 직접 출시는 이번 작업에 포함하지 않는다.
