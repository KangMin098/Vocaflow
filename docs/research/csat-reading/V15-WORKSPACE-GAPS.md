# 후속 Workspace의 실제 공백

최신 읽기 전용 DB의 `knowledge_applications(surface=csat_item_task)`를 제품 코드와 같은 content key·고유 문항·확인/전이 구분으로 집계했다. `cohesion-link`는 draft 1, active 확인/전이 0이다. S-O1·V2·S5·R6 Workspace는 현재 content_keys가 비어 있어 해당 연결의 active 재고가 0이다. 공개 기출 분석과 직접 TASK 확인 콘텐츠는 서로 다른 재고다. [실측](data/v15/product-inventory.json)·[기계 원장](data/v15/workspace-gaps.json)

| Workspace | 실제 읽은 연구 사례 | 관찰 질문과 산출물 | 필요한 다음 입력 |
|---|---|---|---|
| sentence-core / S-O1 | 2016#30 | 인물·주절·방향·시간·수식 대상을 통합한 명제. 대명사 정답이나 화살표만으로 성공 처리하지 않음 | 원문 문장 전체와 주석, 결합 Gold, 성분 오류와 통합 오류의 독립 검수, 새 문장 응답 |
| cohesion / R2 | 2020#37 | 지시구의 선행 명제, 관계 방향, 배열을 제약하는 범위와 대안 경로. 연결어 한 개를 전체 배열의 충분 근거로 쓰지 않음 | 기존 초안 내용/권리 검수, 다른 관계의 새 직접 질문, 식별 가능한 경우만 관계 제거 검사 |
| inference / R6 | 2014B#42 | 명시 전제와 제한된 추론, 더 강한 추론을 배제하는 조건. 인간 목소리를 그리워함에서 대면 방식의 필연성을 자동 확정하지 않음 | 실제 밑줄 함축 입력과 정확 표시, 가능/필연·국소/전역 구별, 복수 Gold와 반례, 새 지문·지연 관찰 |

세 원문을 실제 다시 읽고 질문 후보를 구성했다. 새 PDF 대조·인간 Gold 승인·학생 전이 관찰은 수행하지 않았다. 실제 질문은 비공개 결속 파일에 있고, 원문 정답을 새 TASK의 단독 숙달로 변환하지 않는다. 공개 유형 재고는 `R-IMPLY`/어법/순서 문항 수로 기술할 수 있지만 유형만으로 직접 TASK 재고가 되지 않는다.

V2/S5 패키지의 출처 결속·역할·응답과 노출 분리·5상태·검수 단계를 재사용할 수 있다. 의미 대안 선택의 V2 rubric을 추론 다리 설명에, 한 연산자의 S5 rubric을 전체 문장 통합에 그대로 쓰지는 않는다. 해당 수행에 맞는 기준을 추가해야 한다.

L은 실제 음원·대본·버전·재생 조건과 청취 응답이 필요하다. X는 체제가 확인된 전체 시험·시간·순서·중단·수정·도움 로그와 반복 수행이 필요하다. 읽기 분석에서 듣기나 시간 운영 능력을 추정하지 않는다. 이 연구에서 적격 직접 평가 및 실제 학생 검증 수는 모두 0이다.
