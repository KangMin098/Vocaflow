# v1.3 원문과 파생 단위 경계 감사

기존 v1.2 개발 문항 16개를 새 버전으로 복사했다. 기존 입력·본문·최초 판정을 수정하지 않았다. 본문 16개의 문자열과 PDF 바이트 해시를 모두 대조했고, 새 구두점 단위 144개를 전체 보존 본문과 읽어 확인했다. 인사말·서명 2개를 제외한 구두점 문장 단위는 142개다. 이 수는 독립 명제 수나 학생이 실제 읽은 문장 수가 아니다.

의심 경계 8개 문항은 저장된 실제 문제 PDF 페이지 렌더를 다시 직접 확인했다: 2014A#40, 2016#25, 2022#44, 2019#40, 2014B#38, 2018#39, 2022#25, 2024#35. 전체 필드의 원문 완전성은 v1.2 admission을 상속하며 이번 파생 경계 감사만으로 추가 승격하지 않았다. 인간 검수·권리 확정·공식 다운로드 계보 검증은 수행하지 않았다.

문장 helper는 정확한 UTF-16 start/end를 보존하며 Mr/Ms/Dr·기타 약어·소수를 보호한다. 약어가 문장 끝인 경우에는 실제 원문을 확인한 `forcedEnds`가 필요하다. 모든 새 표본에 수동 경계 검토를 요구한다. `syntactic_completeness=not_inferred_from_boundary`를 남겨 짧게 나눈 것만으로 구문·명제 완전성을 주장하지 않는다.

첫 기계 초안은 `source-mechanical-draft.json`과 ignored 초안 입력으로 보존했다. B.C. 끝 경계를 놓친 초안을 폐기하지 않고, 수정 입력·새 binding과 변경 이유를 별도로 기록했다. 확정 개발 입력은 ignored `local/v13/development-input.json`, 감사는 `source-repair.json`, 수동 검토는 `source-review.json`이다. 전부 이미 노출된 개발 문항이며 새 확인 표본이 아니다.

rev4 `workspaces.json`도 읽기 감사했다. 템플릿 9개가 30 TASK·34 relation 카탈로그에 조인되며 끊긴 TASK/relation 참조는 0개다. 파일에 적힌 readiness는 live 3, ready 1, content_needed 4, blocked 1이다. 이는 정적 설계 상태다. 런타임 작동·학생 직접 수행·독립 검증을 확인한 수치가 아니다. 중심 의미 템플릿의 ‘두 지문 정답 → 120일 안 두 연속 재확인’ 같은 기준과 묶음 수량도 학습자 검증을 거친 능력 판정 규칙으로 승격하지 않는다.

검증: `node --test scripts/research/csat-reading/v13-source.test.mjs` 6개 통과. 명칭·소수, 약어 문장 종결, 다중 인용, 블록 문장 수, 요약틀 역할, 후보 중복 정보 유입을 점검했다. 이 검사는 정보 경계 오류를 막는 회귀 검사이며 독해법의 효과 검증이 아니다.

새 선정 표본은 원분모 12개를 그대로 보존했다. 12개 모두 실제 문제 페이지와 동일형 정답표를 직접 시각 대조하고 PDF 바이트 해시·문자층·보기·발문·각주·표시 범위를 확인했다. 모든 파생 단위 94개를 원문과 수동으로 읽었다. 2022#26은 기존 원장의 인접 페이지 노출이 확인되어 신규 독립 분류 입력에서 제외했으며 다른 문항으로 채우지 않았다. 독립 입력은 11문항·84단위·각주 9개다. 제외 문항의 정본 확인 결과는 노출된 개발 입력으로 별도 보존했다.

2014A#32의 그림은 두 축을 쓰는 막대·선 그래프다. 7개 나이 범주와 캐나다 평균 범주, 총 8범주의 16개 인쇄 수치를 24셀로 전사하고 축·범례·제목을 별도 보존했다. 2017#38 삽입 위치 보기 조각, 2021#30 발문 말미 및 밑줄 후보, 2018#28 밑줄 후보, 2019#35 마지막 후보에 혼입된 각주를 복원했다. 2020#36의 제시문·블록 라벨, 2023#40의 본문/요약틀 상자와 대응 열, 원래 배점·발문 밑줄도 분리했다. 문제 PDF는 종전 정본을 사용했으며 공식 거래/버전 계보의 한계가 해소된 것은 아니다.

최초 12행 source 초안과 입력은 각각 `source-pilot-first-admission.json`, ignored `source-pilot-all12-first-input.json`으로 보존했다. 최종 입력에는 11행만 들어가고 공개 `pilot-source.json`은 source 확인 분모 12와 연구 적격 분모 11을 모두 기록한다. `source-pilot-finalization.json`에 두 단계 해시·제외·수동 검토 완료를 남겼다. source 판단자가 접근한 전체 페이지의 인접 문항 ID도 기록하여 다음 표집의 프로젝트 노출 감사에 사용할 수 있게 했다. source 역할의 정답표 접근은 독립 분류자의 정답 비공개와 구분한다. 원문 확인 담당자는 신규 문항의 의미 분류를 작성하지 않았다.
