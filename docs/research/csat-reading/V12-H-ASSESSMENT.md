# H. 직접 확인·평가 명세

2026-10-14 · 문항 요구(L), 관찰 과제 설계(H), 실제 학생 수준을 분리한다. 여기에는 학생 응답·유효 응답 수·채점 일치도·IRT 난도·성취 문턱 자료가 없다. 정성 루브릭도 후보이며, U(근거 부족)는0점이나 결손이 아니다. 도움·노출·독립·전이·지연은 설명 깊이와 별도 축이다.

## V1 · v.core_meaning

목표: 문맥 도움 없이 낱말의 핵심 의미에 접근한다. 본문을 이용한 뜻 추정과 구분한다.

과제 조건: 문맥·뜻 보기 없이 시작; 필요한 접근 지원은 허용하고 종류 기록.

허용 응답/근거: 뜻 또는 자연스러운 동등 표현, 혼동 뜻과의 차이.

루브릭 후보:

- 핵심 의미를 보존함
- 주어진 선택지 재인에만 의존함
- 의미를 회상하지 못하거나 근거 부족

부분·대안 응답: 쓰기 대신 구두 답; 철자 오기로 의미 인출을 실패 처리하지 않는다.

판정 보류: 사전에 뜻이 표시됐거나 풀이가 전제한 문맥 뜻만 반복했으면 V1 독립 확인 보류.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: ASSESSMENT_GAP: 뜻 인출용 미노출 카드와 채점 허용 답 미검수; CONTENT_GAP: shared_dictionary/FSRS 자산 정적 목록만 확인; 재고·권리·현재 도구 실행 재검증 안 함; VERIFICATION_GAP: 실제 학생 인출·지연 유지 자료 없음

## V2 · v.contextual_sense

목표: 낱말의 가능한 뜻 중 현재 문장/필요 문맥에 맞는 뜻을 선택하고 근거를 밝힌다. 이미 주어진 뜻의 담화상 적합성 검사와 구분한다.

과제 조건: 다의어/용법 변화가 실제로 있는 문장; 인쇄 각주 유지; 문장만/앞뒤 포함 두 조건을 각각 기록.

허용 응답/근거: 선택 의미 + 자연스러운 풀어 쓰기 + 근거 단서 + 다른 뜻이 안 되는 이유.

루브릭 후보:

평가 차원: 뜻 후보의 의미 정확성 / 문맥 단서와 선택 뜻 연결 / 대체 뜻의 부적합 설명

- 의미/근거 설명 불완전: 첫 사전 뜻이나 보기만 반복; 단서가 선택 뜻을 구별하지 못함
- 의미와 문맥 단서 연결: 의미를 보존하고 실제 단서로 두 후보를 구별함
- 대체 뜻과 조건 변화 설명: 비교 문맥에서 뜻이 같거나 달라지는 조건을 단서 변경과 연결함

후보 루브릭; 검수·학생 실험 전 공통 수치화 안 함
이 루브릭은 설명 내용의 깊이 후보이다. 도움/독립성·노출/미노출·전이·지연 유지 여부는 별도 축으로 기록하며 같은 수준 이름/공통 점수에 합치지 않는다. 관찰 증거가 부족하면 U(0점 아님)를 별도 기록한다.

부분·대안 응답: 구두 풀어 쓰기로 대체; 단어 선택형 정오와 설명을 별도 보존. 낯선 문법을 완화한 평행 문장도 비교.

판정 보류: 단서가 여러 뜻을 허용하거나 숙어 전체 뜻만 알면 해결되는 경우 V2 단독 관찰 보류; V3/구문 혼입 명시.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: CONCEPT_GAP: 다의어 의미 선택과 담화 어휘 적합성의 세부 매핑 미확정; ASSESSMENT_GAP: 미노출 다의어 평행 문장·루브릭 인간 검수 없음; TRANSFER_GAP/VERIFICATION_GAP: 전이·지연 과제 실사용 기록 없음

평행/전이 과제 조건:

- pool_status: not_yet_assembled_or_human_validated
- source_requirement: 원문·제시형·동일형 정답표·허용 응답·권리·교육 논증 검수 후 사용
- exposure_requirement: 학습자별 예제/힌트/해설/정답 및 동일·공유·정규화 동일 본문 미노출 확인; 연구자 사전학습 미노출은 보장 못 함
- matching: 낱말/가능 뜻과 기본 어휘 지원은 같게 하고 주제·구문 복잡도를 기록한다.
- manipulation: 의미를 선택하게 하는 단서/상황을 변경; 숙어 전체 의미나 구문 난도가 단독 원인이 되지 않는지 검수.
- response: 뜻 후보 선택·풀어 쓰기·단서·배제 이유
- independence: 교사/힌트/모델 답 없이 최초 응답 확정; 도움 조건은 별도 기록
- delayed_condition: 다른 날의 새 과제; 이전 답 기억 재현 제외. 지연 간격/문항 수의 숙달 문턱 미검증

## V3 · v.multiword

목표: 구·숙어·연어를 관습적인 하나의 의미 단위로 구성한다. 구문 경계 표시만으로 의미 성취를 인정하지 않는다.

과제 조건: 표현의 관습 의미가 검수된 문장; 뜻 노출 전 응답.

허용 응답/근거: 표현 구간 + 통합 의미 + 문자 해석과의 차이.

루브릭 후보:

- 경계와 통합 의미 보존
- 문자 해석만 재현
- 용법 변화를 설명할 근거 부족

부분·대안 응답: 구두 뜻 말하기; 단어별 번역 형식 자체는 금지하지 않는다.

판정 보류: 관습 표현 여부가 불분명하거나 V2 용법과 구별되지 않으면 단독 성취 보류.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: CONTENT_GAP: codebook assets 빈 목록; 실제 표현 카드 풀·권리 검수 없음; ASSESSMENT_GAP: V2/S2 구별 문항 미확보; VERIFICATION_GAP: 지연·전이 기록 없음

## V4 · v.semantic_relation

목표: 짧은 표현 사이 유의·반의·상하위·재진술 관계를 의미 차이까지 구별한다. 문장 명제/발문 적합성의 전체 판정을 대신하지 않는다.

과제 조건: 단어·짧은 구 수준과 완성 명제 수준을 구별해 제시.

허용 응답/근거: 관계 분류 + 공통 의미 + 차이.

루브릭 후보:

- 관계와 차이 설명
- 비슷한 단어만 지목
- 명제/과제 판단과 혼합되어 단독 관찰 불가

부분·대안 응답: 그림/우리말 표현 대조 가능; 영어 표현 접근 지원 기록.

판정 보류: 문맥 없이는 동등성이 불명확하거나 문장 범위 변화가 핵심이면 V4 단독 평가 보류.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: ASSESSMENT_GAP: V4-E3 구별 평행쌍 미검수; CONTENT_GAP: assets 빈 목록; 표현 재진술 풀 실행 검증 없음; VERIFICATION_GAP: 실제 전이 확인 없음

## S1 · s.sentence_core

목표: 문장의 주체·주요 서술·필수 대상/보어를 찾아 핵심 명제를 구성할 토대를 밝힌다. 문법 용어 암기를 평가하지 않는다.

과제 조건: 어휘 지원 조건 고정; 수식 정보는 처음부터 원문대로 제공.

허용 응답/근거: 주체·주요 서술·필수 대상 표시 + 짧은 핵심 명제.

루브릭 후보:

- 주체/서술/필수 관계 보존
- 일부 성분은 맞지만 주체 또는 필수 대상 왜곡
- 문법 명칭만 제시되어 명제 관찰 부족

부분·대안 응답: 색 표시 대신 밑줄/구두 관계 설명 가능.

판정 보류: 직역 정오만 있거나 수식어 삭제로 의미가 바뀐 경우 S1 단독 성취 추정 보류.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: ASSESSMENT_GAP: csat_item_units는 경계 자산일 뿐 정답 성분/허용 답 검수 미확인; CONTENT_GAP: 미노출 핵심 문장 풀이 카드 필요; VERIFICATION_GAP: 실제 학생 구조 응답 없음

## S2 · s.chunk_boundary

목표: 구·절·의미 단위가 시작하고 끝나는 경계를 찾아 잘못된 분절을 피한다. 경계의 길이나 개수 자체는 성취가 아니다.

과제 조건: 슬래시 정답이 여러 개 가능한 경우 허용 분절을 미리 검수.

허용 응답/근거: 경계 표시 + 뜻 보존 여부 + 잘못 끊은 곳의 설명.

루브릭 후보:

- 구·절 경계와 의미 보존
- 기호는 비슷하나 절 관계 왜곡
- 여러 허용 분절이 있어 판정 보류

부분·대안 응답: 구간 괄호/구두 분절 가능. slash 위치의 일치만 평가하지 않는다.

판정 보류: 같은 근거·답만으로 S3와 항상 동시 성공이면 독립성 보류; 형식만 다르면 통합 후보를 재검토.

힌트/노출/독립성: 예제·해설·정답·동일/공유/정규화 동일 본문 노출 기록을 먼저 확인한다. 이 감사의 기출 사례는 연구자에게 이미 노출되어 교육 예제로만 쓴다. 학생별 노출은 별도 기록하며 힌트 뒤 재풀이를 독립 확인으로 세지 않는다. 미노출 평행 과제는 어휘·구조·주제/형식을 결속해 새로 검수한 풀에서 선택하고 아직 확보했다고 주장하지 않는다.

지원 공백: CONCEPT_GAP: S2-S3 독립 관찰 미검증; ASSESSMENT_GAP: 경계·부착 교차 구별 과제 없음; VERIFICATION_GAP: 학생 오류 패턴/지연 자료 없음

## S3 · s.attachment

목표: 수식 구·절이 어느 대상/사건을 꾸미는지 연결하고 그 연결이 명제에 미치는 의미를 밝힌다.

과제 조건: 어휘/경계를 고정하고 후보 대상만 달라지는 문장 포함.

허용 응답/근거: 수식어·피수식어 연결 + 대체 연결이 만드는 명제 차이.

루브릭 후보:

- 대상과 명제 차이를 설명
- 경계만 표시
- 복수 부착이 허용되어 단독 판정 부족

부분·대안 응답: 그림/화살표·구두 관계 설명.

판정 보류: 실제 중의성이 남거나 S2 경계 오류가 원인인지 분리 못 하면 단독 결손 보류.

## R5 · r.central_meaning
