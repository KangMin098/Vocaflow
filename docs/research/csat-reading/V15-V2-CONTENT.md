# V2 문맥 의미 교수·직접 확인 후보

분석 버전 주의: 아래 첫 연결은 DB published version3의 내용이다. 별도 [최신 published revision 대조](data/v15/v3-latest-connection.json)에서8행의 최신4~6 revision도 실제 읽었다. 2024#23 최신6 설명은 달라졌으므로 아래 version3의 비교 단서 위험을 최신 설명의 결함으로 전가하지 않는다. 기존 콘텐츠·Gold·첫 원장을 덮지 않았다.

2026-10-14. `v.contextual_sense` / `ws.vocab-context`. v14 revision3의 기존 3활동과 실제 Gold·4facet씩은 그대로 보존했다. 새 overlay의 다른 지문 활동은 **2021#22** 한 개다. 처음부터 source-complete 본시험 개발 자료인 해당 원문 전체와 현재 공개 v3의 실제 필드를 읽었다. v3는 기존 AI 해석이며 공식 출제 기록이나 교육 효과의 근거가 아니다.

새 전이 활동은 본문 단위 s3~s7의 정확한 UTF-16 범위, 행·파일·PDF·동일형 정답표 hash를 결속했다. 첫 후보 생성의 구체 질문·완전/부분/동등/잘못/보류 응답과 4facet은 비공개 `local/v15/content-packages.json`에 보존한다. 원문을 새로 확보하거나 미노출 평가용 지문을 발견했다는 결과가 아니다.

기본 뜻과 문맥 뜻의 연결, 다의 선택, 의미 동등/비동등, 국소·담화 단서, 문맥 조건과 대안 배제는 실제 4활동에서 다룬다. 관용적인 상응 표현과 생산적인 구성의 차이는 2024#34의 완성 후보에서 다루지만 관용어 전체를 포괄하는 자료는 아니다. V1 일반 뜻 인출, V3 다어 구성, V4 의미 관계, S 문장 통합, E3 후보 적합성을 각각 별도 산출물로 둔다. 어휘 유형이라는 이유만으로 원래 문항이 V2를 독립 측정한다고 하지 않는다.

현재 v3의 2024#23 비교 단서만으로 전체 판단을 닫는 주장, 2024#34의 유일 근거·인과 방향 주장, 2016#23의 소망 표현을 현존 여부 확정으로 읽는 주장은 문맥 의미 과제의 Gold를 대체하지 못한다. 해당 필드의 실제 관찰 hash와 위험 기록은 [후보 원장 revision1](./data/v15/content-candidates-revision1.json)에 있다. 첫 원장의 원천 파일명·형과 필요 범위 누락을 새 revision에서 보완했고 원장 첫 bytes와 Gold는 유지했다. v3를 수정하지 않았다.

V2 8종 합성 응답은 기존 직접 확인 활동의 4facet로 첫 판정을 받을 입력이다. 완전·동등·부분·강화·근거 부족·맞는 뜻과 잘못된 설명·복사·모호 응답을 구별한다. 복사된 정확한 글도 의미 충족과 독립 수행 자격을 분리한다. 이는 학생 응답이나 학생 채점 타당도 결과가 아니다.

기존 활동의 AI 교육 명세 검토와 새 활동의 작성자 검토를 구별한다. 현재 공개 적격·직접 평가 적격·학생 관찰·교수 효과 승인은 모두 0이다. 학생별 같은/공유/정규화 동일 본문과 힌트·Gold 노출은 unknown이며, 인간 내용·권리 검수와 실제 응답 독립 채점이 필요하다. [패키지](./data/v15/content-packages.json) · [14개 역할 overlay](./data/v15/content-roles-revision1.json).

독립 내용 QA의 첫 검토는 새 V2 의미 명세를 조건부 수용했지만 대비 자료의 제공 방식과 지도 역할을 수정 요청했다. revision2에서는 두 실제 합성 응답을 학습자 입력 A/B로 제공하고, 판정·해설은 첫 비교 응답 봉인 후 공개하는 별도 hidden feedback으로 분리했다. 지도 연습에는 판단 텍스트 식별 → 두 대상·뜻 가설 → 본문 단서 비교 → 유지/수정 이유의 단계와 각 시도 이후 공개할 구체 힌트를 추가했다. 지도 지원을 받은 수행은 독립 평가 성공으로 계산하지 않는다. 8활동·14역할과 첫 자료·16합성 채점 입력·v14 Gold bytes는 유지했다. [수정 원장](./data/v15/content-revision2.json)의 후속 독립 재검토 상태를 확인해야 하며 자동 통과로 처리하지 않는다.

revision2 재검토에서 첫 4개 내용 수정 요구가 해결됐지만 지도 역할의 Gold 공개 시점과 지원받은 응답의 명칭이 충돌하는 CR-H01이 남았다. [delivery revision3](./data/v15/content-delivery-revision3.json)는 초기 지도 시도 봉인 → 선택적 단계 힌트와 노출 기록 → 후속 지도 시도 → 최종 지도 응답 봉인 → Gold·해설 공개 순서로 통일한다. 질문과 실제 Gold는 바꾸지 않았다. 힌트 지원이 가능한 지도 연습은 assisted guided로 기록하며 무지원·독립 확인으로 이름 붙이지 않는다. revision3 자체의 후속 독립 검토 상태는 별도 원장으로 남긴다.
