# v1.4 교차 유형 공통 수행: 새로운 비교4개

2026-10-14. [등록](./data/v14/principle-registration.json) 뒤 주장·조건·비재현 기록을 만들었다. 선정 중 이미 본문을 읽은 사실을 등록했으므로 새 맹검 표본 사전등록이라고 표현하지 않는다. 기존 개발8문항을 묶은 **새 비교 조합4개**이며 동일 v1.3 비교 재분석0, 신규 독립 문항 확인0이다. 네 비교 모두 서로 다른 수행을 모두 같은 능력으로 축약하는 강한 주장이 성립하지 않았다.

본문·전체 발문·5후보·주어진 문장/블록/위치/빈칸·각주를 직접 읽었다. 기존 로컬 PDF에서 렌더한 **문제8개 및 동일형 정답 행8개 이미지를 이 문맥에서 다시 확인**했다. 새 PDF 다운로드0이며 원본 파일의 공식 다운로드 거래·권리 계보는 계속 미확정이다. [공개 원장](./data/v14/principle-cross-review.json)은 PDF/key/hash·형·쪽·검토 여부만 제공한다. 세부 판단·후보별 설명·정답 관찰값은 ignored private 입력에 결속했다. 정답 일치 자체를 충분성 인증으로 사용하지 않는다.

공개 전 권리 점검으로 미커밋 상세 초안을 별도 공개용 메타데이터 revision으로 대체했다. [redaction manifest](./data/v14/principle-redaction.json)는 원래 상세 JSON·문서·생성코드의 private 보존 hash를 기록한다. 최초 연구 판정을 수정한 것이 아니며 기존 v1.3 원장도 수정하지 않았다.

R5는 주제의 대표 의미 생성 후보지만 빈칸의 완성 명제 판정에서는 지원 역할일 수 있다. E3는 양쪽 후보 대응에 직접 관련하고,R1/R2는 순서·삽입 구조 판정을 지원하는 구체 제약이다. S5는 안내 상한과조건/부정의 범위 구성에,V2는 실제 어휘 용례에 직접 관찰 가능한 과제를 따로 만들 수 있다. 이러한 역할 설명은 실제 학생의 잠재능력 독립성·선수 인과관계·결손·효과를 입증하지 않는다.

이 결과는 R1 수준의 **단일 AI 원문 결속 개발 검토**다. 공통 수행 후보4와 강한 동일전략 비재현4는 서로 양립한다. 일부 국소 경로가 답 식별을 지지해도 FOV를 완료하거나 최저 정보량을 증명한 것은 아니다. 모든문항에같은양의전역통합이필요하다고일반화하지않는다.

이 문맥은 문제지8페이지의 인접 문항 및6개 연도/형 정답표 전체를 보았으며 노출 원장에 기록했다. 독립 첫분류 문맥으로 재사용하지 않는다. 교수 설명·최소 대조 과제의 설계 근거로 참고할 수 있으나 콘텐츠 공개검수·직접 채점 자격·학생 미노출 확인·전이/지연 관찰·교수 효과는 각각 별도다. 제품 자동 NeedRank/숙달 판정에 사용하지 않는다.
