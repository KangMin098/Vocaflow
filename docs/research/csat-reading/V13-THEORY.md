# v1.3 이론 연결과 적용 한계

기존 [SOURCES](./SOURCES.md)의 접근수준·미확보를 보존한다. 이론은 원문 분석과 교육 과제의 구조를 설명하는 근거이고, Vocaflow TASK의 독립성이나 교수 효과를 대신 검증하지 않는다.

2026-10-14 추가 확인: Hansen(2011) *Evidence-Centered Design for Learning*, ETS RM-11-02의 공개 초록은 학생·증거·과제 모델에 교수 모델을 추가하는 설계를 제시한다. 전체59쪽 정독은 수행하지 않았다. 이번14필드 교육계약은 그 구별을 따른 설계 추론이며, 수능/한국학생의 방법별 효과 결과가 아니다. [ETS 원출처](https://www.ets.org/research/policy_research_reports/publications/report/2011/imbu.html).

NRC(2001), *Knowing What Students Know* 2장 assessment triangle 절을 직접 확인했다. 인지·관찰·해석의 연결을 요구하는 일반 평가 설계 근거로 사용한다. 본문에서 확인한 원리는 기출 정답만으로 세부 TASK 수행을 관찰했다고 할 수 없다는 이번 설계의 근거이며, 30 TASK 분류의 심리측정적 승인은 아니다. [National Academies 2장](https://www.nationalacademies.org/read/10019/chapter/4).

IES/WWC(2007), *Organizing Instruction and Study to Improve Student Learning* 공식 권고 페이지를 확인했다. 예제와 문제풀이 교대·간격 학습·설명 질문 등의 일반 설계 후보를 참고한다. 대상은 내용 학습을 요구하는 다양한 교과이며, 권고마다 근거 강도가 다르다. 이 페이지를 한국 수능 독해의 최적 교수법/학습량/성적 상승으로 옮기지 않는다. [IES 권고](https://ies.ed.gov/ncee/wwc/practiceguide/1).

구성–통합/상황모형은 의미 구성과 통합의 설명틀, L2 읽기 요인 연구는 어휘·문법·읽기의 관련성을 설명한다. 어떤 모델도 모든 문항에 같은 양의 전역추론이 필수라는 결론이나 어휘→구문→담화의 고정 교수 순서를 자동 제공하지 않는다. 기존 담화관계/구조지도/ECD/평가원 공식안내/국내 연구의 출처와 접근 한계는 SOURCES 정본을 따른다. 새 국내 실증·강사 방법별 비교실험을 이번에 확보했다고 주장하지 않는다.

추론 코드의 v1.3 세분화는 이론을 그대로 측정척도로 복제한 것이 아니라 기출에서 빠진 정보와 도출을 추적하기 위한 조작적 코드다. 관계 제거검사 역시 공식 출제기록이나 학생 사고과정이 아닌 연구자의 논리 재구성이다. 실제 학생 응답·독립 전문가 채점·도구 타당성·전이/지연 관찰은 별도 연구가 필요하다.
