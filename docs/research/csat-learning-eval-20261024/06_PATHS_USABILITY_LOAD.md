# 06 학습 경로별 평가 + 사용성·인지 부담 평가 설계 (E6)

> 상태: 설계 문서. 실제 학습자 데이터는 없다. 이 문서의 모든 효과·사용성 판정은 **NOT_EVALUATED** 이다.
> 범위: PC 웹만(모바일 제외). 모든 계측 화면은 키보드만으로 조작할 수 있어야 한다.
> 공통 계약: 수준 U0–U5(RECALL · MEANING · EVIDENCE_LINK · DISTRACTOR_FAILURE · PRINCIPLE_CONDITIONS · TRANSFER), NOT_EVALUATED, UNKNOWN. 노출 X0–X3 / X_UNKNOWN. 경로 FREE · EXPLANATION_FIRST · LECTURE_FIRST — 어느 경로도 틀린 경로로 보거나 불이익을 주지 않는다.
> 출처(읽기 전용): Vocaflow-main-serving 의 DESIGN.md · docs/LEARNING_MODEL.md · docs/csat-learner/ · components/csat/, G1 @810a463ac(04_UI_MODELS_UX · 10_LECTURE_DESIGN · 17_LEARNER_CONTROL_GATE), S1 skeleton-v4/s1-integration. 이 문서는 그 정본을 바꾸지 않는다.

## 1. 원칙

1. **최종 능력 기준은 하나다.** 세 경로 모두 같은 사후 문항·전이 문항·채점 기준(루브릭)으로 판정한다. 경로마다 다른 기준을 쓰지 않는다.
2. **보조 확인과 독립 확인을 나눈다.** 학습 화면 안에서 해설·강의·힌트를 볼 수 있는 상태의 응답은 *보조 확인(assisted check)* 이고 숙달 판정에 넣지 않는다. 숙달 판정은 학습 자료를 본 적 없는 *새 문항*의 독립 응답(independent new-item check)으로만 한다.
3. **클릭·펼치기·시청은 숙달이 아니다.** 해설 펼침, 강의 재생, 다음 버튼은 노출(X) 기록일 뿐 U 수준에 들어가지 않는다(2026-10-23 제품 지시).
4. **노출 차이는 벌하지 않고 통제한다.** 노출이 많은 경로(특히 LECTURE_FIRST)는 같은 문항을 다시 보면 유리하므로, 판정은 노출되지 않은 다른 문항으로만 한다. 노출량 자체로 점수를 깎지 않는다.
5. **사용성·인지 부담 척도는 학습을 재지 않는다.** 아래 §5 의 어떤 척도도 학습 효과·숙달·전이의 증거가 아니다.

## 2. 경로별 평가 계획

| 항목 | FREE | EXPLANATION_FIRST | LECTURE_FIRST |
|---|---|---|---|
| 진입 | 문항부터 풀고 원하면 해설·강의 | 구조 해설을 먼저 보고 문항 | 강의(영상·대본)를 먼저 보고 문항 |
| 기록(로그) | 첫 응답(보조 전), 자료 열람 순서·시점, 재응답, 근거 선택 | 해설 단계별 노출 시점, 해설 안 판단 과제 응답, 첫 문항 응답 | 강의 구간 재생 범위(초 단위), 일시정지·되감기, 강의 안 판단 과제 응답, 첫 문항 응답 |
| 노출 등급 | 열람 범위로 X0–X3 산정 | 기본 X2 이상, 실제 열람으로 확정 | 기본 X3 후보, 재생 범위로 확정. 재생 로그 없으면 X_UNKNOWN |
| 보조 확인 위치 | 해설·강의를 연 뒤의 재응답 | 해설 안의 판단 과제, 해설 직후 같은 문항 | 강의 안의 판단 과제, 강의 직후 같은 문항 |
| 독립 확인 위치 | 세션 종료 후 새 문항 세트(같은 유형·다른 지문) | 같음 | 같음 |
| 지연 확인 | 일정 기간 뒤 새 문항 + 전이 문항(다른 유형 조건) | 같음 | 같음 |

- 로그 필드는 E 계열 공통 스키마를 따른다고 가정한다. 이 문서는 필드를 새로 정하지 않고, 경로를 구분하는 값(`path`)과 노출 등급(`exposure`)이 모든 응답에 붙어야 한다는 것만 요구한다.
- 경로 전환(예: FREE 중 강의 시청)은 허용하고, 응답마다 그 시점의 실제 노출을 기록한다. 시작 경로 라벨만으로 분석하지 않는다(의도 분석 + 실제 노출 분석 둘 다).

## 3. 공통 최종 능력 기준

- **같은 문항 풀**: 사후·지연·전이 문항은 어떤 경로의 학습 화면에도 나오지 않은 문항이다. 문항별 "학습 화면 노출 여부"를 문항 메타에 두고, 노출된 문항이 판정 세트에 섞이면 그 응답은 UNKNOWN 으로 뺀다.
- **같은 루브릭**: U0–U5 판정은 객관식 정답 + 근거 선택(지문 위치 지목) + 오답 원인 선택 + 조건 선택처럼 닫힌 응답으로만 한다. 자유서술·개인 임의 자료는 평가하지 않는다(제품 지시).
- **판정 단위**: 수준별로 "독립 새 문항에서 기준 통과"만 그 수준 달성으로 센다. 보조 확인 통과는 별도 열(assisted_pass)로만 남긴다.
- **결측**: 독립 확인을 하지 않은 학습자는 NOT_EVALUATED. 0점으로 넣지 않는다.

## 4. 공정성 분석

| 설계 선택 | 불리해질 수 있는 경로 | 이유 | 완화 |
|---|---|---|---|
| 같은 문항 재사용 판정 | FREE·EXPLANATION_FIRST 상대적 불리 | LECTURE_FIRST 는 강의에서 같은 문항 해설을 미리 봄 | 판정은 노출 안 된 다른 문항만. 같은 문항은 보조 확인 열로만 |
| 첫 응답 정답률 비교 | LECTURE_FIRST·EXPLANATION_FIRST 가 유리, FREE 가 "못한다"로 보임 | FREE 는 자료 없이 먼저 품 | 첫 응답은 경로 간 비교 지표로 쓰지 않음. 경로 내 기록만 |
| 소요 시간 지표 | LECTURE_FIRST 불리 | 강의 시간이 들어감 | 학습 단계 시간과 독립 확인 응답 시간을 분리. 시간은 효율 해석 금지, 부담 참고치로만 |
| 해설·강의 열람을 "도움 의존"으로 해석 | EXPLANATION_FIRST·LECTURE_FIRST 불리 | 자료 사용이 약점처럼 보임 | 열람은 노출 기록일 뿐 감점·낙인 없음. 화면 문구도 중립 |
| 인지 부담 척도 시점 | LECTURE_FIRST 가 "부담 높음"으로 보일 수 있음 | 긴 단계 직후 측정 | 모든 경로에서 같은 사건(독립 확인 직후) 기준으로도 측정 |
| 사용성 척도(SUS) | 경로마다 본 화면이 다름 | 다른 화면을 하나의 점수로 비교 | 경로별 점수는 그 경로 화면 묶음의 평가로만 보고, 경로 우열 근거로 쓰지 않음 |
| 자기 선택 편향 | 전부 | 학습자가 경로를 고르면 능력 차가 경로 차로 보임 | 사전 수준(사전 문항) 기록, 가능하면 무작위 배정 조건을 별도로 둠. 자기 선택 데이터는 기술 통계만 |
| 키보드 접근 | 강의 플레이어가 키보드 조작이 어려우면 LECTURE_FIRST 불리 | 조작 실패가 부담·시간으로 섞임 | 모든 경로 계측 화면 키보드 점검을 평가 전 선결 조건으로 |

어느 도구도 **학습을 측정하지 않는다.** 결과는 "부담이 어떻게 느껴졌는가 / 화면이 쓰기 쉬웠는가"의 자기 보고이며 U 수준 판정과 섞지 않는다.

### 5.1 주의 사항

- **번역 상태**: 위 척도의 한국어판은 이 작업에서 타당화 출처를 확인하지 않았다. 모두 UNVERIFIED 이며, 사용 전 출처가 있는 한국어판을 찾거나 번역·역번역·소규모 인지 면담을 거친다. 확인 전에는 결과를 다른 연구와 비교하지 않는다.
- **시간 지표**: 길다 = 부담 크다 / 짧다 = 잘한다 로 해석하지 않는다. 자리 비움·탭 전환·재생 속도·키보드 조작 실패가 섞인다. 비활성 구간(예: 입력·포커스 이벤트 없는 구간)을 따로 표시하고 중앙값·분포로만 본다. 경로 간 효율 비교에 쓰지 않는다(§4).
- **NASA-TLX 신체적 요구**: PC 웹 학습에서는 의미가 작지만 원 척도 보존을 위해 뺄지 여부를 사전에 고정한다(뺐다면 "수정판"으로 표기).
- **사고 발화**: 발화 자체가 부담·수행을 바꾼다(반응성). 사고 발화 세션의 응답은 학습 판정 데이터에서 분리한다. 발화 내용은 사용성·설계 진단에만 쓰고, 자유서술 채점으로 쓰지 않는다.
- **측정 피로**: 척도가 많으면 그 자체가 부담이 된다. 한 세션에 PAAS_ME(최대 2회) + SEQ(최대 3회) + 종료 시 NASA_TLX_RAW·SUS 를 넘기지 않는다.
- **접근성**: 모든 척도 입력은 라디오 그룹/슬라이더에 보이는 레이블과 포커스 표시를 갖고 키보드(Tab·화살표·Enter)로 답할 수 있어야 한다. 색만으로 척도 값을 표시하지 않는다.

### 5.2 연구 질문과의 연결

| RQ | 질문 | 도구 | 해석 한계 |
|---|---|---|---|
| RQ-L1 | 경로·단계마다 체감 노력이 어떻게 다른가 | PAAS_ME | 노력 ≠ 학습. 높은 노력은 바람직한 어려움일 수도 과부하일 수도 있음 |
| RQ-L2 | 부담이 어떤 성분에서 오는가 | NASA_TLX_RAW | 세션 전체 회상이라 단계 구분 약함 |
| RQ-L3 | 부담 보조 신호가 자기 보고와 맞는가 | TIMING | 시간만으로 부담 판정 금지 |
| RQ-U1 | 경로별 화면 묶음이 쓰기 쉬운가 | SUS | 경로 우열 근거 아님 |
| RQ-U2 | 판단 유발 상호작용(근거 지목·조건 조작)이 조작상 어렵지 않은가 | SEQ | 쉬움 ≠ 효과 |
| RQ-U3 | 화면이 실제로 시선·생각·판단을 유발하는가(텍스트 덤프로 읽히지 않는가) | THINK_ALOUD | 소수 질적 자료, 일반화 금지 |

## 6. 판정 상태

- 경로별 학습 효과: **NOT_EVALUATED** (실제 학습자 없음)
- 사용성·인지 부담: **NOT_EVALUATED** (실제 학습자 없음)
- 한국어 척도 타당성: **UNVERIFIED**
- 합성 학습자·에이전트 역할극 결과는 위 판정을 바꾸지 않는다. 도구 작동 점검(입력·로그·키보드)에만 쓴다.
