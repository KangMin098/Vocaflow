# 04 · 다른 기출 전이 평가 계약 (E4)

> 범위: 평가 환경 계약. 효과 주장 없음. 데이터 창작 없음. 후보 목록·게이트 결과는 `transfer/candidates.json`(2026-10-24 DB SELECT 전용, 쓰기 없음).

## 1. 정의

| 구분 | 정의 | 측정 수준 |
|---|---|---|
| 근전이(near) | 같은 유형(type_id)·같은 원리 계열, 다른 지문·다른 소재 | U2 EVIDENCE_LINK ~ U4 PRINCIPLE_CONDITIONS |
| 원전이(far) | 같은 원리가 **다른 유형** 또는 다른 시험 구성(학평↔평가원)에서 쓰이는 문항 | U5 TRANSFER |
| 표면만 같은 문항 | 소재·어휘가 비슷하나 원리가 다름 | 전이 문항 아님(방해 대조로만 사용 가능, 평가 산입 금지) |

**동일 원리·다른 표면 규칙**: 전이 문항은 (a) 원리 계열이 기준 문항과 같다는 판정이 분석 정본에 기록되어 있고, (b) 지문 주제·핵심 어휘·정답 위치 패턴이 기준 문항과 겹치지 않아야 한다. type_id 일치는 필요조건일 뿐 원리 동일 판정이 아니다.
**2026-34 주의**: 34번의 「조건 명제 판정」은 그 문항의 분석 결과이며, R-BLANK 전체의 원리로 일반화하지 않는다. 34 전이 후보는 원리 판정을 별도로 받아야 한다.

## 2. 문항 적격 게이트 (전부 PASS 일 때만 eligible)

| 게이트 | PASS 조건 | 근거 위치 |
|---|---|---|
| original | 공식 원문(평가원/교육청 PDF)과 본문·선택지 대조 기록 | 대조 기록(해시·revision) — `body_ok` 플래그만으로는 UNKNOWN |
| answer | 정답이 공식 정답표와 일치 | `csat_items.answer` + `csat_exams.has_answer_key` (공식표 재대조 권장) |
| rights | 학습자 화면 노출·평가 사용 권리 확인 | 현재 csat 테이블에 권리 필드 없음 → UNKNOWN. `evaluateSource` 는 원문 적격 판정이며 권리 증거로 대체하지 않는다 |
| version | 분석 버전(UUID·본문 해시·revision) 고정 | 분석 정본 revision |
| unseen | 해당 학습자가 이전에 보지 않음(X0) | 학습기록·노출 로그. X_UNKNOWN 이면 FAIL 처리 |

UNKNOWN 이 하나라도 있으면 `eligible=false`. 검증 안 된 비교 문항은 전이 평가에 쓰지 않는다.

## 3. 금지

- 학습한 문항(기준 문항 포함)을 전이 문항으로 재사용.
- AI 가 만든 변형·유사 문항을 「실제 기출」로 표시·산입. 변형은 연습용으로만, 별도 표기.
- 탐색·클릭·자유서술을 숙달 점수에 산입.
- 결과로 학습 효과를 주장(학습자 검증 전).

## 4. 기억 효과 통제 — A/B 양식 역균형

- 사전·사후에 **서로 다른 동등 문항**을 쓴다. 각 원리 계열마다 적격 문항 2개 이상(A·B)이 필요.
- 동등성: 같은 type_id·원리 계열, 공식 오답률(`official_error_rate`)이 있으면 근접한 쌍, 배점 동일.
- 역균형: 학습자를 무작위 두 집단으로 — 집단1 사전 A/사후 B, 집단2 사전 B/사후 A. 양식 효과를 집단 간 비교로 분리.
- 경로(FREE/EXPLANATION_FIRST/LECTURE_FIRST)별로 같은 양식 배정 비율 유지.
- 사후 문항은 학습 중 노출 금지(X0 유지 확인).

## 5. 현재 후보 결과 (2026-10-24)

기준: 2026학년도 수능(exam_id `2026`) 22(R-GIST) · 34(R-BLANK) · 38(R-INSERT). 후보는 같은 type_id 의 평가원 문항(2025 수능, 2025/2026 6·9월 모평, 2027 6월 모평).

| 기준 | 후보 수 | eligible | 공통 상태 |
|---|---|---|---|
| 2026#22 | 5 | 0 | answer PASS · original/rights/version/unseen UNKNOWN |
| 2026#34 | 6 | 0 | 동일 · 원리 동일 판정 없음 |
| 2026#38 | 6 | 0 | 동일 |
| 합계 | 17 | **0** | |

원전이(다른 유형) 후보는 원리 계열 판정 정본이 없어 제안하지 않았다.

## 6. 적격으로 바꾸려면 필요한 것

1. 후보별 공식 PDF 대조 기록(original).
2. 기출 문항 학습자 노출·평가 사용 권리 확인과 그것을 담을 필드 또는 기록 — 사용자 결정 필요(DB 변경 시 승인 L4).
3. 후보별 분석 버전 고정(revision·해시) 및 원리 계열 동일 판정.
4. 학습자 노출 이력(X0) 확인 경로.
