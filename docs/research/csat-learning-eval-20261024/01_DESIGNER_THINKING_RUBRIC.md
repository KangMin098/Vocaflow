# 01 · 출제 사고 이해 평가 루브릭 (E1)

> 2026-10-24 · 대량작업 E 하위 E1 · 읽기 전용 조사. 기계 판독본: [rubric/levels.json](./rubric/levels.json)(`e1-rubric-20261024.1`). E7 scorer 는 이 파일의 code 만 쓴다.
> 근거: G1 수락 커밋 `810a463ac` 의 `05_TYPE_B_GIST.md` · `06_TYPE_C_BLANK_INFERENCE.md` · `07_TYPE_D_DISCOURSE.md` · `02_CONTENT_CONFLICTS.md`. DB 는 이번 작업에서 직접 다시 묻지 않았다(G1 이 DB SELECT 로 확인한 사실을 인용).
> 이 루브릭은 **측정 틀**이다. 학습 효과를 주장하지 않는다. 실제 학습자 결과 = **NOT_EVALUATED**.

## 0. 공통 규칙

1. **서열**: U0 RECALL < U1 MEANING < U2 EVIDENCE_LINK < U3 DISTRACTOR_FAILURE < U4 PRINCIPLE_CONDITIONS < U5 TRANSFER. 특수값 `NOT_EVALUATED`(증거 없음) · `UNKNOWN`(기록 손상·모호).
2. **단조 부여**: Uk 는 그 아래 수준의 최소 증거가 같은 문항·같은 시도에서 충족될 때만 준다. U5 만 예외(앵커 U4 + 전이 문항 U2 이상).
3. **노출 상한**: X0 → 상한 없음 · X1 → 상한 없음, 단 cue 가 가리킨 판단 단계는 ASSISTED_ONLY · X2 → 독립 상한 U1 · X3 → 독립 상한 U0, 이후 같은 문항 증거는 모두 ASSISTED_ONLY · X_UNKNOWN → independence=UNKNOWN.
4. **절대 상위 수준을 주지 않는 신호**: 클릭·이동·체류 시간·강의 재생/완료·해설 열기·스크롤. 이것들은 노출(X) 기록에만 쓴다.
5. **닫힌 응답만 채점**: 선지·문장 번호·구간·판정 칸·관계 유형 보기. 자유서술·개인 자료는 채점하지 않는다.
6. **키 결함**: 판정 키가 NOT_VERIFIED 인 칸은 award 에 쓰지 않는다(그 칸 결과는 기록만). AI 평가자 여럿이 일치해도 키 검증을 대신하지 않는다.
7. **경로 중립**: FREE · EXPLANATION_FIRST · LECTURE_FIRST 어느 경로도 틀리지 않다. 경로는 수준이 아니라 노출 기록에 반영된다(해설·강의를 먼저 보면 그 뒤 판단은 대부분 X2/X3 → ASSISTED_ONLY).

## 1. 수준별 정의 · 증거 · 함정

### U0 RECALL — 정답·해설 기억
- **정의**: 정답 번호나 해설 문장을 재현한다. 이해 여부와 무관하다.
- **증거**: `EV-U0-a` 정답 선지 선택 · `EV-U0-b` 해설/강의 문구 재인.
- **최소 증거**: 둘 중 하나.
- **함정**: `TR-U0-1` 정답 일치를 이해로 읽기(찍기·기억과 구분 불가).
- **과제 형식**: 선지 선택만.

### U1 MEANING — 핵심 의미
- **정의**: 핵심 문장·표현의 의미를 지문 범위 안에서 식별한다.
- **증거**: `EV-U1-a` 해설과 **다른 표면형**의 의미 보기에서 정답 · `EV-U1-b` 한정어·조건·부정을 포함한 의미 선택 · `EV-U1-c` 과잉일반화·주체 역전 보기 기각.
- **최소 증거**: a + (b 또는 c).
- **함정**: `TR-U1-1` 해설과 같은 표면형 보기 선택 = U0 · `TR-U1-2` 낱말 뜻만 맞히고 한정자 무시.
- **과제 형식**: 의미 재진술 보기 선택.

### U2 EVIDENCE_LINK — 근거↔선지 관계
- **정의**: 판단을 정하는 지문 근거(문장/구간)와 선지의 관계를 스스로 지정한다.
- **증거**: `EV-U2-a` 결정 근거 구간 선택(키 구간 또는 승인된 허용 구간) · `EV-U2-b` 근거–선지 관계 유형 지정(재진술·귀결·요구–공급 등) · `EV-U2-c` 어휘만 겹치는 미끼 구간을 근거로 쓰지 않음.
- **최소 증거**: a + b. c 실패가 동반되면 a 의 일치를 우연으로 보고 기각(`TR-U2-3`).
- **함정**: `TR-U2-1` **해설을 바꿔 말하기 = U0**(근거 지정이 아니다) · `TR-U2-2` 하이라이트·강의가 근거를 이미 표시한 뒤의 선택 = ASSISTED_ONLY · `TR-U2-3` 어휘 겹침 우연 일치 · `TR-U2-4` 키 구간이 너무 좁게 저장됨(2026-38).
- **과제 형식**: 근거 구간 선택, 선택+근거.

### U3 DISTRACTOR_FAILURE — 오답의 실패 조건
- **정의**: 매력 오답이 어떤 논리 조건에서 실패하는지 지정한다.
- **증거**: `EV-U3-a` 오답별 실패 조건 보기 선택(매력 오답 ≥1) · `EV-U3-b` 진위(content_truth: true/false/unknown)와 요구 충족(requirement_fit: fits/fails) 이원 판정 · `EV-U3-c` 진위 미확정 선지를 거짓으로 단정하지 않음 · `EV-U3-d` 매력 오답의 실패 근거 구간.
- **최소 증거**: a + (b 또는 d).
- **함정**: `TR-U3-1` 「정답이 아니라서」 순환 사유 · `TR-U3-2` unknown 을 false 로 단정했는데 키가 false 로 잘못 저장돼 통과 · `TR-U3-3` 독립 승인 없는 실패 키로 award · `TR-U3-4` 약한 오답만 기각.
- **과제 형식**: 오답 실패 조건 고르기, 이원 판정 격자.

### U4 PRINCIPLE_CONDITIONS — 원리의 적용 조건·예외
- **정의**: 출제 원리를 적용 조건(when_applies)과 예외(when_not)까지 구분한다.
- **증거**: `EV-U4-a` 조건 조작 변형(한정어·부정·표지·위치를 바꿈)에서 판단이 바르게 바뀌거나 유지됨 — 최소 2개 변형, 바뀌는 쪽·유지되는 쪽 각 1 이상 · `EV-U4-b` 비적용 사례 식별 · `EV-U4-c` 과잉일반화 원리 진술 기각.
- **최소 증거**: a + (b 또는 c).
- **함정**: `TR-U4-1` 원리 문장 암기 = U0 · `TR-U4-2` 변형 하나만 맞힘 · `TR-U4-3` 변형이 원 문항과 표면이 같아 기억으로 풀림 · `TR-U4-4` 변형 지문·키 미검수.
- **과제 형식**: 조건 조작.

### U5 TRANSFER — 다른 실제 기출
- **정의**: 같은 사고 구조이되 표면이 다른 **실제 기출**에서 노출 없이 판단한다.
- **증거**: `EV-U5-a` 승인된 짝 문항에서 X0 정답 + U2 수준 근거 지정 · `EV-U5-b` 짝 문항에서 U3 수준 실패 조건 지정 · `EV-U5-c` 구조가 다른 반례 문항에 원리를 잘못 적용하지 않음.
- **최소 증거**: a + (b 또는 c), 앵커 U4 선행, **승인된 실제 짝 필요** — 짝이 0개면 NOT_EVALUATED.
- **함정**: `TR-U5-1` 노출 이력 있는 문항 · `TR-U5-2` 짝 0/미승인인데 임의 문항으로 판정 · `TR-U5-3` 합성·변형 문항을 전이로 계산 · `TR-U5-4` 표면 유형만 같은 다른 구조(34 조건문 → 31 인과).
- **과제 형식**: 새 실제 기출.

## 3. 문항별·수준별 오판 가능성

| 수준 | 2026-34 | 2026-22 | 2026-38 |
|---|---|---|---|
| U0 | 강의 cue c4·c5 가 「정답은 삼 번」을 직접 말함(CC-05) → 강의 뒤 정답은 X3 | c5 직접 누설(CC-05) | c4 직접 누설(CC-05), c1 위치 규칙 간접 누설(CC-06) |
| U1 | `cannot be X` 를 「X 의 반대말」로 고르는 공식 적용이 우연히 정답 의미와 겹침 | coopetition 정의만 맞히고 처방 의미를 놓쳐도 U1-a 통과 가능 | `these` 를 「바로 앞 한 문장」으로 읽어도 의미 보기가 맞을 수 있음 |
| U2 | 근거 구간이 짧아(약 2문장, R-BLANK 경향) 무작위 구간 선택의 우연 일치율이 높음 → c 미끼 필수 | 7번(진단) 선택을 근거로 오인 — 본문에 참이라 「틀린 근거」 판정이 학습자에게 납득되지 않을 수 있음 | **키 결함**: 원 decisive 는 these 범위를 6~7로 좁게 묶음(CC-01, P1) → 4~7 을 고른 학습자를 틀렸다고 처리할 위험. C1 후보 미승인 상태에서는 범위 칸을 award 에 쓰지 않는다 |
| U3 | ② 키가 강의 c7·c10 에서 거짓처럼 전달됨(CC-02) → 「false」 를 고른 학습자를 정답 처리할 위험(TR-U3-2). ④⑤ 키 NOT_VERIFIED | ③ truth=true 키 자체가 NOT_VERIFIED(CC-09) → truth 축 채점 보류, fit 축만 | ③ 위치 실패의 강도 미확정 → ③ 은 「보류」 허용, ④ 만 award 대상 |
| U4 | 「부정어 뒤 빈칸 = 지문이 거부하는 견해」 과잉일반화가 강의 c1·c12 에 있음(CC-03) → 그 문장을 재인한 학습자가 U4-c 를 반대로 판정할 위험 | 변형에서 처방 위치를 옮기면 표면 규칙 학습자도 우연히 맞힐 수 있음 → 변형 2개 이상 | 「짝 없는 예시 앞 = 자리」 과잉일반화(CC-04) |
| U5 | 짝 0개 — 판정 자체 불가 | 짝 승인 전 판정 금지 | 짝 승인 전 판정 금지. DB 2026#38 `choices` 에 본문 조각·각주 혼입(CC-07) → 이 문항 선지 표시 데이터로 채점하지 않는다 |
