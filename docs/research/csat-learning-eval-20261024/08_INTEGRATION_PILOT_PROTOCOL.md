# 08 · 결과 통합 · 학습 전후 분석 방법 · 파일럿 연구 프로토콜 (E8)

> 이 문서는 학습 효과를 주장하지 않는다. **실제 학습자 결과: NOT_EVALUATED.** 아래 프로토콜은 실행 조건이 모두 갖춰지기 전에는 모집·실험을 시작하지 않는다.

## 2. 통합 중 발견·정정한 결함

1. **노출 지도 무시(정정)** — 도구가 E5 지도 형식(`when`/`exposure`)을 읽지 못해 12개 규칙을 전부 버리고 있었다. 형식을 지원하고, 해석 실패 시 오류를 내도록 고쳤다. 회귀 테스트 추가.
2. **최소 근거 무시(정정)** — 수준 제안이 E1 `min_evidence{all_of, any_of}` 를 무시하고 코드 1개로 수준을 부여했다(예: `EV-U2-a` 하나로 U2). 수준 과대 부여 방향의 오류다. 고치고 회귀 테스트 추가.
3. **코드 연결 형식(기록)** — E2 유형 코드의 parent 는 개별 코드가 아니라 수준 와일드카드(`EV-U2-*`)다. 도구는 접두 `EV-U<n>-` 로 수준을 읽으므로 동작에 문제가 없다. 다만 유형 코드가 E1 의 `all_of` 를 대신 채우지는 않는다 — 유형별 채점은 유형 코드를 E1 개별 코드로 사상하는 표(gold 와 함께)가 만들어진 뒤에만 한다.
4. **E6 의 출처 미독해(기록)** — E6 은 G1·S1·제품 코드를 읽지 않고 작성됐다. 06 의 로그 필드명은 05(P6 실제 컬럼)를 정본으로 따른다. 도구 출처는 원문 대조 전(UNVERIFIED).

## 3. 학습 경로와 단계 — 공통 설계

단계: `PRE`(학습 전, 노출 X0 확인) → 학습(FREE / EXPLANATION_FIRST / LECTURE_FIRST 중 학습자 선택) → `POST_ASSISTED_CHECK`(해설·강의 안 확인, **숙달 산입 안 함**) → `POST_INDEPENDENT`(학습 화면에 나오지 않은 동등 문항) → `TRANSFER`(04 게이트 통과 실제 기출, 지연 1주 이상 권장).

- 세 경로는 같은 POST_INDEPENDENT·TRANSFER 문항과 같은 닫힌 응답 루브릭으로 평가한다(06 §3). 경로 사이 우열을 이 설계로 결론 내지 않는다 — 경로는 학습자 선택(무작위 배정 아님)이라 자기 선택 편향이 있다.
- 강의 우선 경로는 노출이 많다는 이유로 감점하지 않는다. 노출이 있었던 문항은 그 학습자에게 ASSISTED_ONLY 일 뿐, 다른 문항에서 독립 수행으로 평가한다.
- 기억 효과 통제: PRE 와 POST 는 같은 원리·다른 문항의 A/B 양식, 학습자 절반씩 역균형(04 §4). 학습한 문항은 POST_INDEPENDENT·TRANSFER 에 다시 쓰지 않는다.

## 4. 학습 전후 분석 방법

1. `validate` → 거부 0 확인. `check` → 결측·버전 불일치·근거 추적 보고를 결과와 함께 낸다.
2. 평가자: 최소 사람 1명 + 다른 평가자 1명(사람 또는 AI). 서로 판정을 보지 않는다. `agree` 로 κ_w·α 와 95% CI, 제외 수 보고. **채택 기준(사전 등록 제안값): 이차 가중 κ ≥ 0.70 이고 CI 하한 ≥ 0.60.** 미달이면 루브릭을 고치고 다시 판정한다 — 결과 분석으로 넘어가지 않는다.
3. 불일치: `review-html` 로 사람이 adjudication. 이의 사례(학습자·평가자 제기)는 원문·정답 키 대조로만 판단하고, AI 다수결로 확정하지 않는다.
4. `compare`(기본 독립 자격만): 학습자별 PRE→POST_INDEPENDENT→TRANSFER 수준 전이표, 경로별 집계. 결측·UNKNOWN 은 대체하지 않고 따로 센다. 효과 크기는 짝 비교 서열 통계(예: 부호 검정 / Wilcoxon 부호순위)와 전이 비율로만 보고하고, 표본이 작으면 기술 통계까지만.
5. 해석 한계를 결과와 같은 쪽에 적는다: 단일 기관·소표본·자기 선택·문항 수 제한·평가자 훈련 효과·외부 노출 미관측.
