# 用途별 자격

자료 역할 후보와 실제 사용할 수 있는 역할은 다르다. [실행 계약](FQ1-CONTRACT.md)은 A–H·승인·학습자·역할 조건을 따로 검사한다. 연구의 실제 공개 및 직접 평가 승인 수는0이다.

| 역할 | 필요한 추가 조건 | 혼동 방지 |
|---|---|---|
| 원문 분석 / 모델 설명 | 정확한원천·의미·TASK·교수 목적·사용권리·실행, Gold를 제공하면E도필수 | 공개되어있다는이유로인간내용/권리 검수를가정하지않음 |
| 지도 연습 | 실제 입력/단계/힌트기록·부분응답·최종지도응답 봉인 뒤Gold | 도움을받은산출물을무도움확인으로변환하지않음 |
| 독립 확인 | 검증된Gold/rubric·인간/실제응답채점·학생미노출·무도움·첫봉인 | 맞는설명복사와의미질은분리;단순문항정답률은숙달이아님 |
| 다른 글 적용 | 다른학습본문/공유/정규화동일본문 제외·동일수행·노출/힌트/평가조건 | 후보가다른ID라는것과독립전이는다름 |
| 지연 확인 | 실제경과·중간재노출/학습/해설/도움 기록·재인vs새수행 분리 | 정해진예시간격이나다른날미노출목록만으로지연수행관찰완료라고하지않음 |

unknown 또는 필수축 not_applicable은 공급 허용이 아니다. 연구용 승인 true 플래그만으로 법적·인간 승인 기록을 만들지 않는다. 대상ID/revision/hash가 맞고 권한 있는 실제 원장에서 검증된 승인 참조가 추가되어야 한다. 그 입력의 권한 검증은 제품 서버 책임이며 이 연구는 제품에 연결하지 않았다.

공장 유형·재고·correct key·페르소나검수·AI합의는 각각 일부 증거다. 모든 자격을 한 PASS로 합치지 않는다. 현재 product `SupplyResult`에 연결할 때 unknown→null과 fail→false를 유지하고 원 A–H를 함께 전달한다. role_candidates를 delivered로 복사하지 않는다.
