# 의미 보존·Gold·채점 경계 — FQ1-gold1

2026-10-14. [운영 규칙](data/gold-rules.json)은 v15 이후의 새 연구 명세이며 기존 rubric·16합성 응답·최초 64facet를 소급 수정하지 않는다. [새 반례 등록](data/gold-boundary-review.json)은 실제 원문·과제와 연결된 10개의 새 합성 응답을 사용한다. 원문·응답·개별 Gold·상세 이유는 ignored local에만 보존한다. 인간 전문가·실제 학생·직접 평가 자격 승인·공개 적격 승인은 각각 0이다.

## 무엇을 명확히 했는가

| 경계 | FQ1-gold1 판정 계약 | 금지하는 해석 |
|---|---|---|
| 결합 partial/defer | 식별 가능한 올바른 개별 절 판정은 결합 구성 요소다. 전체 판정/AND 조건이 빠진 진부분집합은 partial, 어떤 구성 요소도 식별할 수 없으면 defer | 전체 답을 안 썼다는 이유만으로 해석 가능한 두 절까지 unobservable로 취급 |
| 생략된 비교 대상 | 제공된 과제에 유일한 선행 대상을 결속하는 경우만 허용. 지표·범위·논항 순서도 일치해야 한다 | 맞아 보이는 수치를 이용해 연구자가 대상이나 빠진 근거를 추정 |
| 수치 근거/단위 | comparison은 대상·관계·실제 값, units는 지표·연도/기간·척도·단위를 따로 기록 | 실제 값 누락을 units에도 중복 감점하거나 단위만 맞으면 수치 근거까지 충족 |
| 맞는 결론/잘못된 설명 | 근거 결함은 그 근거를 사용하는 facet 구성 요소로만 전파. 관찰된 올바른 형식 결합은 별도로 보존 | 근거 결함 하나로 전 facet를 틀렸다고 하거나 맞는 결론으로 잘못된 근거를 지우기 |
| 복사/의미와 자격 | 정확한 복사문은 의미 관찰로 남긴다. 명시적 사전 해설 접근은 독립 확인 ineligible, 신뢰 가능한 로그 부재는 defer | 문체·유사성만으로 복사 단정, 정확한 문장만으로 무도움 독립 수행 승인 |

같은 facet 안에 명시적 모순이 있으면 올바른 반쪽만 골라 meets로 만들지 않는다. 필요한 원문이 없거나 대상을 유일하게 식별할 수 없으면 defer이다. 의미 facet의 상태와 독립 수행 자격은 서로 다른 출력이다. 이 규칙은 단일 총점이나 학생 숙달값을 산출하지 않는다.

## 실제 응답에 적용한 연구 범위

기존 v15의 16응답·64facet 및 16절차 판정은 재사용한 역사적 관찰이다. 최초 의미 일치 64/64와 절차 일치 16/16을 새로운 검증으로 다시 세지 않는다. 당시 두 AI가 함께 지적한 네 응답의 모호성도 유지한다. 새 규칙으로 그 최초 값을 고쳐 일치도를 높이지 않는다.

새 반례는 S5 6응답과 V2 4응답, 각 4facet로 총 10응답·40facet다. 저자가 원문·발문·기존 활동 계약과 각 실제 응답을 직접 대조해 기대 상태와 이유를 작성했다. 같은 정확한 의미 산출물에 서로 다른 절차 로그를 붙인 대조를 포함한다. 합성 응답은 학생 자료가 아니며 40facet는 10응답에 종속된다. 저자 기대값은 학문적으로 검증된 Gold가 아니다.

독립 재검토에는 원문·과제·새 규칙·10응답만 담은 별도 입력을 제공하며 저자 기대값과 이유를 제외한다. 최초 판정과 불일치는 새 파일에 보존한다. 대상 생략의 유일성, 잘못된 근거의 facet 귀속, 인간 판정에서의 채점 안정성은 별도로 검토해야 한다. 제시 형식이나 반복 문구가 뜻 보존을 대신할 수 없다.

## 실행 가능한 검사는 무엇을 보장하는가

[gold-logic.mjs](../../../scripts/research/factory-qualification/gold-logic.mjs)는 분석자가 이미 부여한 구성 요소·대상 후보 수·명시 모순·근거 의존 관계를 입력받아 상태의 논리 일관성을 검사한다. 자연어 의미를 부분 문자열로 판정하지 않는다. 대상 후보 수와 근거 타당성 자체는 분석자가 원문을 보고 판단해야 한다.

회귀 검사는 결합 전체 구성 요소 삭제, 두 번째 가능한 선행 대상 추가, 실제 값 누락, 잘못된 근거의 의존 관계 전파, 복사 노출 추가, 독립 봉인 로그 누락에서 상태가 바뀌는지 확인한다. 검사 통과는 이 명시 논리의 재현 가능성을 뜻하며 실제 학생 채점기의 정확도·교수 효과·평가 자격을 뜻하지 않는다.

```powershell
node --test scripts/research/factory-qualification/gold-logic.test.mjs
node scripts/research/factory-qualification/gold-review.mjs --check
```

재계산은 같은 hash의 비공개 입력이 필요하다. 새 연구 규칙은 기존 Gold를 교체하거나 제품 자동 채점기로 연결하지 않는다. 출시·권리·학습자 미노출·인간 채점 검증과 실행기 지원은 별도 자격 축으로 보존해야 한다.

저자는 직접 쓰인 단위 구성 요소 하나를 놓친 사실을 인정했다. 숫자와 비교 대상의 결속은 유일한 source 주소인지, 추정한 답을 통한 보충인지 명세가 충분히 정밀하지 않았다. 잘못된 지표 근거는 comparison뿐 아니라 별도로 요구한 indicator-distinction 구성 요소에도 관계되지만, 해당 구성 요소가 응답 전체의 근거를 사용하는지 명시적 경계 설명만 사용하는지 고정되지 않았다. 높은 일치도와 이 결함은 공존한다.

따라서 [FQ1-gold2 제안](data/gold-rules-revision2.json)을 별도로 작성했다. 유일한 source 주소 증거, 대상에 의존하지 않는 관찰 구성 요소, 전 응답에 걸친 명시 근거 의존 관계를 다음 버전에서 고정하자는 제안이다. 40개 첫 상태를 새 버전으로 수정하거나 불일치를 합의로 지워 재계산하지 않았다. 세 응답의 상세 비교와 이유는 `local/gold-reconciliation.json`에 있다. 새 제안은 신규 독립 판정·인간 채점·학생 응답 검증을 통과한 Gold가 아니다.

추가 네 회귀 검사는 부분적으로 관찰된 단위를 대상 모호성과 분리하고, 등록된 지표 구별 구성 요소의 모순을 반영하며, 두 번째 적합 source 주소를 추가하면 유일성을 잃는지 검사한다. 첫 버전 9검사와 합쳐 13/13 통과했다. 이는 연구용 구성 요소 계약의 검사 결과다.

## 실제 공장 내용 검토의 별도 결과

[주 표본](FQ1-DCP-MAIN.md)의 실제 8문항은 B pass 6/fail 2, 키·해설 E pass 4/fail 4였다. [반증 표본](FQ1-DCP-COUNTER.md)의 4문항은 B pass 4, E unknown 4였다. 설명 기능을 잘못 분류한 사례, 제공 문맥만으로 후보 유일성이 확인되지 않는 사례를 opaque issue ID와 private 첫 근거로 보존했다. 표시된 의도 오류와 표시하지 않은 해설 오류를 구별했다.

12개 모두 완전한 accepted/partial/equivalent/defect/defer 루브릭과 인간 채점 검증은 미관찰이다. E의 키 검토 통과는 이 루브릭을 대체하지 않는다. 따라서 [자동 자격 결과](data/qualification-results.json)는 좁은 E pass를 unknown으로 정규화하되 최초 E fail은 유지한다. 이는 최초 AI 판정을 수정한 것이 아니라 검사 범위를 구분한 별도 기록이다.
