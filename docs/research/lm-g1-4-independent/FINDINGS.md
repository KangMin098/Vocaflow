T4-09/10은 `3746bc762` 목적 리뷰 이후 실제 반례로 확인했다. 기존 anchorGate와 고정 조회 응답을 조합한 본문 변경/조회 오류 두 사례, 실제 loader 읽기 블록의 연결 오류 사례를 보존한다. DB 원문 변경이나 실제 장애 실험은 하지 않았다. R5 legacy의 기존 boundary-only 결속 범위를 강화하거나 완전한 원문 검증으로 표현하지 않는다.

T4-07의 후속 반례로 도움받은 공유 문항의 독립 집계0을 확인했다. 모든 공유 문항이 포함됐다고 일반화하지 않고, 실제 `independent_check`와 겹치는 문항 수를 표시하며 원장 미확인 시 집계 보류로 남긴다. T4-08은 골격 삭제·서명 불일치 두 반례에서 수정 전2 FAIL/수정 후 PASS였다. 기존 채점 게이트를 재사용하며 새 채점 기준을 만들지 않는다.

현행 도구 자격이 STALE이어도 과거 독립 첫 관찰의 원장 정오는 남는다. 현행 도구 확인 문항 수와 원장 독립 첫 관찰·맞힘/틀림을 따로 표시하고 공유 집계도 현행 주장과의 교집합으로 한정한다. 기존 판정 창/120일과 전체 기록 집계의 분모를 혼용하지 않는다. 도구 범위 `<summary>`의 최소44px·키보드·focus도 기존 disclosure 안에서 보완/실측한다.

독립 관찰은 맞힌 수가 아니다. 기존 독립 첫 오답의 자격을 없애지 않고, 상세 집계에서 원장 맞힘/틀림을 함께 표시한다. 교수/평가 효과나 능력 등급으로 승격하지 않는다.

2,505행 고정 loader fixture는 3페이지를 읽고 보류 문항을 제외했다. 둘째 페이지 오류는 예외로 남고, 정상0건과 다르다. 12,001개 입력/4 TASK key/24 조합에서 제출 경로의 annotationFor는24회였고, 현재 채점 경로 재사용 후6회다(문항6개, 유효 해시6개). 단일 측정 시간으로 속도 향상을 주장하지 않는다. 실제 DB 대규모 행 실험으로 표현하지 않는다. 골격은 웹 cwd 기준 파일을 읽으므로 root cwd로 실행한 중간 도구 실패는 별도로 보존한다.
