## 3. 독립 평가 · 교수 사례 분리

- `b2-v2-agreement.json items_detail[].use`: 두 트랙 모두 `candidate_if_unexposed` 인 문항만 `independent_check_candidate`, 나머지는 `teaching_case_or_indirect`.
- **원천 결손으로 판정이 닫히지 않은 문항**: 두 배치 10문항 — 도표 2(수치 없음) · 삽입 8(2026 · M2706 · M2609 · 2025 의 #38 · #39, 「주어진 문장」 없음). b2 에서는 두 트랙이 각각 독립적으로 같은 결손을 보고했다 → D1 §2 에 추가. 이 문항들의 링크는 제품에 넘기지 않는다.

## 4. 기존 태그와의 충돌

- DB 의 문항 속성(`csat_dx_item_attribute`)은 축 · 단계 proxy 코드라 rev4 TASK 와 1:1 대응표가 없다 — 자동 비교하지 않았다(대응표는 사람 결정).
- 주 TASK 와 문항 유형(`type_id`)의 관계는 D3 `principle-groups.json primary_task_pairs` 에 있다. 예: 순서 문항 주 TASK 가 R4 · R2 · R1 로 갈린다 — 유형명으로 TASK 를 정하면 안 되는 근거.
