## 4. 기존 태그와의 충돌

- DB 의 문항 속성(`csat_dx_item_attribute`)은 축 · 단계 proxy 코드라 rev4 TASK 와 1:1 대응표가 없다 — 자동 비교하지 않았다(대응표는 사람 결정).
- 주 TASK 와 문항 유형(`type_id`)의 관계는 D3 `principle-groups.json primary_task_pairs` 에 있다. 예: 순서 문항 주 TASK 가 R4 · R2 · R1 로 갈린다 — 유형명으로 TASK 를 정하면 안 되는 근거.
