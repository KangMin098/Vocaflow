# 문항↔TASK 매핑 — 분석자 계약 v2 (goal-data-d2-v2)

> v1 정본: [ANALYST_CONTRACT.md](../../../csat-learner/v62/data-expansion/ANALYST_CONTRACT.md). v2 는 **v1 전체를 그대로 따르고 아래 경계 규칙만 더한다.** TASK 정의(codebook)는 바꾸지 않는다 — 규칙은 판정 절차다.
> 근거: 1차 표본(40문항 · κ 0.584) 갈림 177쌍을 눈으로 본 결과, 갈림의 대부분이 「모든 독해에 깔린 배경 수행을 indirect 로 볼지」 경계였다(V1 14 · E1 7 · R2 11 · E-O1 25 · R-O1 13 — 전부 indirect↔not_applicable).

## 1. indirect 는 반사실 근거가 있어야 한다 (모든 TASK)

`indirect` 로 판정하려면 `counterfactual` 를 쓴다: **그 수행이 빠지면 이 문항에서 구체적으로 무엇이 틀어지는가.**

```json
{ "task_id": "r.relation", "relevance": "indirect", "counterfactual": { "kind": "choice", "choice": 3, "how": "However 의 대조를 놓치면 앞 문장 입장을 필자 주장으로 읽어 ③을 고른다" }, ... }
```

- `kind`: `choice`(특정 오답 선지로 끌린다 — `choice` 번호 필수) · `locus`(결정 지점 원문을 찾지/읽지 못한다 — `quote` 필수, 원문 그대로).
- 「이해에 도움이 된다」 「전제다」 「모든 독해에 필요」 만으로는 indirect 가 아니다 → `not_applicable`(why: 배경 수행 · 결정과 무관).
- 검증기가 `choice` 는 실제 오답 번호인지, `quote` 는 원문에 있는지 확인한다.

## 2. TASK 별 경계

| TASK | direct | indirect(반사실 필수) | not_applicable |
|---|---|---|---|
| V1 기본 의미 | 결정 지점이 **특정 낱말의 기본 뜻 하나**에 달려 있다(어휘 문항 · 선지 낱말 뜻 대비) | 결정 지점 문장에 기본 뜻을 모르면 오독하는 낱말이 있고 그 오독이 특정 선지로 이어진다 | 낱말 뜻이 문맥으로 충분히 보완되는 일반 독해 |
| E1 발문 요구 | 발문에 **부정 · 예외 · 복수 조건**(않은 · 틀린 · 어색한 · 두 빈칸 · 변화 전→후)이 있고 오독 시 정답이 뒤집힌다 | 발문 요구를 넓게/좁게 읽으면 특정 오답(주장↔세부, 목적↔배경)으로 간다 | 유형 표준 발문이고 요구 오독이 특정 선지로 이어지지 않는다 |
| E2 근거 위치 | 결정 근거가 대상(빈칸 · 밑줄 · 선지 진술)과 **떨어져 있어 찾아야** 한다(다른 문장 · 다른 단락 · 일치 문항 탐색) | 근거가 바로 인접 문장이지만 그 위치를 잘못 잡으면 특정 오답으로 간다 | 근거가 대상 문장 안에 있다 |
| R2 문장 사이 관계 | 결정이 **두 문장의 논리 관계 판정 자체**다(연결어 빈칸 · 순서 · 삽입 · 무관한 문장) | 특정 연결 관계(대조 · 양보 · 인과)를 놓치면 특정 오답으로 간다 | 연결어가 있을 뿐 관계 판정이 결정에 쓰이지 않는다 — **연결어 존재만으로 indirect 금지** |
| R4 전개 구조 | 순서 · 삽입 · 흐름 · 요약 구조처럼 **글 전체 배열**이 결정 | 전개 단계(배경→요청 등)를 놓치면 특정 오답(배경을 목적으로)으로 간다 | 한 문장이 결정을 닫는다 |
| S3 · S4 · S5 | 결정 지점 문장의 **그 구조 해석**이 정답을 가른다(어법 문항 · 복잡 구문이 결정 문장) | 그 구조 오독이 특정 오답으로 이어짐을 지목할 수 있다 | 결정 문장의 구조가 평이하다 — 「문장마다 구조가 있다」 는 근거가 아니다 |

## 3. 통합 관찰 TASK(S-O1 · R-O1 · E-O1)는 문항 단위로 판정하지 않는다

1차 표본에서 κ ≤ 0.18 — 한쪽은 늘 무관, 다른 쪽은 늘 간접. 통합 관찰은 정의상 원자 TASK 의 결합이며 선택형 정답 하나로 관찰되지 않는다.
- v2 청크의 `tasks` 에서 제외한다(18 TASK 판정).
- 통합 관찰과 문항의 관계는 **원자 링크에서 파생**한다(제안 · D4 와 함께 사람 결정): 예) S-O1 = 같은 결정 문장에서 S 원자 2개 이상 direct. 파생 규칙은 데이터로만 계산하고 제품 관련도 입력으로 쓰지 않는다.

- 각 판정 AI_PROPOSED(R0). A · B 두 독립 판정이 같을 때만 candidateRelevance(R1). relevance(검토값)는 사람만.
- 원문 · 인용은 `scripts/research/goal-data/local/`(git 제외). 커밋 산출물은 sha256 만.
