# 문항↔TASK 매핑 — 계약 v2.5 추가 규칙 (goal-data-d2-v2.5) · 초안

> v1 · v2 · v2.1 · v2.2 · v2.3 · [v2.4](./CONTRACT_V2_4.md)(봉인) 를 따르고 아래만 더한다. **초안** — T-0111(b7 독립 검증) 결과를 반영해 봉인한 뒤 b8 에 쓴다.
> 근거: b7 주 TASK 갈림 9(일치 · 안내문 E2↔E3 5 · 함축 2 가 두 트랙 정반대 · 제목 1 · 심경 1) · 심경 primary null 행의 indirect 가 secondary 에서 빠지는 v2.2 §1 충돌.

## 1. 일치 · 불일치 · 안내문의 주 TASK(E1 · E2 · E3 다중 direct)

v2.4 §4 의 반사실 검사를 이 유형에 고정한다.
- 정답 선지에 해당하는 **본문 위치를 찾은 순간 대조 없이 판정이 닫히면 → E2**(근거가 표 칸 · 흩어진 단락 · 기호 목록 · 날짜 아래 별도 줄처럼 **찾기 자체가 어려운** 경우).
- 위치는 선지 순서대로 **바로 찾히고**, 수량 · 시점 · 제한어(only · 에만) · 부정의 **표현 대조가 정답을 가르면 → E3**.
- E1(부정 발문)은 이 유형에서 주 TASK 가 되지 않는다 — 발문 방향만 정한다(direct 링크는 유지).
- `primary_reason` 에 「찾은 위치」 와 「대조한 표현」 중 무엇이 결정이었는지 원문 낱말로 쓴다.

## 2. 밑줄 함축(R-IMPLY)의 주 TASK — v2.4 §4 확장

- 기본 = 비유 · 함축의 뜻을 끌어내는 수행 **R6**.
- 반사실 검사: 뜻을 맞게 끌어냈을 때 **선지 하나만 남으면 R6**. 뜻을 맞게 끌어내도 본문 낱말을 재사용한 오답과의 **대조 없이 둘 이상 남으면 E3**.
- 「뜻을 맞게 끌어냈을 때」 는 본문에서 그 비유를 풀어 쓴 문장(이 있으면)을 기준으로 한다 — 판정자의 해석 폭으로 남는 선지 수를 늘리지 않는다.

## 3. primary null 행의 secondary

- v2.2 §1 의 「direct 가 없으면 primary null · secondary []」 를 고친다: **direct 가 없으면 primary null, secondary = indirect 링크 목록**(없으면 []).
- 검증기 면제 조건: 부분 집합 · v2.5 · primary null · direct 0 · secondary 가 정확히 indirect 링크 집합과 같을 것.
