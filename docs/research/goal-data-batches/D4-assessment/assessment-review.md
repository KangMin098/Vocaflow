## 2. 결함 (중요도 순)

1. **「다른 날」 도달 조건이 판정에 들어 있지 않다** — R5 · E2 · V1이 해당한다. 해소(resolved) 규칙은 `skill-diagnosis.ts`의 「확정 뒤 연속 정답 2」뿐이고(`if (streak >= CHECK_ITEMS)`), 경과 일수를 검사하지 않는다. `delayed_check`는 라벨(`load.ts` 「다른 날 확인」)이자 공급 역할일 뿐이다. `supply.ts`의 주석은 「경과 시간 판정은 기존 규칙」이라고 하지만, authored 경로에서 그런 규칙은 찾지 못했다.
2. **「서로 다른 지문/문맥/문장」 조건을 검사하지 않는다** — V2 · S3 · R1 · R5가 해당한다. 판정은 문항이 다른지만 본다. 지금은 세트의 지문이 모두 달라서 결과적으로 충족하지만, 지문을 공유하는 세트가 들어오면 조용히 깨진다.
3. **산출형 도달 조건을 선택형으로 대신한다** — V3(말한다) · S2 · S4(풀어 쓴다). 결과는 proxy이고 도달 조건과 같지 않다.
4. **기준 수치가 코드와 다르다** — S1의 「3문장 이상 연속」과 해소 규칙의 연속 2.
5. **R3/R4 독립성** — 두 TASK가 같은 `discourse_roles` 형식과 같은 `gradeStructure`를 쓴다. 정본의 「독립 관찰 확인 전 잠정」 조건을 확인하는 코드가 없다.
6. **지연 문항 여분이 부족하다** — 대부분 세트의 지연 문항이 1개다. 첫 지연 확인에서 틀리면 다시 확인할 문항이 없다.
7. **허용 대안이 0인 세트가 9개다**(V2 · V3 · V4 · S1 · S3 · S4 · S5 · E1 · E3). 구조상 허용 대안 필드가 없거나 비어 있다. 단일 정답을 전제하는 형식이라 계약 결함은 아니지만, 정답이 정말 하나뿐인지는 사람이 확인하지 않았다.

## 7. 평가 체계 불일치 (`instrument-gap.json` 의 `mismatches`)

- **M1 선행 실패 없는 도달 상태가 없다** (P1) — 확정(verified)은 맞힌 문항 없이 2개가 막혀야 열리고, resolved 는 확정 뒤에만 온다. 첫 확인부터 맞히는 학습자는 unverified → 지도에서 checking 으로 남는다. 코드북 「도움 없이 맞힌다」 류 도달 조건을 만족해도 엔진이 「도달」로 읽을 상태가 없다. **영향:** 목표 달성 엔진이 resolved 만 도달로 세면, 이미 할 줄 아는 TASK 를 계속 미도달로 계획한다. 근거: apps/web/src/lib/csat/map/skill-diagnosis.ts:110 · apps/web/src/lib/csat/map/v4/as-is.ts:236 · apps/web/src/lib/csat/map/v4/as-is.ts:135
- **M2 코드북 도달 조건 ≠ 공통 CHECK 2문항** (P1) — 공통 규칙은 「확정 뒤 연속 2정답」 하나다. 다른 날(R5 · E2 · V1), 서로 다른 지문/문맥(V2 · S3 · R1 · R5), 연속 3(S1), 포인트/유형별 2(S5 · E1)는 판정에 없다. 21개 중 코드북 기준과 공통 규칙이 형식상 같은 것은 V4 · R2 · R6 · E3 네 개. 근거: apps/web/src/lib/csat/map/skill-diagnosis.ts:130
- **M3 개별 TASK 성공 ≠ 통합 능력 성공** (P2) — S-O1 · R-O1 · E-O1 은 관찰만이고 숙달 판정이 없다. 하위 TASK 가 모두 resolved 여도 통합 성공을 확인하는 도구가 없으므로, 엔진은 하위 성공을 통합 성공(점수 · 등급)으로 합산하면 안 된다. 근거: apps/web/src/lib/csat/map/v4/observation.ts
- **M4 연습 성공을 독립 평가로 셀 위험** (P3(방어됨)) — activity='practice' 기록 · 도움 · 해설 뒤 · 합성 · 시각 불확실 시도는 판정에서 빠진다. 창작 세트 교수/안내 지문과 평가 지문의 해시 중복 0건. 남은 위험: validateAuthoredSet 은 passageGroup 이름만 보므로 지문을 공유하는 새 세트가 들어오면 조용히 깨진다. 근거: apps/web/src/lib/csat/map/skill-diagnosis.ts:91
