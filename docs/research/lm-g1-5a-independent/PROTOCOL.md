수용 대상은 콘텐츠 없는 Instrument의 안전 계약이다. A 구성개념·주장, B 검수 자격, C 선택 충돌, D 서버/오류, E 공개 차단·독립성, F 기존 경로를 별도로 판단한다. 실제 V2 수직은 BLOCKED_CONTENT, 전문가 타당도·학생 효과는 검증하지 않는다.

고정 합성 주석으로 B/D/C, 검수자 자기 검수·누락·잘못된 형식, 실제 기존 E 공급자와 V2 충돌을 검사한다. source-probe는 원본 product-server를 git show로 읽어 동일 입력과 비교한다. 첫 실행의 Windows override 경로 오류 결과는 invalid 파일로 보존하고 판정에서 제외한다. 원문 동일 길이 변경·정답 변경·조회 실패를 정상 원문과 함께 검사한다. 원본 실패를 수정된 결과로 덮지 않는다.

격리 React/Chromium은 실제 패널과 합성 props를 번들링한다. useTaskMeta만 대역이며 DB·출시는 없다. 401/400/409/500, 저장 영수증 없는 200, 유실→같은 payload 재전송, 중복 클릭·제출 중 편집, C 미검수/실패를 두 PC에서 검사한다. 실제 앱 검증과 이 결과를 합치지 않는다.

실제 앱은 기존 V2 6조건을 1280×900·1440×900에서 반복하고 독립 T4 14조건·T1/T2/T3·Workspace·복귀·해부·공급 실행기를 재사용한다. 전용 서버·distDir, 본 작업에서 만든 합성 계정만 사용하고 부재 확인까지 보존한다. 수정 중 실행은 소스 해시로 구분하며 최종 HEAD의 핵심 검사를 다시 수행한다. SKIP·미완료·인프라 오류는 PASS가 아니다.

최종 V2 판정에는 `scripts/research/lm-g1-5a-independent/v2-browser.mjs`만 사용한다. 원저자 실행기는 최초 제출 기록으로 남긴다. G05는 정확히 400/no_task여야 하며 401·404를 수용하지 않는다. G06은 문항 HTTP 200과 실제 analysis-theater 렌더 뒤에 패널 부재를 검사한다. 500 페이지의 빈 DOM은 통과할 수 없다. 초기 원저자 6/6의 결과는 이 강화 조건의 증거로 대체하지 않는다.

주석 0개와 공개 차단은 저장 성공 증거가 아니다. 메타데이터 필수값·서버 원문/정답 결속도 실제 밑줄 위치, 뜻/배제 이유의 의미, 맹검 실행 기록 또는 사람 검수의 타당성을 증명하지 않는다. 콘텐츠 검수 때 독립 원장과 동일형 PDF를 별도로 확인한다.

DB/RPC/RLS·기존 학생·콘텐츠 출시·숙달 정책을 변경하지 않는다. 목적 검토와 최종 CI 통과 뒤 safe-merge만 허용한다.
