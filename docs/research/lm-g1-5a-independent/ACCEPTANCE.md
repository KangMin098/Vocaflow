## 무엇을 측정하며 무엇을 측정하지 않는가

B+D 성공은 이번 문항의 두 선택 조건을 충족했다는 관찰이다. 공식 정답을 알면 B를 알 수 있으며 D도 선택지에서 추측할 수 있다. 따라서 B+D만으로 독립적인 문맥 추론, V1 기본 뜻, S5 구문, R5 중심 의미, 전이 또는 숙달을 확정하지 않는다.

B가 틀렸을 때 senseOk=false는 D 조건 성공이 성립하지 않았다는 뜻이다. D의 독립된 언어 능력이 틀렸다는 주장으로 사용하지 않는다. 화면은 이때 밑줄 판별을 다시 보도록 안내한다. B+D가 맞고 C가 틀린 경우 정오 성공과 근거 실패를 따로 표시한다. 미검수 C는 null로 기록하고 성공을 주장하지 않는다. C가 맞아도 문장 번호를 골랐다는 관찰이며 근거 낱말·표현의 지목이나 자유 논증의 증거가 아니다.

## 노출·원문·검수의 실제 경계

기본 문항 화면은 원문 문제지 접근·공식 정답·해설·정답/오답 설명을 다루는 극장을 과제보다 먼저 렌더한다. C2/G는 변경하지 않았다.
