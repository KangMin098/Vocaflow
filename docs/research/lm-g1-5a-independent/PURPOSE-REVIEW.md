# 독립 목적·반증 검토 기록

`node agents/scripts/review.mjs --base origin/main`의 읽기 전용 검토를 사용했다. 자동 AI 코드 검토이며 사람 전문가 검수·학습 효과의 증거가 아니다.

| 회차 | 실제 발견 | 대응 |
|---|---|---|
| 1 | contract-probe의 --pinned가 재실행 시 현재 의존 모듈을 읽음 | 제출 SHA의 contextual-sense·주석 인덱스·레지스트리를 모두 override하여 재현. 원래 첫 실패 기록과 동일 6/10 실패 확인 |
| 2 | 근거 순서만 바꾼 유실 재시도가 새 mutation을 만듦 | 실제 task-meta와 원본 패널로 두 PC에서 재현, cue 정렬 후 같은 payload/ID 재사용 확인 |
| 3 | 원저자 V2 브라우저가 다른 4xx와 오류 페이지 빈 DOM도 통과 가능 | 최종 독립 v2-browser는 400/no_task, 문항 200·실제 극장 렌더를 요구. 원저자 파일·이전 관찰 보존 |
| 4 | 합산기가 반례 실패·빈 manifest·실행기/소스 변경을 충분히 차단하지 못함 | 반례/15개 공급자 검사의 개수·strict true 검증, Git 오류/필수 소스 목록 차단, 실제 실행본과 현재 생성 규칙의 바이트 대조, 단위·격리 검사 실행 전후 소스/실행기 hash 결속. 가드 회귀 3건 통과 |
| 진행 중 공통 | A–F 최종 판정·최종 소스 회귀 결과가 아직 없음 | 미완료 동안 수용하지 않음. 최종 보고와 소스 결속 증거를 제출한 뒤 목적 게이트 재검토 |

최종 목적 검토 결과는 ACCEPTANCE 및 최종 검토 영수증을 기준으로 한다. 위 중간 결함 발견을 삭제하거나 NO_FINDINGS로 바꾸지 않는다.
