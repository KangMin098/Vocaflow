특정 문법 표현이 문법적으로 성립할 가능성, 원문과의 의미 동등성, 기존 유일오답 역할의 자격은 다른 문제다. 원문 복원 키가 같다는 이유로 대체문이 항상 틀리다고 가르치거나 기존 키 오류를 강제하지 않았다. [공장 수정 보고서](FQ11-DCP-REPAIRS.md).
