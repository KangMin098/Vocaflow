# FQ1.1 실제 DCP 12건 수정 후보

2026-10-14. FQ1.0의 main 8건·counter 4건을 그대로 재사용했다. 새 표본을 추가하지 않았으며 최초 입력·판정·DB 행을 변경하지 않았다. 이 문서는 **저자 수정 후보와 독립 검토 대기 상태**를 기록한다. 독립 검토 결과는 별도 봉인 파일로 남겨야 하며 이 첫 원장을 덮어쓰지 않는다.

## 고유 결함 수와 판정 범위

| 최초 판정 | 건수 | 의미 |
|---|---:|---|
| B 실패 | 2 | 의도된 보기 오류가 아니라 해설의 문법 기능 설명 오류 |
| E 실패 | 4 | 해설 문제 2건·제시 문맥에서의 유일성 근거 부족 2건 |
| B/E 중복 | 2 | 두 축에서 같은 문항을 다시 센 수 |
| B 또는 E 실패 고유 문항 | **4** | 2+4를 6문항으로 합산하지 않음 |
| C 실패 / 미확정 / 통과 | 8 / 2 / 2 | 요청 TASK 수행 관찰과 문항 유형 태그를 구별 |
| 독립 설명 응답 루브릭 미확보 | 12 | 키가 있는 것과 새 설명·부분답 채점의 자격을 구별 |

12건 모두 의도된 표시 오류가 있다. 그 사실만으로 원천 의미가 손상됐다고 분류하지 않았다. 확인된 해설 오류 2건, 문맥상 유일성 부족 2건, TASK 불일치 8건은 중복 가능하다. 해설 자체가 없는 1건도 별도로 보존했다. 원천 자체의 오류, 표시 외 생성문의 의미 손상, 정답 위치·복원 키 오류는 이번 자료에서 **확정한 건수 0**이며 전체 원천의 전문적 정확성 통과를 뜻하지 않는다.

원천에서 물려받은 수식 자리 표시·불완전한 표현은 생성 오류와 분리했다. 어휘·통계·전문 과학 문제를 하나의 ‘오답’으로 합치지 않는다. 실제 문제는 [첫 판정과 수정 후보 원장](./data/dcp-repairs.json)의 문항 ID·기존 입력 hash·새 revision hash로 결속했다. 개별 원문·정답·Gold·합성 응답 전문은 공개하지 않았다.

## 새 ContentArtifact revision 12개

| 수정 범위 | 새 후보 수 | 처리 |
|---|---:|---|
| 문법 기능 해설 오류 | 2 | 해설을 고치고 내용절의 기능·주어·서술부·절 범위를 직접 산출하는 S5 후보로 재설계 |
| 나머지 관사·한정사 문법 자료 | 4 | 구 경계·중심 명사·내부 역할을 산출하는 `s.chunk_boundary` S3 후보로 TASK 변경; 기존 S5 주장 유지 안 함 |
| 어휘 유일성 미확정 | 2 | 기존 문맥 유일오답 역할을 폐기하고 원문을 함께 제시하는 V2 의미·비교 범위 대비 연습으로 전환 |
| 나머지 어휘 자료 | 4 | 실제 지시와 의미 설명·근거·강도/범위·대조 산출물을 추가한 V2 후보 |

총 12개는 기존 오류를 고친 **연구용 새 자료 후보** 수다. 독립 검증 완료 수나 독립 평가 자격 수가 아니다. 모든 후보는 guided_practice 역할이며 source-present 설명 과제다. 원문을 같이 보고 의미를 비교하는 성공을 미노출 독립 수행의 성공으로 표시하지 않는다.

각 후보에는 네 산출 구성 요소, 동등 표현 허용, 관찰된 부분 수행 보존, 명시적 모순과 미관찰의 분리, 정답과 모순이 같은 답에 함께 있는 경우의 처리를 기록했다. 자연어 학생 응답을 자동 판정하는 프로그램을 만들지는 않았다. 루브릭 자체가 타당한지도 새 독립 AI 내용 검토 대상이다.

원문에 있는 주장 강도·부정·비교 집단을 바꾸어 정답을 강제하지 않았다. 불완전한 통계식을 새 수치로 채우거나 보이지 않는 그림의 값을 만들지 않았다. 복원 목표 문장 12/12는 현재 로컬 원문과 공백 정규화 기준으로 대조됐다. 복원 발췌 전체의 연속 일치는 11/12이며 1건의 수식 자리 표시 생략은 그대로 남겨 두었다. 이 로컬 대조가 공식 외부 원천 계보나 전문적 사실 검증은 아니다.

## 독립 검토 입력

원문·새 후보·루브릭과 새 합성 경계 응답을 담은 blind packet을 봉인했다. 기존 첫 판정과 저자의 응답 예상 판정은 blind packet에서 제외했다. 새 경계 응답은 12후보×5개=60개이며, 동등 표현·부분 수행·명시적 잘못·해석 불가·옳은 설명과 모순의 병존을 시험한다. 60개는 새로 만든 합성 응답이고 실제 학생의 첫 반응이나 새로운 실물 공장 표본이 아니다. 후보끼리·응답끼리 종속돼 있으므로 60개의 독립 모집단 관측으로 해석하지 않는다.

| `local/dcp-repairs-candidates-first.json` | `170bf79c6ccc4885ec27f81f24af3745a428d36432dfd088f14db21def2f313c` |
| `local/dcp-repairs-blind-first.json` | `9e7c0f3731236f492b3fd13b33308d2a6f041cf8582756bb5678d77067b97bcb` |

저자 검토는 12개의 실제 원천 객체 전부를 읽어 hash 결속하고, 실제 생성 발췌·목표 원문의 전후 문장·키·해설·보존된 전체 원천 첫 검토를 대조한 범위다. 새로 전체 논문의 전문적 타당도를 인증한 검토로 표현하지 않는다. 독립 검토자는 blind packet의 전체 원천과 산출물을 이용해 저자가 놓친 반례와 지시-루브릭 경계를 별도로 확인해야 한다.

## 남은 보류

새 후보의 현재 로컬 원천 결속은 새 제작 시점의 정보다. 기존 DCP가 생성될 때 사용한 원천 revision은 12건 모두 여전히 미확정이다. 기존 created_at을 과거 provenance로 사용하지 않았다. FQ1.0의 source cache fresh 5·stale 5·missing 2 분포도 바꾸지 않았다.

현재 원천 객체의 archived 또는 reject 조건을 확인한 새 연구용 운영 보류는 3건이다. 이는 FQ1.0 F축 실패 2건과 기준이 같지 않으며, 오래된 cache의 blocked를 현재 법적 거절로 승격한 결과도 아니다. 새 내용 수정으로 이 운영 보류나 권리·출시 보류를 해제하지 않았다.

독립 AI 검토 전 완료 **0**, 인간 검수 **0**, 실제 학생 검증 **0**, 공개 자격 **0**, 직접 평가 자격 **0**. 승인·노출·실행 이력과 실제 권리 증거가 부족한 축은 계속 보류한다. 후속 독립 검토의 통과 여부와 사전 수행 사례의 성공은 별도 보고해야 한다.
