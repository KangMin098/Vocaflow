목표/기록·추천 카드·관계도/Inspector의 시각 위계가 유지된다. 과거 경고를 상단으로 올려 편집 시점을 먼저 알 수 있다. 선택 테두리·숫자·보류 문구·관계 선 종류를 함께 쓰며 색만으로 상태를 전달하지 않는다. 긴 수행 기준은 Inspector에서 여러 줄로 제공한다. 첫 행동은 추천 카드와 Inspector에 반복되어 스크롤 아래 계획을 열기 전에도 발견된다.

44px 높이는 실제 제출 DOM bounding rect로 16종 확인했다. 주요 노드 30개는 46px, summary/chip/편집/복귀는 44px, 추천 링크는 49.5px다. focus-record는 해당 상태에 없어서 null이며 17종 모두 측정됐다는 표현은 정정한다. 자체 브라우저 측정은 아니다.

## TASK 말줄임의 영향

기본 R5 선택에서는 1280의 V4가 두 줄 뒤 잘린다. 1440 기본·전체 보기에서는 더 많은 이름이 읽히며, 선택하면 해당 영역이 넓어진다. 실제 V2/S5 선택 캡처가 이 확장 경로를 보여 준다. V4 선택 자체의 새 브라우저 캡처는 없다. 코드의 choose→focus/selected→Inspector 결속, V4 Inspector SSR, 모든 Node aria-label 전량 검사로 보완했다.

FocusStrip은 추천 세 TASK의 전체 이름을 표시한다. 모든 TASK가 추천에 등장한다는 보장은 없으며 V4가 현재 추천 카드에 보인다고 주장하지 않는다. 비추천 TASK는 지도 선택/검색·전체 보기를 이용한다. 마우스 hover만으로 전체 이름을 제공하는 보조 UI는 없어 발견성이 약하다. 선택 후 전체 의미가 확보되는 현재 경로를 제한적으로 수용하고 P3로 남긴다.

## 3B 원본·측정표

원본은 D:/workspace/Vocaflow/docs/design/refs/3b/access-map/access-map-page.png에서 직접 확인했다. 원본에 포함된 계정 표시는 보고서에 전사하거나 재배포하지 않았다. 브라우저 없이 PNG RGB를 읽어 기존 ref-measure와 같은 흰 연결 성분 기준으로 재측정했다.

원본 재측정 결과는 data/reference-pixels.json에 있다. 로컬 tmp의 ref-compare.png도 검토했으나 10-14 파일이며 목표 HEAD에 결속되지 않아 이번 구현 대조에서 제외했다(data/rejected-legacy-pixels.json). 이 오래된 파일로 8/8 주장을 뒷받침하거나 반박하지 않았다.

전체 펼침 DOM 결과와 노드/열 토큰·spec의 결속을 확인했다. 목표 카드·추천·Inspector·학습 경로·준비 상태는 참조에 없는 교육 목적의 의도된 차이다. 기하 수치 일치를 화면 전체의 디자인 완성 또는 교수 효과로 확대하지 않는다. 현재 PC 화면에서 관찰된 정보 위계·탐색·조작과 두 P2 해결을 수용한 것이다.
