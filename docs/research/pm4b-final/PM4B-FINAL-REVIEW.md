## 수용 이유와 경계

영역명은 두 줄까지 읽히며 코드·수·보류 표시를 유지한다. 과거 보기에는 기준일·활용 기록 수·현재 전체 기록 기준을 밝히고 목표/기록 변경은 현재 기준으로 이동시킨다. 직접 목표 팝오버·기록 추가·학습 시작·PLAN 저장이 과거 보기에서 차단된다. 현재 복귀 후 편집·뒤로가기 경계는 제출 브라우저 결과로 확인했다. 이는 UI 경계이며 서버 권한 변경이 아니다.

1280 좁은 열의 V4 노드명은 일부 잘린다. 전체 보기, 선택 후 넓어진 열, Inspector, 보조기술용 전체 이름으로 의미를 복구할 수 있다. 새로운 필수 P2로 올릴 근거는 부족하다. 마우스 hover만으로 전체 이름을 볼 수 없는 발견성은 P3로 남겼다. [시각 판정](PM4B-VISUAL-AUDIT.md).

실제 E 브라우저는 SKIP, 합성 계약은 PASS다. 재고 후보가 실제 공급 적격이나 납품이 되지 않는다. 영속 PLAN 버전 복귀는 NOT_TESTED다. 이 항목들을 실제 연결 PASS로 승격하지 않고 현재 화면·기존 동선 종료 범위 밖에 남긴다.

제품·DB·교재·공장·계정·학습자 기록을 변경하지 않았다. PGlite 검사는 격리 메모리 DB이며 실제 Supabase 적용이 아니다. [종료 범위](PM4B-CLOSURE.md)에 이후 주장 가능한 범위를 고정했다.
