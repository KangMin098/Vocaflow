## 잔여 P3 — 좁은 TASK 이름의 발견성

1280 기본 R5 선택에서 V4가 ‘표현 사이 의미…’로 잘리는 사례가 실제 있다. 선택 전 노드에 native title/별도 hover 설명은 없으므로 마우스만 올려 전체 이름을 즉시 읽는 경로는 없다. 보조기술 이름은 30 TASK 전체를 담으며 독립 실제 Node 함수 SSR로 확인했다. 선택은 Inspector와 영역 확장으로 이어지고, 실제 V4 Inspector SSR은 전체 이름과 수행 조건을 제공한다.

현재 관찰에서 V4의 ‘관계’ 부분 소실이 가장 분명하다. 다른 모든 노드의 잘림 길이를 DOM으로 실측한 순위는 없으므로 전량 최악이라고 단정하지 않는다. 고유 코드/선택 후 설명이 있어 구별 실패나 잘못된 학습 행동의 새 P2 증거는 없다. 제한적 수용한다. 최소 후속안은 hover/focus 시 안정적인 전체 이름 노출 또는 압축 명칭 정책이다. 노드 높이·열 폭·지도 구조의 대폭 변경을 요구하지 않는다.

기본 Inspector 연구 사례 목록(H02)은 P3 관찰을 유지한다. 실제 학습 실패/심한 과밀이 입증됐다고 하지 않는다.
