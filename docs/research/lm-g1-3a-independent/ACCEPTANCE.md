## 적용 경계

실제 DB/RPC/RLS를 변경하지 않았다. 기존 R5 판정·계획량·노출v1·학습지도 구조·정본 TASK는 보존한다. 등급/날짜의 계산 사용, grade-only, 시간 예산, 복합범위, 실제 Factory, 실제 학생 효과는 이 수용 범위 밖이다.


## 목적 리뷰의 추가 반증

첫 리뷰는 PLAN API의 재조회 결속 P1과 S02의 수동 재진입 P2를 지적했다. P1은 실제 개발 DB에서 위와 같이 재현하고 수정 후409·행0으로 재검증했다. S02는 새로 진입하기 전에 기존 문서의 점수·시험 범위가 최신 목표로 갱신돼야 통과하도록 강화했다. 첫 리뷰 지적을 최종 PASS로 덮지 않는다.

현재 목표가 최종 확인 뒤 바뀌어도 저장 PLAN은 계산한 불변 목표 버전에 결속된다. commit 순간의 절대 최신 목표까지 원자 보장한다고 주장하지 않는다. 그러한 정책이 필요하면 목표 잠금을 공유하는 RPC compare-and-commit을 별도 DB 승인안으로 분리한다.


PLAN UI는 관찰한 expectedGoalVersion을 보낸다. 새 요청은 서버 계산 버전과 달라지면409이며, 이미 성공한 같은 요청의 재전송은 원래 목표 버전을 대조한 뒤 원래 결과를 돌려준다. legacy API의 필드 생략은 서버 계산 기준이라는 기존 의미로만 호환하며 화면의 관찰 버전을 검증했다고 주장하지 않는다. 기기 초안/ack는 점수 외에 실제 목표 이력 ID를 포함한다. 버전 없는 예전 초안은 삭제하지 않고 보관·미적용 안내한다.
