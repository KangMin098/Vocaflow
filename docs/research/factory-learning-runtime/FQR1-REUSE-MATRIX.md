# FQR1 기존 실행기 재사용 비교

2026-10-15 실제 컴포넌트·서버 액션·생성/조판 코드를 읽어 재사용 가능 부분을 구분했다. UI/API/RPC 수정이나 실제 학습 실행은 하지 않았다. 비용은 구현 경계의 상대 비교이며 공수 측정·학생 효과의 증거가 아니다.

위 7종은 현재 **supported_by_existing_runner 0**이다. 재사용할 수 있는 구성 요소와 완성된 재생·채점 지원을 같은 수로 세지 않는다. 표시 어댑터 외에도 scoring contract와 qualification이 필요한 다중 상태다. 정상 표본이라고 해도 rights/노출/runtime/역할 자격이 확보되지 않았으면 공개 실행으로 연결하지 않는다.

## 실행기별 경계

**DCP**는 기존 17종의 서버 정오 채점, 입력 유지, 실패 표시, 제출 후 해설, 오답 원인 자기보고, 다음/요약을 제공한다. `backHref/backCta`가 있지만 교재 연습 페이지는 현재 `<DcpPlayer items={items} />`로 기본 홈 복귀를 사용한다. Workspace demand/delivery/qualified content revision의 복귀 계약이 완성됐다고 하지 않는다. 기존 order는 문단 문장 순서이며 word_order와 데이터/채점이 다르다.

**ScriptQuiz**는 선택·제출 후 정답/근거·다음·세션 결과의 흐름을 제공한다. server `gradeScriptQuizAnswer`는 quiz_questions/library chapter/sample ID를 사용하며 DCP key를 읽지 않는다. choices UI를 참고할 수 있어도 그 채점 액션을 DCP에 호출하면 정답 경로가 틀린다. 제출 전 correct_index/source_snippet을 공개 객체에서 뺀 설계는 재사용 가치가 있다. 시간 초과 -1과 사용자 오답의 의미도 새 계약에서 분리한다.

**WordVault**의 StudyMode는 뜻 공개 후 자기평가 1~5를 FSRS로 기록한다. 이는 정답 대조가 아니라 기억 자기평가다. 화면/복습 큐/음성은 기본 뜻·형태 인출 연습에 재사용 후보지만 V2 문맥 의미의 자동 채점이나 독립 평가로 쓰지 않는다. 힌트·뜻을 본 뒤의 응답은 assisted로 기록해야 한다.

**SpellForge 등 철자 입력**은 입력·타이핑 인터랙션 후보다. 문자 맞춤 채점은 문법 대안이나 의미 동등 응답의 기준이 아니다. 이번 감사에서는 해당 모듈의 전체 채점 타당도를 검증하지 않았으므로 공통 scoring engine으로 승인하지 않았다.

**조판기/해설기**는 해당 문항 payload를 해석한 인쇄물 생성과 규칙 해설을 제공한다. 이것은 학습자 최초 응답·힌트·수정 응답 기록이나 서버 정답 숨김 기능이 아니다. 시장 길이/인용/오답 단어 언급 검사와 해설 내용의 참·거짓을 구분한다.

**recordGameScore**는 게임 세션 scores와 FSRS 학습기록을 구별한다. 점수/시간 저장이 문항별 원응답/노출/revision 증거를 대신하지 않는다. DCP attempt와 이 게임 결과를 자동 합산해 TASK 직접 수행 수로 만들지 않는다.

## TASK·우선순위

실제 코드북 S3은 `s.attachment`(수식어의 피수식어 지목), S4는 `s.structural_relation`, S5는 `s.form_scope`다. S3의 직접 과제는 **무엇이 무엇을 꾸미는가**를 명시적으로 묻고 그 응답을 받아야 한다. article/지시어 오류 위치 정답만으로 이를 관찰했다고 할 수 없다. 과거 연구 기록의 ID/판정은 덮어쓰지 않고 이번 계약에서 정본을 결속한다.

우선순위는 stock 규모가 아닌 원문/키/해설 검토 통과와 자격을 전제로 한다. 먼저 unit_vocab 및 표시 선택의 공통 선택 UI/오류 처리 어댑터를 검증할 수 있다. 단답·배열은 인출 기회를 제공하지만 허용 응답과 대안 문법/어순 검수 비용이 더 크다. 근거 설명·의미 대조·수식 대상 지목은 선택 UI에 몰래 추가 채점 조건으로 넣지 않고 별도 발문·입력·피드백 계약으로 설계한다. 학생 효과는 직접 실험 전까지 미검증이다.

Claude Code 최소 E2E는 격리 환경에서 권 선택→정상 구조+실제 역할 자격 확인→사전 키/해설 숨김→요구 입력→검증된 서버 결과 또는 명시적 지원 피드백→최초/수정/assisted·노출 기록→원래 교재/Workspace 복귀를 확인한다. RPC 오류/미지원은 attempt 오답 적재가 없어야 한다. 이 경로를 운영 학생에게 실행하거나 콘텐츠를 발행한 기록은 이번 연구에 없다.
