여섯 문항의 B는 pass4/fail2, E는 pass3/fail2/unknown1이다. E pass는 **해당 제한된 선택 판정**의 근거이며 인간 Gold 검수·학생 채점 신뢰도가 아니다. 어느 문항도 immutable TASK/role demand와 결속된 C pass 또는 직접 V2 수행으로 승격하지 않았다.

vocab_choice는 표시 선택, unit_vocab은 실제 보기 수에 맞춘 선택, blank_word는 단답 입력이 필요하다. 현재 읽기 전용 제품 snapshot의 DCP 재생 분류는 셋을 교재 전용으로 둔다. 5지선다 독해 parser에 억지로 맞추거나 추가 보기를 만들면 발문과 평가 조건이 달라진다. 원장에 정상 구조 metadata로 선정된 표본에서도 내용 실패가 있음을 남겼다. 구조 층과 의미 타당도는 같은 상태가 아니다.

피드백은 학생이 선택·입력한 것, 문맥에서 요구하는 의미와 범위, 어떤 단서가 그 의미를 지지하는지를 연결해야 한다. 다른 네 표시가 인쇄됐다는 설명만으로 그 사용이 적절함을 설명했다고 하지 않는다. 단답형은 명시적으로 승인된 표기 변이만 정규화하고, 목록 밖의 해석 가능한 답은 검토 대기로 남긴다. 일반 자유응답 의미 채점기는 이번 연구에 없다.
