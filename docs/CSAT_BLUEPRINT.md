# 수능 영어 출제 설계도

> 13개년(2014~2026) 기출 **585문항을 전수 계측**해 만든 유형 정의·출제 제약·학습 설계.
> 이 문서의 모든 수치는 재현 가능하다 — 아래 §0 의 명령을 돌리면 같은 숫자가 나온다.
> **작성 2026-08-22.**

## 0. 이 문서를 믿어도 되는 이유 (재현 절차)

```bash
pnpm dlx tsx scripts/csat/extract-questions.mjs   # 원문 → 630문항 (누락 0)
pnpm dlx tsx scripts/csat/classify-types.mjs      # 유형 배정 585/585 (중복 0)
pnpm dlx tsx scripts/csat/measure-blueprint.mjs   # 유형별 제약 실측
pnpm dlx tsx scripts/csat/build-blueprint.mjs     # 설계도 파생 (손으로 적지 않는다)
pnpm dlx tsx scripts/csat/verify-blueprint.mjs    # 홀드아웃 검증 583/585 = 99.7%
pnpm dlx tsx scripts/csat/csat-source-verify.mjs  # 원본 .txt ↔ PDF 대조
```

**분모** — 13개년 585문항. 2014 는 수준별 A/B 두 회분이라 **B형을 2014 대표**로 쓴다(현행 통합
수능은 난이도·구성 면에서 B형 계열). A형 45문항은 폐지 형식이라 참고로만 센다.

**검증 방식이 핵심이다.** 실측에서 뽑은 제약을 같은 실측으로 검사하면 100% 는 동어반복이고
아무것도 증명하지 못한다. 그래서 **한 회차를 빼고 만든 설계도로 그 회차를 예측**한다
(leave-one-exam-out). 최근 8회차(2019~2026)는 **전부 45/45** 다.

| 검증 단계 | 결과 |
|---|---|
| 문항 추출 | **630/630** (누락 0) |
| 유형 배정 | **585/585** (미배정 0 · 중복 0) |
| 설계도 홀드아웃 적합도 | **583/585 = 99.7%** |

**남은 2건을 100% 로 만들지 않았다.** `X-BLANK2` 는 13년 중 2017 한 번만 나온 유형이라
홀드아웃으로는 **원리상** 예측할 수 없다. 억지로 맞추려면 뺀 회차를 다시 넣어야 하고 그건
순환논증이다. `L-FAVOR` 는 2014~15 선택지 언어 탐지 잔여 오차다.

## 3. 이 서비스가 아직 못 만드는 유형 (커버리지 갭)

현행 37유형 중 `csat_dcp_items` 생성기가 다루는 것은 **18종(49%)** 이다.

| 갭 | 유형 수 | 내용 |
|---|---|---|
| **듣기 전체** | **15** | 음성 자산이 없어 문항 생성 자체가 불가 |
| 도표 | 1 | `R-CHART` — 도표 데이터 생성 필요 |
| 안내문 | 1 | `R-NOTICE` — 회차당 **2문항**인데 수단 없음 |
| 장문 제목·어휘 | 2 | `X-TITLE` · `X-VOCAB` |

**배점으로 보면 갭이 더 크다** — 듣기 17 + 도표 1 + 안내문 2 + 장문 2 = **22문항**,
2점 환산 최소 44점. 절반 가까운 점수 구간에 생성 수단이 없다.

## 4. 학습 설계 — 설계도에서 나온 것만

> ⚠️ 여기부터는 **설계도가 말해 주는 것**(시험이 요구하는 바)과 **학습과학**(어떻게 만들 것인가)의
> 결합이다. 앞의 §1~3 은 전부 실측이지만, 이 절의 학습 처방은 실측 + 추론이다. 구분해서 읽어야 한다.

### 4.1 설계도가 강제하는 세 가지 요구량

| 요구량 | 실측 | 의미 |
|---|---|---|
| **읽기 분량** | 독해 **2,955단어/회차** (최근 5회차 평균) | 듣기 25분을 빼면 45분 — 문항당 96초, 답 고르는 시간 포함해 **분당 100단어 이상** 처리 필요 |
| **고배점 집중** | 3점 10문항 중 **빈칸추론 2.0 + 짧은응답 1.8 = 3.8** | 전체 3점의 38% 가 두 유형에 몰린다 |
| **무위험 구간** | 3점이 한 번도 없는 유형 — 안내문(2) · 도표(1) · 내용일치(1) · 목적/요지/주장/심경(4) | 회차당 **8문항 16점**이 저난도 고정 |

### 4.2 수준별 — 어디부터 확보할 것인가

수준 판정은 **모의고사 원점수**가 아니라 **유형별 정답률**로 한다. 총점은 어느 구간이 비었는지 말해 주지 않는다.

| 수준 | 먼저 확보할 것 | 근거 |
|---|---|---|
| **~60점** | 듣기 17문항(34점) + 무위험 8문항(16점) = **50점** | 듣기는 3점이 3.0/회뿐이라 난도 편차가 작고, 무위험 구간은 3점이 0건 |
| **60~80점** | 어법·어휘·무관한문장·순서·삽입 (기호 선택지 6문항) | 지문 이해가 아니라 **형식 규칙**으로 풀리는 구간 |
| **80~90점** | 빈칸추론 4문항 | 3점 2.0/회가 여기 — 여기를 못 넘으면 90 이 상한 |
| **90~** | 함축의미·장문어휘 + 시간 관리 | 남은 3점 잔량과 속도 |

### 4.3 연령별 — 무엇을 언제

수능은 고3 시험이지만 **분당 100단어**는 3년 안에 만들어지지 않는다. 역산하면 다음과 같다.

| 시기 | 핵심 과제 | 설계도 근거 |
|---|---|---|
| **초5~중1** | 읽기 자동화의 기반 — 어휘 인출 속도, 기본 구문 | 분당 100단어는 어휘·구문이 자동화돼야 가능. 유형 훈련은 **아직 무의미** |
| **중2~중3** | 어휘 폭 + 200단어 지문 완독 | 독해 지문 중앙값이 114~214단어. 이 길이를 끊지 않고 읽는 게 전제 |
| **고1~고2** | **유형별 설계도 인식** — 각 유형이 무엇을 묻는지 | 이 문서 §2 가 훈련 대상. 폐지 6종은 제외 |
| **고3** | 3점 레버 + 시간 배분 | 빈칸 4 + 짧은응답 4 에 집중, 무위험 8문항은 속도로 처리 |

### 4.4 기간별

| 기간 | 목표 | 측정 지표 |
|---|---|---|
| **단기 (1~3개월)** | 무위험 8문항 + 듣기 17문항 = **50점 고정** · 시간 배분 확립 | 해당 25문항 정답률 ≥95%, 독해 45분 내 완주 |
| **중기 (6~12개월)** | 기호 선택지 6문항(어법·어휘·무관·순서·삽입) 규칙화 | 6문항 정답률 ≥80%, 빈칸 4문항 ≥50% |
| **장기 (1년+)** | 분당 100단어 + 빈칸추론 안정화 | 읽기 속도 실측 ≥100wpm, 빈칸 정답률 ≥75% |

### 4.5 어휘 — 이 저장소에 이미 근거가 있다

같은 13개년 원문에서 실측한 어휘 데이터가 `shared_dictionary` 에 있다
(`docs/DB_SCHEMA.md` §kice_csat 참조).

| 태그 | 낱말 | 용도 |
|---|---|---|
| `kice-csat-core-4y` | **1,417** | 4개년 이상 반복 출제 — **우선 암기 대상** |
| `kice-csat-13y` | 5,254 | 13개년 원문 등장 전체 |

⚠️ 시중 어휘 목록은 기출 근거가 약하다 — 실측으로 대조한 결과
`csat-prep-core-2k` 1,838 중 **37%**, EBS 덱 1,303 중 **43%** 가 13개년 원문에 한 번도 안 나온다.

## 5. `.md` 냐 DB 냐 — 판단과 근거

**지금은 `.md` + JSON 이 맞다. DB 는 아직 이르다.**

| 산출물 | 형태 | 이유 |
|---|---|---|
| 출제 원칙·유형 설명·학습 설계 | **이 문서** | 서술이라 표로 쪼갤 수 없고, 사람이 읽는 것이 목적 |
| 유형별 제약(기계 판독) | `scripts/csat/data/blueprint.json` | 검증 스크립트가 읽는다. 재생성 가능하고 CI 에 걸 수 있다 |
| 문항 실측 원본 | `scripts/csat/data/*.json` | 재현 절차의 입력 |

**DB 로 옮길 시점** — 문항 생성기가 이 제약을 **실제로 강제**할 때다. 그때는
`csat_dcp_items.type` 과 조인할 제약 테이블이 필요하고, 마이그레이션 승인을 받아야 한다.
지금 테이블을 만들면 **아무도 읽지 않는 스키마**가 하나 늘 뿐이다 — 이 저장소가 이미 겪은 형태다
(`word_lexicon` 동결, `csat-prep-*` vendor placeholder).

## 6. 한계 — 이 문서가 말하지 않는 것

정직하게 적어 둔다. 아래는 **측정하지 않았거나 측정할 수 없었던** 것이다.

1. **오답 설계 원리** — 오답 선택지가 어떻게 만들어지는지는 지문·선택지 의미 분석이 필요하고,
   지금 계측은 형식(개수·언어·길이)까지만 닿는다. 설계도의 가장 큰 빈칸이다.
2. **지문 주제 분포** — 어떤 소재가 몇 번 나왔는지 세지 않았다.
3. **정답 번호 분포** — 정답 키가 원문 .txt 에 없다(문제지만 있고 정답표가 없다).
4. **난이도** — 실제 정답률 데이터가 없다. §4.2 의 수준 구분은 3점 배점과 유형 성격에서
   **추론**한 것이지 정답률 실측이 아니다.
5. **듣기 지문** — 음성이라 지면에 없다. 듣기 유형의 지문 길이·어휘는 계측 대상 밖이다.
