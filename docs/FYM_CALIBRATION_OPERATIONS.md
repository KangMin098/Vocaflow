# FYM calibration 운영 준비 · 문항 revision 3

이번 자료는 기존 8편을 실제 사람 평가로 넘기기 위한 **검토 초안**이다. [96문항 검토본](./reports/frym-calibration-instruments-3-review.md)은 책임자/문항 검토자만 읽는다. 학생이나 blind 의미 평가자에게 보내지 않는다. 실제 참여자·학년별 pass band·등록 증빙은 아직 입력하지 않았다.

## 책임자가 먼저 결정할 것

| 결정 | 현재 준비된 자료 | 사람이 남길 증거 |
|---|---|---|
| 문항/채점 기준 | 8편×12문항, 축별 3문항 개정안 | 문항별 승인/수정과 이유, 검토자 ID·시각 |
| 의미 평가자 | 8항목·4점 척도·critical 규칙 | 자격·작성 독립성·사전 노출 확인, 최초 2명/별도 제3자 배정 |
| 학생 | 두 학년, 균형 배정 규칙 | 가명 ID·학년 확인·봉인된 지문 순서·참여/철회 운영 |
| 허용 난도 | 학년별 10개 측정 양식 | 20개 min/max와 근거, 모집/제외·결측·세션 규칙 |
| 시행 방식 | 아래 읽기/질문 분리 제안 | 질문 단계 순서·재열람·시간 기준·답 변경 방지 방식 |
| 사전 등록 | 기존 register --prepare | 응답 열람 전 외부 등록 시각·책임자 ID·manifest·증빙 |

어떤 사람도 자동으로 배정하거나 승인하지 않는다. 문항 개정안은 학년 공인 척도나 전문가 인증이 아니다. 이번 calibration은 평가자 해석과 문항 반응을 점검하는 회차이며 gold 승격 대상으로 쓰지 않는다.

## 읽기와 질문을 나누어 시행한다

문장 해석 문항의 인용은 다른 문항의 답에 힌트를 줄 수 있다. 질문 전체가 들어 있는 학생 JSON은 **진행자가 보관하는 원본 패킷**이다. 그대로 학생에게 모두 보여주지 않는다. 개정안의 배열은 추론 → 명시 정보 → 어휘 → 문장 순서이며, 배열 정렬만으로 답 열람을 차단한 것은 아니다.

1. Verify에서 해당 지문의 의미 통과와 배정 순서를 확인한다. 미해결 중재는 학생에게 넘기지 않는다. 확정 의미 탈락 지문은 봉인된 규칙에 따라 건너뛴다.
2. 지문만 별도 종이/문서로 보여준다. 문항·어휘 정의·채점 기준은 가린다. 시작/종료 시각과 미지어 등장 위치를 기록한다. 순수 첫 읽기 시간을 종료한 뒤 질문 단계로 간다.
3. R1~R3 추론 문항만 보여준다. 본문 재열람 허용 여부를 미리 정해 모든 참여자에게 동일하게 적용한다. 이 단계의 답을 회수/사진/파일로 보존한다.
4. C1~C3 명시 정보 문항만 보여주고 답을 별도로 보존한다. 이전 단계 답을 수정하지 못하도록 진행자가 원본을 보관한다.
5. L1~L3 어휘 문항을 제시하고 답을 보존한다.
6. 마지막으로 S1~S3 문장 해석 인용을 공개하고 답을 보존한다. syntax 인용을 보고 앞 답을 고치면 해당 시행을 오염 사례로 기록하고, 사전 결측/제외 규칙에 따라 처리한다.
7. 어휘·문장·추론 부담과 체감 난도를 각각 1~5로 묻는다. v2 안내는 1=전혀 어렵지 않음, 5=매우 어려움이다. 책임자는 중간 점수의 해석과 재열람/지원 조건을 protocol.operations에 확정한다. 진행자는 답에 대한 정오 피드백·어휘 설명을 측정 완료 전에 주지 않는다.

위 분리와 답 보존은 **사람 진행 절차**이다. 현재 JSON 패킷/수집기는 단계별 열람·순서·답 잠금을 기술적으로 인증하지 않는다. 시행 기록에 실제 사용한 자료 hash·패킷 hash·단계 시각·진행자·도움 제공/위반 여부를 보관하고 책임자가 사전 규칙으로 판단한다. 수집은 기존 v2 response batch의 같은 item_id에 실제 답을 모아 넣으며 무응답은 null로 남긴다. 단계 시각/위반 기록은 책임자 전용 보조 자료로 보관하고 schema에 임의 키를 추가하지 않는다.

추론을 먼저 묻더라도 같은 지문에 대한 문항 간 관련성과 학습 효과가 사라지지는 않는다. 세 축을 별도로 보고하되 심리측정상 독립 척도라고 주장하지 않는다. 순서 효과와 답의 분산·문항별 반응을 calibration에서 확인한다.

## 정답과 부분점수 검토

정확한 한국어 번역이나 동의 표현은 1점으로 인정한다. 예를 들어 information=정보, symptoms=증상, ICU=중환자실, can=할 수 있다를 설명이 짧다는 이유만으로 감점하지 않는다. 어휘 문항에서 인과/범위 한계를 따로 요구하지 않는다. 구조·추론 문항은 문항이 실제 요청한 단위만 점수에 반영한다.

R3의 결론 쌍은 예시 정답에 한정하지 않는다. 핵심 설명/결과를 보존한 지지 결론과, 범위·인과·확실성 등을 부당하게 강화한 비지지 결론을 정확히 구별하면 다른 타당한 조합도 인정한다. 예를 들어 F14에서 유럽 집단의 관찰을 모든 모집단의 확정 결론으로 확대할 수 없다고 설명하는 답도 허용된다.

무응답은 0점이 아니다. 답이 있는 오답을 0점, 일부 요구 단위만 맞은 답을 해당 문항 기준의 0.5점으로 기록한다. 경계 답·채점자 차이는 원 답과 판단 이유를 보존한다. calibration 결과를 본 뒤 기준을 바꾸려면 새 revision·회차로 분리한다.

명시 정보 문항은 단위별 정답을 우선한다. 일부 요구 단위가 맞고 나머지가 틀린 혼합 답은 0.5점이며, 모든 단위가 틀리면 0점이다. F18 C2의 ‘headbutting의 횟수’는 행동만 맞아 0.5점이고, F14 C3의 ‘의사의 확정 진단, ICU 집단’도 집단만 맞아 0.5점이다. 같은 요구 단위에 모순되는 두 답을 함께 쓰면 그 단위는 맞은 것으로 세지 않는다. 어휘/문장/추론은 뜻·관계 반전이나 근거 없는 단정을 학생 자신의 해석으로 긍정한 0점 오류를 우선하고, 그런 오류 없이 일부 내용만 누락된 경우에 0.5점을 준다. R3에서 잘못된 결론을 **비지지 결론이라고 구별**해 쓰는 것은 오류를 긍정한 답이 아니다. 이 우선순위도 사람 검토 후 데이터 전에 확정한다.

## 기존 명령에 새 문항을 명시한다

기존 default/v1 문항과 pilot 본문은 보존했다. 아래 export는 개정안을 명시적으로 선택하며 새로운 출력 경로가 필요하다.

~~~powershell
pnpm.cmd exec tsx --tsconfig apps/web/tsconfig.json scripts/textbook/frym-validation-export.mjs --pilot scripts/textbook/frym-precision/adaptation-pilot-1.json --preservation-rules scripts/textbook/frym-precision/preservation-rules-1.json --precision-review scripts/textbook/frym-precision/round-1.json --protocol scripts/textbook/frym-validation/protocol-2.draft.json --instruments scripts/textbook/frym-validation/calibration-instruments-3.draft.json --study-id fym-calibration-instruments-r3 --evidence-dir .agent-logs/frym-precision-r2 --output .agent-logs/frym-calibration-instruments-r3
~~~

이 경로는 이번 예행에서 이미 사용했다. 실제 사람 검토본을 수정해 확정한 경우 새 문항 파일·study ID·출력 경로를 사용한다. [기존 등록/수집/보고 명령](../scripts/textbook/frym-validation/README.md)을 이어서 사용한다. 새 protocol은 student_instructions_revision=2로 한국어 안내를 선택하며 필드가 없는 기존 v2/revision=1은 이전 영문 안내와 패킷을 유지한다. 안내 revision은 manifest에, 실제 안내는 packet_hash에 포함된다. 과거 초안 패킷이나 다른 안내의 응답을 새 패킷의 결과로 옮기지 않는다. 현재 자료는 미등록 초안이며 실제 봉인 후 재생성된 .packets가 배포 기준이다.

문항 검토자와 blind 의미 평가자는 같은 자료를 공유하지 않는다. 문항/채점 기준과 관찰 판정을 본 사람을 해당 자료의 blind 평가자로 배정하지 않는다. 실명 대응·참여 동의·보관/철회 기록은 책임자 전용으로 관리한다. 도구는 자료를 발송하거나 DB에 넣지 않는다.
