# 시중 독해 교재 기준 학년 난도 benchmark 계약 v0

로컬 교재/미리보기 import·admission 경로는 [파일 어댑터 실행 계약](../scripts/textbook/frym-benchmark/README.md#local-file-admission-adapter)을 따른다. 원본은 읽기 전용이며 기존 추출기의 페이지 결과를 저장소 밖 검토 후보로 만든다. 별도의 로컬 추출본에서 지문·문항 경계를 확인하고, 봉인 코드북의 9축 분석을 붙인 뒤에만 metadata-only 샘플을 만든다. 자동 추출 실패·경계 불명확·OCR 미검수·권리 불명확은 보류/거부한다. 어댑터의 합성 검증은 실제 교재 corpus 편입이 아니므로 현재 실제 corpus N=0, 9축 실분포=0, benchmark 판정 미개방, Gold-S=0, DB seed=0이다.

상태: **선정·분석 규칙 초안**. 교재 표본, 학년별 분포, 통과 구간은 아직 생성·봉인되지 않았다. F02 E3 합성 응답 28건은 실행·감사와 문항 반응 시뮬레이션의 근거다. 이 benchmark는 교재에 대한 **상대적** 학년 적합성만 평가하며 실제 학생 수행을 대신하지 않는다. 이 문서의 판정은 `BENCHMARK_TARGET_FIT`·`BENCHMARK_LEVEL_SEPARATION`으로 기록한다. 기존 `f02-pilot-judge.mjs`의 실제 학생 기반 `TARGET_FIT`·`LEVEL_SEPARATION`과 동일한 결과 필드에 쓰지 않는다. 합성 E3와 교재 판정을 결합하는 `Gold-S candidate`는 학생 판정이 아니라 별도 합성·교재 경로이며, 실학생 학년 타당성이나 기존 사람 pilot의 `student_validated`를 의미하지 않는다.

실제 표본에는 두 번의 봉인이 필요하다. 첫 번째 `BENCHMARK_SELECTION_PROTOCOL`은 본문 난도 분석 전에 검색 출처·마감일, 판본/권리/학년 기준, 선정 알고리즘, 9축 코드북과 결측·평가자 규칙을 **지문 ID 없이** 고정한다. 그다음 서지·지문/문항 위치를 metadata screening하여 후보 ID와 보류/제외 사유를 기록한다. 두 번째 `BENCHMARK_SAMPLE_MANIFEST`는 첫 봉인 hash와 inventory/screening snapshot hash에 결속하여 선정 ID·제외 ID·층별 구성을 고정한다. 본문 9축 측정은 두 번째 봉인 이후에만 시작한다. 실제 파일 admission CLI는 `frym-benchmark/2`에서 이 세 단계의 hash·run ID·후보 선정 상태·층별 구성을 재검증한다. 다만 전체 제약을 만족하는 해시 순위 최적 조합을 **독립 재계산하는 선택 감사**와 서지·권리 진위 확인은 별도 단계다. 이들이 없는 현재 파일 inventory를 실제 admission이나 봉인된 protocol로 간주하지 않는다.

실행 계약과 합성 fixture 검증은 [benchmark 엔진](../scripts/textbook/frym-benchmark/README.md)에 둔다. 엔진은 봉인 protocol·선정 manifest·9축 metadata가 들어오면 분포와 F02 상대 판정을 계산하고, 현재 F02 seal 및 E3 원출력 감사 경로를 다시 확인한다. **현재 봉인된 실제 benchmark protocol/표본은 0건**이므로 엔진 구현이 학년 타당성 승인을 뜻하지 않는다.

## 1. 표본 단위와 선정

분석 단위는 한 판본의 한 독해 지문과 그 지문에 연결된 문항 세트다. 표본틀은 선정일 현재 확인 가능한 학년 명시 영어 독해 교재의 ISBN·판본별 목록이다. 초등 고학년(초5·초6은 별도 기록), 중1·중2·중3, 고1·고2·고3을 각각 별도 층으로 둔다. 통합 `초고` 층을 보고할 때도 원래 학년을 보존한다. 학년을 명시하지 않는 수능 종합서·성인 교재는 별도 참조군으로만 기록하고 학년 분포에는 넣지 않는다.

표본틀 봉인 manifest에는 검색 마감일, 검색한 출판사 카탈로그·서점 목록의 URL, 검색식과 검색 결과 수, 접근한 확정 판본의 ISBN/발행일, 각 판본에서 열거한 지문 ID 전체와 페이지 범위를 기록한다. 이 manifest에 없는 출판사·판본·지문을 사후 보충하지 않는다. 추가 발견은 새 표본틀 revision으로 분기한다. 목차에서 독립 독해 지문으로 식별되는 항목을 전부 열거하되 해설·예문·복제 지문은 제외하고, 제외 목록도 보존한다. 사용 가능한 검색 출처와 마감일은 실제 검색 전에 봉인해야 하며 현재 미설정이다.

복수 학년을 한 권에 함께 표시한 교재는 학년별 단일 분포에서 제외하고 `MULTI_GRADE_REFERENCE`에만 둔다. 시리즈 전체가 여러 학년을 대상으로 하더라도 해당 권·판본이 단일 학년을 명시하면 그 학년으로만 배정한다. 동일 본문 hash의 지문이 여러 학년 판본에 재수록되면 학년 간 독립 표본으로 중복 계수하지 않고, 각 층의 후보 로그에 연결만 남긴다. 이 규칙과 표지·판권지의 학년 근거 위치를 선별 코드북에 봉인한다.

각 층은 서로 다른 출판사와 시리즈를 확보한다. 제안 배정량은 학년당 30지문, 출판사 3곳 이상, 출판사당 시리즈 2개 이상이다. 한 출판사는 학년 표본의 40% 이하, 한 시리즈는 20% 이하, 같은 지문의 재판은 1건만 허용한다. 이를 충족하지 못하면 그 층은 `INCONCLUSIVE_COVERAGE`이며 F02 판정 기준으로 사용하지 않는다. 이는 모집 목표이지 현재 확보 수량이 아니다. 가용 목록·권리 확인 후 목표를 바꾸려면 표본 내용과 F02 점수를 보기 전에 새 revision으로 기록한다.

선정 순서는 (1) 후보 선별용 장르·단어 토큰화·문항 유형 코드북을 본문 확인 전에 봉인, (2) 판본·학년·ISBN과 지문 위치 확인, (3) 독해 전문 교재 여부와 난이도 단계 기록, (4) 봉인된 선별 코드북으로 장르·길이·문항 유형 분류, (5) 학년별 후보 확정, (6) 아래 모든 제약을 만족하는 30지문 조합 중 정렬된 해시 순위 벡터가 사전식으로 가장 작은 조합 선택, (7) 제외 시 후보를 빼고 같은 알고리즘으로 다시 선택하며 사유와 이전/새 manifest hash 기록이다. 선별과 본 난도 분석을 분리하고 공통 분류는 같은 정의를 쓴다. 적격 조합이 없으면 `INCONCLUSIVE_COVERAGE`다. 인쇄본 후보 ID는 `print:ISBN:edition:passage_id`, ISBN 없는 디지털 판본은 `digital:publisher_id:canonical_url:edition:passage_id`다. URL은 fragment 제거·scheme/host 소문자 정규화 후 직렬화한다. ID 충돌은 `HOLD_ID_COLLISION`으로 제외한다. NFC 정규화 UTF-8로 직렬화한 `seed + "\n" + candidate_id`를 SHA-256 해시하고, 동률은 후보 ID 사전식 순이다. 목표 장르 배분은 30건 기준 설명 12·논설 12·서사 6건이며, 길이는 실제 단어 수를 `<150`, `150–299`, `≥300`으로 분류해 각 구간 최소 6건이다. 출판사 3곳 이상, 각 출판사에서 시리즈 2개 이상, 출판사 상한 12건, 시리즈 상한 6건을 동시에 만족해야 한다. 코드북 봉인 때 인쇄·디지털 ID의 해시 테스트 벡터를 각각 남긴다. F02와 주제·어휘가 비슷하다는 이유로 표본을 골라서는 안 된다. 동일 지문의 재수록, 정답 해설만 있고 본문이 없는 샘플, 출처·판본·권한을 확인할 수 없는 자료는 분포에서 제외한다. 공개 샘플만 사용할 경우 `sample_only=true`를 표시하고 해당 편향을 보고한다.

필수 provenance: `publisher`, `series`, `title`, `grade`, `difficulty_step`, `edition`, `publication_year`, `ISBN`, `passage_id`, `page`, `genre`, `source_method`, `access_date`, `rights_basis`, `analysis_hash`. ISBN이 없는 정식 디지털 판본은 발행처 고유 식별자와 URL·판본을 사용하고 예외를 명시한다. 본문·문항 원문은 권한이 확인된 보관소에만 두고, 저장소에는 식별자·측정치·근거 위치·hash만 기록한다. 접근 불가·권리 불명은 `HOLD_RIGHTS`로 두며 임의 재구성하지 않는다.

선별 코드북에는 동일 지문 판단을 위한 본문 정규화(Unicode NFC, 줄바꿈 LF, 연속 공백 하나), 정규화 본문 SHA-256, 제목·첫/끝 문장으로 확인하는 수동 중복 검수, 대표 판본 우선순위(학년 명시 최신 확정 판본 → 더 완전한 문항 세트 → ISBN/판본 사전식)를 봉인한다. 중복군·대표·제외 사유를 후보 manifest에 남긴 후 추출한다. `analysis_hash`는 보관소의 본문·문항·정답키 각각의 **원본 바이트 SHA-256**과 분석 도구/코드북 hash를 길이 접두 필드로 결합한 manifest의 SHA-256이다. 원본 경로·근거 page/문항 ID와 각 개별 hash를 결과에 결속한다. 어느 입력 바이트라도 바뀌면 기존 분석은 stale이며 새 revision으로 재측정한다.

## 2. 공통 분석 rubric

모든 축은 지문 단위 원수치, 길이 정규화 수치(가능한 경우), 지문 내 근거 위치, 분석자/도구 버전, 신뢰도, 결측 사유를 보존한다. 자동 측정치와 사람 판단치를 별도 필드로 기록한다. LLM 판단은 인용 가능한 짧은 근거 위치와 독립 검수 결과를 요구하며, 모델 출력만으로 사실값을 확정하지 않는다.

| 축 | 관측 항목 | 판정 시 주의 |
|---|---|---|
| 어휘 | 빈도대별 비율, 학술어·추상어·다의어·구동사 수와 문맥상 의미 | 희귀어 개수만으로 학년을 판정하지 않는다. 빈도 기준 목록·버전을 고정한다. |
| 구문 | 문장·절 길이, 종속절·삽입·수식 깊이, dependency depth | 파서 버전과 수동 오류 검토를 기록한다. |
| 정보 밀도 | 문장당 명제, 신규 개념, 지시 대상과 재등장 간격 | 길이 정규화 수치와 절대량을 함께 본다. |
| 담화 | 인과·대조·예시·재진술 관계, 문단 기능, 명시/암시 표지 | 관계가 존재하는지와 독자가 복원해야 하는지를 나눈다. |
| 추론 | 명시 정보, 1단계, 다단계, 암묵 관계 요구 문항 수 | 정답 근거 위치와 필요한 연결 단계를 남긴다. |
| 배경지식 | 지문 외 지식 없이는 핵심 이해가 어려운 개념과 근거 | 낯선 주제와 필수 외부 지식을 구분한다. |
| 추상성 | 구체적 대상 대비 개념·이론 중심 명제 비율 | 사례가 추상 개념을 설명하는 기능을 고려한다. |
| 문항 난도 | 정답 근거 거리, paraphrase 정도, 오답 매력도·오답 근거 | 정답률 예측과 실제 정답률을 섞지 않는다. |
| 처리량 | 단어·문장·문단 수, 유지해야 할 정보·관계 수 | 단순 지문 길이와 작업기억 부담을 분리한다. |

축별 코드북은 **교재 본문 분석 전에** 관측 경계, 계산 단위·분모·정규화 방식, 코딩 척도와 앵커 사례, 0/결측 구별, 분석 도구 버전, 이중 코딩·불일치 중재 규칙을 포함한 별도 revision으로 봉인한다. 여기에 문항 유형별 비교 가능 최소 수, 평가자 일치도 하한, 선택 축 결측 허용량, separation 축별 유효 표본 하한과 `FAIL`/`INCONCLUSIVE` 우선순위를 숫자로 적어야 한다. 빈 필드가 있으면 봉인 실패다. 이 코드북 없이는 `benchmark-calibrated`로 전이할 수 없다. 문항 축은 유형별 비율(해당 유형 문항 수/전체 문항 수)과 해당 유형 내 난도만 비교하고, 유형이 없거나 비교 가능한 문항이 부족하면 `MISSING_ITEM_TYPE`으로 남긴다. 오답 매력도는 사람 코더의 서열 판단으로만 기술하며 관측 정답률인 것처럼 쓰지 않는다. 정량 측정이 불가능한 축에 임의의 0을 넣지 않는다.

각 축의 여러 관측치 중 판정용 주지표 하나, 보조지표 목록, 보조지표가 주지표를 뒤집을 수 있는 조건, 결측 시 우선순위를 코드북에 반드시 적는다. 이 정의가 없는 축은 `INCONCLUSIVE_AXIS`이며 5개 필수·9개 전체 축 통과 수에 포함하지 않는다. 탐색용 지표를 판정에 사후 투입하지 않는다.

## 3. 분포와 판정 사전등록

**교재 본문 분석 전에** 후보 목록·추출 seed, 표본 manifest 생성 규칙, 코드북, 아래 판정 알고리즘과 결측·민감도 기준을 같은 protocol revision으로 봉인한다. F02의 일부 단어·문장 수와 합성 분석치는 기존 E3 `analysis.json`에 이미 노출됐다. 따라서 F02에 대해 완전한 사전 맹검이라고 주장하지 않고, 봉인 기록에 분석자의 기존 노출 범위·파일 hash를 남긴다. 교재 표본 선정자는 F02 본문·E3 분석치를 보지 않은 독립 분석자로 지정하고, 불가능하면 `selection_unblinded=true`로 낮춰 보고한다. 표본을 뽑은 뒤에는 최소 충족 층에 한해서만 축 분포를 계산한다. 보고서는 표본 수, 출판사/시리즈 기여량, 중앙값·사분위·범위, 결측률, 평가자 일치도 및 출판사 하나를 제외한 민감도 결과를 제시한다. 학년별 분포가 겹치면 겹침을 그대로 보고하고, 이를 숨기는 단일 종합 점수는 만들지 않는다. 충분한 표본·신뢰도가 없으면 pass band를 계산하지 않는다.

`BENCHMARK_TARGET_FIT`은 F02 각 버전이 목표 학년의 **같은 장르·비슷한 길이** 참조 분포에 들어오는지 축별로 판단한다. 비교 길이는 단어 수가 F02의 75–125%인 지문이며, 해당 학년·장르·길이 비교군에 12지문·서로 다른 출판사 3곳이 없거나 필수 축의 유효 측정률이 80% 미만이면 `INCONCLUSIVE`이다. 제안 허용구간은 각 축 참조 분포의 10–90 분위이며, 어휘·구문·정보 밀도·담화·추론의 필수 5축 모두와 전체 9축 중 7축 이상이 구간 안에 있어야 `PASS`다. 필수 축의 명백한 범위 이탈은 다른 축 평균으로 상쇄하지 않는다. 기존 F02 의미 보존 검수의 현재 hash가 유효하지 않으면 `FAIL_INTEGRITY`다. 실제 학생 이해도 hard gate를 합성·교재 자료로 대신하지 않는다. 경계값 계산·동률 처리와 수동 척도 정의는 코드북에 봉인한다.

F02 비교 결과에는 기존 frozen seal 식별자와 중1·고1 각각의 `passage_hash`, 기존 seal의 **두 학년 공통** `item_set_hash`·`scoring_key_hash`, 사용한 E3 batch의 run ID·입력 hash를 결속한다. 학년별 문항/채점 hash를 추가로 계산한다면 새 필드명과 정렬·직렬화 규칙을 별도 revision에 기록하며 기존 공통 hash를 대체하지 않는다. 측정에 사용한 본문·문항·정답키가 E3 및 seal의 입력과 하나라도 다르면 `STALE_F02_INPUT`으로 결합 판정을 차단하고, 해당 측정은 새 revision에서만 다시 한다.

`BENCHMARK_LEVEL_SEPARATION`은 중1→고1의 축별 변화 방향과 크기를 교재 참조군의 중1→고1 변화와 비교한다. **비율 계산이 가능한 정량 축**에 한해 참조 변화는 고1 중앙값−중1 중앙값이고, 출판사 하나씩 제외한 모든 민감도 계산에서 방향이 유지되는 축만 `DIRECTION_STABLE`이다. 서열 축에는 차이의 50% 규칙을 적용하지 않고, 독립 평가자가 같은 앵커 척도에서 고1이 중1보다 높은지 판단하며 불일치 시 `INCONCLUSIVE_AXIS`로 둔다. 안정 축이 5개 미만이거나 담화·추론 두 축이 모두 불안정하면 전체 `INCONCLUSIVE`이다. 제안 `PASS`는 안정 축 가운데 최소 3축에서 F02 변화가 같은 방향이고, 그 안에 담화 또는 추론 1축이 포함되며, 반대 방향 축은 1개 이하인 경우다. 그 3축 중 정량 축은 **F02 변화와 참조 변화의 부호가 같고**, F02 절대 변화량이 각각 **참조 변화량의 절댓값**의 50% 이상이어야 한다. 어휘만 상승하면 `FAIL`이다. 변화 크기의 최소량은 코드북의 측정 해상도보다 커야 하며, 정확한 경계는 분석 전 봉인한다. F02 두 버전의 독립 `BENCHMARK_TARGET_FIT`과 separation이 모두 통과해야 `Gold-S candidate` 검토를 열 수 있다. 이후에도 권리·provenance·최신 hash·검수 상태를 별도 seed gate에서 재확인한다.

Separation의 두 학년 참조군은 **같은 장르와 F02 각 버전의 75–125% 길이 범위가 서로 겹치는 공통 구간**에서만 고른다. 각 학년별 그 공통 구간에 12지문·3출판사 이상이 없거나 장르 비율 차이가 10%p를 넘으면 전체 `INCONCLUSIVE`다. 비교군의 장르별 가중치와 축별 유효 표본 하한은 분석 전 코드북에 봉인한다. 공통 길이 범위가 비면 두 학년 전체를 그대로 비교하지 않는다.

서열 축의 참조 변화는 동일한 앵커로 독립 코딩한 두 학년의 분포를 비교해 `higher`/`same`/`lower`로 기록한다. 출판사를 하나씩 제외한 모든 비교에서 방향이 같고 평가자 중재 결과도 같을 때만 서열 축을 `DIRECTION_STABLE`에 포함한다. 불일치나 `same`은 `INCONCLUSIVE_AXIS`로 두고 안정 축 5개 계수에 넣지 않는다. 이 참조군 안정성 판정과 F02 두 버전의 별도 서열 코딩을 혼합하지 않는다.

## 4. 실행 순서와 현재 상태

1. 판본 메타데이터·권리 확인 → 선별 코드북 봉인 → 본문 장르·길이·중복 검수 → 학년별 후보와 제외 로그 확정.
2. 선정 seed·배정·대체 규칙, 축별 분석 코드북, 분석 도구 버전, 결측·판정 band와 집계 규칙을 **본문 난도 분석 전에 사전 봉인** → hash 기록.
3. 결정적 표본 추출 → 독립 분석과 불일치 중재 → 봉인된 규칙으로 학년별 분포 및 민감도 산출. 현재 **실측 0건**.
4. F02 측정·비교 → `BENCHMARK_TARGET_FIT`과 `BENCHMARK_LEVEL_SEPARATION` 개별 판정. 분석 후 규칙 변경은 새 protocol revision이며 기존 결과를 소급 변경하지 않는다.
5. 둘 다 통과한 경우에만 `Gold-S candidate` 검토. Gold-S 및 DB seed는 별도 승인·gate.

현재 `local-cross-agent-audit-ready=true`, E3 합성 유효 N=28, 교재 benchmark 실측 N=0, 실제 학생 N=0, `BENCHMARK_TARGET_FIT=unopened`, `BENCHMARK_LEVEL_SEPARATION=unopened`, 기존 학생 `TARGET_FIT=unopened`, `LEVEL_SEPARATION=unopened`, `Gold-S=0`, DB seed=0이다. 기존 [`market-benchmark.mjs`](../scripts/textbook/market-benchmark.mjs)의 출판 교재 구성·문항 비교 수치를 이 지문별 학년 난도 분포로 재사용하지 않는다.
