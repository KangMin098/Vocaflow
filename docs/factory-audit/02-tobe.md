## 0. 재설계의 한 문장

**공정을 바꾸지 않는다. 눈금을 바꾼다.**

진단의 결론은 「공장은 돌아가는데 계측이 거짓말을 한다」였다. 그러므로 단계를 합치거나 나누거나
순서를 바꾸자는 제안은 **하나도 없다.** 8칸 구조는 시중 공정과 1:1 로 맞아 있고, 재료도 문항도
남아돈다. 고칠 것은 **무엇을 보고 통과라고 말하는가** 하나다.

### T1 상세 — 무엇으로 바꾸나

```
  현재 (factory.ts:516-541)
    num = csat_coverage().published 합   = 802     ← 기출 분석
    den = csat_coverage().in_scope_items 합 = 802
    → 100% 통과

  제안
    num = renders.colophon.review.personaReview.passed 합  = 4    ← 교재 문항
    den = renders.colophon.review.personaReview.items  합  = 408
    → 0.98% 막힘 (검수 화면과 **같은 수**)
```

기출 쪽 수(802/802)는 **없애지 않는다** — ① 기출 원천의 눈금으로 이미 살아 있다.
⑦에서 빼는 것이지 지우는 것이 아니다. 두 화면이 같은 라벨로 다른 수를 말하는 것만 끝낸다.

### T2 상세 — 게이트를 어떻게 다시 쓰나

지금: `bindingIndex >= 1.200` → 미달이면 `short`.
제안: **판정을 둘로 가른다.**

| 조건 | 상태 | 화면이 말하는 것 |
|---|---|---|
| `bindingIndex >= target` | `pass` | 통과 |
| `bindingIndex < target` **이고** `targetReachable` | `short` | "더 만들면 닿는다" — 지금과 같음 |
| `bindingIndex < target` **이고** `!targetReachable` | **`unmeasured`** | **"막는 것은 생산이 아니라 증거다 — EBS 해설집이 코퍼스에 0건"** |

`unmeasured` 를 쓰는 이유: 이 저장소의 규약이 **「못 잰 것은 통과가 아니다」**이고, 동시에
**「못 잰 것은 실패도 아니다」**이기 때문이다. 지금 ②는 실패(빨강)로 서 있는데 실패가 아니다 —
아무도 재지 않은 것이다. 그리고 `judgeStage` 는 이미 `unmeasured`(severity 1)를
`short`(2)·`blocked`(3)보다 **약하게** 접으므로, ②가 다른 공정의 진짜 경보를 덮지 않게 된다.

⚠️ **이 변경은 게이트 기준 변경이다.** 승인 없이는 손대지 않는다.

## 4. 검수 오류 유형 × 층 매핑표 — 「오류 0」 폐기

**폐기 이유.** 「오류 0」은 분모가 없어 측정할 수 없고, 달성 여부를 말할 수 없는 목표는 목표가 아니다.
대신 **오류 유형별 검출률 + 탈출 경로**로 다시 쓴다.

| 오류 유형 | 잡는 층 | 현재 검출률 | **제안 목표** | 탈출 시 회수 경로 |
|---|---|---|---|---|
| 해설 누락 | L1 차단 | ~100% | **100% (차단 유지)** | 발행 불가 |
| 인용 불일치 | L1 차단 + L2 | ~100% | **100%** | `analysis-drain-validate` |
| 정답 ≠ 정답표 | L1 차단 | ~100% | **100%** | 〃 |
| 순환논법 8종 | L1 차단 | ~100% | **100%** | 〃 |
| 자동 검수 미통과 | L1 차단 | ~100% | **100%** | 발행 불가 |
| 정답 번호 쏠림 | L3 **경고만** | 16/19 기록 | **차단으로 승격? → 결정 필요** | **없음** |
| 규칙 교정 위반 | L1 교정 · 경고만 (오탐 3%) | 19/19 기록 | 경고 유지 | 없음 |
| **해설 품질(내용 오류)** | **L2 단독** | **0.98%** | **권당 표본 ≥ 20%** | **없음 → 신설 필요** |
| **오답 설계 부실** | **L2 단독** | **0.98%** | **권당 표본 ≥ 20%** | **없음 → 신설 필요** |
| **학년 적합성** | **L2 단독** | **0.98%** | **권당 표본 ≥ 20%** | **없음 → 신설 필요** |
| **지문 자립성** | **L2 단독** | **0.98%** | **권당 표본 ≥ 20%** | **없음 → 신설 필요** |
| 지문 어수 규격 | L3 + L4(A6) | 측정됨 | **A6 ≥ 1.15** | 재조판 |
| 선택지 수 규격 | L4(A7) | 측정됨 | A7 ≥ 1.09 | 재조판 |
| 유형 다양성 | L4(A5) | **못 잼** | **측정기 먼저** | 없음 |

### 4-1. 배포 차단 조건 — 명시안

| 조건 | 지금 | **제안** |
|---|---|---|
| L1 차단 항목 하나라도 걸림 | 발행 불가 (`publish-gate.ts`) | **유지** |
| **L2 표본 < 20%** | 아무 규칙 없음 | **권 단위 발행 보류** — 「검수 안 한 책」과 「검수한 책」을 가른다 |
| **L2 표본 중 pass < 100%** | 3인 pass 요구 → 실질 차단 | **유지 · 현황판이 그 사실을 말하게 한다(T1)** |
| **L4 미측정 축 존재** | 아무것도 안 막음 | **차단 아님 · 다만 「우위」 문구를 화면에서 못 쓰게 한다** |

> **L4 는 배포 차단 조건이 아니다** — 학습자가 받는 책의 품질이 아니라 시장 대비 위치를 재는 축이기 때문이다.
> 다만 **10/28 축(35.7%)만 잰 상태에서 「시중 대비 120%」를 화면·문서에 쓰는 것은 근거가 없다.**
> 그 문구를 쓰려면 A5 측정기(T8)와 EBS 해설 코퍼스가 먼저다.

### 4-2. 탈출 오류의 발견·회수 경로 — **지금 존재하지 않는다**

|---|---|---|

## 7. 승인 요청

3단계에서 구현할 후보. **되돌리기 싸고 하류 영향 큰 것부터 최대 3개.**

| | 제안 | 되돌리기 | 하류 영향 | 게이트 기준을 바꾸나 | 승인 |
|---|---|---|---|---|---|
| 1 | **T1** ⑦L2 를 교재 문항으로 | 매우 쌈 | 1위 | 아니오(모집단 교체) | ☐ |
| 2 | **T2** ② 에 `targetReachable` 판정 추가 | 쌈 | 2위 | **예 — 게이트 기준 변경** | ☐ |
| 3 | **T3** 자유도 패널을 mv 로 | 쌈 | 3위 | 아니오 | ☐ |
| 4 | **T4** 「조판 풀」 라벨 분리 | 매우 쌈 | 4위 | 아니오 | ☐ |

**권고: T1 · T3 · T4.** 셋 다 게이트 기준을 안 바꾸고 눈금·라벨·출처만 고치므로
「승인 없이 게이트 기준을 바꾸지 않는다」는 규칙 안에 있다.
**T2 는 게이트 판정 규칙을 바꾸므로 별도 승인이 필요하다.**

그 밖에 **결정 필요 항목 10개**가 §2(브랜드 5) · §3-1(커버리지 1) · §4(차단 조건 3 · 신고 경로 1)에 있다.
