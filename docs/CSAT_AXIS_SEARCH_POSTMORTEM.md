# 수능 출제 사고 축 탐색 — 중단 보고서

> **결론: 통일 축을 찾지 못했다. 가설 4개가 전부 실패했고, 실패의 원인이 내 측정 도구에 있다.**
> 가설 5를 만들어 같은 도구로 또 시험하는 대신 여기서 멈추고 원인을 적는다.
>
> 2026-08-22 · 6사이클 · `/goal` 규칙의 "3회 연속 실패 시 접근 전환, 그래도 안 되면 원인 분석 후 중단" 적용.

---

## 1. 시도한 가설과 실패 방식

| # | 가설 | 검사 | 결과 |
|---|---|---|---|
| 1 | 출제자는 **명시되지 않았지만 확정되는 것**을 묻는다 | 유형별 3점 부여율 | **반증** — 요약문 0/13 · 요지 0/13 · 심경 0/12. 전부 확정형인데 3점이 13년간 0 |
| 2 | 출제자는 **근거가 한 곳에만 있는 지점**을 감춘다 | 3점/2점 빈칸 각 2문항 정독 | **반증** — 3점 빈칸도 근거가 분산(2022 #33 세 곳 · 2019 #34 다섯 곳) |
| 3 | 출제자는 난이도를 **오답의 어휘 위장**으로 조절한다 | 빈칸 52문항 → 6유형 107문항 | **부분 성립 후 일반화 실패** — 빈칸에서만(28.8% vs 8.3%), 함축·주제는 방향 반대 |
| 4 | 축은 출제 수단이 아니라 **학습자의 읽기 실패**에 있다 | 표면 전략의 정답 적중률 | **반증** — 유형별로 보면 1/4만 방향 일치 |

## 2. 왜 실패했는가

### 2.1 측정이 전부 어휘 수준이다

가설 3·4의 지표는 **선택지 낱말이 지문에 나오는 비율** 하나다. 이걸로는:
- 어휘는 안 겹치는데 의미가 가까운 오답(2019 #34)을 못 잡는다
- 논리 관계(인과·대조·양보)의 오독을 못 잡는다
- 추상화 수준의 차이를 못 잡는다

**축이 의미·구조 수준에 있다면 내 도구로는 원리상 안 보인다.** 즉 "축이 없다" 와 "내 자가 짧다" 를 구분할 수 없다.

### 2.2 집계가 착시를 만들었다 (심슨의 역설)

가설 4에서 집계는 깨끗했다 — 표면 전략 적중률이 2점 44.3%, 3점 26.1%.
그런데 **3점 46문항 중 35개(76%)가 빈칸추론**이다. 집계는 빈칸을 다시 잰 것이었고,
유형별로 가르니 4유형 중 1유형만 방향이 맞았다.

> 하위 그룹 구성을 확인하기 전에는 집계를 믿지 않는다 — 이번에 실제로 당했다.

### 2.3 배점을 난이도의 대리로 썼다

3점/2점은 **출제자가 부여한 것**이지 실제 정답률이 아니다.
"출제자가 무엇을 어렵다고 보는가" 의 기록으로는 적합하지만,
**학습자가 실제로 어디서 틀리는가** 는 말해 주지 않는다.

### 2.4 학습자 실패를 직접 관측할 자료가 없다

가설 4는 "학습자의 읽기 실패" 를 축으로 삼았는데, 정작 **어떤 오답을 실제로 고르는지**
자료가 없다. 선택 비율 없이는 실패를 재현했다고 주장할 수 없고,
내가 만든 "실패 모드" 는 결국 내 상상이다.

## 3. 그래도 남은 것 — 버리지 않는다

이 탐색이 실패했다고 앞선 작업까지 무효는 아니다. 다음은 실측으로 확정됐다.

| 확정된 것 | 근거 |
|---|---|
| 문항 630/630 추출 · 유형 43종 배정 585/585 (미배정·중복 0) | `scripts/csat/data/` |
| 정답·배점 630/630 · **배점 교차검증 100%** | 문제지 `[3점]` vs 평가원 정답표 |
| 형식 불변식 — 45문항 · 3점 정확히 10 · 선택지 5 · 영역 경계 | 13/13 회차 |
| 순서 유형 선택지 순열이 **고정 템플릿** (2017·2024 두 번만 교체) | 13개년 토큰 시퀀스 대조 |
| **빈칸추론 한정** — 3점 오답이 지문 어휘로 두껍게 위장됨 (28.8% vs 8.3%) | 52문항 전수 · 회차 8/9 일치 |
| 3점은 **국지 판단** 유형에 몰림 (빈칸 67 · 함축 63 · 어법 62 vs 요지·요약·심경 0) | 585문항 |

마지막 둘은 **유형 한정 사실**이지 축이 아니다. 그렇게 표시해 둔다.

## 4. 다시 시작한다면 필요한 것

우선순위 순으로, 없으면 같은 실패를 반복한다.

1. **선택지 선택 비율(오답률) 자료** — 가장 결정적. 이게 있어야
   "이 오답은 이런 오독을 잡는다" 가 주장에서 관측으로 바뀐다. EBSi·입시업체 공개분.
2. **의미 수준 측정 도구** — 어휘 중첩을 넘어서는 것. 문장 임베딩으로 정답–오답 의미
   거리를 재면 가설 3 계열을 제대로 시험할 수 있다. 이 저장소에 이미 임베딩 자산이 있는지 확인할 것.
3. **유형별 균형 표본** — 3점 문항의 76%가 빈칸인 편중을 통제해야 집계가 의미를 갖는다.
4. **듣기 대본** — 17문항(38%)이 지금 통째로 분석 밖이다.

## 5. 열린 질문 — 정직하게

**통일 축이 정말 없을 수도 있다.** 유형마다 다른 능력을 재도록 설계됐다면
"하나의 출제 사고" 는 애초에 없는 것이고, 그렇다면 학습도 유형별로 갈 수밖에 없다.

다만 **4개 가설이 실패했다는 것은 내 가설이 틀렸다는 뜻이지 축이 없다는 증명이 아니다.**
위 4가지 자료·도구를 갖추기 전에는 이 둘을 구분할 수 없다. 구분할 수 없다는 사실 자체를
결론으로 적어 둔다.
