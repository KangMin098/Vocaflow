# 실제 AI 수행에서 발견한 교수·피드백 수정

2E/2F 구현 뒤 실제 학습자 역할 응답을 제품 채점기로 확인하고, 불일치를 두 신규 독립 세션으로 재검토했다. 사람 검토 행·공유 DB 쓰기·권리 부여는 0이다.

1. `r5-cm-transfer-1`에서 반박 대상 문장을 뒷받침으로 선택한 응답에 ‘중심과 관계없는 문장’이라고 안내하던 문구를 고쳤다. 반박 대상도 글의 맥락과 관련 있으므로 관계를 다시 구분하도록 안내한다. Gold의 반박 분류와 주요 정답 계약은 유지한다. 감사자 사이에 이 문장을 선택 근거로 허용할지 차이가 있었으며, 반박 대상과 직접 뒷받침을 구별하는 현재 계약을 유지한 이유를 기록했다.
2. `r5-cycle-ind-1`의 조건문은 ‘이유’와 ‘예시’가 모두 가능한 관계 질문이었다. 두 감사자가 이 모호성에 동의했다. 전역 채점 규칙을 느슨하게 바꾸지 않고, 명시적인 재진술 문장의 관계를 묻는 **보충 세트 v2**로 수정했다. 지문·객관식 선택지·정답은 그대로다.
3. v1 파일·검토·학습자 응답은 보존하고 활성 레지스트리는 v2만 사용한다. v1의 부분집합 등록 예외를 제거했으므로 역사적 v1 영수증으로 신규 등록할 수 없다. 아직 공유 DB에 창작 원장이 없고 v1을 실제 등록하지 않았으므로 DB 행을 덮어쓰지 않았다. 설치 전 이 조건을 다시 검사한다.

감사 신규 세션은 Claude `1b8ce6a0-15c3-4747-b238-3aa244e689b7`, Codex `01a15e44-99a5-7f62-b46e-f8b6c80b798b`다. 수정 v2는 Claude `b1b9994b-adcf-4ab0-9695-0e60ec895908`, Codex `01a15e47-751e-7f70-a531-1738b8fcaf60`가 각각 3문항을 수락했다. 실제 `verifyAiReviewReceipt`로 원본 세션·프롬프트·응답·문항/Gold 해시를 대조해 통과했다.

활성 파일 SHA-256: `408d40fdd5a1e24ec9bf5ce2b5e398e09c86a4dbf9aa16523bb305d41268c08c`.

수정 뒤 신규 학습자 세션 Claude `17fcc75d-13f6-42da-8b57-868b19bc83f7`, Codex `01a15e48-51a4-7041-8a96-a3c5b72aa561`의 8응답은 중심·객관식·관계 판단을 통과했다. Claude의 반박 문장 선택은 하위 근거 판정 불일치로 보존했다. 초기 오답은 합성 상태이므로 학습 향상/인과효과의 증거로 쓰지 않는다. 통합 SQL 시험은 새 Codex 원시 응답을 그대로 사용한다.

프롬프트·세션·원시 응답·수정 이력·제품 채점은 [evidence/2g-diagnostic](./evidence/2g-diagnostic)에 있다. 이전 A/B 결과의 우위 판정 불가 결론은 바꾸지 않는다.
