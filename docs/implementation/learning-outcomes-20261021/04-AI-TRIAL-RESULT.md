## 실제 실행과 비교

Claude Code `claude-opus-5-5`와 Codex `gpt-6.1-sol`에 학습자 역할을 부여했다. 사전 과제는 모델별 1회, 이후 각 모델을 A/B 두 조건으로 분기했다. **분기 실행 24회 = 학습 12회 + 사후/전이/SIMULATED_DELAY 평가 12회**다. 앞서 실행한 사전 2회를 합치면 학습자 요청은 26회이고, 독립 채점 대상 평가 답안은 14개다. 채점·교수 검수·반례 검토 세션은 이 분모에 포함하지 않는다.

평가 지문과 키를 학습 실행 전 동결했고, 정답·루브릭·다른 사후 과제는 학습자에게 주지 않았다. 사전 응답을 재생했으므로 사전 문항의 일부 인용은 학습 문맥에 포함됐다. 지문 분리 검사는 **완전한 지문의 정규화 본문**이 겹치지 않는다는 뜻이며 모든 평가 유래 단어가 없다는 뜻은 아니다. 전이는 미술/제목과 다른 도구 설명서 상황의 암묵적 주장을 다뤘다. 모델의 사전학습 노출은 알 수 없다.
