# 원문 판정 기준 — 정본

> **원문 판정(내용 판정 · 보관 판정)의 기준은 이 파일 하나다.** 판정자(`csat-source-judge` —
> `.claude/agents/` · `.codex/agents/` 두 벌)는 청크를 다루는 **절차만** 갖고, 무엇을 어떻게 가르는지는
> 판정 전에 이 파일을 읽고 따른다. 기준을 판정자 정의나 청크 지시에 다시 쓰지 않는다 — 두 벌로 손수
> 고치던 정의가 이미 한 번 어긋났다(2026-09-24 확인).
>
> 코드에 있는 목록(차단 장르 · 주제 장르 · 교재 재료)의 정본은 `scripts/csat/gate-rules.mjs` 이고, 이 파일의
> 표와 **같아야 한다** — `scripts/csat/__tests__/judge-criteria.test.mjs` 가 어긋나면 실패한다.
> 기준을 바꾸면 이 파일과 `gate-rules.mjs` 를 **같은 커밋**에서 고친다.

## 1. 판정은 두 가지다

| | **내용 판정** | **보관 판정** |
|---|---|---|
| 묻는 것 | 이 글을 **지금 이대로 게시**해도 되는가 | 이 원본을 **교재 원천으로 남길** 가치가 있는가 |
| 대상 | 발췌본 · 개별 기사 · 문항이 붙은 원본 | 자르지 않은 원본(`purpose:'raw'` — 지금은 PLOS 논문 전문) |
| 청크 입력 | `content` — **본문 전문** | `sections` — 서론·배경·고찰·결론 절(`lib-plos-sections.mjs`) |
| 청크 만드는 곳 | `gate-article-export.mjs` | `plos-raw-triage-export.mjs` |
| 출력 `basis` | 없음 또는 `"full"` | `"sections"` |
| 결과가 들어가는 칸 | `csat_fit.gate.verdict` | `csat_fit.gate.retain` (`gate.verdict` 는 건드리지 않는다) |
| 여는 것 | 게시 적격(학령·CEFR 등 다른 축도 통과해야) | 발췌(`plos-extract` 는 보관된 원본만 자른다) |
| **망설여지면** | **막는다** — 되찾지 못한 글은 격리에 남을 뿐이고, 잘못 살린 글은 학생에게 간다 | **남긴다** — 보관 쪽 오류는 발췌본의 내용 판정에서 걸리지만, 버린 원본은 다시 읽히지 않는다 |

보관 판정은 **게시를 열지 않는다.** 보관된 원본에서 나온 발췌본은 반드시 내용 판정을 따로 받는다.

## 2. 읽는 범위 — 반드시 전부 읽는다

- 청크의 입력 본문(`content` 또는 `sections`)을 **처음부터 끝까지** 읽고 판정한다. 앞 몇백 자만 보고 판정하지 않는다.
- 근거(2026-09-24 · 같은 PLOS 30편을 세 방식으로 판정):

  | 읽은 범위 | 전문 판정이 보관한 17편 중 버린 편수 | 전문이 버린 13편 중 보관한 편수 | 분량 |
  |---|---|---|---|
  | 앞 800어(실제로는 판정자가 앞 350~600자만 읽었다) | **12** | 0 | 약 16% |
  | 서론·고찰 절 전부 | **0** | 5 | 43% |
  | 전문 | 기준 | 기준 | 100% |

  논문은 읽을 만한 단락이 **고찰 쪽**에 많다. 초록만 보면 거의 모두 「전문 용어 중심」으로 보인다.

## 3. verdict — 셋 중 하나

| 값 | 내용 판정에서 | 보관 판정에서 |
|---|---|---|
| `use` | 설명·논증문으로 읽힌다. 한 편의 글로 논지가 서고 자족적이다 | 입력 절들 어디든 떼어 내면 고교~성인 영어 지문이 될 만한, **일반 독자에게 읽히는** 설명·논증 단락이 있다 |
| `narrative` | 이야기·전기·회고 — 사건이 시간순으로 흐른다(심경 19번 · 장문 43~45번 유형용) | 사례·회고처럼 사건이 시간순으로 흐르는 단락이 중심이다 |
| `reject` | 아래 차단 장르 중 하나다 | 어느 단락을 떼도 유전자·경로 이름, 수치, 수식 나열이라 일반 독자용 지문이 안 된다(`reference`), 또는 다른 차단 장르 |

`narrative` 는 **탈락이 아니다.** 서사를 통째로 막았다가 `mood`·`long_reference` 지문이 재고에서 사라진 적이 있다(2026-09-06 · `gate-rules.mjs` 주석).

## 4. genre

**`reject` 면 genre 는 반드시 차단 장르 9종 중 하나다.** (`gate-rules.HARMFUL` + `UNFIT` + `poetry-drama`)

| genre | 뜻 |
|---|---|
| `fragmentary` | 캡션·표 조각·문장 중간에서 끊긴 덩어리. 앞뒤 없이 뜻이 안 선다 |
| `reference` | 사전 항목·목록·참고문헌·방법 절차·수치 나열 — 읽는 글이 아니다 |
| `mixed` | 서로 다른 글이 섞였다. 주제가 중간에 갈아엎힌다 |
| `bias` | 특정 집단에 대한 편견이 전제로 깔렸다 |
| `doctrine` | 교리·신조를 사실로 제시한다 |
| `pseudoscience` | 의사과학 |
| `obsolete-fact` | 지금은 폐기된 사실을 현재형으로 말한다. **철회 논문**(제목이 `RETRACTED:` · `WITHDRAWN:` · `EXPRESSION OF CONCERN:` 으로 시작)도 여기다 — 본문이 읽혀도 버린다 |
| `polemic` | 선동·일방적 정치 논박 |
| `poetry-drama` | 운문·희곡 |

**`use`·`narrative` 의 genre 는 주제 분류다** — 아래에서 고른다(새 낱말을 만들지 않는다). `use`/`narrative` 에 차단 장르를 쓰면 적재기가 거부한다.

## 5. uses — 이 원문으로 어떤 교재를 만들 수 있는가

**`use`·`narrative` 면 하나 이상, `reject` 면 빈 배열.** 정본은 `gate-rules.SOURCE_USES`. 이것은 수능 목록이 아니다 —
`textbook/market-spec.json`(시중 영어 교재 79종 · 표준 발문 41종)에서 실측한 매핑이다.

| 태그 | 읽어서 판단할 것 | 이 재료가 여는 시중 유형 |
|---|---|---|
| `argument` | 논지가 한 편으로 선다 | 주제·제목·요지·주장·목적·요약·빈칸 |
| `structured` | 단락·문장 경계가 뚜렷해 떼고 끼울 수 있다 | 순서·문장삽입·무관한 문장 |
| `sequence` | 사건·절차가 시간순으로 이어진다 | 장문 지칭·서사 지문 |
| `mood` | 인물의 심경·분위기가 읽힌다 | 심경 |
| `factual` | 확인 가능한 사실 진술이 여럿이다 | 내용 일치 |
| `vocab` | 문맥으로 뜻이 잡히는 어휘가 있다 | 어휘 선택·어휘 빈칸·어휘 교재 |
| `grammar` | 문장이 정확해 어법 문항을 만들 수 있다 | 어법 선택·어법 수정·배열 |
| `spoken` | 대화·구어체다 | 듣기·받아쓰기·낭독 |

- **길이로 고르지 않는다.** 어수창과 밴드는 기계가 잰다(`compose-unit.itemWordSpec`). 답할 것은 그 재료가 이 글에 있는가뿐이다.
- 넉넉히 달지 말고 실제로 있는 것만 단다.
- 보관 판정의 uses 는 「발췌하면 이 재료가 나올 단락이 있다」로 읽는다.

## 6. why

**한국어 한 문장 · 12자 이상 · 편마다 따로.** 무엇이 이 글을 그 판정으로 만들었는가를 적는다 — 보관 판정이면 **근거가 된 절과 그 단락이 하는 말**까지.
「좋은 글이다」처럼 되짚을 수 없는 말, 여러 편에 복사한 같은 문장은 쓰지 않는다(2026-09-24 시범에서 81편에 같은 문장이 붙었다). 나중에 이 판정을 뒤집으려는 사람이 읽을 문장이다.

## 7. 원천별 요령 (실측)

- **자족성이 내용 판정의 첫 축이다.** 지문 밖(그림·앞 장·원본 쪽)을 가리켜야 뜻이 서면 `reject`/`fragmentary`.
- **VOA 기사**: 끝에 붙은 댓글 안내·구독 권유·기자 소개 때문에 글을 버리지 않는다 — 잔재 제거는 다른 공정이다. 본문이 링크 목록·편성표뿐이면 `reject`/`reference`.
- **발췌본**(300~400어): 문장 중간에서 시작·끝나는 것만으로 버리지 않는다 — 발췌는 원래 그렇다. 한 덩어리로 뜻이 서는지 본다. 장면이 둘 이상 겹쳐 주제가 갈리면 `mixed`.
- **논문**: 서론·고찰이 통념→반전→물음으로 서면 `use`. Methods·Results 수치 나열, 저자 기여·연구비 진술이 중심이면 `reference`. 논평·에세이(절 구분 없음)는 대개 `use` 쪽이다.
- **인용 표시**(`[12]` · `(Smith et al., 2019)`)만으로는 탈락이 아니다 — 기계 규칙(`gate-rules.mjs`)이 따로 본다.
- **소재가 민감하다는 이유만으로 버리지 않는다.** 판단은 그 본문이 **실제로 하는 말**에 건다(정책을 다루는 글 ≠ `polemic`, 선동을 연구하는 논문 ≠ `polemic`).
- **난이도로 버리지 않는다.** 학령·CEFR 은 기계 축이 따로 가른다(발췌본 탈락의 대부분이 `cefr_above_band` 다). 판정자는 내용만 본다.

## 8. 기준을 바꿀 때

1. 먼저 **전량 또는 무작위 표본**으로 지금 기준과 새 기준을 나란히 판정해 차이를 잰다(AGENTS.md 「일화를 근거로 권고하기」).
2. 이 파일 + `gate-rules.mjs`(목록이 바뀌면) + 판정 규칙판(`RULES_VERSION`, 결과가 바뀌면)을 같은 커밋에서 고친다.
3. `node --test scripts/csat/__tests__/judge-criteria.test.mjs` 가 통과해야 한다.
