# 영어 전 영역 원리 후보 (초안 · 2026-10-10)

> 상태: **분석자 추론(attribution `inferred`) · DB 미등록**. 원리 층이 빈 7개 영역(「원리 근거 비교」 영역 지도 실측)의 출발점이다.
> 등록 · 채택 전 할 일은 영역마다 같다 — ① 원문 확인한 연구 서지 등록 ② 기출 관찰 연결(수능 듣기 · 어휘 · 어법 문항) ③ 반대 설명 탐구 질문 ④ 「검토 중」 등록 → 채택 검토.
> 연구자 이름 · 이론명은 **찾아볼 방향**이지 근거가 아니다. 서지 · 결과를 원문으로 확인하기 전에는 근거로 연결하지 않는다.

| 영역 | 원리 후보(처리 기제) | 수능 문항에서 보이는 모습 | 확인 · 반대 설명으로 볼 것 | 첫 방법 후보 |
|---|---|---|---|---|
| 듣기 | 연속 음성에서 단어 경계를 나누는 처리(분절)가 의미 처리보다 먼저 막힌다 | 아는 단어를 듣고도 못 알아듣는 오답 | 어휘 부족 · 작업기억 한계로도 설명된다 — 대본을 보면 맞히는지로 가른다 | 대본 확인 전 · 후 받아쓰기 비교 |
| 어휘 | 단어를 여러 번, 간격을 두고 **꺼내 쓰는(인출)** 경험이 기억을 오래 남긴다 | 외운 단어를 지문 속에서 못 알아봄 | 노출 빈도만으로 설명되는가 — 인출 없이 반복 노출한 집단과 비교 | 간격 인출 카드(FSRS · 이미 플랫폼에 있음) |
| 어법 | 형태와 의미를 함께 주목해야(형태-의미 연결) 규칙이 이해에 쓰인다 | 규칙은 외웠는데 문장 속 어법 판단 오답 | 명시 규칙 암기만으로 충분한가 — 규칙 시험 vs 문장 판단 점수 차 | 의미가 바뀌는 최소쌍 문장 판단 |
| 쓰기 | 글의 목적 · 독자를 먼저 정하면 구조가 따라온다 | (수능 직접 문항 없음 — 요약문 완성 · 순서 문항과 연결) | 구조 템플릿 연습으로도 같은 효과인가 | 요약문 한 줄 쓰고 원문 구조와 비교 |
| 말하기 | 계획 → 표현 → 점검의 처리 부담을 나눠야 유창성이 오른다 | (수능 직접 문항 없음) | 단순 반복 연습과의 차이 | 같은 과제 반복 + 사전 계획 시간 |
| 발음 | 소리 범주를 구별하는 지각이 발음 산출보다 먼저다 | 듣기 최소쌍 혼동(예: 강세 · 연음) | 철자 지식 간섭으로 설명되는가 | 최소쌍 듣고 고르기 → 따라 말하기(EchoMatch 와 연결) |
| 읽기(일반) | 글 전체 표상(상황 모형)을 세우며 읽어야 세부가 위치를 얻는다 | 세부 일치는 맞히는데 요지 · 제목 오답 | 어휘 · 배경지식 부족으로도 설명된다 | 단락마다 한 줄 요약 후 요지 고르기 |

## 이미 있는 것과의 관계

- 「논리 · 글 구조」 영역에는 원리 사슬이 있다: 주장 · 근거 연결(학습자에게 켜짐) · 글 순서 단서(초안). 위 「읽기(일반)」은 그 상위 · 옆 원리 후보다.
- 플랫폼에 이미 있는 학습 모듈(Flashcard · FSRS · EchoMatch · Dictation)이 듣기 · 어휘 · 발음 방법 후보의 실행 화면이 된다 — 새 화면보다 **기존 모듈에 원리 사슬을 연결**하는 것이 먼저다.

## 순서 제안

1. 어휘(간격 인출) — 플랫폼에 실행 모듈과 기록이 이미 있어 원리 → 과제 → 기록 → 신호 연결이 가장 짧다.
2. 듣기(분절) — Dictation 기록으로 「대본 전 · 후」 비교가 바로 된다.
3. 나머지는 연구 서지 등록이 먼저다.
