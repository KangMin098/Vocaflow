# /csat 학습자 최적화 재설계 — 지시문 (2026-09-17)

> 사용자 지시문 원문을 보존한다. 결정 기록은 [csat-learner/DECISIONS.md](./csat-learner/DECISIONS.md),
> 게이트 리포트는 `docs/csat-learner/gate*-report.json`.

## 0. 진단 — 세 가지 지적은 하나의 원인에서 나온다

| 지적 | 실제 원인 | 결정 |
|---|---|---|
| 화면이 복잡하고 낯설다 | 앞선 설계(모드 4개·라우트 7개·렌즈 8개·레이어 6장)는 관리자·분석가의 사고 구조를 학습자에게 그대로 노출했다 | 라우트 3개, 화면당 행동 1개, 선택은 시스템이 대신 |
| 업로드한 기출 PDF가 너무 작다 | 시험지 한 페이지(2단·A4)를 통째로 캔버스에 그렸다 | 페이지를 그리지 않는다. 학습자 PDF에서 해당 문항 텍스트만 뽑아 큰 글자로 다시 흘려 넣는다(reflow) |
| 분석과 원문이 따로 있다 | 원문 캔버스 / 레이어 패널 2열 구조 | 분석을 원문 안에 넣는다. 문장을 탭하면 그 문장의 설명이 바로 아래 펼쳐진다. 열이 하나 |

핵심 전환: "기능을 고르는 화면"에서 "다음 버튼 하나로 굴러가는 루프"로.

## 1. 학습자 루프 — 화면 3개, 행동 1개

```
[홈]  오늘의 세션 1장: "빈칸 2문항 + 복습 1문항 · 약 9분"  → [시작]
[학습]  문항 1개가 한 화면. ① 풀기 ② 이해(문장 안 인라인 설명 · 강의 듣기 선택) ③ 한 줄 + [알겠어요]/[헷갈려요]
[기록]  스트릭·유형별 정확도·복습 대기 수. 숫자 3개와 막대 하나.
```

지속 장치: 세션 ≤10분 · 먼저 풀고 나중에 본다 · 틀린 문항은 3일·10일 뒤 복습 · 유형 교차 ·
한 줄 메타인지 확인 · 압박 없는 스트릭 · 시작까지 탭 2회.

PDF: 브라우저 안에서만 읽는다(서버 전송 없음). pdf.js `getTextContent` → 문항 경계 → 문항 텍스트만 reflow
(본문 18~19px · 줄 ≤65자 · 줄간격 1.65) → 분석 앵커는 reflow 된 문장에 붙는다 → 추출 실패 회차만 이미지 크롭 폴백.
회차별 추출 결과는 IndexedDB 에 남는다(원본 바이트는 저장하지 않음).

## 2. 지시문

```text
[A] 절대 제약
A1. 학습자 라우트는 3개뿐: /csat(홈) · /csat/session(학습) · /csat/progress(기록). 나머지는 삭제하거나 관리자 영역으로.
A2. 화면당 주 행동은 1개. 탭·모드·렌즈·필터 UI 금지.
A3. 학습자 화면에 표(table) 렌더 금지.
A4. 정오 확인 전에는 분석·밑줄·설명이 DOM에 없다(미렌더).
A5. 원문은 학습자 PDF에서 브라우저 안에서만 추출·표시. IndexedDB에는 추출 텍스트·해시만.
A6. PDF 페이지를 캔버스로 그리지 않는다. reflow 기본, 이미지 크롭은 추출 실패 시 폴백.
A7. 분석은 원문 문장 안에 인라인으로. 좌우 2열 금지.
A8. 알림·푸시·랭킹·뱃지 없음. 스트릭 표시는 숫자 1개.

[B] 화면 명세
/csat — 카드 1장("오늘 · 빈칸 2 + 복습 1 · 약 9분" + [시작]) + 스트릭 한 줄.
  PDF 없으면 카드 하단 "이번 세션 PDF 1개 필요 · [받기 ↗] [여기 놓기]".
  세션 구성: 약한 유형(최근 20문항 정확도 최하) 1 + 다음 순서 유형 1 + 복습 큐 1. 큐가 비면 신규 1.
  첫 방문 온보딩 1장(풀고 → 이해하고 → 한 줄 남기기) + [시작]. 다시 안 보임.
/csat/session — 한 문항 = 한 화면, 상단 "2 / 3"
  ① 풀기: reflow + 선지 카드 5 + 작은 타이머(색 변화 없음). 탭 → 즉시 정오. 오답이면 정답 카드도 표시.
  ② 이해: 근거 문장 밑줄 → 탭 시 아래 설명(≤3문장) 펼침/접힘. 오답 카드 탭 → 한 줄 + 관련 문장 스크롤·강조.
     함정 마커 1개. [강의 듣기] 선택. 설명 기본 5개 이하, 나머지 [더 보기].
  ③ 한 줄: "다음에 이 유형: …" + [알겠어요] [헷갈려요]. [헷갈려요] → 3일 후 복습(정답이어도).
  마지막: "오늘 끝 · 2/3 정답 · 내일 복습 1" + [홈으로] [한 세트 더].
/csat/progress — 스트릭 · 이번 주 문항 수 · 복습 대기 + 유형별 정확도 막대 1열.

[C] reflow 파이프라인
C1 회차 식별(실패 시 드롭다운) · C2 문항 경계(2단은 x로 열 분리) · C3 문항 텍스트(y→x 병합, 하이픈 결합,
머리/바닥글 제거, 선지 분리) · C4 문장 분할·해시는 공용 모듈 재사용 · C5 본문 ≥18px, 줄 ≤65자,
line-height 1.65, 선지 ≥48px · C6 실패 시 bbox 크롭 2.5배 + 설명 카드 목록, 실패율은 관리자 evidence 이벤트로 ·
C7 IndexedDB 캐시, 원본 바이트 미저장.

[D] 시각 규칙
D1 375px 우선, 주 버튼 하단 1/3 · D2 색 의미는 정답·오답·근거 3개뿐 · D3 본문 서체 1 + 숫자 서체 1, 제목보다 본문이 크다 ·
D4 모션은 정오 표시와 설명 펼침 2곳, 150ms, reduced-motion 존중 · D5 빈 상태·에러는 한 문장 + 버튼 하나.

[E] 게이트
Gate 0 정리(유지/삭제/관리자 이동 표) · Gate 1 reflow(샘플 2회차 경계 ≥95%, 문장 앵커 ≥95%) ·
Gate 2 학습 화면(375px 스크린샷 3장, F3~F6) · Gate 3 홈·세션·복습·기록(F1·F2·F7·F8) · Gate 4 자기비평.

[F] 완료 조건
F1 열기 → 첫 문항까지 탭 2회, 3G 10초 이내(캐시 있을 때) · F2 학습자 라우트 3개 외 0 ·
F3 정오 전 분석 텍스트 DOM 0 · F4 375px 본문 ≥18px, 가로 스크롤 없음, 선지 ≥48px ·
F5 <table> 0, 탭/모드/필터 0 · F6 근거 탭 → 펼침, 오답 탭 → 스크롤 자동 테스트 ·
F7 [헷갈려요] → 3일 후 세션(시간 모킹) · F8 세션 구성 단위 테스트 · F9 PDF 없는 홈은 안내 한 줄만 추가 ·
F10 Lighthouse 모바일 접근성 90+, 키보드 완주.
```

## 3. 버리는 것 / 남기는 것

| 이전 | 처분 |
|---|---|
| 모드 4개·라우트 7개 | 학습자 화면에서 삭제. 관리자 쪽으로 |
| 레이어 6장 토글 | 삭제. 근거·오답·함정은 문장 안 인라인, 어휘는 [더 보기] |
| 단권화 드래그 보드 | 삭제 |
| 원문 캔버스 + 우측 패널 2열 | 삭제. 1열 reflow |
| 강의 TTS·큐·앵커 엔진 | 유지 — ② 이해 단계의 [강의 듣기] |
| BYO-PDF·해시 앵커·서버 무저장 | 유지 — 표시만 페이지 렌더 → 문항 reflow |
| 관리자 evidence 렌즈 | 그대로 — 학습자 실패 이벤트의 수신처 |

## 5. 판단이 필요한 지점

reflow 는 학습자 PDF 의 문항 텍스트를 큰 글자로 다시 보여 주므로 화면상 원문이 그대로 보인다. 출처는 학습자가
직접 받은 공식 파일이고 서버는 아무것도 받지 않지만, 이미지 크롭보다 텍스트 재조판이 저작권상 더 민감하게
읽힐 여지가 있다 → **상업화 전 변호사 자문 항목에 추가.**
