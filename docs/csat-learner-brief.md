# /csat 학습자 재설계 (분석 중심) — Claude Code 지시문 (재작성판)

## 0. 무엇이 바뀌는가 — "풀기"에서 "출제자 읽기"로

이전 판의 루프는 **풀기 → 정오 → 이해**였다. 그 구조는 문제집 앱의 구조이고, 기출을 다시 푸는 건 이 플랫폼의 목적이 아니다. 목적은 **출제자가 이 문항을 어떻게 만들었는지 재구성하는 것** — 왜 이 지문을 골랐고, 어디에 구멍을 냈고, 정답 근거를 어디에 심었고, 오답을 어떤 제조법으로 만들었고, 다음엔 어떻게 변형할 것인가.

그래서 학습자의 행동이 바뀐다. 답을 고르는 대신 **출제자의 수를 먼저 예측하고 → 실제 설계와 대조한다.** 인출 연습은 그대로 남되, 인출 대상이 "정답"에서 "출제 논리"로 옮겨간다. 정답은 처음부터 공개한다 — 정답을 아는 상태여야 눈이 "왜"에 머문다.

| 이전 | 재작성 |
|---|---|
| 풀기(타이머·선지 탭·정오) | **없음.** 정답은 문항 열자마자 표시 |
| 이해(근거·오답 설명 펼침) | **예측 → 대조 3회**: 근거 위치 · 오답 제조법 · 출제 의도 |
| 한 줄(다음에 할 일) | **출제 공식 한 줄** + 변형 예측 카드 1장 |
| 세션 = 약한 유형 + 신규 + 복습 | 세션 = **같은 유형 2문항 대조** + 전이 확인 1문항 |
| 기록 = 정확도 | 기록 = **예측 적중률 · 함정 계열 커버리지 · 모은 출제 공식 수** |

화면 3개·행동 1개·PDF reflow·서버 무저장·인라인 분석은 그대로 유지한다. 단순함은 목적이 바뀌어도 필요하다.

## 1. 학습자 루프 — 화면 3개

```
[홈]  오늘의 해부 1장: "빈칸 추론 · 2문항 대조 + 전이 1 · 약 12분"  → [시작]
   │
[해부]  문항 1개가 한 화면. 정답은 처음부터 표시.
   ① 훑기(30초)  reflow된 지문 + 정답 선지 표시 + 문두. 아무 설명 없음.
   ② 예측 3수    출제자의 수를 맞힌다. 각 예측 전에는 분석이 DOM에 없다.
        수1 "정답 근거는 어느 문장에 심었나"   → 문장 탭 → 대조(출제자의 실제 근거 문장 밑줄 + 왜 그 자리인지 한 단락)
        수2 "이 오답은 어떤 제조법인가"       → 오답 선지 탭 → 계열 4개 중 선택 → 대조(실제 계열 + 지문의 어느 구를 비틀었는지)
        수3 "출제 의도 한 줄"                → 보기 3개 중 선택 → 대조(분석 자료의 의도 서술)
   ③ 설계도     지금까지 대조한 것이 한 장으로 접힌다: 소재(무엇) | 형식(어떻게) | 근거 자리 | 함정 계열 | 의도.
                아래에 변형 예측 카드 1장: "같은 설계를 다르게 내면?" (근거: 과거 변형 이력 1줄)
   ④ 공식 한 줄  "빈칸이 주장 문장이면 근거는 뒤 예시에서 재진술로 온다" + [내 공식에 넣기] [아직 모르겠음]
   → 2번째 문항(같은 유형). 끝나면 "두 문항에서 같았던 것 / 달랐던 것" 대조 카드 1장.
   → 전이 문항 1개: 예측 3수만, 설계도는 자동 비교("이 공식이 여기서도 맞았나").
   │
[내 공식]  모은 공식(유형별) · 예측 적중률 · 함정 계열 커버리지(본 계열/전체). 그 이상 없음.
```

### 왜 이 순서인가 (방법론과의 대응)

| 루프 요소 | 방법론 | 학습 원리 |
|---|---|---|
| 정답 선공개 | 문제별 심층분석은 정답을 아는 상태에서 하는 작업 | 답 찾기에 쓰이던 주의를 "왜"로 돌린다 |
| 예측 3수 | 소재/형식 분리 · 함정 계열 · 출제 의도 | 인출 연습·생성 효과 — 보기 전에 스스로 가설을 세운다 |
| 같은 유형 2문항 대조 | 패턴 종합 | 대조 학습: 상수(출제 공식)와 변수(소재)가 분리돼 보인다 |
| 변형 예측 카드 | 변형 예측 | 다음 시험에 옮길 수 있는 형태로 패턴을 저장 |
| 전이 문항 | 검증·갱신 | 공식이 다른 문항에서도 서는지 즉시 확인 |
| 내 공식 | 단권화 | 학습자가 고른 문장만 쌓인다 — 시스템 요약이 아니라 자기 언어 |
| [아직 모르겠음] → 3일 후 같은 공식의 다른 문항 | 회독 | 간격을 두고 같은 패턴을 다른 소재로 재확인 |

### PDF 표시 — 이전 판 그대로 (문항 reflow, 페이지 렌더 금지, 서버 무저장)

변경 없음. 정답 표시는 reflow된 선지 카드 위에 마크만 얹는다.

/csat (홈)

  - 첫 방문 온보딩 1장: "예측하고 → 대조하고 → 공식 남기기" 그림 3개 + [시작].

/csat/dissect (해부) — 한 문항 = 한 화면, 상단 "1 / 3 · 빈칸 추론"

  ② 예측 3수(순서 고정, 각각 주 버튼 하나):
     수1 근거 자리: 지문 문장이 탭 가능해진다. 학습자가 1문장 탭 → [이 문장] →
        대조: 실제 근거 문장 밑줄 + 학습자 선택과 일치/불일치 표시 + "왜 이 자리인지" ≤ 3문장 인라인.
     수2 오답 제조법: 오답 선지 4장 중 시스템이 1장 지정(함정 계열이 있는 것 우선) → 계열 보기 4개(칩) → 선택 →
        대조: 실제 계열 + 지문의 어느 구를 비틀었는지 그 구로 스크롤·강조 + 한 줄.
     수3 출제 의도: 보기 3개(분석 자료의 의도 1 + 그럴듯한 오답 2) → 선택 → 대조: 의도 서술 인라인.
     각 대조에서 학습자가 맞았으면 "적중", 틀렸으면 "출제자는 여기를 봤다" — 둘 다 같은 톤, 점수 없음.
  ③ 설계도: 카드 1장에 소재 | 형식 | 근거 자리 | 함정 계열 | 의도 5칸. 각 칸은 위 대조에서 이미 본 것의 요약(새 정보 없음).
     아래 변형 예측 카드 1장: "같은 설계를 다르게 내면?" 한 문장 + 근거(과거 변형 이력) 한 줄. [근거 보기] 인라인.
  ④ 공식 한 줄: 분석 자료의 wrapup에서 생성. [내 공식에 넣기] [아직 모르겠음].
     [아직 모르겠음] → 이 문항의 공식 태그로 3일 후 전이 문항 큐.
  → 2번째 문항 동일. 두 문항 후: 대조 카드 1장 "같았던 것(공식) / 달랐던 것(소재·근거 자리)" 각 한 줄.
  → 전이 문항: ②만 수행, ③은 "이 공식이 여기서도?"로 자동 대조(같았음/달랐음 + 한 줄). ④ 생략.
  → 세션 끝: "오늘 · 예측 7/9 적중 · 공식 +1 · 새 계열 2" + [홈으로] [한 유형 더].

## 3. 이전 판 대비 처분

| 이전 판 요소 | 처분 |
|---|---|
| 풀기·타이머·정오·정확도 | 삭제. 목적이 아니다 |
| 이해 단계(설명 펼침) | "예측 → 대조"로 대체. 같은 인라인 표시를 쓰되 예측 뒤에만 |
| 한 줄(다음에 할 일) | "공식 한 줄"로 — 전략 조언이 아니라 출제 설계 규칙 |
| 복습 큐(오답 기준) | 전이 큐(공식 태그 기준)로 — 틀린 문항 재풀이가 아니라 같은 패턴의 다른 소재 |
| 기록(정확도) | 내 공식(단권화) |
| 강의 TTS | 유지. ③ 설계도 카드에 [강의 듣기] — 큐 role 순서가 그대로 출제자 사고 순서 |
| PDF reflow·앵커·무저장 | 유지 |

## 5. 판단이 필요한 지점 두 가지

1. **정답 선공개.** 분석 목적이면 맞지만, "한 번은 풀어 보고 싶다"는 학습자가 있을 수 있다. 이번 판은 넣지 않았다 — 넣으면 다시 채점 UI가 따라온다. 필요해지면 훑기 화면에 정답 마크를 3초 뒤에 나타나게 하는 정도가 상한이다(DECISIONS.md에 항목만 열어 둠).
2. **예측 보기의 데이터 의존.** 수2·수3의 보기는 분석 자료의 함정 계열·의도 서술이 문항마다 채워져 있어야 만들어진다. Gate 0의 채움률이 낮으면 세션에 쓸 문항이 적어지므로, 관리자 evidence 화면의 "배포 가능" 기준에 이 두 필드를 포함시키는 것이 먼저다.
