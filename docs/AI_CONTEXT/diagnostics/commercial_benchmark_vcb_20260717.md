## 3. 종합 판정 — 우위/열위 지도

### 🟢 플랫폼 구조적 우위 (코드로 실동작 확인 — 종이책 불가능)
1. **FSRS 정식 알고리즘 + 서버 권위 재계산** — 단순 박스반복 아닌 D/S 기반 개인 스케줄(`flush-actions.ts`)
2. **다모듈 → 단일 SRS 수렴** — Flashcard·SpellForge·WordBlitz·PairFlip·아케이드14·ScriptQuiz가 전부 같은 `vocabularies`/`learning_records`에 기록. **게임해도 복습이 진짜 반영**
3. **EchoMatch 발음 정밀채점** — Piper TTS + DTW 3축(억양/강세/리듬). 단어장앱엔 없음
4. **VRL 진단→V-Level→i+1 추천 자동 파이프라인**
5. **결정론 "오늘의 처방" 5블록**(복습→듣기→읽기→연습→검증)
6. **문맥 학습** — 사용자/도서 텍스트 AI 추출 + 원문 리더 + 원어민 낭독 + shadow
7. **수능 문항유형별·기출연도별 세트**(시중 이상 정밀)
8. **Dual Coding 삽화 카드**(그림책 장면+단어, 큐레이션 도서 한정)

### 🔴 열위/동급 위험 (반드시 개선 — "비슷하면 안 됨" 위반)
1. **저레벨 큐레이션 오염** — auto-vlevel V1 굴절 35%·V2-3 파생 30% (초등이 못 낼 수준)
2. **뜻 뉘앙스 얕음** — bare gloss(≤6자) 33.5%·용법노트 27%·**니모닉 0%**·평균 11.8자 (프리미엄 시중 대비 얕음)
3. **예문 KO 번역 없음 + 일부 세트 예문 결측**(kice/book 세트)
4. **니모닉 학습 UI 부재** — 어원 힌트만, 플래시카드 뒷면에 어원/니모닉 미노출
5. **삽화 = 큐레이션 도서 한정** — 사용자 입력 텍스트·일반 세트엔 그림 없음
6. **시험(TOEIC/공무원) 기출빈도 코퍼스 부재**
7. **mock 잔존** — WordVault 랜딩 Browse `MOCK_WORDS`, 빈 상태 데모 폴백 → 첫인상 훼손
8. **신규 아케이드 6종 세션점수 미영속**(리더보드 신뢰도 제한)

## 5. 우위 보장 전략 (thesis)

**승리 조건**: 플랫폼의 승부처는 종이책과 "더 좋은 단어 목록"으로 겨루는 게 아니라, **종이책이 구조적으로 불가능한 "적응형·멀티모달·문맥·개인화 학습 시스템"**이다. 이 우위는 이미 실재(FSRS·다모듈수렴·발음채점·진단·처방·문맥). **단, 콘텐츠 품질 parity가 전제** — 저레벨 오염·얕은 뜻이 남으면 "시스템은 좋은데 단어가 이상하다"로 첫인상이 무너진다.

**3-tier 실행 순서**:
1. **콘텐츠 parity 확보(danger zone 제거)** — P1(오염 게이트)·M1(뜻 심화)·D2(mock 제거). *"비슷하면 안 됨" 조건의 최소 방어선.* → 시중과 **최소 동급**
2. **시스템 우위 증폭** — F1(니모닉/어원 카드)·F2(적응형 플랜)·M2(니모닉)·D1(삽화 확대). → 시중이 **못 하는 학습효과** 전면화
3. **고유 매력 완성** — 문맥추출·발음채점·처방·어원 이중배당을 학습여정으로 연결. → **대체 불가 제품**

**한 줄 결론**: 플랫폼은 **시스템(적응·멀티모달·개인화·발음·문맥)에서 이미 시중을 압도**하나, **콘텐츠 품질의 danger zone(저레벨 오염·얕은 뜻·니모닉 0)이 우위를 가린다**. P1(생성기 오염 게이트)→M1(뜻 심화)→F1(니모닉/어원 카드)→D1(삽화) 순으로 콘텐츠 parity를 확보하면, 실재하는 시스템 우위가 그대로 "시중보다 명백히 낫다"로 전환된다.
