## 핵심 발견 (설계 문서 대비 정정 2건)

1. **`reading_sessions` 이름 충돌 (④)** — 설계는 `CREATE TABLE reading_sessions`(유창성)를 신규로 가정했으나, **동명 테이블이 이미 활성**(읽기-플랜 분절, 262 rows). CTP 유창성 로그는 **`reading_fluency_log`** 등 별칭 필수. — 단정(실측)
2. **attempt granularity = 세션 단위 (⑦)** — 설계는 "attempt granularity 정찰 후 error_cause 부착점 확정"이라 유보했음. 실측: per-question 응답 테이블이 **없음**(`scores`는 module 단위 집계). 따라서 error_cause 는 **신규 per-item 테이블**에 부착(기존 확장 불가). — 단정(실측)

## 확인된 설계 정합 (변경 불요)

- **stage×source 매핑 정확** — article v≤6 = S1–S3, 도서 v7–9 = S4(킬러). 설계의 stage_catalog CASE 와 일치.
- **stage_band CASE 경계중복(S3 논증 vs S4 v7-9)은 현 데이터에 부재** — 논증 article 전량 v5-6, v7-9 전량 도서. 단, 향후 대비 우선순위 규칙 명시(article=register 우선, 도서=v_level).
- **syntax_score 자체 산출 = runtime-LLM-0 정합** — winkNLP 없이 정규식으로 충분(문장 p90·절 깊이).

## 리스크 (abort 아님 — 볼륨 주의)

- **S3 논증-파생 소스 = OWID 8건뿐** — DCP order/insert 는 4문장+ 문단 필요 → S3 문항 풀 소량. (동결 헤지 OECD/UNDP = PDF-블록으로 부재 — [CSAT_SOURCE_MATRIX](../../CSAT_SOURCE_MATRIX.md) §20.4). S3 문항 목표치 보수적 설정.
- **S4 = 발행 도서 5권** — 킬러 정독 코퍼스 얇음. Pressbooks/도서 스케일이 선행되면 완화.
- **abort 트리거 미발동** — CTP P0 = **GO** (④⑦ 2건 데이터모델 정정 반영 조건).
