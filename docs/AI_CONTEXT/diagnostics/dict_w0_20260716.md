## 🔴 피벗 발견 — 착수 전 반드시 알 것

1. **kaikki(외부 증거원)가 로컬에 부재** — `data/` 어디에도 kaikki 덤프 없음. → 이 설계의 핵심 전제(서브에이전트가 kaikki를 쥐고 검증)가 **현재 성립 불가**. **W3(어원 root)·W4(gloss 대조 검증)·W2-fetch가 전부 이 하나에 막힘.** — **단정**
2. **플랜의 "구조" 객체 대부분 그린필드** — `word_roots`·`root_links` 테이블 없음 · `entry_type`·`etymology`·`word_root` 컬럼 없음 · `generate_curated_word_set` RPC 없음. "확장"이 아니라 신설. — **단정**
3. **W2 파일럿 스크립트 부재** — `dict-fetch-batch.mjs`·`dict-update-batch.mjs` 존재하지 않음(있는 건 `example-fill.mjs`·`dict-common.mjs`·`derivational-seed.mjs`). 파일럿의 "확장" 대상이 없음. — **단정**

## W2 파일럿 판정 — 지금 실행 부적절

플랜은 파일럿(rank 12,001–13,000)을 병렬 확장 전 게이트로 요구. 그러나:
- **fetch 소스 없음**(kaikki 부재) · **스크립트 없음**(`dict-fetch/update-batch` 부재)
- rank 12–13k 결측 필드는 ipa/syn/ant 계열 — **ipa는 LLM 부적합**(음성), **syn/ant는 외부검증 없이 자가생성 = 플랜의 저가치 카테고리**
→ 지금 파일럿을 돌리면 **검증 불가능한 자가생성 배치**(플랜 원칙 위반). **실행하지 않음** — **단정**

**대조**: 예문(example_en)은 외부검증 불요라 LLM 적합 → 그 슬라이스만 이미 완료(단일어 172개 → 100%, v06.252). W2의 나머지는 소스 확보 전 부적절.

## → 사용자 결정 필요 (W0가 가른 게이트)

이 설계의 **실효 가치는 kaikki 확보 여부에 100% 종속**됩니다. 정직한 3갈래:

1. **kaikki 확보 후 재개** (권장) — kaikki.org 영어 Wiktionary 추출(JSONL, 수 GB) 다운로드+정규화 → 그때 W2(syn/ant/ipa 대조채움)·W3(etymology root)·W4(검증)가 **비로소 성립**. 확보는 별도 태스크(대용량 I/O). 이후 병렬 세션 정당.
2. **kaikki 없이 축소 실행** — 실효 가능한 것만: (a) W1 curation RPC 확장(`generate_curated_word_set`, 기존 축으로) (b) Phase B per-sense v_level(5,170, 이미 백로그·LLM 적합) (c) A1–B2 코어 예문 등 LLM 적합 필드. **syn/ant/ipa/etymology는 제외**(소스 없음).
3. **여기서 중단** — 추출 신뢰 기반은 이미 완결(v06.248~252). dict는 뜻·POS 100%. 추가 투자 보류.

**병렬 N세션 착수는 kaikki 확보(1) 또는 축소범위 확정(2) 전까지 유보**가 안전선 — 소스 없는 병렬 충전은 오염만 N배.
