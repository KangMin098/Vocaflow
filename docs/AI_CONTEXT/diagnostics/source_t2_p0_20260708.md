## P0-1 — OWID 실측

- **1a 리스트 경로**: `https://ourworldindata.org/atom.xml` = 유효 Atom feed, **10 entry**(실 기사 URL). 대량 GET 가능. (`atom-topic-pages.xml` = 404)
- **1b 밀도**: 3건 순수 산문(차트/grapher 제외) word_count — food-trade 976 · migrants 736 · children-die 1,332 → **avg 1,014**. 임계 600 **여유 통과**.
- **1c 라이선스**: 페이지 명시 **"License: CC BY."** + `creativecommons.org/licenses/by`. **SA 페이지 미발견**(3-표본). 3rd-party 데이터만 개별 라이선스(본문 산문은 CC-BY).
  → ingester `license='CC-BY-4.0'` 고정 적합 (SA 발견 시 페이지별 기록 로직은 표본상 불요, 방어적 유지 권장).
- **1d v_level**: 정량 VRL 실행 보류(§4-D 소스 일괄 CEFR 금지 정합). 정성 추정 **B2~C1** (data/argumentative 산문). analyze 단계 문서별 실측 위임.
- **구조**: `<article>`×1 · **grapher 차트 div**(예: 3개) · `<figure>/<iframe>/<table>` 초기 HTML 0 → **grapher div 제거 후 산문 구성** (P1 셀렉터).

## P0-2 — DOAB / OBP 실측

- **2a DOAB API**: DSpace. `/server/api/discover`(v7 JSON API)는 **HTML 반환(비가용)**. **레거시 `/rest/search`(v6, JSON) 가용.** license 메타 = `publisher.oalicense`/`dc.rights` = **출판사별 자유텍스트**("open access" 189 · Springer CC 84 · 다수 verbal CC-BY 변형) → **표준 facet 불가, 항목별 파싱 필수**. 코퍼스 규모는 大(≥50 명백).
- **2b OBP**: 카탈로그 **450 titles**. 책 URL `/books/10.11647/obp.NNNN`, 챕터 URL `.../chapters/10.11647/obp.NNNN.MM`(URL 단위 챕터 구분).
  - 🔴 **결정적 차단**: "Read Online" 챕터 페이지 = **client-rendered(JS)**. 서버 HTML `<p>` 산문 미노출(표본 챕터 = 저자 bio·에러페이지 "please contact support"만, 일부 책 챕터링크 `undefined`). full-text 다운로드 = **PDF**(`cdn.openbookpublishers.com/*.pdf`), 본문 HTML/XML 없음.
  - **라이선스 혼재**: 챕터 페이지 권위값(예 obp.0527=`by-nc`). 책 랜딩 페이지엔 boilerplate CC-BY 링크 혼입 → 랜딩 grep 부정확, **챕터 페이지 라이선스가 권위**. 표본상 **CC-BY-NC 다수**(OpenStax 차단과 동형: `acp_classify_license`='restricted').
- **v_level/noise 표본**: 서버 HTML 산문 미추출로 **측정 불가**(client-render 차단이 선행 결함).

## P0-3 — LCP 스키마 (확정)

- `library_books`: **`license`(text 자유텍스트) + `copyright_safe_in_kr`(bool)만.** `license_class`·`display_only`·`register`·`lexical_noise` 부재 확정.
- license 실분포(현행): "U.S. Public Domain" 17 · "Public domain in the USA." 4 · "PD-US" 2 · "CC BY 4.0" 2 · "PD-Body / CC-BY-Summary" 1 · "CC-BY-SA-3.0" 1 (합 ~27권, 전부 PD/CC — restricted 0).
- `library_source_catalogs` 구조: source·display_name·description·api_endpoint·catalog_url·documentation_url·license_summary·notes·catalog_size·composite_score·quality_×7·copyright_safe_in_kr·is_implemented·is_enabled·**cefrj_auto_assign_tier**(Tier). → OBP row 초안 가능(트랙 진행 시).

## P0-4 — register 기록 방식 (확정)

- **`RawArticle` 타입에 `register` 필드 없음.** register 는 `apps/web/src/app/api/acp/dev-process/route.ts:141` 의 **`REGISTER_BY_SOURCE[source]` 맵**(소스→단일값)으로 dev-process 시 부여.
- 지시문 P1의 **"per-article register 휴리스틱(argumentative 기본+데이터서술 expository)"** 은 현 패턴과 불일치 → **선택 필요**: (a) `owid→argumentative` 맵 1줄(현 패턴, 단일값) vs (b) `RawArticle.register` 필드 신설 + dev-process 가 `article.register ??
