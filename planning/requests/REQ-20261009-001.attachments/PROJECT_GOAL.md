## 1. 최상위 목표(L0)

**VG-L0 — 학습자의 연령·수준·목적에 맞는 영어 이해·사용 능력의 지속적 발전을 지원하는 개인화 학습 플랫폼.** 다양한 원천 콘텐츠와 어휘·문장·독해·듣기·강의·게임·평가 및 교사 지원을 학습 목적별로 구성하고, 진단→목표/계획→학습/Practice→피드백→복습→새 맥락 전이→재평가의 증거를 학습자 관점에서 연결한다.

- 플랫폼의 공통분모는 **학습 상태·콘텐츠 계보·증거 연결**이지 동일 교수법이나 하나의 강제 UI 경로가 아니다.
- 수능·모의평가·학평은 특화된 학습 환경이며 플랫폼 전체와 동의어가 아니다.
- 콘텐츠 공장과 교사 도구는 최종 학습자 가치를 가능하게 하는 수단이다.
- 최상위 가치 가설: 학습자에게 적절한 과제와 피드백, 간격을 둔 연습과 새로운 맥락에서의 적용을 제공하면 독립적인 영어 수행 향상에 기여할 수 있다. **Vocaflow에서 입증된 사실은 아니다.**

## 2. 계층 규칙

- L0: 플랫폼 존재 목적. 성공 판정은 장기간·다집단 효과 증거가 필요하다.
- L1: 전략적 결과 영역. 네 축 모두 유지한다.
- L2: 달성해야 하는 제품 능력/학습 역량.
- L3: 사용자 시나리오 또는 서비스 계약으로 검증 가능한 능력.
- L4: 코드·데이터·테스트·문서·실험 등 실행 가능한 작업 단위.
- L4 작업은 반드시 정확히 하나의 주 L3, 그 위의 L2/L1/L0 추적 경로를 갖는다. 다른 목표는 관련 링크로 둔다.

## 3. 계층 정본

### L1-A 학습자 성취
- **VG-L2-A1 진단/목표 모델**: 현재 능력·불확실성·목적을 표시한다.
  - VG-L3-A1-01 선택/간단 진단/목표 설정에서 학습 경로를 생성한다.
  - VG-L3-A1-02 부정확하거나 부족한 응답 데이터는 원인 판정에서 제외하거나 불확실성을 표시한다.
- **VG-L2-A2 연습·피드백·지식 유지**: 영역별 학습 방법에 맞는 연습, 근거가 있는 피드백, 간격 복습을 제공한다.
  - VG-L3-A2-01 어휘의 회상/인식, 문장 분석, 독해, 듣기 각각의 성공 기준을 별도로 측정한다.
  - VG-L3-A2-02 필요할 때 강의/TTS/게임이 학습 과제를 보조하며 필수 강제 단계가 되지 않는다.
- **VG-L2-A3 전이·재평가**: 학습 때 본 문항 외의 새 과제에서 수행을 측정한다.
  - VG-L3-A3-01 동일 기술의 미노출 문항/텍스트로 전이 시험을 실행한다.
  - VG-L3-A3-02 기준선·후속 평가 및 테스트 조건을 기록하고 개선 여부와 불확실성을 표시한다.

### L1-B 목적·수준별 학습 경험
- **VG-L2-B1 학습 환경군**: 초등 고학년/중등/고등 및 기타 학습자를 기술/목표에 따라 구분하되 학년만으로 난도를 단정하지 않는다.
  - VG-L3-B1-01 기초 어휘·문장·독해/일반 읽기/듣기/기출·시험 준비의 진입점을 제공한다.
  - VG-L3-B1-02 선택적 강의·게임·교실 모드가 같은 학습자 프로필에 연결된다.
- **VG-L2-B2 학습자 관점의 일관성**: 자유로운 화면 이동과 하나의 이해 가능한 진행 기록을 제공한다.
  - VG-L3-B2-01 수능 및 공용 학습 이력의 **조회 모델**을 통합하되 원자료·척도는 의미가 다른 경우 보존한다.
  - VG-L3-B2-02 오늘 할 일/완료/다음 단계/목표 대비 진행과 실패 복귀가 보인다.

### L1-C 신뢰 가능한 콘텐츠 생태계
- **VG-L2-C1 원천→학습 자료 계보**: 도서·기사·어휘 자원·시험 지문·영상 및 저작물을 추적한다.
  - VG-L3-C1-01 원천 식별자·권한 상태·대상·변형·버전·근거·품질을 기록한다.
  - VG-L3-C1-02 배포 가능한 콘텐츠만 학습자 화면에 보이고, 사용 불가 자료는 차단 이유를 표시한다.
- **VG-L2-C2 학습 목적에 맞는 공급**: 무제한 생성 대신 미충족 학습 수요에 맞춰 공급한다.
  - VG-L3-C2-01 주제/수준/영역/품질/시도율 기준으로 우선순위 대시보드를 제공한다.
  - VG-L3-C2-02 미발행 기사·미사용 구문·중복 만화 계통의 유지/동결/폐기 결정을 근거와 함께 남긴다.

### L1-D 검증 가능하고 지속 가능한 운영
- **VG-L2-D1 학습 이벤트·측정 계약**: 학습 과제, 출처, 응답, 피드백, 재방문, 전이를 추적한다.
  - VG-L3-D1-01 공통 식별자/스키마와 중복 방지 및 마이그레이션 적합성을 보장한다.
  - VG-L3-D1-02 QA/개발/실사용 계정을 구별하며 학습 성과 지표를 섞지 않는다.
- **VG-L2-D2 출시 품질**: 인증, 접근성, 개인정보, 동작 배포, 실패 복구를 검증한다.
  - VG-L3-D2-01 CI 결과가 실제 실행/스킵/실패를 구분하며 브라우저 E2E와 배포 검증이 있다.
  - VG-L3-D2-02 관리자/학습자 권한 및 개인정보 최소 수집과 삭제/정정 정책을 검증한다.
- **VG-L2-D3 효과 증거 및 의사결정**: 기능 작동, 사용성, 학습 성과를 분리한다.
  - VG-L3-D3-01 외부 사용자의 과제 완수 및 장애를 관찰한다.
  - VG-L3-D3-02 사전 정의된 기준선/후속/지연/전이 평가로 효과를 검증하고 결과의 한계를 명시한다.

## 4. 대표 L4 실행 작업 템플릿

모든 L3 하위에 아래 L4 작업을 실제 작업별로 생성한다. 이들은 완료 사실이 아닌 **필수 작업 유형**이다.

1. `contract`: 사용자 시나리오·데이터 정의·실패 조건·보안 및 권한을 명세한다.
2. `implementation`: UI/API/데이터/배치 중 필요한 부분만 구현한다.
3. `verification`: 단위/통합/E2E/권한/회귀를 실제 실행하고 로그·커밋을 기록한다.
4. `evidence`: 비교 기준·테스트 결과·재현 경로·한계를 정리한다.
5. `delivery`: 목표 파일 갱신, 리뷰, 커밋/push 및 실행 가능한 릴리스 점검을 남긴다.

## 5. 범위와 순서

### 릴리스 R0 — **한 개의 실제로 완결된 학습 여정**
- PC 웹 우선은 2026-10-09 사용자가 승인한 전략이다. 실제 main 반영은 STEP 3에서 검증한다.
- 우선 후보: 짧은 텍스트/기초 독해 진입 → 학습 목표 → 읽기/핵심 어휘·문장 연습 → 확인 문제 → 피드백 → 복습 → 새 지문 과제 → 재평가 → 학습 기록.
- 시험 대비 특화 기능은 같은 기반을 재사용하되 R0 출시 경로의 필수 요소는 아니다.
- 계정 유무에 따른 경험/기록 전환을 검증한다.
- 선택적 강의/TTS/게임은 학습 경로를 방해하지 않는 경우에만 포함한다.
- 필수 게이트: 합법 배포 가능한 학습 자료, 인증/접근성/데이터 신뢰도, 성공하는 실제 배포, 스킵되지 않는 E2E, 핵심 플로우 기록.

### R1 — 영역·목적별 확장
- 읽기·어휘·문장·듣기의 경로를 공통 프로필/진행 기록으로 연결.
- 수능·학평·모의평가의 독립 근거·평가 척도와 공통 회고 연결.
- 교사 도구/교실은 실제 교사 사용성 검증을 거쳐 선택적으로 출시.

### R2 — 장기 비전
- 수준/목적 간 학습 경로 이동, 다중 콘텐츠 파이프라인 최적화, 의미 있는 장기 학습 효과 증거, 확장 가능한 저작/교실/기관 활용.
- 모바일, 결제, 다국어 등은 별도 수요·전략·보안 검토 전까지 R0 확정 범위 아님.

## 6. 기능과 학습 효과의 서로 다른 판정

- `implemented`: 코드는 존재하지만 실행 성공은 보증하지 않는다.
- `verified_technical`: 핵심 기능의 실제 실행·배포·테스트 증거가 있다.
- `validated_usability`: 실제 대상 사용자의 과제 수행 증거가 있다.
- `validated_learning`: 타당한 측정 설계에 따른 학습 성과 증거가 있다.
- `validated_causal_effect`: 적절한 비교·통제·표본과 분석으로 특정 효과의 인과 주장을 검토했다.
- 상위 판정으로의 자동 승격 금지. 합격률·효과 크기의 수치 목표는 외부 파일럿 전 사전 등록하고 사용자/교육 전문가와 합의한다.

## 7. 조사에서 확인된 제약과 미검증 사항

첨부된 STEP 1 보고 **요약의 진술**: 학습 환경 24종, 관리자 87개, 아케이드 19종, 테스트 계정 5개; Flashcard/WordBlitz/Dictation/아케이드 16종은 테스트 기록 존재. 읽기 완료·전이 및 외부 학습자 효과 기록 0건. 기사 미발행 92.3%, 구문 약 83만 건 대비 시도 20건. 수능/공용 회고 및 복습 큐 단절. CI E2E 스킵과 Vercel 배포 스킵, main-DB 마이그레이션 불일치 보고. **독립 현장 재검증을 마친 사실은 아니다.**

## 8. 최종 성공의 검증 가능 정의

1. `product`: 대상 사용자들이 목표 → 실제 학습 → 복습 → 새 과제 → 재평가의 흐름을 완주할 수 있다.
2. `learning`: 공정한 평가에서 사전 정의된 학습 능력 향상과 지연 유지/전이 여부를 보고한다. 향상이 없으면 그대로 보고한다.
3. `content`: 각 게시 자료의 출처/변환/품질/권한과 교육 목표가 추적된다.
4. `operations`: 배포, 개인정보, 접근권한, 이벤트, 데이터 무결성과 복구가 증거로 검증된다.
5. `strategy`: 확장 결정은 학습 수요와 효과/운영 비용 근거에 따른다.

## 9. 승인된 전략 및 후속 검증

SD-R0-01~04 확정. 향후 사용자 승인을 다시 요청하지 않는다. STEP 3는 승인된 R0와 기존 구현 간 갭을 조사한다. 체험 자료의 권리 상태, 익명 이벤트의 인증 계정 귀속, 재평가 문항 독립성, PC 브라우저 E2E, 개인정보·배포 검증은 아직 미검증이다. 출시 승인은 각 게이트의 실제 증거 확보 후 별도 판정한다.

## 10. R0 대표 사용자 여정 (전략적으로 확정, 기술적으로 미검증)

1. PC 웹에서 비로그인 사용자가 중등 수준의 독해 체험 콘텐츠에 접근한다.
2. 체험 과제를 완료하고 이해/오답에 대한 설명 또는 피드백을 확인한다.
3. 가입·로그인을 선택할 수 있고, 동의·보안 조건을 충족한 체험 기록은 중복 없이 계정에 연결된다.
4. 목표·수준을 수정할 수 있으며 읽기, 필요시 어휘·문장 Practice를 자유롭게 오간다.
5. 완료한 시도는 학습 이력과 복습에 일관되게 기록된다.
6. 이전에 노출되지 않은 자료로 전이 및 재평가를 수행하고 기존 학습과 연결해 조회한다.
