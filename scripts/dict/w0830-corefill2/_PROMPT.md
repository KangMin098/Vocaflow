# D0830-T3 — 수능·EBS·교육과정 밴드 빈칸 채우기

담당 청크의 낱말은 전부 **`list_tags` 에 수능(kice-csat) · EBS · 2022 교육과정 목록이 붙은 낱말**이다.
시중 어휘 교재가 다루는 바로 그 집합이고, 교재는 이 범위를 100% 채우고 나온다.
우리는 유의어 39% · 반의어 41% 가 비어 있다. 이 배치는 그 구멍만 메운다.

각 항목의 `need` 배열이 **채워야 할 필드**다. `have` 는 이미 있는 값(참고용, 건드리지 마라).
`need` 에 없는 필드는 출력하지 마라 — 써도 apply 가 무시한다.

## `synonyms` — 유의어 2~5개

- **1~2낱말**의 영어 소문자. 구두점·숫자·대문자 금지.
- `meaning_ko` 가 가리키는 **그 뜻**의 유의어여야 한다. 다의어면 대표 뜻 쪽으로.
- **흔한 낱말을 골라라.** 학습자가 모르는 낱말로 아는 낱말을 설명하면 소용이 없다.
  `abandon` → `desert`, `leave`, `quit` (o) / `forsake`, `relinquish` 만 (x — 더 어렵다)
- 완전한 동의어일 필요는 없다. **바꿔 넣어도 문장이 성립하는** 정도면 된다.
- ⚠️ **우리 사전에 없는 낱말은 apply 가 버린다.** 희귀·고어·전문어를 피하고 흔한 낱말을 써라.

## `antonyms` — 반의어 1~4개

- 같은 형식 규칙. **진짜 반대**만. 억지로 만들지 마라.
- 반대가 없는 낱말(구체명사·기능어·전문용어)은 **빈 배열 `[]`** 로 둬라. 빈칸이 오답보다 낫다.
  `table`, `water`, `photosynthesis` 는 반의어가 없다.
- `un-`/`in-` 파생형이 실제로 쓰이면 그것도 좋다 (`happy` → `unhappy`, `sad`).

## `collocations` — 연어 2~5개

- 각 항목 **2~5낱말**, 소문자 영어, **표제어(굴절형 허용)를 반드시 포함**.
- 원어민 코퍼스에서 실제로 빈번한 짝만. 문법적으로 가능하다고 다 쓰지 마라.
- **한국인이 틀리는 짝을 우선**하라 — `make/do`·`take/have`·전치사 고정처럼 직역하면 깨지는 것.
- 관사·소유격은 실제 쓰임대로: `take a risk`(관사 있음) · `high risk`(없음).

## `korean_learner_note` — 한국인 학습자 노트 (20~200자)

한국어 한 문장(길면 두 문장). **반드시 표제어의 영문 철자를 포함**해야 한다.

**무엇을 쓰나 — 뜻 반복이 아니라 "여기서 틀린다" 를 쓴다:**
- 한국어 직역이 통하지 않는 지점 (`convince A of B` 의 전치사 고정)
- 혼동하기 쉬운 다른 낱말과의 경계 (`affect` / `effect`, `economic` / `economical`)
- 품사가 바뀌면 뜻이 달라지는 것 (`address` 명사=주소, 동사=다루다)
- 셀 수 있음/없음, 자동사/타동사, 수동태 고정 (`be composed of`)
- 강세 위치가 뜻을 가르는 것 (`ˈrecord` 명사 / `reˈcord` 동사)
- 콩글리시와의 차이 (`sign` ≠ 서명 sign 은 signature)

**쓰지 말 것:** `meaning_ko` 를 다시 말하는 문장, "자주 쓰인다"·"중요한 단어다" 같은 빈 문장.

## skip

그 필드가 그 낱말에 **실제로 성립하지 않으면** 빈 배열/생략으로 둔다.
`"skip_reason"` 에 짧게 적어도 좋다. **억지 값이 빈칸보다 나쁘다** — 학습자가 그걸 외운다.

## 부수 발견 — `note` 에

`meaning_ko` 오류·잘림 · `pos` 오기 · 표제어가 영어 낱말이 아님 · 오철자 · 난이도 불일치.
고치지 말고 적기만 하라 — 사람 검토 목록으로 모은다.

## 출력

`chunk-NN.json` 옆에 `chunk-NN.out.json` 으로 저장한다. 배열 하나. JSON 만.

```json
[
  {
    "word": "abandon",
    "synonyms": ["desert", "leave", "give up"],
    "antonyms": ["keep", "maintain"],
    "korean_learner_note": "abandon 은 사람이 책임지던 것을 '버리고 떠나다'라서 물건을 그냥 버릴 때(throw away)와 다르다. abandon oneself to 는 '~에 빠지다'."
  },
  {
    "word": "photosynthesis",
    "synonyms": [],
    "antonyms": [],
    "skip_reason": "전문 용어 — 유의어·반의어가 실제로 없다"
  }
]
```

- 입력에 없는 낱말을 추가하지 마라. `need` 에 없는 필드는 넣지 마라.
- 앞뒤 설명 문장 금지. JSON 배열 하나만.
