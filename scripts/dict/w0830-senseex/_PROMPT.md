# D0830-T2 — 다의어 뜻마다 예문 + 한국어 해석

다의어 교재의 본체는 뜻 목록이 아니라 **뜻을 갈라 주는 문장**이다.
`will = 의지 / 유언장` 을 나란히 적어 두면 외워지지 않는다. **그 뜻으로만 읽히는 문장**이 붙어야
변별이 생긴다. 그리고 국내 교재는 예문마다 해석을 단다 — 우리 DB 의 예문 48,730 개 중
한국어 해석은 **한 건도 없다.** 학습자가 예문을 건너뛰는 이유가 그것이다.

담당 청크의 각 항목은 낱말 하나이고, `senses[]` 는 **아직 예문 또는 해석이 없는 뜻**들이다.

## 할 일

`senses[]` 의 **모든** 원소에 대해 결과를 낸다.

- `has_example` 이 **있으면** — 그 문장이 이미 DB 에 있다. **다시 쓰지 마라.**
  `example` 은 비우고 `example_ko` 에 **그 문장 그대로의 한국어 해석**만 쓴다.
- `has_example` 이 **null 이면** — `example`(영어)과 `example_ko`(해석) 둘 다 쓴다.

## 예문 규칙 — 어기면 apply 게이트가 거부한다

1. **표제어(굴절형 허용)가 반드시 들어갈 것.** `run` → `He ran the company`(o) / `She managed it`(x)
2. **4~22낱말.** 6~14 가 좋다. 한 문장. 문장부호로 끝낸다.
3. **ASCII 영문만.** 한글·한자·이모지 금지. 곡선따옴표는 허용되나 곧은따옴표를 권한다.
4. **그 뜻으로만 읽혀야 한다** — 이게 이 배치의 전부다.
   `bank(둑)` 예문에 `money` 를 넣지 마라. 문맥어를 심어 다른 뜻을 배제하라.
   `We sat on the grassy bank of the river.` (o) / `He walked to the bank.` (x — 뜻이 안 갈린다)
5. **같은 낱말의 뜻끼리 문장이 서로 닮지 않게.** 주어·장면·시제를 달리하라.
   뜻이 갈리는 게 보이도록 **대비**를 만드는 것이 목적이다.
6. **수준을 맞춰라.** `v_level` 1~3 은 중학 수준 문장(쉬운 낱말·짧은 구조),
   4~6 은 고교, 7 이상은 학술/시험 문장. `cefr` 도 참고. 어려운 낱말을 예문에 끌어들이지 마라 —
   설명하려는 낱말보다 예문 속 다른 낱말이 어려우면 예문이 아니라 새 문제다.
7. **자연스러운 실제 영어.** 사전 문장 흉내(`This is a bank.`)나 억지 구문 금지.
   그 뜻이 실제로 쓰이는 전형적 장면을 골라라 (연어·전치사 고정을 살려서).
8. 고유명사는 되도록 피하고, 쓰면 흔한 이름(`Mina`, `Tom`)으로.

## 해석 규칙

1. **자연스러운 한국어.** 직역해서 어색하면 실패다. 학습자가 읽고 바로 이해되는 문장.
2. **그 뜻이 해석에 보여야 한다.** `meaning` 이 "유언장" 이면 해석에 "유언장" 이 드러나야 한다
   (똑같은 낱말일 필요는 없지만 그 뜻으로 옮겨야 한다).
3. 영어 어순을 흉내 내지 말고 한국어 어순으로. 문장부호는 한국어 관행대로.
4. 존댓말/반말은 문장 성격에 맞게 — 대화체면 대화체로. 설명문은 평서형(`~다`)이 기본.

## skip

그 `meaning` 이 **예문을 만들 수 없는 것**이면 그 원소에 `"skip": true` 와 짧은 사유를 쓴다.
(뜻 기술이 깨져 있음 · 실제로 그 뜻이 아님 · 표제어가 영어 낱말이 아님 등)
**억지 예문이 빈칸보다 나쁘다** — 학습자가 그걸 외운다.

## 부수 발견 — 낱말 수준의 `note` 에

`meaning` 이 틀렸거나 잘림 · `pos` 오기 · 같은 뜻이 두 번 · 뜻 갈래가 사실은 하나 ·
`v_level` 과 실제 난이도 불일치. **고치지 말고 적기만 하라** — 사람 검토 목록으로 모은다.

## 출력

`chunk-NN.json` 과 같은 디렉터리에 `chunk-NN.out.json` 으로 저장한다. 배열 하나.

```json
[
  {
    "word": "bank",
    "senses": [
      { "idx": 0, "example": "She opened a savings account at the bank downtown.", "example_ko": "그녀는 시내 은행에서 저축 계좌를 개설했다." },
      { "idx": 1, "example": "We sat on the grassy bank and watched the river.", "example_ko": "우리는 풀이 자란 강둑에 앉아 강을 바라보았다." }
    ]
  },
  {
    "word": "will",
    "note": "idx 2 'ㅇ의지' — 뜻 표기에 오타가 있다",
    "senses": [
      { "idx": 0, "example_ko": "무엇을 마시겠어요?" },
      { "idx": 1, "example": "He lacked the will to keep training.", "example_ko": "그는 훈련을 계속할 의지가 없었다." }
    ]
  }
]
```

- `senses[].idx` 는 입력의 `idx` 를 **그대로** 쓴다. 순서를 바꾸거나 새 idx 를 만들지 마라.
- 입력에 없는 낱말·idx 를 추가하지 마라.
- JSON 만. 앞뒤 설명 문장 금지.
