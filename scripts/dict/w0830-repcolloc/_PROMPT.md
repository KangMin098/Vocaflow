# D0830-T6-1b — 대표 뜻 연어 보강

## 무엇이 문제인가

담당 청크의 낱말들은 **연어가 전부 맞는데, 전부 부차적 뜻에만 붙어 있다.**

| 표제어 | 대표 뜻 | 지금 붙어 있는 연어 |
|---|---|---|
| `pen` | 펜, 필기구 | `sheep pen` · `pig pen` · `playpen` — **전부 '우리'** |
| `pin` | 핀, 시침바늘 | `enter pin` · `pin number` — **전부 두문자어 PIN** |
| `swallow` | 삼키다 | `barn swallow` 등 — **전부 '제비'** |
| `train` | 기차 | **전부 동사 '훈련하다'** |

**틀린 값이 아니다.** 그 뜻들은 `senses[]` 에 정식으로 등재돼 있다.
그래서 앞 배치(T6-1)는 **지울 것이 없어 손대지 못했고**, 이 배치로 넘겼다.

## 왜 학습자에게 닿는가

컴포저의 `collocation` 블루프린트가 이 배열을 **그대로 목차로 쓴다.**
`pen` 카드를 열면 연어 자리에 양 우리가 나온다. 틀리지는 않았지만 그 낱말을 배우러 온
학습자에게는 **아무 쓸모가 없다.**

## 할 일

낱말마다 **대표 뜻**(`meaning_ko` · 대개 `senses[0]`)의 연어 **2~3개**를 만들어
`add.collocations` 에 넣는다.

`why` 필드에 앞 배치가 "무엇이 비어 있는지" 적어 두었다 — 그것을 채우는 것이 일이다.

## 규칙 — 어기면 apply 게이트가 거부한다

1. **표제어(굴절형 허용)가 반드시 들어갈 것.** `swallow` → `swallow a pill`(o) / `gulp down`(x)
2. **2~5낱말.** 2~3 이 좋다. 문장이 아니라 **덩어리**다.
3. **ASCII 영문만** (accent 는 허용). 한글·한자·이모지 금지.
4. **이미 있는 것과 겹치지 말 것.** `collocations` 에 있는 값은 그대로 둔다 — 이 배치는
   **더하기만 한다.** 지우자고 제안하지 마라.
5. **대표 뜻의 연어여야 한다.** 이 배치의 전부다. `pen` 이면 `write with a pen` · `ballpoint pen` ·
   `pen and paper` 처럼 **필기구 뜻**의 결합을 낸다.

## 무엇이 좋은 연어인가

**실제로 함께 쓰이는 결합**이어야 한다 — 사전에서 뽑은 정의가 아니라, 그 낱말을 쓸 때
원어민이 실제로 함께 놓는 낱말이다.

- 좋다: `ballpoint pen` · `pen and paper` · `sign in pen` (전형적 결합)
- 나쁘다: `good pen` · `use a pen` · `nice pen` (아무 명사에나 붙는 밋밋한 조합)
- 나쁘다: `pen is a tool` (문장이지 연어가 아니다)

동사면 전형적 목적어·전치사를, 명사면 전형적 수식어·동사를, 형용사면 전형적 피수식 명사를 골라라.

## 못 하겠으면 `skip`

대표 뜻에 굳어진 연어가 실제로 없으면 `"skip": true` 와 짧은 사유를 쓴다.
**억지 연어가 빈칸보다 나쁘다** — 학습자가 그걸 외운다.
(기능어·고유명사·단일 지시체 명사가 여기 해당할 수 있다)

## `note` — 부수 발견

`meaning_ko` 오류 · `pos` 오기 · `senses` 갈래 중복 등. **고치지 말고 적기만 하라.**

## 출력

`chunk-NN.json` 옆에 `chunk-NN.out.json`. 배열 하나. JSON 만.
**입력의 모든 낱말에 한 줄씩** 낸다 (skip 도 한 줄이다 — 빠뜨리면 다음 배치가 영원히 다시 묻는다).

```json
[
  { "word": "pen", "add": { "collocations": ["ballpoint pen", "pen and paper", "write in pen"] } },
  { "word": "swallow", "add": { "collocations": ["swallow a pill", "hard to swallow"] } },
  { "word": "pm", "skip": true, "note": "약어라 대표 뜻(오후)의 굳어진 연어가 없다" }
]
```

- 입력에 없는 낱말을 추가하지 마라. 앞뒤 설명 문장 금지.
