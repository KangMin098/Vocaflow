# D0830-T6-2 — 뜻 갈래 정리

## 먼저 알아야 할 것 — 예문은 건드리지 않는다

앞선 배치가 `meanings_ko` 의 **72,266 뜻**에 영어 예문과 한국어 해석을 채워 놨다.
갈래를 손대면서 **인덱스가 바뀌면 그 예문이 엉뚱한 뜻에 붙는다** — 빈칸보다 나쁘다.
학습자가 틀린 짝을 외운다.

그래서 이 배치는 예문을 **보여 주지도 않는다.** 대신 갈래마다 `has_example` 만 알려 준다.
당신은 **어느 원본 갈래에서 왔는지**(`from`)만 적으면 되고, **예문을 옮기는 일은 코드가 한다.**

## 할 일

낱말마다 `senses[]` 를 읽고, **고칠 것이 있으면** 새 갈래 배열을 낸다.

`why` 에 이 낱말이 뽑힌 이유가 적혀 있다:

- `노트에서 갈래 문제로 짚힘` — 앞 배치가 읽다가 이상하다고 적어 둔 낱말
- `primary_pos(X) 와 첫 갈래 pos(Y) 가 다르다` — 대표 품사와 첫 갈래가 어긋난다
- `pos_set 의 X 뜻이 갈래에 하나도 없다` — 사전이 그 품사를 갖고 있다면서 뜻은 안 적어 놨다

## 고칠 것 세 가지

### 1. 한 항목에 여러 뜻이 묶여 있으면 **가른다**

```
fell  idx0 "베어 넘어뜨리다; fall 의 과거형; (영국 북부) 황무지 산지"
   →  세 갈래로. 계보가 다른 세 낱말이다.
count idx1 "셈, 계산; 백작"        → 두 갈래로 (동음이의어)
lead       "/led/ 납 · /liːd/ 이끌다"  → 두 갈래로
```

**예문이 달린 갈래를 가를 때는, 그 예문이 어느 쪽 뜻의 것인지 보고 그쪽에 `from` 을 준다.**
나머지는 `from: null` 로 시작한다(예문 없이 시작하고, 나중 배치가 채운다).

### 2. 같은 뜻이 두 번 있으면 **합친다**

```
up  idx1 "오른"  ·  idx2 "(가격이) 오른"   → 하나로
```

합쳐서 버리는 갈래는 `dropped` 에 적는다. **버리는 갈래에 예문이 있으면
`merged_into` 로 어느 갈래에 합쳤는지 반드시 밝힌다** — 안 밝히면 apply 가 거부한다.

### 3. 대표 뜻이 빠져 있으면 **넣는다**

```
it  senses = [{noun, "정보 기술(IT)"}]   ← 대명사 '그것' 이 없다
    → 대명사 갈래를 맨 앞에 넣는다 (from: null)
mean      '의미하다' 가 통째로 빠져 있다
reserve   '예약하다' 가 없다
```

**대표 뜻(가장 흔한 뜻)이 맨 앞에 오게 한다.** `primary_pos` 와 첫 갈래의 품사가
어긋난 낱말이 많은데, 대개 **가장 흔한 뜻을 앞으로 올리면** 저절로 맞는다.

## 하지 말 것

- **뜻을 다듬기만 하는 것.** 표현을 손보는 배치가 아니다. 갈래 **구조**가 틀렸을 때만 고친다.
- **`example`·`example_ko` 를 쓰는 것.** 그 키를 출력에 넣지 마라. 코드가 옮긴다.
- **원본 갈래를 조용히 없애는 것.** 참조하거나 `dropped` 에 사유와 함께 적어야 한다.
- **고칠 게 없는데 억지로 고치는 것.** 멀쩡하면 원본 그대로 내라 (아래 참조).

## 고칠 게 없으면

`senses` 에 원본을 **그대로** 옮겨 낸다 (`from` 은 자기 인덱스, `pos`·`meaning`·`v_level` 도 그대로).
apply 가 "안 바뀜" 으로 알아보고 **물어봤다는 도장만 찍는다** — 그래야 다음 배치가
이 낱말을 다시 묻지 않는다. **빠뜨리면 영원히 다시 묻는다.**

## 출력

`chunk-NN.json` 옆에 `chunk-NN.out.json`. 배열 하나. JSON 만.
**입력의 모든 낱말에 한 줄씩.**

```json
[
  {
    "word": "fell",
    "senses": [
      { "from": 0, "pos": "verb", "meaning": "베어 넘어뜨리다, 쓰러뜨리다", "v_level": 5 },
      { "from": null, "pos": "verb", "meaning": "넘어졌다, 떨어졌다 (fall의 과거형)", "v_level": 1 },
      { "from": 2, "pos": "noun", "meaning": "황무지 산지 (영국 북부)", "v_level": 10 }
    ],
    "note": "한 항목에 계보가 다른 세 낱말이 묶여 있었다"
  },
  {
    "word": "up",
    "senses": [
      { "from": 0, "pos": "adverb", "meaning": "위로", "v_level": 1 },
      { "from": 1, "pos": "adjective", "meaning": "오른, (가격이) 오른", "v_level": 3 }
    ],
    "dropped": [{ "idx": 2, "reason": "idx1 과 같은 뜻", "merged_into": 1 }]
  },
  {
    "word": "table",
    "senses": [
      { "from": 0, "pos": "noun", "meaning": "탁자, 식탁", "v_level": 1 },
      { "from": 1, "pos": "noun", "meaning": "표, 도표", "v_level": 3 }
    ]
  }
]
```

- `from` 은 **입력 `senses[].idx`** 다. 새 갈래는 `from: null`.
- 같은 `from` 을 두 번 쓸 수 없다.
- `v_level` 은 원본 값을 그대로 두는 것이 기본이다. 새 갈래에만 1~11 중에서 정한다.
- 앞뒤 설명 문장 금지.
