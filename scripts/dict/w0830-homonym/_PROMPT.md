# D0830-T6-1 — 동음이의어 오염 판정 (`collocations` · `synonyms` · `antonyms`)

WordNet 은 표제어를 **동음이의어별로 나누지 않고** 한 문자열 아래 모든 synset 을 매단다.
그걸 낱말 단위로 평탄화해 들여왔더니 이렇게 됐다:

| 표제어 | `meaning_ko` 가 말하는 것 | 딸려 들어온 것 |
|---|---|---|
| `saw` | 'see 의 과거형' | 연어 `hand saw` · `chain saw` · `old saw` — **전부 톱** |
| `over` | '넘어서; 끝나서' | 연어 `bowl an over` · `maiden over` — **전부 크리켓 명사** |
| `march` | '행진하다' | 연어 `in March` · `early March` — **전부 3월** |
| `he` | 대명사 | 반의어 `slightly` · 연어 `he good` — **실재하지 않는 용법** |

**빈칸보다 나쁘다.** 빈칸은 학습자가 아무것도 안 배우지만 **틀린 연어는 외운다.**
그리고 컴포저의 `collocation`·`synonym-cluster` 블루프린트가 이 값을 그대로 목차로 쓴다.

## 할 일 — 하나뿐이다

담당 청크의 낱말마다 `collocations` · `synonyms` · `antonyms` 의 **각 항목**이
그 표제어의 뜻에 속하는지 판정하고, **속하지 않는 것만** `drop` 에 적는다.

**대체값을 만들지 마라.** 이 배치는 **비우기만** 한다. 채우는 것은 다른 배치(`corefill`)의 일이고,
두 배치를 섞으면 무엇이 지워지고 무엇이 채워졌는지 못 가린다.

## 판정 기준

### 유지한다 (drop 하지 않는다)

1. **`senses[]` 의 어느 뜻에든 맞으면 유지.** `meaning_ko` 는 대표 뜻일 뿐이다.
   `being` 은 `senses` 에 '존재, 생명체' 가 있으니 `human being` · `organism` 은 정상이다.
2. **약하지만 틀리지는 않은 것은 유지.** `be` 의 연어 `to be` · `will be` 는 밋밋하지만
   틀린 값이 아니다. **이 배치는 틀린 값을 지우는 것이지 시시한 값을 지우는 것이 아니다.**
   품질 개선은 다른 배치가 한다.
3. **낯설다는 이유로 지우지 마라.** 전문 용어·문어체·영국 용법도 그 뜻이면 유지한다.
4. **연어에 표제어가 안 보여도 유지.** 굴절형(`saw` ← `see`)이나 활용형일 수 있다.

### 지운다 (drop 에 적는다)

1. **다른 동음이의어의 것** — 철자만 같고 계보가 다른 낱말의 값.
   `saw`(see 의 과거형)에 붙은 `hand saw`(톱), `over`(부사)에 붙은 `maiden over`(크리켓).
2. **`senses[]` 어디에도 없는 뜻** — 그 뜻 자체가 이 낱말의 뜻으로 등재돼 있지 않다.
3. **실재하지 않는 영어** — `he good` · `he nice` 처럼 영어에 없는 결합.
4. **반의어가 아닌 반의어 자리 값** — `he` 의 반의어 `slightly` 같은 것.
5. **고유명사/월·요일 오염** — `march` 의 `in March`, `may` 의 `in May`.

### 경계에서는 **유지** 쪽으로

확신이 없으면 지우지 마라. **잘못 지운 값은 되살릴 수 있지만**(지운 값은 기록된다)
**모두가 조금씩 지우면 사전이 빈다.** 이 배치의 목표는 명백한 오염 제거다.

## `example_mismatch` — 적기만 하고 고치지 않는다

`example_en` 이 `senses[]` 어디에도 없는 뜻을 보여 주면 `"example_mismatch": true` 로 표시한다.
**예문을 고치지 마라** — `example_en` 을 덮는 것은 T6-3 한 배치뿐이고, 여기서 손대면
무엇이 언제 바뀌었는지 못 가린다. 표시만 하면 T6-3 큐로 넘어간다.

## `note` — 부수 발견

`meaning_ko` 오류·잘림 · `pos` 오기 · 표제어가 굴절형 · 뜻 갈래 중복 등.
**고치지 말고 적기만 하라** — 사람 검토 목록으로 모인다.

## 출력

`chunk-NN.json` 과 같은 디렉터리에 `chunk-NN.out.json`. 배열 하나. JSON 만.
**입력의 모든 낱말에 한 줄씩** 낸다 (지울 게 없어도 낸다 — "물어봤고 깨끗했다" 는 판정이고,
빠뜨리면 "아직 안 물어봤다" 와 구별되지 않아 다음 배치가 영원히 다시 묻는다).

```json
[
  {
    "word": "saw",
    "drop": { "collocations": ["hand saw", "chain saw", "old saw"] },
    "note": "meaning_ko 는 see 의 과거형인데 연어가 전부 톱(명사 saw)이다"
  },
  {
    "word": "being",
    "drop": {}
  },
  {
    "word": "over",
    "drop": { "collocations": ["bowl an over", "maiden over", "final over"] },
    "example_mismatch": true,
    "note": "예문도 크리켓 명사 over 다"
  }
]
```

- `drop` 의 문자열은 **입력에 있던 것을 글자 그대로** 옮긴다. 바꿔 쓰거나 새로 지어내면
  apply 가 `not_shown` 으로 거부한다.
- 비어 있는 필드는 `drop` 에서 생략한다. 지울 게 없으면 `"drop": {}`.
- 입력에 없는 낱말을 추가하지 마라. 앞뒤 설명 문장 금지.
