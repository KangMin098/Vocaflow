# args.me 재저작 드레인 — 지시서

## 무엇을 만드는가
수능형 **독해 지문** 1편 = **140~200어**(목표 중앙 164어), 영어, 자족적 논증문.

## 왜 재저작인가
입력은 CC BY 4.0 이지만 **표현을 쓰지 않는다.** 사실·쟁점·논지 구조만 읽고
**네 문장으로 새로 쓴다.** 산출물은 우리 저작(CC0)이다.
입력이 인터넷 토론글이라 표현 품질이 낮다 — 베끼면 그 품질이 따라온다.

## 통과 기준 (전부 기계로 재검사한다)
1. **길이** 140~200어. 중앙 164어를 겨냥.
2. **어휘** NGSL+NAWL 밖 비율 **≤10%** (기출 중앙 8.4%).
   ⚠️ **2026-09-23 정정 — 이 칸이 자주 떨어진 것은 게이트 버그였다.**
   단어 목록 로더가 CSV 첫 칸만 읽어 굴절형 8,933개를 버렸고, 그 결과
   is·are·was·were·their·them·better·best·children·an·does·did 가 전부
   off-list 로 집계됐다(목록 12,700 → 3,767). **지금은 고쳐졌다.**
   **그러니 be동사·소유대명사·비교급·불규칙 과거를 피하지 마라.**
   그것들을 피해 쓴 앞선 청크는 be동사 밀도가 0.00~0.21/100어였다
   (정상 영어는 3~5). **자연스러운 교재 영어로 쓰는 것이 기준이다.**
   어휘는 내용어를 쉽게 고르면 저절로 맞는다.
   - 전문용어·고유명사·약어를 피한다. 필요하면 쉬운 말로 풀어 쓴다.
   - 입력 원문의 off_list_pct 가 11~12% 다 — **그대로 옮기면 떨어진다.**
3. **자족** 혼자 읽혀야 한다. 금지: opponent / round / rebuttal / you said /
   the resolution / this debate / as I said earlier / 각주·인용번호.
   특정 인물·단체·사건을 전제하지 않는다.
4. **논증** 주장 하나 + 근거 둘 이상 + 마무리. 설명문이 아니라 **주장하는 글**.
5. **문장** 4~8문장. 평균 20~26어. 모든 문장이 대문자로 시작하고 마침표로 끝난다.

## 하지 말 것
- 입력 문장을 바꿔 쓰기(낱말만 교체) — 파생물이다. **논지만 취하고 새로 쓴다.**
- 1인칭(I/we), 독자 호명(you), 수사적 질문 남발.
- 한쪽으로 치우친 정치·종교 선동. 쟁점은 다루되 **논증**으로 다룬다.
- 입력 주제가 지문으로 부적절하면(게임쇼·개인 신상·비속어 등) `skip` 으로 표시.

## 출력 형식
`chunk-NNN.out.json` 에 아래 모양으로. **입력 배열 순서를 그대로 지킨다.**

```json
{
  "contract": "argsme-textbook/v1.out",
  "chunk": "001",
  "items": [
    {
      "id": "<입력 id 그대로>",
      "sha256": "<입력 sha256 그대로>",
      "verdict": "write" | "skip",
      "skip_reason": "<skip 일 때만: 한 줄>",
      "topic_ko": "<주제 한국어 한 줄>",
      "passage": "<영어 지문 140~200어>",
      "claim": "<이 글의 주장 한 문장, 영어>"
    }
  ]
}
```

## 배열 밀림 사고를 막는 법 (이 저장소에서 6번 났다)
- 입력 배열을 **직접 순회**하며 쓴다. 별도 목록을 만들어 합치지 않는다.
- 쓰기 전에 **인덱스 15개 이상**을 눈으로 대조한다(입력 id ↔ 출력 id).
- `id` 와 `sha256` 은 **입력에서 복사**한다 — 그래서 밀려도 검사기가 못 잡는다.
  따라서 **눈 대조가 유일한 방어**다.
