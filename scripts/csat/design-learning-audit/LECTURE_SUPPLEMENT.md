# 강의 대본 재작성 보충 (2026-10-11 · 지시문 §8)

정본: `apps/web/scripts/csat-lecture/WRITER.md` 를 그대로 따른다(형식 · 약식 · 검사). 아래를 더한다.

1. 사실의 정본은 청크에 실린 **지금 DB 의 최신 분석**(이번에 교정 · 적재된 버전)이다. 분석에 없는 사실 · 수치 · 선택률을 말하지 않는다.
2. 강의는 정답 해설 낭독이 아니라 설계 원리 수업 — 큐 역할 순서: 학습 목표(이 문항이 판단시키는 관계) → 구조 관계 → 정답 조건/표현 변환 → 대표 오답 비교 → 원리와 적용 조건 · 통하지 않는 경우.
   유형 교수 계약 `apps/web/src/lib/csat/teaching-contract.ts` 의 relation · pitfalls 를 쓴다. 무조건 요령 금지(「선지 번호 = 지문 순서」 등).
3. 선택≠참거짓 유형(어법 · 어휘 · 불일치 · 도표): 정답 아닌 선지는 「내용이 맞아서 답이 아닌」 것으로 말한다 — 함정으로 부르지 않는다.
4. 문장 번호는 청크의 문장 지도(골격) 번호와 같아야 하고, 말로 하는 「N번째 문장」도 그 범위 안. 정답표로 거꾸로 추론하는 말 금지(가드 `lecture-no-answer-key-inference`).
5. 다른 에이전트가 함께 일한다 — 자기 청크의 `.out.json` 만 쓴다. DB · git · lecture-data 는 건드리지 않는다.
