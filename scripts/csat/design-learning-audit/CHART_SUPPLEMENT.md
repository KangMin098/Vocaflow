# 도표(R-CHART) 교정 보충 — 원본 도표를 보고 쓴다 (2026-10-11)

`REDO_SUPPLEMENT.md` 와 정본 `_PROMPT.md` 를 따르고 아래를 더한다.

1. **원본 도표를 반드시 본다.** 조정자가 문항마다 로컬 문제지 PDF 경로를 준다. Read 도구로 그 PDF 의 쪽(`pages`)을 열어 해당 번호의 도표 · 표를 **눈으로** 읽는다(보통 2~4쪽). 도표를 찾지 못하면 그 문항은 쓰지 않고 `needs_source` 로 보고한다.
2. **값은 도표에서 읽은 그대로.** 막대 · 칸의 수치 · 단위(%, %p, 명, 배)를 적고, 선지마다 「도표의 어느 값과 어느 값을 견주면 참/거짓인가」를 계산으로 보인다. 정답표로 값을 거꾸로 맞추지 않는다(validate V13).
3. **정답 대조.** 도표에서 읽은 값으로 판정한 정답이 공식 정답(`answer`)과 다르면 고쳐 쓰지 말고 그 문항을 `needs_source` 로 보고한다 — 읽기 실수일 가능성이 크다.
4. **발문은 부정형**(「일치하지 않는 것은?」)이라 정답 아닌 넷은 **맞는 진술**이다 — trap · why_tempting 을 비우고 how_to_reject 에 「도표의 어느 값 대응 · 계산 · 그래서 맞다」를 쓴다. 함정 서술은 정답 선지(바뀐 값 · 비교 방향 · 배수/차이 혼동)에만.
5. **확인 기록**: 정답 선지 `confirmed_at.note` 에 「원본 도표 확인 — <파일명> <쪽>쪽, 읽은 값: …」을 남긴다(학습자 칸 아님). 로컬 경로 전체는 쓰지 않고 파일명만.
6. 학습자 칸에 「원본을 봤다 · PDF · 쪽」 같은 작업 사정을 쓰지 않는다(V12).
