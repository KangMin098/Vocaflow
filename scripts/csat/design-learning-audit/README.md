## 한계 — keep 은 품질 보증이 아니다

검수 에이전트 대부분이 40문항 중 일부만 정독하고 나머지는 기계 검사(정답 표시 일치 · 인용 축자 · 빈 칸)만으로 keep 을 줬다
(각 청크 보고: 정독 4~40문항). 특히 빈칸 · 순서 · 삽입 · 요약은 인용 대조로 결함이 드러나지 않는다.
→ 2차: keep 중 미정독 문항을 10문항 청크 · 전문 정독 필수 · 문항별 `read: full|partial` 기록으로 다시 본다. 학평 2,606 도 같은 방식.

  유형별 keep 잔존: R-BLANK 74/109 · R-ORDER 44/56 · R-INSERT 23/53 · R-SUMMARY 11/24 · X-ORDER 14/24.
