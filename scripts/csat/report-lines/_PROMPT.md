# 유형 리포트 줄 재작성 — 명세

`chunk-01.json` 을 읽고 `chunk-01.out.json` 을 쓴다. 근거 서술 재작성(`../locus-refold/_PROMPT.md`)과 같은 목적의 **줄 단위** 판이다 — 그 명세의 「반드시 뺄 것 · 반드시 남길 것」을 그대로 따른다.

## 무엇을 고치나

`lines[]` 의 줄마다 `failure_modes`(학습자가 미끄러지는 자리) 또는 `procedure_steps`(풀이 절차 한 단계)의 한 줄이다. 분석자 작업 로그(청크 · 관찰 번호 · 날짜 갱신 · 내부 필드명 · 배치 지시)가 섞여 있어서 **학습자 화면에 그대로 나간다.**

같은 사실을 **고등학생에게 하는 한 줄**로 다시 쓴다.
- 작업 로그 표지를 전부 뺀다. 「이 청크에서」 → 뺀다 · 「2026-09-04 갱신」 → 뺀다.
- 규칙 · 비율 · 표지어 · 예외는 남긴다.
- 원본에 없는 **문항 id** 와 **영어 표현**을 새로 쓰지 않는다(게이트가 대조한다).
- 출제자의 의도를 확인된 사실처럼 쓰지 않는다 — 「출제자가 노렸다」가 아니라 「이 자리에서 자주 틀린다」처럼 관찰로 쓴다.
- `context[type_id]` 에 같은 유형의 다른 줄이 있다. 고친 줄이 그것들과 **같은 말을 되풀이하게 되면** 짧게 차별점만 남긴다.

## 출력

```json
{ "lines": [ { "type_id": "R-BLANK", "field": "failure_modes", "index": 8, "text": "…" } ] }
```

입력의 `type_id` · `field` · `index` 를 그대로 옮긴다. 줄마다 하나, 빠짐없이.
