## 4. 맹검 분리

- 1단계 입력은 문항 · revision · 골격 서명 · 밑줄 문장 번호 · 문장 범위만 담는다. 검수자는 원문을 DB 에서 직접 읽고 판별 · 자기 말로 쓴 문맥 뜻 · 근거 문장을 **먼저 제출**한다.
- 2단계(뜻 선택지 고르기)는 1단계 제출 파일의 SHA256 이 원장에 남은 뒤에만 연다. 선택지에 정답 표시 · 배제 이유 · Claude 근거는 없다.
- 공식 정답은 공개 자료라 검수자가 알 수 있다 — 그래서 **판별(B) 일치는 독립성의 증거가 아니다.** 일치율은 뜻(D) · 근거(C) 로만 잰다(0.85 미만이면 반영하지 않는다).
- 두 AI 의 일치는 사람 전문가 검수가 아니다. accepted 승격 · 출시는 사람 게이트다.
