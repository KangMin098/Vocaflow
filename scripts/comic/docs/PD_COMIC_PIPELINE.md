# PDCP — Public-Domain Comic Pipeline (설계 + 1차 구현)

> 퍼블릭 도메인 스캔 만화를 **현대적 학습 콘텐츠**로 바꿔 학습자에게 게시하는 파이프라인.
> 기존 CCP(AI 생성 만화)와 **저장·리더·발행 게이트를 공유**하고, 소스 단계만 갈아 끼운다.
> 작성: v07.6 · 실측 검증 소재 `ClassicsIllustrated027TheSpy` (Internet Archive)

---

## 0. 왜 CCP 확장인가 (새로 만들지 않는 이유)

이미 있는 것을 다시 만들 이유가 없다:

| 이미 있음 | 재사용 |
|---|---|
| `comic_pages` — `(library_book_id, chapter_idx, page_order)` 자연키 = **컷 단위** | 그대로 |
| `comic_books` — 발행 게이트 헤더 + `qc_verdict` | `backend='pd-scan'` 으로 구분 |
| `/admin/comic/[bookId]` 검수 콘솔 (stepper · QC · 컷 전수 검수 · 게시/보관) | 그대로 |
| `/text/[id]/comic` 학습자 리더 (stave 레일 · 대사존 · verbatim blur→reveal · Light/Dim) | 그대로 |
| `ComicHeroCard` (라이브러리 발견 진입) | 그대로 |

**핵심 정합**: `comic_pages` 가 이미 "페이지"가 아니라 **컷** 단위다. PD 스캔도 컷으로 쪼개면
스키마 변경 없이 그대로 들어간다. 이것이 아래 §3(컷 분할)이 선택이 아니라 **필수**인 이유다.

## 1. 소스 · 법적 검증 (게이트 0)

이 단계를 통과하지 못한 소재는 파이프라인에 **진입 자체를 금지**한다.

### 1순위 소스
- **Internet Archive** — Classics Illustrated 계열. 문학 원작 각색이라 Vocaflow 의 도서 카탈로그와 1:1로 붙는다.
  - 실측: `https://archive.org/metadata/<identifier>` 로 파일 목록, `/download/<id>/page/nN_w1200.jpg` 로 페이지 이미지 직접 취득 가능(검증됨).
- 대체: Digital Comic Museum · Comic Book Plus (PD 확인된 골든에이지 스캔 아카이브)

### 판정 규칙 (미국 저작권 기준)
1. **1929년 이전 발행** → 무조건 PD
2. 1930~1963 발행 → **갱신(renewal) 여부**가 갈림. UPenn 저작권 갱신 기록에서 호별 확인.
   갱신 기록이 없으면 PD, 있으면 **제외**.
3. 1964 이후 → 자동 갱신 → **제외**
4. Classics Illustrated **Junior** 는 안전한 PD 가 아니다 — 제외.

### 기록 의무
호마다 다음을 남긴다(감사·분쟁 대비). 근거 없는 소재는 발행 게이트에서 차단:
`source_archive` · `source_identifier` · `source_url` · `issue_no` · `published_year` ·
`pd_basis`(`pre-1929` | `no-renewal` | `explicit-license`) · `pd_checked_at` · `pd_checked_by`

> ⚠️ 한국에서 서비스하더라도 **원작 각색의 원저작물**(예: Cooper 『The Spy』)과
> **그 만화 각색본**의 저작권은 별개다. 위 판정은 각색본 기준이다.

## 2. 복원 — `scripts/comic/pd/restore.mjs` ✅ 구현·검증됨

```bash
FFMPEG_BIN=/path/to/ffmpeg node scripts/comic/pd/restore.mjs \
  --in raw/ --out restored/ [--sat 1.22] [--scale 2]
```

의존성은 **ffmpeg 하나뿐**(이 워크스테이션에 Python/OpenCV/sharp 없음 — 실측).

| 단계 | 처리 | 근거 |
|---|---|---|
| ① 스캔 여백 크롭 | 모서리 색을 배경으로 보고 콘텐츠 bbox 검출 | 골든에이지 스캔은 분홍/회색 스캔대 여백이 크게 남음 |
| ② 종이 탈황변 | 종이색을 **채널별 90분위수**로 추정 → 채널 게인 | 평균은 잉크에 끌리고 최댓값은 하이라이트 한 점에 휘둘림 |
| ③ 디노이즈 | `nlmeans=s=1.6:p=3:r=9` | 망점(halftone)만 녹이고 선화는 보존 |
| ④ 색 복원 | `eq=contrast=1.10:saturation=1.22:gamma=0.97` | 바랜 잉크 회복. 채도 과하면 네온처럼 뜸(1.15~1.35 권장) |
| ⑤ 업스케일·샤픈 | `scale=2x:lanczos` → `unsharp` | 업스케일 **후** 샤픈해야 레터링 에지가 산다 |

**설계 결정**: 화이트밸런스는 "종이를 흰색으로 정렬"이지 "최대 채널로 끌어올리기"가 아니다.
최대 게인 1.35 로 물려 청색 과보정을 막고, 종이를 250 근처에 두어(순백 아님) 계조를 남긴다.
파라미터는 **페이지마다 다시 추정**한다 — 장마다 변색 정도가 다르다.

원본은 절대 덮어쓰지 않고 `restore.manifest.json` 에 페이지별 추정 종이색·게인·크롭을 남겨
재현·감사 가능하게 한다.

**실측 결과** (`ClassicsIllustrated027TheSpy` p7, 2089×3000):
종이 rgb(250,241,234) → 게인 1.000/1.037/1.068 · 분홍 여백 제거 · 3592×5228 출력.
말풍선 텍스트가 흰 배경 위 선명한 검정으로 살아나 폰 가독성이 확연히 개선됨.

## 3. 컷 분할 — `scripts/comic/pd/segment.mjs` ⚠️ 구현·부분 검증

```bash
FFMPEG_BIN=... node scripts/comic/pd/segment.mjs \
  --in restored/ --out panels/ [--web 1200] [--analysis 1100] [--dilate 2]
```

### 왜 필수인가
1940년대 지면은 A4 인쇄 전제의 조밀한 4~8컷 그리드다. 폰에 그대로 띄우면 레터링이 깨알이 되어
핀치줌 없이는 못 읽는다 — 학습 콘텐츠로서 치명적이다. 컷으로 쪼개 **세로 스크롤 한 컷씩**
보여주면(Comixology Guided View · 웹툰 관성) 폰 화면 전체가 한 컷에 할당된다.

### 알고리즘 (두 번 갈아엎은 결과)
1. ~~재귀 XY-cut(거터 투영)~~ — **실패**. 위·아래 컷의 프레임선 y 가 몇 px 어긋나 있어
   **전폭이 흰 행이 존재하지 않는다**(실측: 480×699 축소본에서 흰 행 5줄뿐, 전부 상단 여백).
2. **배경 플러드필 + 4-연결요소** — 채택.
   테두리 흰 픽셀에서 배경을 채워 컷 *바깥* 거터만 칠하고, 안 칠해진 성분의 bbox = 컷.

### 두 개의 결정적 파라미터 (실측으로 잡음)
- **`--analysis 1100`** — 분석 해상도. 480px 로 줄이면 2~6px 거터가 1px 미만으로 뭉개져
  컷이 **전혀** 안 나뉜다. 1100px 에서 거터가 살아난다(실측: 세로 거터 x=598~599 검출).
- **`--dilate 2`** — 배경 마스크 팽창. 거터가 2px 수준이라 망점 잡티 하나, JPEG 링잉 한 점만
  걸쳐도 통로가 막혀 페이지 전체가 1컷으로 붙는다. 프레임선(3~6px)보다 작게 유지해야
  프레임을 뚫고 컷 내부로 배경이 새지 않는다.

### 현재 정확도와 한계 (정직하게)
실측 p7(4컷 페이지) → **3컷 검출**. 우측 컬럼의 상·하 컷이 병합됐다 —
캡션 박스("MEANWHILE, IN THE WHARTON PARLOR…")가 거터를 가로질러 두 컷을 잇기 때문.

병합/과분할이 남는 것을 전제로 한 **자동 1차 분할**이다. 그래서 §6 검수 단계에서
사람이 컷 경계를 확인·보정하는 것을 파이프라인에 넣었다. 자동 분할률을 신뢰도로 QC 에 싣는다.

## 4. 대사 추출 · 어휘 태깅

PD 스캔은 AI 생성 만화와 결정적으로 다르다 — **대사가 이미지에 구워져 있다**.
Vocaflow 리더의 대사존·verbatim blur→reveal·vocab 칩은 전부 `comic_pages.bubbles` 를 먹고 돌아가므로
텍스트를 **데이터로** 꺼내야 한다.

1. **OCR** — IA 아이템의 `*_text.pdf`(이미 OCR 됨)를 1차 소스로 쓰고, 컷 bbox 로 대사를 배분.
   OCR 이 없으면 컷 단위로 별도 OCR.
2. **truecasing** — 골든에이지 레터링은 전부 대문자다. 그대로 두면 학습 자료로 못 쓴다.
   문장 경계·고유명사 복원 필요.
3. **어휘 태깅** — 레마화 → `shared_dictionary` 매칭 → V-Level 산출 → `target_vocab` 적재.
4. **bubbles 좌표** — 컷 내 상대 좌표(0~1)로 저장. 리더의 대사존이 이미지를 가리지 않게 배치.

> 이 단계는 **미구현**이다. OCR 엔진 선택(IA 텍스트 재사용 vs 자체 OCR)이 선행돼야 한다.

## 5. 적재 — `comic_pages` 매핑

| PDCP 산출 | 컬럼 |
|---|---|
| 컷 순번(권 전체 통산) | `page_order` |
| 원본 페이지 번호 | `chapter_idx` (또는 도서 챕터 매핑) |
| 컷 이미지 URL(공개 버킷) | `image_url` |
| OCR·정제된 대사 | `bubbles` |
| 태깅된 어휘 | `target_vocab` |
| 도서 난이도 | `book_v_level` |

`comic_books`: `backend='pd-scan'` · `style='<시리즈 slug>'` · `qc_verdict` 에 자동분할 신뢰도 기록.

## 6. 검수 (기존 Admin 재사용 + PDCP 전용 체크)

`/admin/comic/[bookId]` 의 컷 전수 검수에 3개 체크를 얹는다:
- **컷 경계** — 병합/과분할 확인. 잘못된 컷은 반려 → 재분할
- **가독성** — 복원 후 레터링이 폰에서 읽히는가
- **법적 근거** — §1 기록이 채워져 있는가 (미기재면 발행 차단)

## 7. 학습자 게시 방안

### 7-1. 어디에 뜨는가 (기존 표면 재사용)
- **발견**: `/library/books` 상단 `ComicHeroCard` — 이미 발행 만화를 노출
- **읽기**: `/text/[id]/comic` — stave 레일 · 세로 스크롤 몰입 모드 · Light/Dim
- **진입**: TextViewer `ModePills` 의 "만화"

### 7-2. PD 소재에만 필요한 것
1. **출처·라이선스 표기** — CC-BY 가 아닌 PD 여도 아카이브 출처는 밝히는 게 신뢰의 문제다.
   리더 하단 + 도서 상세에 `원작 · 발행연도 · 아카이브 · PD 근거`.
2. **"복원됨" 배지** — 1940년대 원본을 복원했다는 사실은 **숨길 게 아니라 파는 포인트**다.
   "1945년 원본 · 디지털 복원" 은 콘텐츠의 매력이자, 화질 기대치를 정직하게 세팅한다.
3. **원본 보기** — 복원본이 기본이되 원본 스캔을 볼 수 있는 링크. 복원의 투명성.

### 7-3. 학습 통합 (이게 본질)
만화는 읽을거리가 아니라 **L1~L2 진입 계층**이다. 기존 CCP 리더가 이미 하는 것을 그대로 받는다:
- verbatim blur→reveal 로 회상 유도
- `target_vocab` 칩 → WordVault 담기
- 완독 → `module_history` 에 'comic' 기록 → 같은 도서의 ScriptQuiz·Dictation 으로 연결

**PD 만화의 고유 가치**: Classics Illustrated 는 문학 원작 각색이라
`library_books` 의 원작(예: Cooper 『The Spy』)과 **같은 도서 아래 묶인다**.
학습자는 *만화로 진입 → 원문으로 상승* 하는 계단을 한 도서 안에서 밟는다.
이것이 AI 생성 만화와 다른, PD 소재만의 전략적 이점이다.

## 8. 필요한 스키마 변경 (승인 대기)

§1 의 법적 근거를 저장할 곳이 현재 없다. `supabase/migrations/` 에 넣을 SQL 은
`scripts/comic/pd/migration.sql` 참조 — **사용자 승인 전에는 적용하지 않는다**(CLAUDE.md 규칙).
