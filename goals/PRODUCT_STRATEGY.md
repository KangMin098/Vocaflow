## 1. 제품 명제와 포지셔닝

**Vocaflow = 콘텐츠와 훈련 경험을 목적별로 연결하고, 학습 성과를 확인할 수 있는 영어 학습 운영 체계.**

- 해결 문제: 좋은 학습 자료의 부족만이 아니라 **학습 과제·피드백·복습·전이·평가가 분리되어 어떤 역량이 향상됐는지 알기 어려운 문제**.
- 학습자가 얻는 가치: 지금 할 일, 하는 이유, 이해가 안 된 부분, 다음 연습, 이전 대비 달라진 점을 파악한다.
- 교사가 얻는 가치(후속): 학습 자료와 과제를 배포하고 수행/진전을 관찰한다. 현재 검증된 교사 유입 채널이 아니다.
- 콘텐츠 운영자가 얻는 가치: 양적 확대보다 근거, 적합성, 활용도, 재사용 가능성을 관리한다.
- 제품이 약속 **하지 않는 것**: 단시간 성적 상승 보장, 자동 원인 판정의 무오류, 게임 시간이 곧 학습 효과, 합법성 미확인 콘텐츠의 자유 배포.

| 기초·초등 고학년 | 의미 있는 어휘와 짧은 문장 이해 | 텍스트·그림·오디오·선택형 게임 | 미노출 항목 이해/회상 | R1 후보 |

| 고등 일반·학술 읽기 | 복합 문장과 논증 구조 이해 | 장문, 관계 분석, 어휘/구문/강의 | 독립 독해·전이 | R1 |

| 교사·수업 | 과제 배포와 학습 관찰 | 교실, 진도, 콘텐츠 할당 | 실제 교사/학급 사용성 | 검증 후 |

## 3. 공통 학습 상태와 서로 다른 교수법

**연결해야 할 것**: learner, learning_goal, competency/skill, content_identity, activity, attempt, feedback, review_due, assessment, transfer_evidence, provenance, confidence.

**획일화하지 말 것**: 강의/게임/독해/듣기의 순서와 지속 시간, 동일한 정답률 척도, 서로 다른 문항 유형의 해석, 모든 모듈의 동일 피드백.

- 어휘: 간격 회상, 의미 구별, 문맥 적용.
- 문장: 구조 이해와 의미 구성, 어휘/구문을 읽기로 연결.
- 독해: 문장 간 관계, 핵심 주장/근거, 추론, 선택지 판단; 텍스트 수용만으로 완료 처리하지 않는다.
- 듣기: 음성 인식·의미 이해·필요시 받아쓰기/발화 연습; TTS 청취 기록과 실제 듣기 평가를 구분.
- 강의/TTS: 특정 막힘을 설명하고 연습으로 복귀시키는 지원 수단; 재생만으로 숙달 판정 금지.
- 게임: 반복 노출·동기 부여·유창성 과제의 선택적 UI; 점수/플레이 시간이 학습 향상을 대체하지 않는다.
- 교실: 개별 학습 목표와 연결되되 교사가 과제를 조정할 수 있는 모드.
- 한국 시험: 출제 조건, 문제 유형, 답/오답의 근거, 품질 불확실성, 시험별 전이 측정을 유지.

## 4. 콘텐츠 공급부터 실제 학습까지

`source_discovery -> rights/provenance -> ingestion -> segmentation/normalization -> linguistic and pedagogical analysis -> level/goal fit -> human/automated QA -> publish decision -> task selection -> learning interaction -> feedback/review -> novel-context transfer -> reassessment -> demand/quality feedback to supply`

기존 도서(LCP)·기사(ACP)·어휘(VCB/VRL/lexicon)·시험 원문·구문 생성·교재 공장·만화(CCP/PDCP)·영상은 각자 전문 파이프라인으로 유지할 수 있다. 그러나 **학습자에게 공개되는 산출물**은 최소 공통 출처·적격·학습 목표 계약을 만족해야 한다. 생성 성공 수보다 학습 수요 충족/사용/유지/전이 지표를 우선한다.

권한 상태가 미확인이라면 비공개 연구/대기 상태로 두고 출시 자료로 승격하지 않는다. 기존 저작권 자료를 출처만 표시하면 배포 가능하다고 판단하지 않는다.

## 5. 진단에서 재평가까지의 연결

1. 학습 목적을 선택하고 모르는 영역은 `unknown`으로 표시한다. 진단 부재를 결함으로 취급하지 않는다.
2. 짧은 기준 과제 또는 신뢰 가능한 기록으로 계획을 세운다.
3. 읽기·어휘·구문·듣기 중 필요한 Practice를 수행한다.
4. 문항마다 근거 있는 피드백과 수준별 지원을 제공한다.
5. 복습은 영역별 규칙으로 예약하지만 학습자에게는 하나의 오늘의 할 일로 보인다.
6. 새 텍스트·다른 문맥·다른 문항을 통해 전이를 별도로 측정한다.
7. 재평가는 기준선과 비교 가능한 조건을 기록하고 실제 변화만 보고한다.
8. 학습 지도가 다음 선택을 설명하되 불확실한 원인 판정은 강요하지 않는다.

## 9. 출시 전략과 중단 규칙

**R0**: 중등 일반 영어·독해 학습자가 PC 웹에서 비로그인 체험 → 선택적 가입/로그인 → 읽기/Practice → 피드백 → 복습 → 미노출 전이 → 재평가 → 진행 기록 조회까지 수행할 수 있는 배포 가능한 제품. 수능, 교실, 결제, 모든 게임, 모든 공급 파이프라인의 동시 완성은 요구하지 않는다.

**R1**: 일반 독해에서 어휘·문장·듣기, 고등/수능 특화 및 선택적 강의/게임의 연결성을 확장. **R2**: 교사·기관/상용화/모바일 및 콘텐츠 공급 최적화. R1/R2는 순서 조정 가능.

다음 조건에서는 R0 공개 보류: 핵심 플로우 오류, 자료 공개 권한 불명, 권한/개인정보 중대 결함, 학습 기록 누락, 실제 배포/스킵 없는 핵심 E2E 부재. 반면 실제 학습 효과 미검증은 **효과를 주장하지 않는 제한적 사용성 파일럿** 자체를 막지 않는다.

## 10. 지표 체계

- 공급: 권한 확인률/출처 추적률/활성 콘텐츠 사용률/미발행 사유.
- 기술: 핵심 여정 E2E 실행성공, 프로덕션 스모크, 이벤트 완전성, 접근권한/복구.
- 행동: 진입→첫 과제→피드백→복습→새 과제→재평가 도달 퍼널과 이탈/실패 원인.
- 학습: 문맥 간 전이, 지연 유지, 비교 가능한 재평가 변화와 신뢰구간/제약.
- 사업(후속): 실제 유입 및 사용성, 교사 수요, 지속 이용/가격 의향. 테스트 계정을 활성 사용자로 집계하지 않는다.

모든 목표값은 `design_target`으로 저장하고 측정 가능성·표본 크기·효과 최소치와 분석 계획을 파일럿 전 등록한다. 제품 품질 합격 수치와 인과 효과 수치가 서로 다른 것임을 유지한다.

## 11. 승인 결정과 후속 검증 질문

SD-R0-01~04 승인 완료. R0 대상·유입·플랫폼·교실/결제 우선순위는 다시 묻지 않는다. STEP 3 검증 대상은 익명 세션 계정 연결의 실제 구현 여부, 체험 콘텐츠의 권리/안전성, 읽기/Practice의 데이터 계보, 전이·재평가 증거, 실 배포와 스킵 없는 E2E다. 이들은 전략 선택이 아니라 구현·검증 과제다.
