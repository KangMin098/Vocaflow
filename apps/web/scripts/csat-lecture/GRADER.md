# 강의 대본 심사 지침 — 독립 심사관용

> 이 파일은 서브에이전트 심사관에게 그대로 전달된다. 너는 대본을 쓰지 않았다. 부풀린 점수는 쓸모없는 것보다
> 나쁘다 — 여기서 통과한 대본이 그대로 학습자에게 소리로 나간다.

## 읽을 것 (전부)

- 문항·분석·지문: `scripts/csat/lecture-drain/chunk-<이름>.json` (한 줄 JSON)
  - `source.sentences` — 지문을 문장으로 자른 것. `k` 는 0부터, 화면 막대 번호는 **k+1**
  - `source.choices` · `answer` · `analysis`(우리 분석 — **틀린 곳이 있을 수 있다. 지문에 대고 판단하라**)
  - 알려진 데이터 흠: 선지 문자열 끝에 깨진 글자가 붙은 경우 · 빈칸 표시가 빠진 경우 — 무시한다
- 대본: `scripts/csat/lecture-drain/chunk-<이름>.out.graded.json` (**이 스냅숏만** 본다. `.out.json` 이나 `*.grade*.json` 은 열지 않는다)
  - 큐 = `{ r 역할, t 화면에서 빛나는 곳, s 말하는 조각 }`. `t` 가 `sentence:k` 면 막대 k(말로는 k+1번째)
  - 문자열 조각은 한국어, `{en}` 은 영어. 숫자는 일부러 한글이다(「일 번」 = ①, 「에이 단락」 = (A))
  - 「여기 N번째 문장」은 그 막대가 켜졌다는 뜻이다(이 일치는 기계가 이미 검사했다)

## 매길 것 (문항마다 80점)

| 키 | 만점 | 만점의 뜻 |
|---|---|---|
| `why` | 20 | 근거가 **어디**(맞는 문장·단락)이고 **왜** 정답이 되는지(논리 관계)를 말한다. 지문에 대고 확인하라 |
| `eliminate` | 20 | 오답마다 제 큐가 있고, **결정적**이고 정확한 배제 근거를 **자리와 함께** 댄다. 보조 근거만 대거나, 틀린 근거, 그 자리가 주장을 받쳐 주지 못하면 깎는다 |
| `trap` | 15 | 함정 이름 + 미끄러지는 **정확한 자리(문장 번호)** + 왜 끌리는지 + 할 행동 |
| `strategy` | 15 | 지문을 읽기 **전에** 할 일, 이 문항·이 유형에 맞게. 정리의 첫 십 초 행동과 일치 |
| `formula` | 10 | 다음 같은 유형에 옮길 한 줄 규칙 + 첫 십 초에 할 일 |

형식·길이·낭독 표기는 기계가 이미 쟀다 — 보지 않는다.

**사실 확인**: 지문이나 정답과 어긋나는 말, 틀린 문장 번호(N = k+1), 틀린 단락 글자(순서 문항 — `(A)`·`(B)`·`(C)` 가 단락 첫 문장에 붙어 있다), 오답 배열을 잘못 읽은 것(`source.choices`), 과장된 단정 → 해당 항목에서 깎고 `fixes` 에 적고 **`factual_error: true`**. 사실 오류가 하나라도 있으면 그 대본은 점수와 상관없이 떨어진다.

**`factual_error` 는 사소해 보여도 켠다** — 틀린 문장 번호 하나, 「바로 뒤」인데 실은 같은 문장, 개념을 거꾸로 말한 것(「이용한다」를 「만든다」로) 모두 해당한다. 「틀린 것은 아니지만 어긋날 소지」라고 적을 것이라면 켠다. 켜진 대본은 고쳐서 다시 심사받는다 — 끄는 쪽이 학습자에게 틀린 자리를 가리키게 한다.

**보정**: 최상위 수능 강사가 자랑할 만한 대본 ≈ 72~80. 무난하지만 일반론 ≈ 60. 근거 오류·자리 오류는 크게 깎는다.

## 쓸 것

`scripts/csat/lecture-drain/chunk-<이름>.grade.json` 하나(UTF-8, 올바른 JSON):

```json
{
  "grader": "independent-subagent",
  "gradedAt": "<ISO 시각>",
  "grades": {
    "<문항 id>": {
      "why": 0, "eliminate": 0, "trap": 0, "strategy": 0, "formula": 0,
      "factual_error": false,
      "notes": "한국어 1~3문장",
      "fixes": [ { "cue": "c3", "what": "한국어: 무엇이 틀렸고 어떻게 고칠지" } ]
    }
  }
}
```

큐 id 는 강의 안에서 순서대로 `c1`, `c2`, … 이다. 대본이 있는 **모든 문항**을 넣는다.
`notes`·`fixes` 에 지문 영어를 **7단어 넘게 연달아 옮기지 않는다**.
여러 청크를 맡았으면 청크마다 따로 쓴다.

끝나면 청크별로 짧게 보고한다: 문항 수 · 평균(/80) · 80점 만점 기준 60 미만 문항 · `factual_error` 문항과 큐.
